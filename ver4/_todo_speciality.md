# 특성 개편 TODO

## 방향

- 특성은 숫자 보정이 아니라 **규칙**을 바꾼다. 확정(반드시 치명타·반드시 성공), 행동 경제, 범위 확장, 변환, 권한 부여를 우선한다.
- 퍼센트 보정은 장비·병종·레벨에 맡긴다.
- **반격은 특수한 상황에서만 일어난다.** "반격받지 않음" 계열 특성은 만들지 않는다.
- 이동을 막는 효과, 재이동, 은신, 지형 생성처럼 코드를 복잡하게 하고 버그를 만들기 쉬운 효과는 넣지 않는다.

## 유지 (현행 그대로)

국사무쌍, 부호, 백출, 필살, 찔러공격, 독공, 심공, 침착, 위압, 부관, 반격술

무쌍술 (구 분기술): 물리 병법 '분기'의 이름을 '무쌍'으로 바꾼다. 효과는 그대로(공격범위 안의 모든 적 공격).

## 공통 규칙

### 판정 충돌

- **공격 특성과 방어 특성이 충돌하면 방어가 우선한다.**
  - 반드시 명중·반드시 성공 vs 명중 0·면역 → 방어 우선
  - 허실(책략 100% 성공) vs 독내성 등 면역 → 면역 우선. 허실과 간파는 지력 비교라 동시에 발동하지 않는다.
- **피해 처리 순서:** 치명타 판정 → 방어력(버프 포함) → 철벽 감소

### 2회 공격

- 2회 공격은 **2회 공격 확률**(design.md 2부 2.3, 순발 기반)로 판정한다. 연전·신장은 이 확률을 100%로 만든다. 확률 100%를 주는 특성이 여럿이어도 2회다.
- **판정 시점이 첫 타격 전으로 바뀐다.** 첫 타격의 명중·빗나감과 상관없이 두 번째 타격을 시도한다. 첫 타격으로 대상을 격파하면 두 번째 타격은 없다.
- 두 번째 타격도 명중·치명타를 따로 판정한다. 독공·찔러공격·심공 등 공격 특성도 모두 적용된다.
- 상대의 반격은 2회 공격이 모두 끝난 뒤에 한다.
- **반격도 그 부대의 2회 공격 확률로 다시 판정한다.** 2회 반격이 될 수 있다.
- 협동 공격도 2회 공격을 판정한다.

현행 규칙과 다른 점: design.md는 "모든 첫 타격이 끝난 뒤 대상마다 2회 공격 판정, 반격 제외, 반격은 대상마다 한 번만"이다. 판정 시점과 반격 2회를 이 문서대로 바꾼다.

### 추가로 일어난 공격

- 반격·협동·응사·반계로 생긴 공격은 다시 반격·협동·응사·반계를 일으키지 않는다.
- 협동은 아군이 직접 한 물리 공격에만 반응한다.

### 버프·디버프 수치

- 부대 능력치 버프는 **+20%**, 디버프는 **-20%**로 통일한다. 이동력·사거리처럼 고정치를 더하는 버프는 예외다.
- 특성이 자동으로 거는 버프(수성·신속·원시)의 유효기간은 **2턴**이다. 매 턴 다시 걸려 갱신된다.
- 버프는 한 번 걸리면 유효기간 동안 유지된다. 버프를 건 조건(예: 성)을 벗어나도 꺼지지 않는다.
- 신속 버프(이동력 +2)와 질풍(+2)은 서로 다른 출처라 함께 가지면 +4다.

### 배율

- 배율끼리는 **더한다.** 예: +100%, +100%, +100% → +300% (회복량 4배)

## 확정 효과

### 물리 공격

| 특성 | 효과 |
|---|---|
| 용장 | 자신보다 무력이 낮은 대상을 공격하면 반드시 치명타 |
| 투신 | 자신보다 무력이 낮은 상대에게 공격받고 그 상대가 자신의 공격범위 안에 있으면, 반격 버프가 없어도 반드시 반격. 피해 계수 0.7 × 2 = 1.4 |
| 연전 | 2회 공격 확률 100% (두 번째 타격 시도가 반드시 일어남. 명중은 따로 판정) |
| 협동 | 자기 진영 차례에, 자신의 공격범위 안의 적이 아군의 물리 공격을 받으면 같은 대상을 50% 피해로 공격. 공격 행동을 소모하지 않음 |
| 기습 | 자신이 숲에 있으면 반드시 치명타 |
| 신장 | 자신보다 무력이 낮은 대상을 공격하면 반드시 치명타 + 2회 공격 확률 100% |
| 난사 | 난사 공격 가능 (현행 trait_013 유지) |
| 사방격 (신규) | 물리 공격 범위가 십자가 됨. 주변 칸의 적은 75% 피해 |
| 팔방격 (신규) | 물리 공격 범위가 3×3이 됨. 주변 칸의 적은 75% 피해 |
| 공성 | 대상의 지형 방어 보정 무시 |
| 회심 | 일반 공격과 공격 책략이 치명타 확률과 상관없이 반드시 치명타. **아이템 '옥쇄' 전용** (필살·심모의 상위호환) |

- 사방격·팔방격: 적만 맞는다. 두 번째 타격과 반격·협동·응사에도 적용되고, 주변 칸 타격에도 독공·심공·필살 등 공격 특성이 적용된다. 둘 다 있으면 팔방격만 적용한다. 범위는 겹쳐도 넓어지지 않는다(발석거 십자 + 사방격 = 십자, 발석거 + 팔방격 = 3×3).
- 일기토는 스토리 이벤트로만 일어난다. 자신의 커맨드, 특성으로 일기토를 일으키지 않는다. 일기토 대상과 근접하게 이동 후 행동을 종료하면 발생한다.
- 협동: 조건을 만족하는 협동 장수가 여럿이면 모두 협동한다. 적 차례에는 아군이 협동하지 않는다. 적도 협동 특성이 있으면 적 차례에 협동한다. 책략 공격에는 발동하지 않는다.

### 방어

| 특성 | 효과 |
|---|---|
| 철벽 | 한 번의 피격에서 자신의 최대 병력 10%를 넘는 피해는 절반만 받음 |
| 금강 | 상대 공격이 치명타로 판정되면 그 타격을 무조건 막음(방어 성공). 반드시 치명타인 공격에는 오히려 강함 |
| 간접공격면역 (구 방패) | 적의 원거리 공격이 자신에게 명중할 확률 0 (= 방어 성공) |
| 응사 (구 원거리방어) | 적의 물리 공격이 빗나가면, 자신의 공격범위와 상관없이 공격자를 타격. 피해 계수 0.7 |
| 반계 (구 책략방어) | 공격 책략을 받으면 같은 공격 책략을 시전자에게 되돌림 |
| 수성 (구 불굴) | 성에 있으면 매 턴 방어력 +20% 버프를 자신에게 걺 |

- 철벽 예: 최대 병력 1000, 받는 피해 250 → 기준 100. 100 + (150 × 0.5) = 175를 받는다.
- 간접공격면역·금강으로 막은 공격은 방어 성공(빗나감)이다. 응사가 발동하고, 위압(빗나가도 50% 피해)도 적용된다.
- 간접공격면역 + 응사: 원거리로 공격해 온 적은 항상 빗나가고 항상 응사를 맞는다.
- 반계: 반계 부대가 적의 책략을 간파해 되받아치는 것이다. 명중·피해는 **반계 부대의 능력치**로 계산한다. 병법치를 소모하지 않고 사거리와 상관없다. 연환으로 추가로 맞은 대상도 반계한다.

### 책략

| 특성 | 효과 |
|---|---|
| 귀모 | 책략 사거리 +3 |
| 허실 | 자신보다 지력이 낮은 부대에게 모든 책략 100% 성공 |
| 심모 (신규) | 책략이 성공하면 반드시 치명타 |
| 연환 | 공격 책략이면, 맞은 대상에 인접한 대상 중 무작위 1명에게 같은 책략을 한 번 더 적용. 추가 타격에도 허실·심모 적용 |
| 팔진도 (신규) | 병법 '팔진도' 사용 가능. 아군 1명에게 팔진도 버프(2턴): 그 아군의 1×1 범위 책략(공격·회복·버프·디버프·방해 등 정신력 계통)이 3×3 범위가 됨. 물리 병법과 팔진도 자신에는 적용 안 됨. 병법치는 밸런싱으로 정함 |
| 화신 | 화염계 책략 100% 성공 + 100% 치명타 |

책략 사용 권한은 아래 "책략 계통 특성(상·중·하)"이 준다.

### 상태 방어

| 특성 | 효과 |
|---|---|
| 간파 | 자신의 지력이 시전자보다 높으면 적이 거는 모든 책략을 100% 방어 (방어 성공). 막은 공격 책략에도 반계가 발동 |
| 군율 | 부정적인 상태이상에 걸리지 않음 |

### 지원·성장

| 특성 | 효과 |
|---|---|
| 의술 | 성·회복 책략·도구 등 모든 병력 회복의 회복량 +100% |
| 인덕 | 자기 진영 차례 시작에 8방향 인접 아군의 병력을 최대치의 10% 회복 |
| 용인술 (신규) | 부관 능력치를 매력 기반 반영 공식 대신 항상 110%로 부대 능력치에 반영 |
| 보급 | 자신이 쓴 도구가 인접 아군 하나에게도 적용 |
| 집중 | 병법치 회복량 2배 |
| 고육 (구 명경, 이름 제안) | 병법치가 모자라면, 모자란 병법치의 10배만큼 병력으로 대신 지불. 병력이 모자라면 사용 불가 |
| 양생 | 자기 진영 차례 시작에 병력 최대치의 10% 회복 (정병 통합) |

| 호운 | 전투 중 처음 전투불능이 될 때 1회 병력 1로 버팀 |

## 책략 계통 특성 (단계별)

책략을 계통별 **병종 특성**으로 준다. 상위 단계는 하위 단계의 책략을 모두 포함한다. 같은 계통을 여러 출처에서 받으면 가장 높은 단계만 적용한다. 책략 이름은 조조전 책략을 최대한 따른다.

| 계통 | 특성 | 단계 |
|---|---|---|
| 화염계 | 화계 | 하·중·상 |
| 수계 | 수계 | 하·중·상 |
| 토지계 | 지계 | 하·중·상 |
| 회복계 | 구휼 | 하·중·상 |
| 버프계 | 독려 | 하·상 |
| 디버프계 | 견제 | 하·상 |
| 방해계 (독 포함) | 계략 | 하·상 |

독은 방해계에 넣는다. 독계 공격 책략(독룡 등)과 독술 특성은 삭제한다.

### 공통

- 범위 용어: **단일**(대상 1칸), **십자**(대상 + 상하좌우, 5칸), **3×3**(대상 + 8방향, 9칸). '4방'이라는 말은 쓰지 않는다.
- 장수·장비도 계통 특성을 줄 수 있지만 **(하)까지만** 준다. 중·상은 병종 전용이다.
- **모든 병법에 필요 레벨이 있다.** 계통 특성이 있어도 필요 레벨 미만인 책략은 쓸 수 없다.
- **학습도 필요 레벨 이상이어야 한다.** 특성치(경험치)를 소모하는 것과 별도로, 필요 레벨을 넘어야 배울 수 있다. 현행 "권장 Lv는 자격 제한이 아니다" 규칙을 바꾼다.
- 삭제: 풍계(풍진·회오리·천풍), 뇌계(뇌격·연뇌), 독계 공격(독룡), 화진, 화상(병법), 설파, 이간, 환술, 정신통일, 명상, 수호, 책략장벽, 호풍, 기우, 기마사, 그리고 현행 버프 병법(격려·분발·방진·철갑·대분발·대방진·정신강화·전이). 풍계·독술 특성도 삭제.

### 현재 문관 계열 (참고)

design.md 성장 트리는 `사마 → 참모 → 군사`(공격 책략)와 `사마 → 방술사 → 선술사`(버프·회복)다. 현재 데이터(`campaign.json`)에는 사마·참모·군사만 있고 방술사·선술사는 없다. 병법을 병종에 직접 나열한다.

| 병종 | 현재 데이터의 병법 | 현재 학습 특성 |
|---|---|---|
| 사마 | 초열·탁류·소회복·격려 | 계략·의술·집중·격려 |
| 참모 | 초열·탁류·혼란·봉책 | 없음 |
| 군사 | 초열·탁류·혼란·봉책 | 연환 |
