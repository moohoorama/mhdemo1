# ver4 GUI 개편 설계 (조조전식 UI)

개선표 1–19번을 구현한다. 20번(키보드·패드 커서 조작)은 제외한다.

## 원칙

- 규칙·저장 형식·콘텐츠는 바꾸지 않는다. 콘텐츠 해시가 바뀌면 기존 저장을 못 읽으므로
  대사 화자도 GUI에서 `이름:` 구간을 나눠 처리한다.
- 코어에는 화면용 읽기 전용 조회만 더한다(`OfficerStats`, `CounterDamage`, `Threat`).
- 세션에 보내는 명령은 그대로 `move`/`attack`/`wait`다. CLI·시뮬레이션 결과는 같다.

## 행동 흐름 (1–4)

```
유닛 클릭 → 이동 범위(파랑) → 칸 클릭 → [임시 이동: 샌드박스 엔진에 move 적용, 걷기 재생]
  → 유닛 옆 행동 메뉴(공격·병법▸·도구▸·일기토·학습▸·대기)
     ├ 우클릭/Esc: 임시 이동 취소, 원위치
     └ 공격/병법/도구 → 사거리(빨강)·대상 표시 → 대상에 마우스: 예측 창 → 클릭: 확정
확정 = 세션에 move(있으면) → 행동 → wait(남은 행동이 없으면)
```

- 임시 이동은 `core.Restore(스냅샷)`으로 만든 샌드박스에만 적용한다. 메뉴의 합법 행동과
  예측은 샌드박스에서 계산한다. 취소하면 샌드박스를 버린다.
- 화면 동기화(`sync`)는 임시 이동 중인 유닛을 건너뛴다.
- 세션 요청은 `send`(기록·자동 저장)와 `request`(send + 재생)로 나눈다. move·wait는 화면에
  이미 보였거나 연출이 없으므로 `send`만 쓴다.

## 화면 배치 (5–8, 13–15)

- 맵이 1280×850 전체를 쓴다. 위: 상단 바(맵·턴·진영·승리/패배 조건·미행동 수·메뉴).
  오른쪽 위: 미니맵. 왼쪽 아래: 유닛 정보 카드와 지형 창. 오른쪽 아래: 도구 버튼(부대 일람·위협
  범위·기록·자동 진행·진영 종료).
- 마우스가 올라간 칸에 커서 테두리를 그린다.
- 적을 선택하면 그 적의 위협 범위, `위협 범위` 버튼을 켜면 적 전체의 공격 범위를 겹쳐 그린다.
- 전투 시작 때 목표 창을 띄운다.

## 연출·창 (9–12, 16–19)

- 맵 이펙트: 화살(궁병), 화계·수계, 회복 빛, 버프 고리, 상태 이상 소용돌이, 베기.
- 레벨업 창: 재생이 끝난 뒤 순서대로 보여 주고, 능력치 증감과 경험치 바를 표시한다.
- 전투 기록: 이벤트를 한국어 문장으로 바꾸고, 화면 위쪽에 잠깐 띄운다. 기록 창에 50줄을 보관한다.
- 대사: 아래쪽 대화창 + 이름표 + 초상. 클릭·Enter·Space로 진행한다.
- 출전 준비: 출전 체크, 능력치, 장비 교체 시 능력치 증감 비교, 부관.
- 결과 창: 승리 시 부대별 획득 경험치·레벨, 보상 아이템, 최다 공훈. 패배 시 재도전·불러오기.
- 메뉴·저장: 한국어 제목, 슬롯마다 장·턴·저장 시각.
- 창 스킨: 코드로 그리는 9-slice 형태 프레임 하나를 모든 창·버튼에 쓴다.

## 파일

| 파일 | 내용 |
|---|---|
| `gui/game.go` | Game, 요청/재생, 입력 분배, 최상위 그리기 |
| `gui/skin.go` | 색, 창·버튼·바·글자 그리기 |
| `gui/command.go` | 행동 흐름 상태, 행동 메뉴, 대상 지정, 예측 창, 위협 범위 |
| `gui/hud.go` | 상단 바, 도구 버튼, 정보 카드, 지형 창, 미니맵, 메시지 |
| `gui/windows.go` | 메뉴, 저장/불러오기, 설정, 확인, 부대 일람, 기록, 레벨업, 목표, 결과 |
| `gui/scenario.go` | 대사, 선택지, 출전 준비, 장비·부관 |
| `gui/effects.go` | 맵 이펙트 |
| `gui/events.go` | 이벤트 → 한국어 문장 |
| `core/api.go` | 조회 3종 |

## 하지 않는 것

- 전투 컷인 화면, 상점, 배치 칸 선택: 코어 규칙이 없거나 별도 에셋이 필요하다.
- 턴 제한 표시: 규칙에 턴 제한이 없다.
