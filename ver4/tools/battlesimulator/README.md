# 전투 시뮬레이터

두 진영의 레벨·출전 장수·병종 수치·지형을 정해 놓고, 한 가지 지형으로 채운 16×12 맵에서
양쪽 모두 AI로 싸우게 한다. 화면으로 한 판씩 보거나, 화면 없이 여러 판을 돌려 승률을 본다.
규칙은 게임 코어(`internal/core`), 설정과 맵 구성은 `internal/skirmish`, 화면은 게임 전장(`internal/gui`) 그대로다.

```sh
cd ver4
go run ./tools/battlesimulator                       # 설정 창 → 전투 (battle.json을 불러옴)
go run ./tools/battlesimulator -n 200                # 화면 없이 200판: 승률·평균 턴·장수별 평균 피해·퇴각률
go run ./tools/battlesimulator -config my.json -seed 7
```

## 설정 창

처음에 설정 창이 뜬다. 탭 세 개:

- **진영 · 전장**: 지형(초원·황무지·성내·숲), 배속(×1·×2·×4·×8), 최대 턴, 시드, 진영별 기본 레벨과 장수 목록.
  장수 이름을 누르면 장수를 고르고, 레벨("기본"은 진영 레벨을 따름), 병종(◀ ▶)을 바꾼다.
  오른쪽에 그 설정의 공격·방어·순발·사기·병력이 바로 계산되어 나온다. 진영당 10명까지.
- **병종 수치**: 병종별 병과보정치(공격·방어·정신·순발·사기·병력), 병력계수, 이동, 사거리. 금색은 출전 중인 병종.
- **지형 수치**: 계통별·지형별 계수와 이동 비용(0은 들어갈 수 없음).

숫자는 클릭 +1, 우클릭 −1, 휠, Shift를 누르면 ×10이다. 출전할 수 없는 설정(예: 들어갈 수 없는 지형)이면
아래에 이유가 뜨고 "전투 시작"이 꺼진다. "설정 저장"은 `-config` 파일(기본 `battle.json`)에 쓴다.
병종·지형 수치는 캠페인 값과 달라진 것만 저장된다.

전투 중: F 배속, L 전투 기록, U 부대 일람, 휠 확대, 우클릭 드래그 이동. 결과 창에서 "다시"(R, 다음 시드),
"설정"(S, 설정 창으로), "종료".

## 설정 (`battle.json`)

| 키 | 뜻 |
|---|---|
| `Terrain` | `초원`·`황무지`·`성내`·`숲` (`maps.json`) |
| `Seed`, `MaxRounds`, `Speed` | 첫 시드, 이 턴을 넘기면 무승부, 화면 배속 (기본 1, 30, 1) |
| `Ally`, `Enemy` | `Level`(진영 기본 레벨)과 `Officers`. 장수는 `"관우"` 또는 `{"Officer": "관우", "Level": 12, "Class": "중기병"}` |
| `Classes` | `campaign.json`의 `Classes`를 필드 단위로 덮어씀. 예: `{"경기병": {"Bonus": [16, 8, 4, 9, 8, 16], "HPFactor": 3}}` |
| `Terrains` | 병과별 지형 계수·이동 비용을 덮어씀. 예: `{"기병": {"f": {"Factor": 0.8, "Cost": 3}}}` |

- `Bonus` 순서는 공격·방어·정신·순발·사기·병력이다.
- 같은 장수를 양쪽에 세울 수 있다. 장수마다 `A1·관우`, `E1·관우`처럼 진영별 사본을 만든다.
- 아군은 서쪽 두 열, 적군은 동쪽 두 열에 가운데 행부터 선다(진영당 최대 24명).
- 전멸전이다(`Stage.Goal = "rout"`). 경험치·레벨업·아이템이 없고, 적 AI도 멀리서 기다리지 않고 다가온다.
- 숲(`f`)은 캠페인 규칙에서 모든 병과가 들어갈 수 없는 칸이다. 숲에서 싸우려면 `Terrains`로 `Cost`를 주어야 한다
  (기본 `battle.json`에 들어 있다).

## 맵

`assets/content/simulator-maps.json`이 규칙 타일(`Tiles`)과 그림 타일(`Art`, 없으면 `Tiles`)을 정한다. 숲은 규칙상 전부 숲이지만
유닛이 가려지지 않도록 나무를 듬성듬성 그린다. 맵 그림은 다른 전투 맵처럼 `tools/build_assets.py`가
`assets/graphics/maps/SIM_*.json`으로 만든다. 맵을 바꾸면 다시 돌린다.
