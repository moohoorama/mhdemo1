# 장비 공격(attack) 작업 노트

대상: `grid/attack/<dir>-<n>.txt` 8방향 × 4프레임. 기본형 경기병 찌르기의 몸·말 자세, 프레임 시간, 효과 배치는 그대로 두었다.
머리·수염·투구·전포·띠는 대기 0프레임(모델 시트)에서 정수 이동으로 옮겼다. 사모는 손으로 그렸다.

## 공통

- **머리**: 프레임마다 기본형 투구 위치로 오프셋을 재서(예: SW 0 (+1,−1), SW 2 (−6,+3), W 1 (+7,0)) 모델 시트 머리·수염을 옮겼다.
  기본형 공격 머리가 대기보다 1px 넓은 곳(S 계열 투구 왼쪽, 정면 계열 볼 1열)은 그 열을 `m`/`o`/`d`로 채웠다.
- **몸**: 기본형의 진영색3 위주 몸을 모델 시트처럼 진영색2 바탕 + 그림자 쪽 `l`로 다시 칠했다. 어깨·가슴의 철(`b c`)은 흑갑 `m n o`
  또는 전포로 바꿨고 몸에 철은 없다. 장화 철은 `n o`. 허리띠 `p q…` + 늘어진 끝 `r`.
- **손**: 기본형 말 태그 손(`v w x A`)은 모두 피부 `d e`로 다시 칠했다. 자루는 모두 테마 C(`t`, 꼬리 `u`)이고 말 태그 자루는 남기지 않았다.
- **사모 날**: 날밑 고리 `c` + 날 7칸(k7…k1) + 날끝 외곽선. 방향에 맞춰 세 가지 꼴을 썼다.
  - 가로(E·W, SW 0·1, SE 0·1, NE 0·1, E 0·1): 대기 템플릿을 90° 돌린 꼴(굽이 위아래 1행, 2열마다).
  - 2:1 대각(SW 2·3, SE 2·3, NE 2·3, NW 0~3): "계단 2칸 → 1px 옆으로 → 계단 2칸" 꼴. SW 2를 기준으로 좌우 대칭/180° 회전해 같은 모양을 재사용하고,
    빛은 늘 위·왼쪽 가장자리 `a`가 되도록 다시 칠했다.
  - 원근(S 0~3, N 0~3): 카메라 쪽/먼 쪽으로 찌르므로 날을 4행(넓은 행 → 오른쪽 → 왼쪽 → 끝)으로 줄였다(굽이 1번).
  - 붉은 술 `p`/`q`는 고리 바로 뒤, 자루 아래쪽에 2px.
- **효과**: 쐐기·고리는 기본형 칸을 정수 이동만 해서 날끝 앞(1px 이상 떨어짐)으로 옮겼다. 셀 가장자리 1px을 남겼다.
  기본형이 쐐기·고리 안에 철/테마 C로 그려 둔 칸(S 3, N 3, SE 2, E 2의 `a b E`, `c t u`)은 효과 `4`/`E`/`1`로 바꾸거나 지웠다
  (profile의 "S 3·N 3 테마 C 잔픽셀" 정리 포함). 효과가 말 위를 지나는 칸(S 3 고리 오른쪽·아래)은 말을 뚫지 않게 비웠다.

## 의도된 가려짐·끊김

- 자루는 몸·머리 뒤를 지나며 두 토막으로 보인다(SW 0·1 손 뒤, W 0·1 얼굴 뒤, E 0 팔 뒤, NE·NW 몸 뒤, N 어깨·팔 뒤). 날은 늘 한 번만 찍힌다.
- SE 1: profile 5절 "머리·수염과 겹치면 날이 머리 뒤로 가고 끝 2–3px만 보여도 된다"를 따라 날 끝 5칸(굽이 1번)만 보인다.
- S 2·3: 허리띠는 말 머리에 가려 보이지 않는다(기본형 허리가 말 머리 뒤).
- 정면 계열(SE 0·S 0)의 손이 수염 가시와 외곽선 없이 맞닿는 칸이 있다(모델 시트 E와 같은 처리).

## 검수 1 반영 (review-attack-1.md)

- 반드시: 몸의 철 잔픽셀 정리. NE 0 장화 (53,36)`n` (54,36)(53,37)`o`, NE 1 (52–53,36) `n o`, W 0 (53,38)`o`, NW 2 무릎 (44,32)`n`,
  E 3 투구 뒷자락 (49,22)`o`. 전 프레임의 철 칸을 다시 나열해 날·날밑 고리 밖에 철이 없음을 확인했고 iron recolor 시트에서도 날만 바뀐다.
- 2:1 대각 날(SW·SE·NE·NW 2·3): 굽이를 2열 마디로 바꿨다. SW 2 기준 (25,33)`a`·(25,34)`b`, (25,32)(25,35) 외곽선, 날끝 (21,35)로 1행 올림
  (빈 (21,36)은 외곽선). SW 3은 (+5,−2) 이동, SE 2·3은 좌우 대칭, NE 2·3은 180° 회전, NW 2·3은 상하 대칭으로 같은 칸을 옮겼다.
  NE·NW는 회전/대칭 뒤 날끝이 그림자 쪽으로 처져 "ʌ"로 보여서 날끝을 빛 쪽(위) 1행으로 올렸다(NE 2 (80,15), NE 3 (75,17), NW 2 (28,11), NW 3 (33,13)).
- NE 0·1 날: 날끝 쪽을 세로 2칸 마디(NE 0 (62–63,18–19), NE 1 (57–58,18–19))와 끝 1칸((63,17)/(58,17))으로 바꿔 아래 마디(60–61,21–22)와 함께 꺾임 2개를 뒀다.
  날이 대각으로 8행이 됐다(45° 대각이라 길이는 기존과 비슷).
- S 2 고리: 오른쪽 반 불투명 `E`를 반투명 `5`로 바꿨다. 말 앞다리(46–49열) 위를 지나는 칸은 반투명으로 바꾸면 다리가 뚫리므로 비우고 다리를 살렸다
  (고리가 다리 뒤로 지나 보임).
- 외곽선 구멍: NE 2 (72,17), NE 3 (67,19), E 2 (78,29), SE 0 (57,28), NW 2 (36,13) → `#`.

- SE 2 앞 주먹: (62,29)(62,30) `e`, (63,30) `d`로 넓혀 주먹이 자루(62–63,31)에 닿게 했다. (63,29)(64,29)(64,30)은 외곽선 유지.

## 남은 의문

- NE·NW 2·3은 물결이 빛 쪽 가장자리(위)에 있다(회전·대칭 결과). 1배에서는 물결로 읽힌다.
- W 2·E 2는 쐐기가 셀 가장자리에 붙어 있어 사모를 2px 늘리지 못하고 기본형 날끝 위치를 썼다(profile 허용).
- SE 0은 수염을 가리지 않으려고 창을 기본형보다 2행 낮췄고 붉은 술은 생략했다(띠와 겹침).
- N 2는 손(57–58,17)을 머리 옆에 새로 그렸다(기본형은 팔이 자루를 가림).
