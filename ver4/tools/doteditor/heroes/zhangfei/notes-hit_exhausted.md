# 장비 피격·탈진 작업 노트

시트: `preview/sheet-idle_hit_exhausted-N_NE_E_SE_S_SW_W_NW.png` (`render.py sheet zhangfei --anims idle,hit,exhausted --zoom 4`).
recolor: `preview/recolor-*-hit_exhausted.png`.

## 작업 방법과 도구

- 픽셀은 손으로 정했다. 보조 스크립트(`scratchpad/hitex-zhangfei/`)는 세 가지다.
  `put.py`는 내가 적은 문자열을 그대로 행에 쓴다. `blk.py`는 내가 고른 사각형을 정수만큼 옮겨 복사한다(모델 시트의 머리·수염·사모 덩어리, 기본형 말 머리).
  `side.py`·`check.py`는 읽기만 한다(나란히 출력, 철 픽셀 수·막힌 구멍 검사).
- **merge.py 사용 기록**: 처음에 피격 0·1프레임 16장을 `merge.py`로 시작했다. 기본형 대기0과 기본형 해당 프레임이 같은 칸은 모델 시트 픽셀,
  다른 칸은 기본형 픽셀을 자동으로 골랐다. 오케스트레이터 지적(그림을 자동으로 고르는 스크립트는 금지)을 받고 바로 중단했다.
  그 16장은 모두 렌더해서 보고 손으로 다시 맞췄다. 피격 0은 모델 대기0과 픽셀이 같음을 비교로 확인했다.
  피격 1의 8장은 모델 대기0 행을 통째로 다시 깔고, 기본형 피격1의 말 머리 구간만 블록으로 옮긴 뒤 경계를 손으로 고쳤다.
  그래서 merge가 만든 픽셀은 남아 있지 않다. 이후 프레임에는 merge.py를 쓰지 않았다.

## 피격 (hit)

- 0 = 모델 대기 0 그대로.
- 1: 기수는 모델 대기0이고, 말 머리만 기본형 피격1을 따른다(대부분 1px 들림). S는 기본형처럼 기수 전체(사모 포함)를 (0,−1) 옮겼다.
  N은 기본형 차이가 명암뿐이라 전포 명암 3px만 바꿔 0과 구분했다.
- 2(충격)·3(회복): 머리·수염·투구 덩어리를 기본형 머리 이동량만큼 정수 이동했다. 사모·손은 한 덩어리로 옮겼고, 몸통은 기본형 자세에 맞춰 모델 색으로 다시 칠했다.

  | 방향 | 2 머리 / 사모 / 몸통 | 3 머리 / 사모 / 몸통 |
  |---|---|---|
  | SW | (+3,−2) / (+2,0) / 하체 (0,−1) | (+1,−1) / (+1,0) / 하체 그대로 |
  | S | 기수 전체 (0,−3), 다리를 늘림 | 피격1과 같은 (0,−1) |
  | SE | (−3,−2) / (−3,−2) / 손~몸통은 다시 그림 | (−1,−1) / (−1,−1) / 하체 그대로 |
  | E | (−3,−1) / (−2,−1) / 몸통 (−2,−1), 다리 (0,−1) | 상체·사모 (−1,0), 다리 그대로 |
  | W | (+3,−1) / (+2,−1) / 몸통 (+2,−1), 다리 (0,−1) | 상체·사모 (+1,0) |
  | N | 상체·사모 (0,+1), 하체 (0,−1) | 상체·사모 (0,+1) |
  | NE | (−3,0) / (−2,0) / 몸통·다리 (−1,0) | 머리 (−1,0), 사모·몸통 그대로 |
  | NW | 머리+사모 (+3,0) / 몸통 (+1,0) / 하체 (0,−1) | 머리+사모 (+1,0) |

- 표정(2·3): 공통 규칙 `hurt`로 그렸다. 눈 두 칸은 왼쪽 피부색, 오른쪽 아래 대각 칸은 외곽선이다.
  입은 콧수염 행에 외곽선을 둔다(S는 2px, 그 외 1px. 옆모습은 눈 열 또는 그 앞 1열).
  기본형의 테마 B3 입 `r`은 얼굴과 함께 모두 없어졌다. 남은 `r`은 모델 시트의 띠 끝뿐이다.
- 말 머리·몸 자세는 기본형 각 프레임을 따랐다.

## 탈진 (exhausted)

- 머리는 기본형처럼 숙인다. 머리 이동량은 SW (−5,+2), S (0,+3), SE (+5,+2), E (+7,0), W (−7,0), N (0,−3), NE (+5,−2), NW (−5,−2)이다.
  반쯤 감은 눈: 눈 윗칸은 피부2(`e`), 아랫칸은 외곽선이다. 입은 콧수염 행 외곽선 1px이다. 땀방울은 N 2프레임에만 있다(기본형과 같이 철1).
- **장팔사모를 앞으로 늘어뜨렸다**: 손(무릎 높이 `de` 2×2)에서 자루가 3열에 1행씩(끝은 2열) 내려가 손~고리가 약 9px이다(대기 자루 길이).
  끝에 **가로로 누운 날**을 둔다. 모델 날(7행 + 고리 + 술)을 90° 돌린 모양이다. 넓은 면, 굽이 3번(2열마다 1px), 위쪽 가장자리 철1, 아래 철3, 고리 철3 3px, 술 `p q` 2px이 늘어진다.
  모든 방향에서 같은 픽셀 모양이다(SE·E·N·NE·NW는 좌우만 뒤집음). 날은 말 머리·어깨 높이에 놓인다.
  사모를 두는 쪽: SW·S·W는 화면 왼쪽, SE·E·N·NE·NW는 오른쪽(관우와 같음).
- 프레임: 기본형 1·3에서 말 머리가 1px 숙여지는 방향(SW·S·SE·E·W·NE)은 사모와 손도 1px 내렸다. 3에서 머리가 더 숙여지는 방향(SW·SE, E·W는 1·3 모두)은 머리를 1px 더 옮겼다.
  2는 기본형도 0과 거의 같아 0을 그대로 쓰거나 명암 1–2px만 바꿨다(N 2는 땀방울).
- 몸통은 기본형의 숙인 몸을 모델 색으로 다시 칠했다. 전포는 `j k l`, 붉은 띠는 `p q`, 장화는 `n o`이다.
  기본형의 말 태그 자루(`x A`)와 철 장화(`b c`)는 모두 없앴다.

## 의도된 것

- 탈진에서 날·자루가 말 머리/목 위를 지나며 말 픽셀을 덮는다(무기가 말 앞).
- 탈진 SW·W: 술과 말 목 사이에 막힌 배경 칸 몇 개가 있다(SW (38–39,33–35), W (33–34,35)). 날·술이 말과 떨어져 있어서 생긴 틈이다.
- 탈진 S: 다리 사이 말 머리 위의 배경 칸은 기본형에 원래 있다.
- 피격·탈진 NE·NW 다리 사이 막힌 칸, E 대기 계열 (56,27–28)은 모델·기본형에 원래 있다.
- 등 계열(N·NE·NW) 탈진에서도 사모 손을 몸 오른쪽에 보이게 두었다(관우와 같음).

## 의문점

- 탈진 S는 사모가 화면 왼쪽으로 꽤 길게 나간다. 관우 검수에서도 선택 사항으로 남은 부분이라 같은 기울기를 썼다.
- 탈진 2 프레임은 기본형처럼 0과 거의 같다. 숨쉬기는 말 머리(1·3)로 드러난다.
- 피격 SE 2는 기본형처럼 말 갈기 `A`가 기수 가슴 앞을 지나 띠를 일부 가린다(말이 솟구침).
