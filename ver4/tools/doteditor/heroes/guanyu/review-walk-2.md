# 관우 walk 검수 2

판정: **통과**

좌표는 `NN|` 뒤 첫 글자를 x=0으로 센다(헤더 눈금). 검수 1의 x는 이 기준보다 3 컸다(작가가 바르게 옮겨 반영함).

본 것: `render.py sheet guanyu --anims walk --dirs SE|SW|S|N --zoom 8`(idle 0과 나란히), 해당 격자, 32프레임 태그 그룹별 픽셀 수.

## 검수 1 지적 확인

- SE 0–3: 가슴을 가르던 말 갈기·목 세로줄이 녹포로 메워졌다(f0·f1·f3 24–28행, f2 23–27행 x49–50). idle SE 덩어리와 같은 모양이고 소매–몸통 경계 외곽선 하나만 남았다.
  고삐 손이 4프레임 모두 `dd` + `e`(x55–56)로 같아서 깜빡이지 않는다(피부 픽셀 수 4프레임 모두 22). 허리띠 아래 말 목 1–2px은 괜찮다. → 해결
- SW 0: 무기·손·소매가 f1과 같다(무기 (−1,0)). 25행 소매가 이어지고, 고삐 손 (49,28) `d`, (50,28) `e`가 있으며, 가슴의 말 피부 픽셀과 (49,29) `A`가 없어졌다. → 해결
- S 0·1: 허리띠 오른끝 `kkkikddo`(x53–55 `ddo`)로 고삐 손이 f2·f3과 같아졌다(피부 23으로 4프레임 일정). 아래 `v` 1px은 외곽선이 되었다. → 해결
- N 0·1·3: 허리띠가 x54에서 끝나고 `##q#`로 자루가 idle·f2처럼 허리띠 행에서 보인다. 아래 토막과 한 직선(x57)이다. → 해결

## 퇴행 확인

- 이번에 바뀐 파일은 SE 0–3, SW 0, S 0·1, N 0·1·3뿐이다. NE·E·W·NW와 나머지 프레임은 검수 1 때와 태그별 픽셀 수가 같다.
- 32프레임 모두 철 22·테마C·털 수가 일정하다. 날·금고리·수염이 잘리거나 두 번 찍힌 곳이 없다. faction은 허리띠 1행과 정면 계열 깃 1px뿐이고, themeA는 두건·녹포 한 덩어리로 일관된다.
