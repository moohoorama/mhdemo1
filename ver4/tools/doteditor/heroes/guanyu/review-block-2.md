# 관우 block 검수 2

판정: **통과** (반드시 0, 권장 0)

좌표: x는 `NN|` 다음 첫 글자를 0으로 센 열, y는 행.

## 검수 1 지적 반영 확인

- block/NW/1 검은 덩어리: 해결. x46–49, 20–24행이 말 머리 색(`v w x A`)으로 채워졌고, 검정은 두건 왼쪽 외곽선 x51과
  볼 `d` (50,21) 둘레((49,21)(51,21)(50,20)(50,22))만 남았다. 볼은 f0 (48,20)을 (+2,+1) 옮긴 자리라 강체 이동과 맞다.
  f0→f1→f2→f3를 이어 보면 두건 왼쪽 검은 폭이 3–5px 안에서만 바뀌어 더 이상 깜빡이지 않는다.
- block/NW 꼬리: f0·f3 (45,26) `q` + (44,27) `r`, f1 (47,27) `q` + (46,28) `r`, f2 (52,29) `q` + (51,30) `r`. 양옆 외곽선이 있고
  (44,27)→(60,19)와 같은 직선(프레임 이동량만큼 평행이동) 위에 있다. 갈기가 어두워 여전히 눈에 잘 띄지는 않지만, 등 방향에서 양 끝만
  보이는 것은 의도한 것이고 필수 항목이 아니므로 더 고칠 것은 없다.

## 다른 부분이 그대로인지

- block 그리드 중 수정 시각이 바뀐 파일은 NW-0–3뿐이다. 다른 block 방향의 파일은 검수 1 이전 시각 그대로다.
- NW-0·1의 언월도(날 7행·금고리·술 (60,21)/(62,22)·손·자루)와 두건·몸통·허리띠는 검수 1 때 덤프와 같다. 바뀐 칸은 위의 두 항목뿐이다.
- NW-2·3의 날·금고리·술·손 위치도 프레임 이동량 (+7,+3)/(+1,0)과 맞고, 철 22px는 그대로다.
