# 궁병 대기 모델 시트 v1

작업본: `grid/idle/{N,NE,E,SE,S,SW,W,NW}-{0,1,2,3}.txt`.
8방향의 기본 외형은 01 천 두건 후보로 작성했다. 사용자 선택 전의 검토용 기본안이며 SW 후보 네 개는 `candidates/`에 보관한다.

## 형태

- 경보병의 발 접지·다리·얼굴 폭과 세로 2px 눈을 유지했다.
- 투구 술과 철 투구를 낮은 천 두건으로 바꾸고 몸 앞의 방패를 지웠다.
- 검이 있던 손 위치를 활 손잡이에 이어 그렸다. 활은 활채 2px, 시위 1px로 몸 밖에 충분히 드러난다.
- 진영색 옷과 갈색 가죽 허리띠를 사용했다. 장화와 정강이 보호구는 원본의 위치를 유지한다.
- 등 뒤의 가죽 화살통에는 세 개의 밝은 깃과 나무 화살대가 있다. N·NE·NW에서는 얼굴을 완전히 가린다.
- 왼쪽을 보는 SW/W/NW와 S는 왼쪽, 오른쪽을 보는 NE/E/SE와 N은 오른쪽에 활을 둔다.

## 태그

`jkl`: 두건과 천옷. `def`: 얼굴과 손. `mno`: 가죽 보호대·화살통·허리띠·장화.
`pqr`: 시위와 화살깃. `stu`: 활채와 화살대. `abc`: 작은 금속 보호구. 후보 04만 `ghi` 머리카락을 사용한다.

현재 승인용 모델 시트의 대기 4프레임은 동일 자세다. 검토 중인 외형이 프레임마다 달라지지 않게 고정했다. 사용자 승인 후 확정 외형을 기준으로 호흡·걷기·활 쏘기·막기·피격·탈진을 작성한다.

## 검토 파일

- SW 후보: `preview/candidates-SW.png`
- 대기 8방향: `preview/sheet-idle-N_NE_E_SE_S_SW_W_NW.png`
- 재질 확인: `preview/recolor-idle-{faction,themeA,themeB,themeC}.png`

입력 격자만 작성했으며 yaml import·게임 반영은 수행하지 않았다. 대기 승인 전에는 다른 동작 격자를 수정하지 않는다.
