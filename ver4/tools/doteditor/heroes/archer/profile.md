# 궁병 / archer

경보병 원본의 56×46 셀, 발 기준점 (28,38), 약 10px 머리와 2.5등신을 유지하는 일반 궁병이다. 기존 ver2 궁병 SW 시트와 unit3d의 archer 정의를 참고했다. 기존 궁병의 진영색 옷, 나무 활, 등 뒤 화살통을 유지하고 장수 장식이나 수염은 넣지 않는다.

| 부위 | 태그 | 표현 |
|---|---|---|
| 낮은 천 두건, 상의, 바지 | faction1–3 / j k l | 쇠 투구의 술을 없앤 둥근 두건, 진영색 짧은 옷 |
| 얼굴·손 | skin1–3 / d e f | 일반 병사의 얼굴, 세로 2px 눈, 수염 없음 |
| 허리띠·장화·팔 보호대·화살통 | themeA1–3 / m n o | 갈색 가죽 |
| 활 시위·화살 깃 | themeB1–3 / p q r | 밝은 삼베, 시위는 1px |
| 활·화살대 | themeC1–3 / s t u | 갈색 목재, 2px 굵기의 연속 곡선 |
| 남은 소형 보호구 | iron1–3 / a b c | 팔·정강이 작은 철 보호구 |

활은 가운데 손잡이와 위아래 휘어진 활채가 이어진 하나의 나무 무기다. 활채와 시위 사이의 빈 공간은 의도한 공간이며 활채 자체는 끊기지 않는다. 검과 방패는 없다. 화살통은 등에 메고 화살 깃 세 개가 위로 보인다. 대기는 활을 몸 앞에 낮게 들고 시위를 당기지 않는다. 공격은 화살 얹기 → 당기며 조준 → 발사 → 팔을 낮추며 회복의 4단계로 예정한다. 막기는 활을 들어 몸 앞을 보호한다.

| 방향 | 얼굴 | 활 | 화살통 |
|---|---|---|---|
| S | 정면, 두 눈 | 몸 왼편 앞 | 오른쪽 어깨 뒤 가장자리 |
| SW | 왼쪽 3/4, 두 눈 | 왼편에 전면 노출 | 오른쪽 뒤 |
| W | 왼쪽 옆, 한 눈 | 왼편 전면 | 등 오른쪽 |
| NW | 얼굴 안 보임 | 왼쪽 외곽, 팔 일부 가림 | 등 가운데 |
| N | 얼굴 안 보임 | 오른쪽 외곽 | 등 가운데 |
| NE | 얼굴 안 보임 | 오른쪽 외곽 | 등 왼쪽 |
| E | 오른쪽 옆, 한 눈 | 오른편 전면 | 등 왼쪽 |
| SE | 오른쪽 3/4, 두 눈 | 오른편 전면 | 왼쪽 뒤 |

대기 승인 전에는 다른 동작을 그리지 않는다. 첫 시트는 같은 자세의 고정 대기로 형태와 재질을 검토하며 호흡은 승인 후 필요한 경우 추가한다.
