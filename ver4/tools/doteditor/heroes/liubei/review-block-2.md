# 유비 막기(block) 검수 2

판정: **통과** (반드시 0, 권장 0)

검수 1의 권장 3건이 반영됐는지 다시 봤다. 본 것은 W·E·SW 시트(6배)와 격자 파일이다.

검수 1 이후에 바뀐 파일은 W-1·W-2·E-1·E-2·SW-0·SW-3 여섯 개뿐이다(파일 수정 시각으로 확인). 나머지 26프레임은 검수 1 때 그대로다.

## 반영 확인

- **block/W/1·2, block/E/1·2**: X 묶음이 1행 올라갔다.
  - 교차점이 턱 앞에 온다. W-1은 (22–23, 22), E-1은 (33–34, 22)이고, 2프레임은 1행 아래다.
  - 칼끝 1px은 입·턱 높이(W x25, E x31, 19행)에서 얼굴 위에 그려진다.
  - 눈(17–18행)은 W·E 모두 보인다.
  - 손·코등이·소매는 그대로 이어진다. 허리 아래 몸통 행(28행)은 빈틈 없이 메워졌다.
  - 이제 S·SW·SE와 같은 높이의 "턱 앞 X"로 읽힌다.
- **block/W/2, block/E/2**: 떠 있던 신 1px이 다리 외곽선에 붙어 2px 뒤꿈치가 됐다(W 33행 x30–31 `oo`, E 33행 x25–26 `nn`). 시트에서도 들린 뒷발로 읽힌다.
- **block/SW/0·3**: 앞트임이 3px(`jkk`)로 줄고 오른쪽 판이 `qq`(+`q`)로 넓어졌다. 대기와 장옷 양이 비슷해서 0→1, 3→대기에서 깜빡이지 않는다.
