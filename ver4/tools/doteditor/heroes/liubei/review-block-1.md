# 유비 막기(block) 검수 1

판정: **통과** (반드시 0, 권장 3)

본 것: `render.py sheet liubei --anims idle,block --zoom 4`, 방향별 `--anims block --dirs <d> --zoom 10`,
`frame block S 2 / N 2 / W 1 / W 2 / SW 1 / E 1`(기본형 비교), `recolor --anims block`(iron·skin·hair·faction·themeA·themeB·themeC·outline).
비교 기준은 모델 시트 v2 대기와 profile §4·§6·§8, notes-block.md다.

## 확인한 것 (문제 없음)

- **가려짐(앞 방향)**: S·SW·SE·E·W의 1·2프레임에서 X 칼날이 얼굴·턱 위에 그려진다. 눈은 모두 보인다.
  - S: 두 눈이 보이고 수염이 가려진다(profile 허용).
  - SW·SE: 앞 칼 끝이 두 눈 사이(코)에 온다. 두 눈이 다 보인다.
  - E·W: 칼끝 1px이 턱에 걸친다. 눈 1px이 보인다.
- **X 읽힘**: 다섯 방향 모두 두 날이 교차하는 X로 읽힌다. 교차점에서 뒤 칼이 두 토막 나는 것은 의도대로다.
  - 날은 방향마다 5–6px 계단이고 끊김이 없다.
  - 코등이(C2·C3)는 날과 직각인 대각선 2–3px로 놓였다. 그 바깥에 손(피부 2×2)이 있다.
  - 손은 장옷 소매(`q r`)를 거쳐 어깨와 이어진다.
- **뒤 방향**: N·NE·NW의 1·2프레임은 머리 옆과 위로 칼끝만 보인다.
  - 칼끝은 4px로 profile(2–3px)보다 길다. notes의 이유(3px면 칼로 읽히지 않음)에 동의하므로 지적하지 않는다.
  - N 1·2는 관모 양옆에 대칭으로 나와서 "X가 머리 뒤에 있다"로 읽힌다.
  - NE 1·2는 오른손 피부 1–2px이 머리 옆에서 칼끝과 이어진다.
- **동작**: 0 세워 든 준비 → 1 X 버팀 → 2 밀림 → 3 X 풀고 대기 쪽으로 흐름이 읽힌다.
  - 2프레임은 모든 방향에서 기본형처럼 머리·몸이 뒤로 밀리고 발이 들린다. 막기로 읽힌다.
  - N-2·NW-2·NE-2의 발끝 1px이 기준점 아래로 내려가는 것, E-2·W-2의 발이 1행 뜨는 것도 기본형 2프레임과 같아서 지적하지 않는다.
  - 3프레임은 v2 대기와 맞물린다. S-3은 v2 바로 선 자세, E-3·W-3·SW-3·SE-3은 대기 자세다.
- **장옷·진영색**: 장옷이 몸을 따라간다. 1·2프레임에는 든 팔의 소매까지 장옷이다.
  - 진영색은 매듭·앞트임 속옷·허리띠·바지에만 바뀐다.
  - 테마 B는 장옷에만, 테마 C는 관모·어깨·코등이에만, 철은 칼날에만 바뀐다. 다른 곳으로 번진 색은 없다.
- **머리**: SW·SE 머리는 v2처럼 1px 앞에 있고, 모든 프레임에서 크기가 같다.

## 권장

- block/W/1·2, block/E/1·2: X 교차점이 턱보다 2행 아래(목·어깨 높이)에 있다.
  - W-1 교차점은 (22–23, 23)이고 턱수염 끝은 21행이다. E-1도 같다(교차 (33–34, 23)).
  - 앞을 보는 다른 방향(S·SW·SE)은 교차점이 턱 바로 앞인데, 옆 방향만 X가 가슴 앞으로 내려가 보인다. profile §6은 "교차점은 턱 앞 1–2px"이다.
  - X 전체(날·코등이·손·소매)를 1행 올려서 교차점이 22행(턱 앞)에 오게 한다. 얼굴 위로 올라오는 칼끝은 입·턱까지만 덮고 눈(17–18행)은 그대로 둔다.
  - 2프레임도 같은 양만큼 올린다.
- block/W/2: 33행 x31의 `o`(신 A3) 1px이 무릎 옆에 외곽선에 싸여 혼자 떠 보인다.
  - 들린 뒷발 뒤꿈치로 그린 것 같지만, 4배 시트에서는 다리와 떨어진 갈색 점으로 읽힌다.
  - 기본형처럼 다리 뒤쪽 외곽선(x30)에 붙은 2px 발 모양으로 잇는다(예: 33행 x30–31 `oo`, 34행 x30 `#`).
  - 아니면 지우고 외곽선만 남긴다. E-2의 33행 x25 `n`도 같은 방식으로 맞춘다.
- block/SW/0·3: 앞트임 진영색이 x25–28로 넓다. 오른쪽 판은 2px(x29–30)뿐이라 대기(x30–33)보다 장옷이 훨씬 적게 보인다. 0→1과 3→대기에서 옷이 바뀌는 것처럼 깜빡인다.
  - notes의 남은 의문과 같은 지적이다.
  - 앞트임을 대기 폭(4px)에 맞게 1px 줄이고, 오른쪽 판을 `q`로 1px 넓힌다(24–29행). 부검 소매가 그 자리를 덮는 행은 그대로 둔다.
