# 삼국지 전장 원화
공통 SPRITE_ART_GUIDE.md를 따른다. 독자적인 1990년대 삼국지 전술 RPG 도트 원화.
부대 atlas: 5열×4행. 행: 보병·기병·궁병·문관. 열: 대기·걷기A·걷기B·공격·피격.
생성 시 실제 시트 크기에서 셀 크기를 기록한다. 모든 셀은 같은 크기이며 접지점은
셀 중앙 X, 높이의 82%. 배율·앵커를 셀마다 자동 조정하지 않는다.
대기120ms, 보행140ms, 공격180ms, 피격160ms. 오른쪽 아래를 보는 3/4 투영.
미세 호흡은 상체 위치만 이동하며 발·크기를 고정. 프레임간 크기나 팔레트 변경 금지.
원본은 이 폴더, 배포 atlas는 assets/graphics. 후처리는 project tools 밖의 전용 파일.
초상 atlas: 4열×1행, 유비·관우·장비·간옹. 동일 정사각형 프레임, 눈높이 고정.
지형 atlas: 4열×2행. 순서: 초원·사막·숲·산 / 성채·요새·마을·물.
상단에서 내려다본 사각 전술 타일. 불투명. 모든 셀 같은 크기, 지면 기준점 중앙.
지형 자체에는 UI·선택 범위·좌표·부대를 그리지 않는다.

## 원화 실측 (units-v2-source.png)
실제 시트 1402×1122. 생성기가 행 경계를 정확히 지키지 않아 단순 4등분을 사용하지 않는다.
수동 확인한 행 범위는 [0,289), [289,602), [602,856), [856,1122).
접지 기준 Y는 원본 좌표 276, 594, 847, 1093. 열은 원본 너비의 5등분.
모든 프레임에 동일한 원본 픽셀 배율을 적용하고 행별 접지 기준을 사용한다.
개별 프레임 bbox 자동 정렬/배율 변경은 하지 않는다. 일부 공격 무기 끝은 추가 원화
정리가 필요하며 실제 저해상도 재생에서 최종 확인하기 전 완성 판정을 하지 않는다.
