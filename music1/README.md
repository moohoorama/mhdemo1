# 삼국지 SRPG BGM (MIDI)

삼국지 영걸전·공명전·조조전 스타일의 BGM 3곡을 General MIDI로 만든 것입니다.
음악 생성 AI는 쓰지 않았습니다. 음악 이론에 맞춰 음표를 코드(`compose.py`)에 직접 적고,
반주만 패턴 함수로 자동 생성했습니다.

## 파일 구성

```
music1/
├── compose.py          # 작곡 + MIDI 생성 스크립트 (Python 표준 라이브러리만 사용)
├── midi/
│   ├── 01_main_theme.mid
│   ├── 02_battle.mid
│   └── 03_event.mid
└── preview/            # fluidsynth로 렌더링한 미리듣기 mp3
```

## 곡 목록

| 파일 | 제목 | 조성 / 템포 | 길이 | 구성 |
|---|---|---|---|---|
| `01_main_theme.mid` | 천하 | D단조 5음계, 88 BPM | 약 1:50 | 금관 팡파르 인트로 → A: 디즈 + 고쟁 아르페지오 → B: 금관 총주 + 현악 + 타이코 → (A·B 한 번 더) → 마무리 |
| `02_battle.mid` | 출진 | A단조 5음계, 152 BPM | 약 1:04 | 현악 반복 + 타이코 인트로 → A: 얼후·디즈 옥타브 선율 → B: 금관과 함께 고조 → (A·B 한 번 더). 반복 재생용 루프 구조 |
| `03_event.mid` | 도원 | G장조 5음계, 66 BPM | 약 2:14 | 고쟁 인트로 → A: 디즈 → B: 얼후 + 느린 현악 → (A·B 한 번 더) → 마무리 |

## 작곡 과정

### 1. 장르 특징을 규칙으로 정리

원작 BGM은 **중국풍 오케스트라 게임음악**입니다. 관현악에 중국 5음계 선율을 얹은 형태이고,
그 시절 코에이 게임에서는 신디사이저로 관현악을 흉내 냈습니다. 이 특징을 다음 규칙으로 바꿨습니다.

- **선율은 5음계만 사용**: 반음이 없는 음계(도·레·미·솔·라 계열)를 씁니다. 동양적으로 들리게 하는 가장 큰 요소입니다.
- **중국 악기는 비슷한 GM 음색으로 대신 사용**

  | 원래 악기 | GM 대체 악기 (프로그램 번호) |
  |---|---|
  | 얼후 | 바이올린 (40) |
  | 디즈 | 플루트 (73) |
  | 고쟁 | 코토 (107) |
  | 큰북 | 타이코 (116) |
  | 징 | 차이니즈 심벌 (드럼 채널, 52번 음) |
  | 관현악 | 현악 합주 (48), 느린 현악 (49), 금관 섹션 (61), 팀파니 (47), 콘트라베이스 (43), 피치카토 (45) |

- **곡마다 다른 성격**: 메인은 웅장하게, 전투는 빠르고 긴장감 있게, 이벤트는 느리고 서정적으로 잡았습니다.

### 2. 곡의 뼈대 정하기

곡마다 조성, 템포, 마디별 화음 순서를 먼저 정했습니다. 한 마디는 4/4박자입니다.

| 곡 | A 부분 화음 | B 부분 화음 |
|---|---|---|
| 메인 | `Dm F Gm Dm Bb C Dm Am` | `Bb C Dm F Gm C Dm Dm` |
| 전투 | `Am Am F G Am Am F E` | `C G Am Em F G Am E` |
| 이벤트 | `G Em C D G Em Am D` | `Em C G D Em C D G` |

전투곡은 A와 B 모두 마지막 마디를 단조 Em이 아닌 **E장조 화음**으로 끝냅니다.
다시 Am으로 돌아가고 싶어지는 긴장감이 생겨서 반복 재생할 때 자연스럽게 이어집니다.

### 3. 선율은 손으로 작성

선율은 `음이름:박자` 문자열로 적었습니다. `R`은 쉼표이고 `|`는 마디 구분용 표시입니다(무시됨).

```
D5:1.5 C5:0.5 A4:1 G4:1 | A4:1.5 C5:0.5 F5:2 | ...
```

선율을 쓸 때 지킨 원칙입니다.

- **강박에는 화음 구성음**: 예를 들어 Dm 마디는 D나 A로 시작합니다. 사이는 5음계 음으로 잇습니다.
- **8마디 단위로 질문하고 대답하는 구조**: 4마디째는 쉼표나 긴 음으로 한 번 쉬고, 8마디째에서 마무리합니다.
- **곡마다 다른 리듬 습관**

  | 곡 | 리듬 | 효과 |
  |---|---|---|
  | 메인 | 점음표 (1.5박 + 0.5박) | 당당하게 걷는 느낌 |
  | 전투 | 같은 음 8분음표 연타 (`A4:0.5 A4:0.5 ...`) | 몰아붙이는 느낌 |
  | 이벤트 | 긴 음을 길게 끌기 | 여운 |

### 4. 반주는 패턴 함수로 자동 생성

화음 순서를 넣으면 함수가 반주 음을 채웁니다.

| 함수 | 역할 |
|---|---|
| `pad` | 현악이 화음을 한 마디씩 길게 깔아줌 |
| `arpeggio` | 고쟁이 화음 음을 근음 → 5도 → 옥타브 → 3도 순서로 올라갔다 내려옴 |
| `bass_roots` | 베이스가 근음과 5도를 짚음 |
| `hits` | 타이코·드럼이 마디마다 같은 리듬을 반복 (예: 전투곡 타이코는 0, 0.75, 1.5, 2, 3, 3.5박) |
| `roll` | 팀파니·스네어 롤. 점점 세지게 해서 다음 부분으로 넘어가는 신호로 사용 |
| `ostinato` (전투곡) | 현악이 8분음표로 같은 음형을 반복 |
| `riff` (전투곡) | 금관이 마디 안 네 군데를 끊어 치는 반주 |
| `pizz_bass` (전투곡) | 피치카토 베이스 8분음표 |

### 5. 기계 같은 소리 줄이기

- **셈여림 흔들기**: 음마다 셈여림을 무작위로 ±4~5 정도 바꿉니다. 곡마다 시드를 고정해서 매번 같은 결과가 나옵니다.
- **정박 강세**: 정박에 오는 음은 조금 더 세게 칩니다.
- **음 길이 조절**: 전투곡 선율은 음 길이의 85%만 울리고 끊어서 또렷하게, 이벤트곡은 100% 이어서 부드럽게 들립니다.
- **잔향과 팬**: 악기마다 잔향(CC91)과 좌우 위치(CC10)를 따로 설정했습니다.

### 6. MIDI 파일 직접 작성

외부 라이브러리 없이 표준 MIDI 파일(Format 1, 4분음표당 480틱)을 바이트 단위로 직접 씁니다.
첫 트랙에는 템포와 박자 정보가 들어가고, 나머지 트랙은 악기마다 하나씩입니다.

### 7. 확인한 범위

fluidsynth로 오디오를 렌더링해서 다음만 확인했습니다.

- MIDI 파일이 문제없이 읽히는지
- 길이가 예상과 맞는지
- 음량이 지나치게 크지 않은지

**작곡자(Claude)는 소리를 직접 들을 수 없어서 음악적으로 좋게 들리는지는 확인하지 못했습니다.**
실제로 들어보고 고쳐야 합니다.

## 사용법

### MIDI 다시 생성

```bash
python3 compose.py
```

### 곡 수정

`compose.py`에서 곡마다 `main_theme()`, `battle()`, `event()` 함수를 고치면 됩니다.

- **선율**: `a_mel`, `b_mel` 문자열의 음이름과 박자를 바꿉니다. 한 마디의 박자 합은 4가 되어야 합니다.
- **화음**: `a_ch`, `b_ch` 목록을 바꿉니다. 지금은 장3화음(`C`)과 단3화음(`Am`)만 지원합니다.
- **템포**: 각 함수 끝의 `write_midi(..., bpm, ...)` 값을 바꿉니다.
- **악기**: `Track(...)`의 프로그램 번호를 바꿉니다. 파일 위쪽에 GM 번호 상수가 있습니다.

### 미리듣기 렌더링

```bash
SF=/opt/homebrew/Cellar/fluid-synth/2.5.1/share/fluid-synth/sf2/VintageDreamsWaves-v2.sf2
for f in midi/*.mid; do
  b=$(basename "$f" .mid)
  fluidsynth -ni -q -g 0.2 -r 44100 -F "/tmp/$b.wav" "$SF" "$f"
  ffmpeg -y -i "/tmp/$b.wav" -af "loudnorm=I=-16:TP=-2" -codec:a libmp3lame -q:a 3 "preview/$b.mp3"
done
```

- fluidsynth 기본 사운드폰트(VintageDreamsWaves)는 레트로한 신디사이저 음색입니다.
  GeneralUser GS 같은 GM 사운드폰트를 쓰면 더 오케스트라처럼 들립니다.
- 금관 총주 부분은 그대로 렌더링하면 소리가 찌그러집니다. 그래서 게인을 0.2로 낮추고
  세 곡의 음량을 -16 LUFS로 맞췄습니다. MIDI 파일 자체의 악기 간 음량 균형은 바꾸지 않았습니다.
