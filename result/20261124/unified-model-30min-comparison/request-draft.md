# 매우 어려움 단일 모델 30분 비교 실험

## 목적

전투별 전용 가중치 없이 전체 게임에서 동일한 정책을 사용하는 두 접근을 비교한다.

1. 기존 Go 기반 숫자형 입력·합법 행동 후보 평가를 확장한 단일 모델.
2. Laya 기반 단일 체크포인트 모델.

각 접근에 **독립적으로 30분의 학습·개발 시도 시간**을 부여하고, 매우 어려움 난이도의 정상 새 게임에서 재도전 없이 어디까지 승리하는지 확인한다. 한쪽의 30분을 다른 쪽으로 옮기지 않는다. 설치·모델 다운로드·환경 준비와 최종 평가는 별도로 시간을 기록하고 30분 학습 시간에 포함하지 않는다. 실제 사용한 시간과 중단·실패 사유를 남긴다. 동시에 실행한다면 자원 경쟁으로 불공정해지므로 같은 조건에서 순차 실행한다.

## 정책과 목표

- 두 모델 모두 전투별 전문가 선택이나 스테이지 전용 가중치를 사용하지 않는다. 현재 공개된 승리·패배·부목표의 종류·대상·구역·진행과 전투 상황을 입력에 포함한다. 숨겨진 복병, 미래 이벤트, 난수를 노출하지 않는다.
- 패배·턴 초과를 피하면서 경험치를 얻고, 부목표의 아이템 등 보상을 획득하며, 돈·아이템·병법치 등 물자를 아껴 이후 전투에 이어가는 것을 목표로 한다. 턴과 적을 경험치 획득 기회로 보고, 실제 효과가 있는 회복·강화·도구 사용도 고려한다. 승리 전에 장기 성장을 무시한 단순 속도 경쟁으로 만들지 않는다.
- 30분 내에 처음부터 두 정책 모두 완전 구현·학습이 어렵다면, 가능한 범위를 구현해 실행하고 어떤 기능이 규칙 기반으로 남았는지, 학습이 불가능했다면 정확한 이유와 완료 범위를 보고한다. 준비·상점·이야기의 규칙 기반 사용 여부를 두 모델에 동일하게 명시한다.

## 공정한 평가

- 실제 정상 새 게임, 매우 어려움, 재도전 없이 첫 패배까지. 같은 고정 콘텐츠와 난이도·자원·게임 규칙, 동일 개발 및 평가 시드, 같은 추론 조건을 사용한다. 경험치·재고를 인위적으로 지급하지 않는다.
- 30분 동안 본 개발 시드와 별도 미사용 평가 시드를 분리한다. 각 모델의 **최고 기록**(마지막으로 승리한 전투 번호와 첫 패배 전투), 전체 시드별 결과, 평균·중앙값과 시드 수를 기록한다. 최고 기록만으로 안정적인 실력이라고 주장하지 않는다. 평가에 사용한 시드와 실행 제한·실패를 모두 기록한다.
- 전투별 승패·턴·장수별 획득 경험치 및 레벨·부목표와 보상·소모품과 돈 변화를 수집한다. 측정할 수 없는 항목은 추측하지 말고 누락 이유를 기록한다. 시드 표본 수와 훈련·평가의 실제 계산 시간도 기록한다.
- 결과의 범위를 분명히 한다. 30분 실험은 해당 시드와 예산에 대한 비교이며 게임 전체를 안정적으로 완주한다는 보장이 아니다. 최종 체크포인트의 출처, 모델·콘텐츠·코드 해시, 시드, 명령, 로그, 오류를 보존한다.
- 기존 학습 모델, 보고서, 저장 파일과 미커밋 변경을 보존하고 덮어쓰지 않는다. 콘텐츠 해시를 임의로 바꾸거나 검사만 우회하지 않는다. 최종 배포 모델 교체는 하지 않는다.
