# 군사·세객 계열 장수 확인과 특성 조정 논의 결과

## 결론

기존 요약의 장수 목록은 현행 데이터와 맞지 않는다. `ver5/assets/data/characters.json`의 `Characters`에서 병종(`Class`)으로 직접 찾은 결과, 군사·종횡가 장수는 요약보다 훨씬 적다. 요약의 목록은 쓰지 않는다.

## 현행 데이터 (characters.json, Class 기준)

- 군사(`strategist`): 방통(`pangtong`), 이유(`liru`), 전풍(`tianfeng`), 심배(`shenpei`). 4명.
- 종횡가(`diplomat`): 손건(`sunqian`), 봉기(`fengji`). 2명.
- 세객(`orator`), 책사(`staff_officer`): 직접 지정된 장수 없음.

## 기존 요약과의 차이

- `result/20261124/strategist-orator-officers/summary.md`가 든 군사 13명(제갈량, 사마의, 서서, 진궁, 진등, 순유, 동승, 괴월, 괴기 등)과 종횡가 13명(곽가, 정욱, 곽도, 유표, 향랑, 노숙, 가후, 진교, 저수, 마속, 공융 등)은 `characters.json`에 이름 자체가 없었다. 출처가 다른 자료이거나 잘못 옮긴 목록으로 보인다. 확인 전까지 쓰지 않는다.
- 요약의 "파진은 전풍·서서·괴기에 있다, 격파는 없다"도 이 기준으로는 재확인되지 않았다. 특성 파일에서 파진·격파를 가진 장수는 따로 확인해야 한다.

## 특성 조정 논의 (미적용)

- 장구·약점공략을 세객에서 종횡가로 옮기는 안은 기록만 했다. 게임 데이터는 바꾸지 않았다.
- 파진·격파를 누구에게 줄지는 미정이다.
