# 이후 스토리 문관 추가 후보 확인 결과

## 결론

다섯 명 중 게임에 실제로 들어 있는 인물은 없다. 마속과 마량만 스토리 데이터에 설정이 있을 뿐, 합류가 확정된 것은 아니다. 법정, 장완, 비위는 데이터에 없다.

## 근거 (ver5 기준)

- `assets/data/characters_story.json`:
  - 마속(`masu`): 병종 `diplomat`(종횡가), `Playable` 없음, `Learn` 비어 있음.
  - 마량(`maliang`): 병종 `sorcerer`(방술사), `Playable` 없음, `Learn` 비어 있음.
  - 법정, 장완, 비위: 없음.
- `assets/data/characters.json`(플레이어 장수 데이터): 다섯 명 모두 없음.
- `docs/fullstory.md`: 다섯 이름 언급 0회.
- 기존 요약 `result/20261124/future-counsellors/summary.md`의 내용(마속·마량은 설정만 있고 합류 설정 없음, 법정·장완·비위는 데이터 없음)과 일치한다.

## 구분

- 역사적 역할상 추가 후보라는 판단과, 게임에서 합류가 확정된 상태는 다르다. 이번 확인은 후자는 아니라는 결과다.
- 게임 데이터와 줄거리는 수정하지 않았다.
