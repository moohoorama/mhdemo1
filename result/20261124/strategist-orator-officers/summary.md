# 군사·세객 계열 장수와 특성 논의

장구와 약점공략을 세객에서 종횡가로 옮긴다는 사용자의 결정을 기록한다. 파진과 격파의 개인 배정은 미정이다. 게임 데이터는 변경하지 않았다.

인물 데이터에 직접 지정된 병종 기준(동일 인물 중복 제외):

- 군사: 방통, 이유, 전풍, 심배, 제갈량, 사마의, 서서(단복 포함), 진궁, 진등, 순유, 동승, 괴월, 괴기.
- 종횡가: 손건, 봉기, 공융, 곽가, 정욱, 곽도, 유표, 향랑, 노숙, 가후, 진교, 저수, 마속.
- 서생: 양홍, 송충, 제갈균, 유파. 조정 사자와 신하는 일반 역할로 별도.

파진은 현재 전풍, 서서, 괴기의 개인 특성에 이미 있다. 격파는 현재 이들 인물의 개인 특성에 없다. 스테이지별 병종 덮어쓰기와 레벨에 따른 실제 등장 병종은 별도다.
