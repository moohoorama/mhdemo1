# 병종 특성 조정안 기록 및 종횡가 특성 확인 결과

## 결론

조정안은 기록만 했다. 게임 데이터는 바꾸지 않았다. 군사와 종횡가의 현재 특성을 `classes.json`에서 확인했다.

## 현재 데이터 (ver5/assets/data/classes.json)

- 군사 `strategist`: 신규 학습 풀 `terrain_craft`(지형공작) 1개. 승급 Plan은 서생·책사 특성을 이어받아 총 11개 항목이다.
- 종횡가 `diplomat`: 신규 학습 풀 `stratagem_spread`(대혼란 계열) 1개. 승급 Plan은 서생·세객 특성을 이어받아 총 13개 항목이다.

## 기존 요약과의 차이

- `result/20261124/class-trait-revision-notes/notes.md`는 군사 13, 종횡가 15로 적었다. 신규 1개와 이어받는 특성을 합친 값이다.
- 앞선 `class-trait-count` 요약은 군사 1(12), 종횡가 1(14)로 적었다. 괄호 값에 자기 풀을 더했는지가 달라서 생긴 차이다.
- 이번 확인은 Pool과 Plan 항목 수를 기준으로 했다. 둘 중 어느 쪽이 맞는 정의인지는 정하지 않았다.

## 조정안 기록 (미적용)

- 책사 격파를 장수 고유 특성으로 전환.
- 책사의 화계·수계·지계 강화를 군사로 이동.
- 세객 수계 제거.
- 세객 혼란을 종횡가로 이동.
- 세객 파진·장구·약점공략의 고유 특성화는 검토 중.
- 권사 특성이 적다는 문제는 구체안 없음.
