# 문관 병종 특성 조정 후 구성 확인 결과

## 결론

예상 구성 요약은 기록된 조정안과 맞다. 게임 데이터는 바꾸지 않았다. 아래 수치는 `ver5/assets/data/classes.json`의 현행 Pool과 조정안 적용 계산을 대조해 확인했다.

## 현행 데이터 (Pool)

- 서생 3, 책사 9, 군사 1, 세객 11, 종횡가 1, 방술사 5, 선술사 3.
- 방술사와 선술사의 현행 구성은 요약과 같다. 선술사 누적 11은 서생 3 + 방술사 5 + 자기 3과 맞는다.

## 조정안 적용 시 (계산 확인)

- 책사 신규 5: 현행 9에서 격파 1, 화계·수계·지계 강화 3을 뺀 값. 부관임명, 확산, 수계, 지계, 집중. 맞음.
- 군사 신규 4: 지형 조성 1 + 화계·수계·지계 강화 3. 맞음.
- 세객 신규 9: 현행 11에서 수계와 혼란을 뺀 값. 맞음.
- 종횡가 신규 2: 현행 1(대혼란 계열) + 혼란 1. 맞음.

요약에 적힌 누적 수(책사 8, 군사 12, 세객 12, 종횡가 14)는 서생 등 이어받는 특성을 더한 값과 맞는다.

## 구분해서 볼 것

- 세객의 파진·장구·약점공략을 고유 특성으로 바꾸는 안은 아직 미확정이다. 적용하면 세객은 신규 6, 누적 9가 되고 종횡가는 신규 2, 누적 11이 된다.
- 위 수치는 조정안을 가정한 예상이다. 현행 데이터와 다른 것은 의도된 차이다.
