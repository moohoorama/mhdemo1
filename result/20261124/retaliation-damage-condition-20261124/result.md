# 보복 중첩 조건 확정 기록

## 결정 (사용자 요청)

- 보복은 피격 시 실제 병력 피해가 있을 때만 중첩이 쌓인다.
- 빗나감과 0 피해(면역 포함)에는 중첩되지 않는다.

## 근거와 연결

- 앞선 검토(`result/20261124/retaliation-stack-duration/notes.md`, `result/20261124/counterspell-real-casting/notes.md`)에서 집계 기준 후보를 A~G로 나눴다. 이번 결정은 A(명중이고 피해가 0보다 큼)에 해당한다.
- 반계가 빗나간 책략도 되돌아가는 문제는 별개다. 이 결정은 보복 중첩만 정한다.

## 구현 시 확인할 것

- 집계 지점은 `strike`의 피격 처리 뒤(`combat.go` 333행 부근, 앞선 검토 기준). 빗나감은 피격 처리에 닿지 않으므로 자연히 제외된다.
- 0 피해 면역 판정이 피격 처리 전에 끝나는지 확인이 필요하다.
- 아직 미정: 최대 중첩, 소모 시점(직접 공격 후·자기 차례 종료), 부관이 맞았을 때 주장의 중첩 여부.

## 상태

기록만 했다. 게임 데이터와 코드는 바꾸지 않았다.
