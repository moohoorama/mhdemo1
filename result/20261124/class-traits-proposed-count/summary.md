# 병종별 신규 특성 개수: 현행 / 조정 후

## 결론

`ver5/assets/data/classes.json`의 병종별 `Pool`(학습 가능 특성)을 기준으로 등급별 신규 특성 수를 집계했다. 결정된 조정(책사·군사·세객·종횡가)을 적용한 "조정 후" 값을 함께 적었고, 미결정 항목은 따로 표시했다. 게임 데이터는 바꾸지 않았다.

- 신규 = 해당 병종 자신의 `Pool`에만 있는 특성 개수(승급 이어받기 제외).
- 조정 후 = 결정 사항만 반영. 미결정 항목은 "조정 후"에 넣지 않고 비고에 적었다.
- 민중(commoner)은 Pool이 0개이므로 표에서 제외한다.

## 기존 요약과의 차이 (불일치)

1. `result/20261124/class-trait-count-20261124/result.md`의 괄호 값(승급 경로 합산)이 Pool 합과 어긋난다. 서생 계열에서 한 개씩 적게 나온다.
   - 책사 9(11) → Pool 합 12, 세객 11(13) → 14, 방술사 5(7) → 8, 선술사 3(10) → 11, 군사 1(12) → 13, 종횡가 1(14) → 15.
   - 무인 계열(무도가·권사·흉적·의적·권성 등) 괄호 값은 모두 Pool 합과 일치한다.
   - `scholar-class-trait-projection` 문서의 선술사 누적 11은 Pool 합과 맞고, `class-trait-count`의 10은 오기로 보인다.
   - `class-trait-revision-notes/notes.md`의 군사 13, 종횡가 15는 Pool 합과 맞다.
2. 괄호 기준이 섞여 있다. 군사 1(12), 종횡가 1(14)은 자기 Pool을 뺀 값이고, 무인 계열 괄호는 자기 Pool을 포함한다. 이번 표는 신규 수만 쓰고 누적은 별도로 두었다.

## 데이터 이상 (Pool 밖 Plan 특성)

- 전차대(`chariot`)의 Plan에 `pierce`(관통)가 있는데, 자기 Pool과 조상 Pool 어디에도 없다. 장창병·경보병 Pool과도 무관하므로 Plan이 학습 대상 밖의 특성을 가리키는 상태다. 확인이 필요하다.
- 나머지 Plan 특성은 자기 Pool 또는 승급 조상의 Pool에 모두 있다.
