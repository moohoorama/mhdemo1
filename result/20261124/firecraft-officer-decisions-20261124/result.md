# 허사·황보숭 화공 교체 결정 기록 결과

## 결론

결정을 기록했다. 게임 데이터는 바꾸지 않았다(게임 적용 보류).

## 확인 (characters_story.json)

- 허사(`xusi`): 현행 특성 `cunning`(귀모), `deep_scheme`(심모), `foresight`(선견). 결정 기록과 맞다. 심모 → 화공으로 바꾸고 귀모는 유지한다.
- 황보숭(`huangfusong`): 현행 특성 `half_cost`, `fire_god`(화신), `exhort`. 결정 기록과 맞다. 화신 → 화공으로 바꾼다.

## 효과 차이 (기록 내용)

- 화공: 화계 공격 책략이 명중하면 확정 치명타.
- 심모: 성공한 책략 전체에 확정 치명타.
- 화신: 화염계 책략 위력 +20%, 확정 성공, 확정 치명타.
- 화공은 화계 선행 조건이 있어 실제 반영 때 병종, 획득 조건, NPC 선행 조건을 확인해야 한다.
