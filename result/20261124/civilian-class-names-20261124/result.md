# 문관 병종과 이름 논의 결과

## 결론

논의 기록만 남겼다. 게임 데이터는 바꾸지 않았다.

## 현행 데이터 (classes.json)

- 문관 병종 이름: 서생, 책사, 군사, 방술사, 세객, 종횡가, 선술사, 도독 등.
- 장사, 상서령이라는 이름의 병종은 없다. 제안 명칭이며 아직 대응 병종이 정해지지 않았다.

## 논의 기록 (notes.md 기준)

- 법정은 군사로 둔다.
- 장완과 비위는 방술사로 둔다.
- 장사·상서령으로 바꾸는 명칭은 검토 중이다. 어느 기존 병종에 대응할지 미확정이다.

## 남은 일

- 장사·상서령을 어느 병종에 붙일지 결정.
- 결정 후 병종 데이터와 장수 데이터 반영 여부 판단. 지금은 반영하지 않는다.
