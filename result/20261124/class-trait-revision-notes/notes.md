# 병종 특성 조정 논의 기록

아래는 사용자의 조정안이며 아직 게임 데이터에 적용하지 않는다.

- 책사의 격파를 병종 특성에서 빼고 장수 고유 특성으로 전환한다.
- 책사의 화계강화·수계강화·지계강화를 군사에게 옮긴다.
- 세객의 수계를 뺀다.
- 세객의 혼란을 종횡가로 옮긴다.
- 세객의 파진·장구·약점공략도 장수 고유 특성으로 전환할지 검토 중이다. 아직 확정되지 않았다.
- 책사·세객에 비해 권사의 특성이 너무 적다는 문제 제기가 있다. 구체적 변경안은 아직 정하지 않았다.

## 현행 데이터 확인

- 군사의 신규 학습 풀은 지형 조성 1개다. 서생 3개와 책사 9개를 이어받아 총 13개다.
- 종횡가의 신규 학습 풀은 대혼란 1개다. 서생 3개와 세객 11개를 이어받아 총 15개다.
- 이 수치는 변경안 적용 전의 학습 가능 특성 수이며, 자동 보유 특성의 수가 아니다.
