# 상급 병종 능력치 증가 특성 명칭

상급 병종의 전투 능력치 보너스 특성을 병종 단련 대신 효과가 드러나는 공격력 증가, 방어력 증가 등으로 부른다. 정신력 증가·순발력 증가·사기 증가도 필요한 능력치에 같은 방식의 이름을 사용한다. 실제 병종별 배정은 기존 논의에서 미확정이다. 특성의 효과는 해당 전투 수치 +10%, 주장과 부관이 각각 같은 특성을 배웠으면 +10%p씩 합산해 총 +20%. 다른 고유·일반 특성의 중복 금지 규칙은 유지한다. 기존 명중 관련 특성은 공격명중률증가·방어확률증가로 별도다. 게임 코드는 수정하지 않았다.
