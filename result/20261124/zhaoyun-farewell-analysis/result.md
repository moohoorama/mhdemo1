# 13장 소패 관청 조운 작별 장면 흐름 분석

- `story13.json`에서 조운은 이미 관청에 함께 있는데 장비가 갑자기 “조운이 할 말 있대유”라고 소개한다. 조운 본인이 한마디 할 수 있는 자리라 중간 전달이 부자연스럽다.
- 이어 `explore13_farewell.json`으로 탐험 전환하면 관청에 유비와 조운만 배치된다. 조운에게 말 걸면 `ch13.json`의 같은 장면 출연진이 지정된 자리로 배치되고, 다른 인물들이 다시 대화에 참여한다. `explore.go`의 배치·adoptScene 코드를 통해 정적 출연진 지정과 전환을 확인했다. 화면에서 사람들이 사라졌다 돌아오고 유비 위치가 바뀌어 보일 가능성이 있다. 실제 캡처는 모니터 부재로 실패해 보이는 방식은 확정하지 못했다.
- 조운에게 직접 말을 걸었는데 조운이 다시 “드릴 말씀이 있습니다”로 시작한다. 이미 말이 있다고 알리고 찾아간 다음 같은 예고를 반복한다.
- “일이 일단락”과 귀환 의도 뒤 “그 명을 끝까지 다하지 못하는 자”는 어색하다. 맡은 일을 끝냈으니 돌아가는 것인데, 무슨 명을 다하지 못한다는 것인지 불명확하다. 함께 남고 싶은 마음과 공손찬에게 돌아갈 도리는 맞지만, 이유를 설명하는 말이 논리를 흐린다.
- 바로 전 장비가 긴박하게 여포 소식을 알린 뒤 웃음이 가라앉기도 전에 할 말 전달→조작 중단→작별이라는 서로 다른 흐름이 겹친다. 송별연 제안 직후 이튿날로 넘어가는 전환도 빠르다.
- `c13-f01`은 예를 하는 비트에 `Play: attack`을 쓴다. 실제로 어떤 동작처럼 보이는지는 화면 확인이 필요하다.
- 검증: 현재 `story13.json`, `explore13_farewell.json`, `ch13.json`, 관련 GUI 전환 코드를 읽었다. 스토리 색인은 직전 기록대로 오래되었을 수 있어 실제 파일로 확인했다. 캡처 시도는 `no monitor was found at initializeGLFW`로 실패했다. 게임 데이터는 변경하지 않았다.
