# 공통 스크롤바 디자인 시안 5개와 게임 화면 캡처 (접수, 미착수)

## 상태

요청은 접수했다. 시안 5개, 게임 캡처, 비교판은 아직 만들지 않았다. 코드도 바꾸지 않았다.

## 확인한 것

- 스크롤바 그리기 코드: `ver5/internal/gui/table.go:206`의 `tableBar`. 목록·표 공통으로 쓰인다.
- `go build ./internal/gui/` 통과(확인 시점).
- 실행 중인 캡처 작업은 없다(`_uidemo-vm` 없음).
- 작업 트리에 `internal/gui` 미커밋 파일이 36개 있다. 다른 세션 작업으로 보인다.

## 계획

1. 현재 `tableBar`의 색·폭·손잡이를 기준으로 기존 스크롤바 모습을 캡처한다.
2. 시안 5개를 서로 구분되게 정한다(예: 얇은 선, 굵은 손잡이, 끝 화살표 있음, 밝은 트랙, 눌림 강조 등). 각 시안을 HTML 모형으로 먼저 보여 준다. 모형은 실제 게임 캡처가 아니라고 표시한다.
3. 게임 캡처는 시안별로 `tableBar`를 바꿔야 한다. 소스를 직접 고치면 공유 파일과 겹치므로, 변형 값을 받는 캡처 전용 경로가 필요하다. 이 방식은 사용자 확인이 필요하다.
4. 캡처는 한 번에 하나씩 실행한다. PC와 휴대폰 참고 크기 모두 찍는다.
5. 비교판 HTML과 결과 Markdown을 `result/20261124/20261124-scrollbar-design/`에 남기고 `docs/history.md`를 갱신한다.

## 확인이 필요한 점

- 게임 캡처를 위해 `tableBar`에 시안별 변형 값을 받는 임시 경로를 넣어도 되는지, 아니면 모형만 먼저 만들고 캡처는 시안을 고른 뒤 하는지.
