# 수공을 시나리오 소속으로 (25장)

- 이야기 장면 `c25-flood`(`ver5/assets/scenes/ch25.json`)의 `c25-e05` 줄 뒤 비트(`Surge` 단계)가 수공을 재생하고, 끝나면 출전 준비로 넘어간다.
- 물·바위는 다시 굽지 않았다(`assets/graphics/effects/flood`). 병사는 장면 배우(`Army` 배역을 본뜸), 관우·미축은 둑 위 장면 배우.
- 수공이 도는 동안 배속은 1 고정(시나리오 1.5배속의 영향 없음).
- `suigong-scene.mp4`: 장면 첫 줄 → 클릭 → 여울 행군 → 암전 → 둑·관우 → 터짐 → 여울 → 하얀 화면. `sheet.png`: 40프레임마다 한 장.
- 재현: 임시 데모는 지움. `go run ./cmd/_uidemo-vm -ui suigong -stage B25 -frames 937` 는 전투 지도용 개발 데모(장면의 `Surge` 단계에서 배역을 읽음).

## 남은 점
- 여울은 장면 지도에서 `~`(물)이라 병사가 강 한가운데를 건너는 모습이다(전투 지도의 모래톱 아님).
- 장면 첫 화면은 조홍과 병사 둘뿐이고, 클릭하면 대군이 나타난다(컷).
- 커밋하지 않음.
