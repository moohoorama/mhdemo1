# 문관 계열 병종 특성 조정 예상

확정적으로 말한 조정안 적용 가정. 게임 데이터는 변경하지 않았다. 괄호는 해당 등급 신규 / 하위 병종 포함 누적 학습 풀 수다.

- 서생 (3/3): 화계, 구휼, 선견.
- 책사 (5/8): 부관임명, 확산, 수계, 지계, 집중. 격파는 고유 특성화, 화계강화·수계강화·지계강화는 군사로 이동.
- 군사 (4/12): 지형 조성, 화계강화, 수계강화, 지계강화. 서생과 책사 특성 포함 누적 12개.
- 세객 (9/12): 부관임명, 민첩 저하, 사기 저하, 공격력 저하, 방어력 저하, 정신력 저하, 파진, 장구, 약점공략. 수계 제거, 혼란은 종횡가로 이동.
- 종횡가 (2/14): 대혼란, 혼란. 서생·세객 특성 포함 누적 14개.
- 방술사 (5/8): 부관임명, 독려, 상태이상치료, 구휼강화, 구휼확산. 서생 특성 포함.
- 선술사 (3/11): 독려강화, 강화 연장, 지형정비. 서생·방술사 특성 포함.

파진·장구·약점공략을 세객에서 빼 고유 특성화하는 안까지 적용한다면 세객은 신규 6 / 누적 9개, 종횡가는 신규 2 / 누적 11개다. 이 안은 아직 미확정이다.
