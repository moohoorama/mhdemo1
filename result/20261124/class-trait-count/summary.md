# 병종 등급별 특성 개수 조회

`ver5/assets/data/classes.json`의 병종별 `Pool`을 세었다. 괄호는 승급 경로의 하위 병종 풀을 합친 중복 없는 학습 가능 특성 수다. 장수·장비 특성은 제외했다.

- 기본: 경보병 3(3), 민중 0(0), 경기병 3(3), 궁병 4(4), 서생 3(3), 적병 3(3), 황건적 2(2), 무도가 3(3)
- 중급: 중보병 3(6), 장창병 4(7), 중기병 3(6), 궁기병 3(6), 노병 4(8), 책사 9(12), 세객 11(14), 방술사 5(8), 흉적 4(7), 권사 2(5)
- 상급: 전차대 3(10), 근위병 3(9), 노기병 3(9), 친위대 4(10), 연노병 4(12), 발석거 3(11), 군사 1(13), 종횡가 1(15), 선술사 3(11), 도독 8(8), 의적 3(10), 권성 3(8)

도독은 승급 경로가 없어 독립적으로 집계했다. 민중·황건적은 특수 병종이다.
