써 보며 나온 불편(대사가 화면 밖에 뜸, 혼잣말이 읽기 어려움, 영어 id뿐임, 그래프가 얽힘)을 5개 개선안과 스테이지 점프로 풀었습니다. 아래 화면은 모두 제안 모형이고, 아직 구현하지 않았습니다. 예시 내용은 1장 탁현 데이터를 따랐습니다.

2. 대사와 혼잣말을 게임처럼 보여 주기

작음

혼잣말(Chatter)은 | 로 이어 붙인 문자열이라 한 줄로 뭉칩니다. 말풍선 목록으로 쪼개고, 이벤트 대사는 초상과 말풍선으로 읽히게 합니다.

3. 한글 이름과 실제 그림, id는 작게 병기

중간

id는 남기되 작은 글씨로 두고, 한글 이름을 크게 씁니다. 스프라이트는 이름 대신 실제 도트 그림을 보여 줍니다(도트 렌더는 이미 순수 Go로 가능).

4. 그래프를 구역 클러스터와 이벤트 레인으로 다시 배치

큼

지금은 깊이(BFS) 순서라 구역과 이벤트가 섞입니다. 구역은 허브와 가지 한 덩어리로 묶고, 이벤트는 그것을 시작하는 사람 옆에 붙입니다. 위에서 아래로 흐르게 하고, 복귀선은 선택했을 때만 보입니다.

5. 따라가기 모드: 플레이 순서로 번호 붙이기

큼

“이 흐름 따라가기”를 켜면 지금 열린 길만 강조하고, 플래그를 세울 때마다 새로 열리는 길을 보여 줍니다. 길이 왜 닫혀 있는지도 바로 보입니다.

  1. 1
    시작 이벤트 탁현 거리 · 장비를 만남
    + c01-met
  2. 2
    주점에서 관우에게 말 걸기 열린 길 · 지금 가능
    필요 c01-met ✓+ c01-tavern
  3. 3
    성문 밖 복숭아 숲, 장비에게 말 걸기 잠김 · 2번 이후
    필요 c01-tavern+ c01-oath
  4. 4
    의병 주둔지에서 관우 출진 잠김 · 3번 이후
    필요 c01-oath
  5. 5
    B01 전투
개선플래그 → 어떤 길이 열리는지 연결
플래그세우는 곳열리는 곳
c01-met① 시작 이벤트② 주점 대화
c01-tavern② 주점의 소동③ 복숭아 숲
c01-oath③ 도원결의④ 의병 주둔지

지금의 플래그 표는 id만 나열해서 “누가 무엇을 여는지”가 안 보입니다. 3번의 한글 이름과 함께 쓰면 순서 설명 그대로 읽힙니다.
