# 새 상품 안내 대사에서 숫자 제거

사용자 요청: 새 상품을 홍보하는 야외 점원의 말풍선과 말을 걸었을 때의 설명에서 **가격·회복량·능력치 등 상품 수치 숫자를 빼 달라**. 아이템 수치가 나중에 변경될 때 대사가 틀어지고 함께 수정해야 하는 문제를 피하기 위함이다. 상품 이름과 용도·특징은 플레이어가 이해할 수 있게 설명하되 수치에 의존하지 않는다. 실제 상품 가격·효과 데이터와 상점 UI의 정확한 수치 표시는 바꾸지 않는다.

- 기존 결과 `result/20261125/20261125-shop-advert-workflow/result.md`, 야외 점원 말풍선과 `Talk`·`adverts` 등 실제 구현 전체를 조사한다. 낙양·평원·서주·업 등 모든 새 상품 안내를 확인하고 해당 문구의 수치가 남지 않게 고친다. 사용자에게 보이는 대사에서 아라비아 숫자뿐 아니라 수치 표현을 살피되 일반적인 관용 표현까지 무작정 없애지 않는다.
- 기존 테스트·규칙이 안내 대사에 가격·효과 수치 일치를 요구한다면 이를 고쳐, 상품명과 실제 기능의 정합성은 계속 검증하면서 숫자를 반드시 적게 하지 않는다. 수치를 바꿔도 대사가 어긋나지 않는 회귀 테스트를 추가한다. 데이터의 성능을 임의로 변경하지 않는다.
- 이야기 문구를 바꾸므로 `ver5/docs/story-writing.md`, `ver5/docs/data-speech-style.md`와 관련 지침을 읽고 문구 초안과 사용자 선택 절차를 따른다. 새 상품 안내 자체는 빠지지 않게 유지한다. 현재 임시 A안과 다른 시안 문구에도 숫자가 있으면 함께 확인해, 사용자 선택 후 숫자가 다시 들어오지 않게 한다. 기존 미커밋 변경을 보존한다.
- 실제 게임에서 대표 야외 점원의 말풍선과 대화를 캡처하고, 적용한 문구와 자동 테스트 범위·결과·남은 사용자 선택 사항을 기록한다.
- `process/<name>/progress.md`에 매분 실제 진행을 기록하고, 테스트 단계에서 요청 문서를 `test/<name>/`으로 옮겨 테스트 실행 시각·결과·실패 수정 및 재시험을 남긴다. 필수 테스트를 모두 통과한 후에만 `result/YYYYMMDD/<name>/`으로 옮기고 `ver5/docs/history.md`를 갱신한다.
