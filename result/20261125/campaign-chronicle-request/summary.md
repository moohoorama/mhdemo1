# 사용자용 역사서와 분기 검토 요청

스타크래프트 II 임무 기록실은 완료한 임무를 다시 플레이하는 기능임을 블리자드 공식 자료로 확인했다. 사용자가 원하는 것은 플레이 중 도달한 지점의 실제 상태를 숨은 저장으로 남기고, 도달한 지점만 표시해 선택한 저장을 불러오는 사용자용 기능이다. 현재 기획의 가상모드 조건은 12장 제갈현·고순 생존 및 22장 관우·미방 화해 후 24장 느린 길 선택이다. B12 이전 기록으로 다시 시작해 조건을 충족하면 새로운 진행에서 가상 분기 조건에 도전할 수 있지만, 기존 진행의 결과를 바꾸는 것은 아니다. 기능 설계·구현 요청을 등록했다.
