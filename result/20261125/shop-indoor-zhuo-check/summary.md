# 실내 점원과 탁현 주점 콩 판매 확인

현재 03·08·14장 해당 상점에서 실내의 추가 광고 NPC 점원#1은 없어졌지만 실제 거래 주인·상인은 남아 있다. 서주 도구점의 기존 늙은 점원도 남아 있다. 현재 탁현 explore01 장비의 주점에는 판매 Shop 연결이 없고, 탁현 도구점 tools는 콩을 판매하지 않는다. 현재 03장 낙양 주점은 콩을 판매하고 외부 점원이 홍보한다. Git 이력상 7dc28f1 이전 탁현 주인에게 Shop=tavern이 있었고 해당 변경에서 제거됐다. 해당 커밋 직전의 tavern 재고도 bean(콩)·liquor(술)이어서 과거 탁현 주점에서 콩을 판매했다.
