주요 ★특성 후보

  • 장창견제 900: 자기 차례의 직접 근접 공격 명중 시 대상의 다음 차례 이동력 -1.
  • 직선돌격 1000: 방향 변경 없이 3칸 이상 이동 후 직접 근접 공격 시 물리 피해 +15%, 반격에는 미적용.
  • 전차충각 1000: 방향 변경 없이 3칸 이상 이동 후 첫 직접 근접 공격 명중 시 1칸 밀기. 돌파와 중복 방지 필요.
  • 물리피해감소 1000: 받는 물리 피해 -10%; 전차대와 중기병 후보.
  • 기세타기 900: 3칸 이상 이동 후 직접 근접 공격의 공격력 +10%; 돌진과 중첩 위험 검토.
  • 밀집대형 1000: 주변 8칸 아군 1기당 방어력 2%, 최대 8%; 방진과 구별 필요.
  • 기동압박 900: 직접 사격 명중 대상의 다음 차례 순발력 -10%; 저지 사격과 중첩 검토.
  • 추격사격 1000: 저지 사격 상태의 적에게 직접 원거리 공격력 +10%.
  • 약점사격 800: 직접 원거리 물리 피해 +10%.
  • 흔적사격 800: 대상 칸에 불씨·물웅덩이·돌무더기가 있을 때 직접 원거리 물리 피해 +10%; 화시의 책략 성분 제외, 새 흔적 생성 전 판정.
  • 밀집사격 1000: 주변 8칸 아군 1기당 직접 원거리 물리 피해 +4%, 최대 20%.

  • 약화관찰 800: 이미 약화된 적에게 공격 책략 피해 +10%.
  • 지형계략 1000: 흔적 위 적에게 해당 속성 공격 책략 피해 +10%; 기존 속성·흔적 보정 중첩 상한 검토.
  • 교란연장 800: 자신이 건 능력치 약화 지속 +1턴; 장구와 중복 금지 후보.
  • 이간 1000: 혼란 상태 대상에게 거는 능력치 약화 지속 +1턴.
  • 응급지원 800: 병력 절반 이하 아군 대상 회복량 +10%.
  • 역경구휼 1000: 병력 절반 이하 아군 대상 회복량 +20%; 응급지원과 중복 금지 후보.
