# 기마사격 적용 결과

기마사격: 자기 차례에 3칸 이상 이동한 뒤 직접 하는 원거리 물리 공격·사격 무예의 명중률 +15%p. 반격·협동 등 자동 공격에는 적용하지 않으며 명중률 상한과 원거리 공격 면역은 기존 규칙을 따른다. 장수 고유 기습과 함께 있으면 기존 효과와 합산된다. 부관에게서 배운 특성도 전달된다.

궁기병 학습 풀에 추가하고 궁기병·노기병 NPC 특성 계획에 30레벨 습득을 추가했다. 학습 비용 700과 NPC 레벨 30은 실제 적용을 위해 정한 가안이다. 피해량은 변경하지 않는다.

`go test ./internal/core ./internal/content ./internal/gui -run 'TestMountedShot|TestClassPoolsFollowTraitDesign|TestSplitCounters|TestUIContentFits' -count=1` 통과. 이동 2/3칸, 직접 공격과 반격, 근접 공격, 자기 차례, 원거리 면역, 전투 예측을 확인했다. 전체 테스트나 실전 밸런스는 별도 수행하지 않았다.

이전 적용 때 사용자의 궁기병 아이디어 수용을 내가 확정으로 판단하지 않고 후보로 남긴 것이 누락 사유다.
