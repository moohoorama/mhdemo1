# 소모 아이템 아이디어 10가지 (돈 소비처)

## 현재 상태 (assets/data 확인)
- 소모 아이템 9종뿐이다: 병력 회복 3(콩 400/200원, 보리 700/400원, 쌀 2200/1000원), 병법치 회복 3(술 30/300원, 특급주 60/600원, 빼갈 120/1200원), 만능약(상태이상 해제 300원), 인수 2(중급 2000원, 상급은 상점 미판매). 효과 종류는 hp·mp·cure·promote 넷이다.
- 장비 가격은 1200~2400원이고 군량낭·지도·군마는 1200~1600원이다.
- 판 보상 돈은 시나리오 파일 기준 1000~3000원이 대부분이다. 한 판 수입이면 소모품 몇 개 또는 장비 하나 값이다.
- 문제점: 병력 회복 고정값(400~2200)은 레벨이 오르면 쓸모가 줄고, 소모품이 회복 한 방향뿐이라 돈이 쌓여도 쓸 데가 장비·인수밖에 없다.
- 게임에는 이미 버프 20%·3턴, 독·화상, 지형 속성(불·물·땅) 규칙이 있어 아래 안은 대부분 기존 규칙을 재사용한다.

## 설계 메모
- 가격대: 판 수입(1000~3000)에 맞춰 300~1500은 일상 소비, 2000 이상은 고민하는 구매로 둔다. 1번·6번이 돈이 남는 후반 주요 돈 소비처 후보다.
- 구현 난이도: 쉬움 = 1, 2, 6, 8 (기존 hp·cure 형식에 효과 추가). 중간 = 3, 4, 7 (기존 버프·화계·전투불능 규칙 연결). 어려움 = 5(설치 객체), 9, 10(출전 화면·탐험 대화 연동).
- 상점 분배 제안: 주점 = 해독탕·격문, 도구점 = 금창약·숫돌·초석, 미축 상단 = 첩보 서신·예물, 종군 상인 = 병서 죽간.
- 한 판 사용 횟수 제한(3, 7)을 두지 않으면 돈으로 난이도가 무너진다. 어려움(normal) 기준 밸런스는 사용 제한을 포함해 검증이 필요하다.
- 확인하지 않은 것: 전투 중 아이템 사용 UI와 사용 가능한 효과 종류의 코드 구현. 이 문서는 데이터·문서만 조사했고 구현 가능 범위는 코드 확인이 더 필요하다.
