# 병종 계열과 등급별 전투 스타일 논의

사용자는 특성을 추가하기 전에 일반 병종의 계열별·등급별 전투 스타일을 먼저 정하고자 한다. 찔러공격은 사모의 개성을 해치고, 진지고수는 고유 특성이며, 산악지형보조는 기병에 맞지 않고 방어확률증가는 중갑 중기병과 맞지 않는다. 저지사격은 궁기병의 근접 히트앤드런 개성이다. 무도가 상급의 민첩하강 공격과 중급·상급 특성 재배치를 검토하고, 전차대·창병·중기병은 딜탱 측면을 고려한다. 조사 기록: `result/20261125/class-style-discussion/summary.md`. 이 요청은 스타일 논의이며 게임 데이터 변경 지시가 아니다.
