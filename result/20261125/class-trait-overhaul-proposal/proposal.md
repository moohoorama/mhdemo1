# 병종 등급별 특성 개편안

기존 게임 데이터의 승급 계열과 Pool을 바탕으로 한 토론용 제안. 실제 데이터는 변경하지 않았다.

## 보병·기병·궁병

| 병종 | 습득 가능 특성 후보 |
|---|---|
| 경보병 | 대각공격, 대비, 화계, 반격술, 호위, 방어력 증가 |
| 중보병 | 부관임명, 철갑, 원거리피해감소, 방진(800), 대비, 반격술, 방어력 증가 |
| 근위병 | 중갑, 침착, 수성, 방어력 증가, 호위, 철갑, 신규 진형유지 |
| 장창병 | 부관임명, 장창, 공성, 협동, 대각공격, 돌파, 신규 장창견제 |
| 전차대 | 급소, 돌진, 충격, 대각공격, 신규 직선돌격, 신규 전차충각, 신규 물리피해감소 |
| 경기병 | 기마술, 공격명중률증가, 초원지형보조, 돌진, 반격피해감소, 공격력 증가 |
| 중기병 | 부관임명, 반격피해감소, 책략피해감소, 돌진, 공격력 증가, 신규 물리피해감소, 신규 기세타기 |
| 친위대 | 대각공격, 돌진, 충격, 급소, 공격력 증가, 신규 물리피해감소, 신규 밀집대형 |
| 궁기병 | 부관임명, 조준, 저지 사격, 기마사격, 근접사격, 공격력 증가, 신규 기동압박 |
| 노기병 | 장전, 화시, 연발, 순발력 증가, 근접사격, 공격력 증가, 신규 추격사격 |
| 궁병 | 구휼, 공격명중률증가, 조준, 저격, 신규 약점사격, 신규 순발력 증가 |
| 노병 | 부관임명, 수계, 화시, 조준, 신규 흔적사격, 신규 순발력 증가, 신규 물리피해 증가 |
| 연노병 | 독려, 관통, 연발, 원시, 신규 밀집사격, 신규 물리피해 증가, 신규 연속사격 |
| 발석거 | 공성, 사방격(원), 원시, 공격력 증가, 신규 성벽파쇄, 신규 포격준비 |

## 주요 신규 특성 후보

모든 수치와 비용은 임시안이다.
- 진형유지 1000: 주변 8칸 아군 1기당 방어력 2%, 최대 8%; 방진과 합산 여부 및 중복 효과 재검토.
- 장창견제 900: 자기 차례의 직접 근접 공격 명중 시 대상의 다음 차례 이동력 -1.
- 직선돌격 1000: 방향 변경 없이 3칸 이상 이동 후 직접 근접 공격 시 물리 피해 +15%, 반격에는 미적용.
- 전차충각 1000: 방향 변경 없이 3칸 이상 이동 후 첫 직접 근접 공격 명중 시 1칸 밀기. 돌파와 중복 방지 필요.
- 물리피해감소 1000: 받는 물리 피해 -10%; 전차대와 중기병 후보.
- 기세타기 900: 3칸 이상 이동 후 직접 근접 공격의 공격력 +10%; 돌진과 중첩 위험 검토.
- 밀집대형 1000: 주변 8칸 아군 1기당 방어력 2%, 최대 8%; 방진과 구별 필요.
- 기동압박 900: 직접 사격 명중 대상의 다음 차례 순발력 -10%; 저지 사격과 중첩 검토.
- 추격사격 1000: 저지 사격 상태의 적에게 직접 원거리 공격력 +10%.
- 약점사격 800: 직접 원거리 물리 피해 +10%.
- 흔적사격 800: 대상 칸에 불씨·물웅덩이·돌무더기가 있을 때 직접 원거리 물리 피해 +10%; 화시의 책략 성분 제외, 새 흔적 생성 전 판정.
- 밀집사격 1000: 주변 8칸 아군 1기당 직접 원거리 물리 피해 +4%, 최대 20%.
- 연속사격 1000: 직접 사격의 연타 두 번째 물리 피해 +10%p. 연발 병법과의 중첩 재검토.
- 성벽파쇄 1000: 성·성벽·관문 등 구현상 식별 가능한 방어 구조물 위 적에게 직접 원거리 물리 피해 +15%.
- 포격준비 800: 이동하지 않은 자기 차례 직접 원거리 물리 공격 피해 +10%.
- 약화관찰 800: 이미 약화된 적에게 공격 책략 피해 +10%.
- 지형계략 1000: 흔적 위 적에게 해당 속성 공격 책략 피해 +10%; 기존 속성·흔적 보정 중첩 상한 검토.
- 교란연장 800: 자신이 건 능력치 약화 지속 +1턴; 장구와 중복 금지 후보.
- 이간 1000: 혼란 상태 대상에게 거는 능력치 약화 지속 +1턴.
- 응급지원 800: 병력 절반 이하 아군 대상 회복량 +10%.
- 역경구휼 1000: 병력 절반 이하 아군 대상 회복량 +20%; 응급지원과 중복 금지 후보.
- 난폭 800: 물리 공격 시 주는 피해 +10%, 받는 물리 피해 +10%.
- 격앙 900: 병력 절반 이하일 때 사기 +10%.
- 배수의진 1000: 병력 절반 이하일 때 주는 물리 피해 +15%, 받는 물리 피해 +10%.
- 민첩타격 800: 직접 근접 공격 명중 시 대상 순발력 -10%, 2턴.
- 흔들기 900: 순발력 저하된 적 대상 직접 근접 공격 명중률 +10%p.
- 연타압박 1000: 연타 두 번째 타격 명중 시 대상 다음 차례 이동력 -1.

기존 순발력 증가 및 방진 등은 신규가 아니라 기존이다. 신규를 구분하는 표의 오류는 최종 답변을 따른다. 기존 특성의 정확한 작동·상속·중첩과 밸런스 테스트가 필요하다.
