# 미구현·미검증 항목 조사

2026-11-25 현재 코드·데이터와 이전 결과 기록 비교. 기마사격(mounted_shot)·심공 10%·법정 산악지형보조는 2026-11-25 추가 완료되어 이전 결과의 미구현 표기는 구식이다. (이 파일은 후속 변경을 반영해 갱신함.)

## 미구현 또는 미확정
- 병종 풀 3·5·5 개편은 일부만 적용됨(현재 classes.json 확인): 궁기병 4(기마사격 포함), 노기병 4, 중보병 4, 권사 3. 사용자 목표는 유연한 기준이므로 단순 숫자 미달이 반드시 결함은 아니며 추가 특성은 아직 정하지 않았다.
- 심공은 10%로 변경되어 권사·의적 풀에 들어갔고 이 항목은 해소됨(여몽 포함 전역 적용). 별도 병종용 분리 여부는 더 논의되지 않았다.
- 법정 네 번째 특성은 산악지형보조로 채워짐(해소). 다만 구릉은 Ambush가 아니었던 초기 설명은 이후 구릉 Highland 추가로 바뀌었다.
- 법정·장완·비위 인물 데이터는 존재하지만 현재 scenario/scenes에 인물 ID 참조가 없어 합류 및 출전 이야기는 없다. 초상 등 실제 화면 자산은 별도 검토가 필요하며 사용자의 미래 스토리 확정은 아니다.
- 방술사·선술사의 장사·상서령 개명은 아직 논의 중이며 적용하지 않았다.
- 3막 이름·종료 카드는 정해지지 않았다. 1막·2막 카드는 적용되어 있다.

## 구현했으나 검증·결정이 남음
- 반계: 책략 경로 구현 및 치명 지형 흔적 단위 시험 통과. 빗나간 원 책략에도 발동하는 기존 조건은 그대로이며 범위 책략 반계, 전체 효과·재반계와 화면 연출은 더 확인해야 한다. 원 책략의 명중 조건 및 범위 처리 확정은 별도다.
- 보복: 실제 피해 시 중첩과 자동 반격 제외, 턴 종료 제거 구현. 다단·범위, 0피해/면역, 부관 전달의 실제 전투 전체 경로 및 UI 검증은 보완 필요. 중첩 상한 99는 저장 구조에 따른 임시 제한이다.
- 방진·수성·능력치 증가: 구현 및 일부 단위 시험 완료. 부관의 중복, 방진·사세삼공·진지고수·수성 등의 실제 조합과 밸런스 전체 검증 필요. 궁기병 보너스 수치, 기마사격 비용 700과 NPC Lv30, 하후연 강화 NPC Lv40은 적용 시 임시로 잡은 값.
- 이전 전체 검사에서 강하 일기토 배치, 손건 웨이포인트, c27v 웨이포인트, 별도 scrollbar UI 데모의 순수성 검사 실패가 있었으나 이번 조회에서는 재실행하지 않았고 원인·현재 상태 미확인.
- 이전 반계·막 종료 카드 캡처는 Mac 잠금으로 실패. 이번에 재시도하지 않았으므로 화면 검증 완료로 보지 않는다.
