# 사용자용 기록 기능 이름을 「지난 이야기」로 변경

사용자가 앞서 역사서라고 임시로 부른 사용자용 기록·불러오기 기능의 이름을 **「지난 이야기」**로 확정했다. 이미 구현된 `result/20261125/20261125-campaign-chronicle/result.md`를 먼저 확인하고 실제 게임에 사용자에게 보이는 이름을 반영한다.

- 시작 화면·게임 메뉴·창 제목·확인/실패 안내 등 이 기능을 부르는 사용자 표시의 `역사서`를 자연스러운 문맥의 `지난 이야기`로 바꾼다. 내부 저장 디렉터리, 데이터 형식, 코드 식별자를 이름 변경 때문에 바꾸어 기존 사용자 기록을 잃지 않는다.
- 필요하면 화면 안내에 “지나온 시점부터 다시 시작합니다”를 넣어 선택하면 실제 저장을 불러온다는 기능을 분명히 한다. 가용 공간과 기존 UI 문구를 확인하고 지나치게 길어지지 않게 한다.
- 관련 사용자 문서·테스트의 표시명을 갱신하고 기존 기록의 불러오기·분기 동작을 보존한다. 실제 시작 화면·게임 메뉴·창을 PC/모바일 게임 캡처로 확인하고 관련 테스트를 실행한다. 기존 다른 미커밋 변경은 보존한다.
- 요청 처리 규칙에 따라 `process/<name>/progress.md`를 매분 기록하고, 작업 후 요청을 `test/<name>/`으로 옮겨 테스트 실행 시각·결과를 기록한다. 필수 테스트가 모두 통과한 뒤에만 `result/YYYYMMDD/<name>/`으로 옮긴다. 결과 폴더에 캡처와 변경·검증 및 한계를 남기고 `ver5/docs/history.md`를 갱신한다.
