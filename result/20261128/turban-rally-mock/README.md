# 황건 진채 외침 시안 (타이틀 영상 2번 컷)

- `index.html`: 진채를 세운 실제 게임 캡처(`rally.png`) 위에 외침 붓글씨를 웹 애니메이션으로 얹은 시안, 노란 머리띠 전후(`headband.png`).
- 웹뷰: https://claude.ai/artifact/8pddAmQH5uVYw4kNxTM6wP
- 캡처 재현: `rally-mock-scene.json`을 `uidemo-vm -ui scenefile -stage rally-mock-scene.json -size 2560x1700`로(2배율, 타이틀 1배율 화면과 같은 범위).
- 게임 코드는 바꾸지 않았다. 머리띠 그림은 산적·무뢰배 도트에서 진영색 띠를 한 줄 위로 늘리고 띠 자락 네 칸을 찍은 시안.
