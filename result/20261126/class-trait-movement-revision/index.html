병종 특성 수정안

특성별 정리

특성상태정리
돌진변경 제안기세는 만들지 않음. 이동 칸 수에 따라 공격력이 증가하는 기존 돌진을 유지하고 중기병·친위대에 배정. 전차대에서는 제거.
방패술이름·효과 변경 제안원거리 물리 공격을 받을 때 방어력 1.2배. 현행 원거리 피해 30% 감소를 대체.
장거리 사격신규 후보연노병에 제안. 대상과의 거리가 멀수록 원거리 물리 피해 증가. 이름·거리당 증가율·상한은 미정.
기동 공격신규 후보전차대가 이동하면 물리 피해 +10%. 효과는 같은 진영의 다음 차례 시작 시 해제.
기동 방어신규 후보전차대가 이동하면 받는 물리 피해 −10%. 적의 차례에도 유지하고 같은 진영의 다음 차례 시작 시 해제.
근접피해감소신규 후보중기병이 받는 근접 물리 피해 감소. 감소율 미정.
밀집대형이름·비용 변경 제안기존 방진을 밀집대형으로 개명. 주변 8칸 아군 1기당 방어력 +4%, 비용 800 제안.
견제이름·대상 변경 제안기존 저지 사격을 견제로 바꾸고 장창병과 궁기병에 적용. 명중 시 적의 다음 차례 이동력 −2.
정지 방어신규 후보근위병이 이동하지 않고 차례를 마치면 방어력 증가. 효과량 미정. 진지고수는 고유특성으로 유지.

이동 보너스 적용 시점

아군 턴에서 이동하면 즉시 보너스를 얻고, 아군 차례가 끝난 뒤 적의 차례에도 유지한다. 아군 진영의 다음 차례가 시작될 때 이전 보너스를 해제한다. 이후 다시 이동하면 새로 적용된다. 이동하지 않으면 다음 적 차례에는 기동 보너스가 없다.

돌진 역시 이 기간 동안 공격력 증가가 유지되므로 적 차례 반격에도 영향을 준다. 강제 이동을 이동으로 셀지, 이동 경로 취소·대기·다른 아군의 추가 이동은 어떻게 처리할지는 미정이다.

현재 구현 확인

현재 돌진은 이동 칸당 공격력 +5%이며, 아군 차례가 끝날 때 이동 칸 수를 0으로 지워 적 차례의 반격에는 적용되지 않는다. 이를 검증하는 기존 테스트도 있다. 따라서 요청한 지속 시간에는 코드와 테스트 변경이 필요하다. 현재는 확인과 설계 정리만 했고 구현하지 않았다.

노병과 연노병

현재 Pool 기준 노병은 4개, 연노병은 5개다. 숫자만 보면 노병이 적지만 장거리에서 피해를 늘리는 상급 사격의 성격을 살려 연노병에 제안한다. 노병에는 다른 선택지를 보충할 수 있다. 거리 2를 기준으로 할지, 화시의 물리 부분에 적용할지, 주변 피해나 부관 특성과 중첩할지는 미정이다.

병종 역할

  • 중기병·친위대: 공격력 중심 돌진, 근접전 중심.
  • 전차대: 이동 중 물리 피해와 물리 피해 감소, 적 후방 공략. 돌진은 제외.
  • 중보병: 밀집대형과 방패술로 방어력을 올려 화살을 막음.
  • 장창병·궁기병: 견제로 적의 기동을 제한.
  • 연노병: 물리 피해 중심의 대형 사격과 장거리 사격.

상시 공격력·방어력·물리 피해 증가 특성은 최상위 병종에만 배치한다는 기존 방향을 유지한다. 중기병의 돌진은 이동 조건부 특성이다.
