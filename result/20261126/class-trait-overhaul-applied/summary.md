# 병종 특성 개편 코드 반영

확정한 특성 변경을 엔진·데이터에 반영했다. 공격력·방어력은 하나의 계수에 모든 증감을 더해 곱하고, 타격의 피해도 `max(0, 1 + 주는 증가 − 받는 감소)` 한 번만 곱한다. 걸은 칸 수는 다음 자기 차례까지 남아 돌진·기동공격·기동방어가 적 차례 반격에도 적용된다. core·content·autoplay·ai 테스트 통과. `견제`는 이미 디버프 책략 이름이라 저지 사격을 `저지`로 불렀다(미결).

## 추가 (11-27): 반격·치명타·연타·요극을 합산 계수로
반격(기본 0.5, 반격술 1.0)·연타 두 번째 타격(0.5)·요극(0.5)은 계수의 시작 값, 치명타(+0.5)·속성 지형 보정·반격강화·반격피해감소는 더하고 뺀다. `damageAt`/`ext`. 범위 몫·병법 계수·난이도는 계수 밖.
