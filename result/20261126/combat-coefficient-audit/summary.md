# 현행 전투 계수 확인

현행 방진은 주변 1기당 4%, 3기 12%다. 5%라면 제안값이며 3기 15%. 현행 rules.go는 상시 능력치 증가, 주변·방진, 체력 관련 보정, 상태이상 보정을 단계별로 곱하고 각 단계에서 정수로 내림. 지형은 물리 피해식에서 다시 곱한다. 중갑은 방어 상태 +20%, 방비는 미구현이라 두 개 +40% 합산 예시는 가정이다. 이전 레벨50 계산의 방진 12% 후 +40%를 1388×1.4=1943으로 계산한 것은 가정상 단계별 곱이고 사용자 희망 계수 합산과 다르다. 1240×1.52=1884.8, 최종 내림 1884 (방진 4%×3); 5%×3이면 1240×1.55=1922.

공격 피해: max(1, 공격력×공격자 지형−방어력×방어자 지형+(레벨+10)×20)×병법 계수. 이후 방어 피해 감소·공격 피해 증가·난이도 등을 현재 combat.go damage가 여러 배율로 곱한다. boost는 속성 지형과 치명 보너스를 서로 합산하지만 반격·범위 등의 share는 별도 곱한다. 기본 반격 비율 0.5에서 반격 강화·참격은 더하고 공격자의 반격피해감소는 비율을 빼며 0 미만 방지. 이후 최종 피해에 곱한다. 철벽 등 bulwark 한도 피해 처리는 마지막에 적용.

사용자 제안은 같은 공격력/방어력/피해 계수 안에서 증가와 감소를 합산 후 한 번 적용하는 방식으로 이해된다. 반격 −50%와 일반 물리 피해 +20%를 같은 피해 계수에 합칠지(70%) 또는 별도 반격 계수(50%×120%=60%)로 둘지는 최종 정의가 필요하다. 이 기록은 분석이며 코드 변경 없음.
