# 이야기 신규 요소 추출 설계

시나리오의 장 순서와 JSON을 읽어 각 장의 출전 전·승리 보상·출전 후 지급, 인물 합류, 탐험 이벤트 지급과 상점 첫 상품 등장 후보를 마크다운으로 출력한다. 지급 아이템의 장비 특성, 합류 인물의 고유 학습 후보도 데이터에서 보인다. 조건과 출처 ID를 보존하고, 탐험 이벤트 호출 여부와 선택 분기·장 간 전투 경로는 자동 확정하지 않는다. 기본판과 가상 분기는 장별로 분리하며 특정 범위만 조회할 수 있게 한다. 1~11장 결과를 만들어 사용자 기억과 비교한다. Go 엔진이나 기존 자산은 변경하지 않는다. 단일 Python CLI 및 Markdown 결과를 확인한다.
