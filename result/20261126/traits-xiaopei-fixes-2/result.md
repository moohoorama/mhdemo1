# 전가·독공·선행 특성 및 소패 전투 수정

## 변경

- 전가: 자신의 해로운 상태이상과 능력치 약화를 인접 적에게 넘긴다. 면역·기존 상태로 적용되지 않으면 원래 유닛에 남긴다. `ver5/internal/core/combat.go`, `ver5/assets/data/traits.json`, `ver5/docs/data-character.md`.
- 독공: 물리 공격과 적에게 가하는 피해·상태 책략이 적중하면 독을 건다. 짐독의 선행을 독공으로 설정했다. `ver5/internal/core/combat.go`, `ver5/assets/data/traits.json`.
- 우금: 이미 군율이 엄명의 선행이며 군율은 자기 상태이상 면역이다. 우금의 개인 특성 계획 순서만 군율→엄명으로 고쳤다.
- B15: `cao-main` 조건은 3턴에서 4턴 이후로 바꾸고 본군의 Y를 6칸 줄였다. 일반 궁병 셋과 궁병 병종인 하후연을 제외했다. 제외된 하후연의 전투 대사도 제거했다. 본군은 하후돈 퇴각 후 아군 턴이라는 기존 조건을 유지한다. `ver5/assets/scenario/hero/stage15.json`, `ver5/docs/fullstory.md`.

## 선행 검사로 고친 항목

- 정욱·이유: 짐독 앞에 독공.
- 심배: 중갑 앞에 대비.
- 황보숭·허사·번궁: 화공 앞에 화계.
- 유비: 용인술 앞에 부관임명.
- 순유: 수공 앞에 수계.
- 법정: 지공 앞에 지계.
- 우금: 군율을 엄명보다 앞에 배치.
- 유벽: 지계강화 앞에 지계.
- 하후연: 저지 강화 앞에 저지 사격.
- 육손: 25레벨 중갑에 앞서 대비를 24레벨로 추가.
- 연노병: 50레벨 관통 선행 저격을 49레벨 병종 계획에 추가. 해당 병종을 쓰는 여러 인물에도 적용된다.

특성 표시명은 데이터 기준이며 `prerequisites-before.log`, `prerequisites-new.log`, `prerequisites-after.log`에 검사 과정을 보존했다.

## 검증

- 보유 특성 선행, 장수의 1~99레벨 계획, 모든 병종 계획, 짐독·군율, B15 본군 조건을 검증하는 테스트 추가 후 통과.
- 전가와 독공 책략·상태이상 면역 및 기존 특성 회귀 테스트 통과.
- `go test ./internal/content ./internal/core` 통과. B15 자동 밸런스 rush는 0/5 승리, 평균 1.2턴(아군이 4턴 전에 패배하여 본군 연출을 측정하지 못함).
- `_facecheck B15`로 시작 유닛 방향을 확인. GUI 캡처는 `no monitor was found at initializeGLFW`로 실패했다. 슬롯 9의 실제 B15 플레이도 수행하지 못했다. 따라서 조조 본군 위치·연출은 실제 게임 화면 확인이 필요하다.
- Ollama 서버를 재시작한 뒤 스토리 색인을 갱신했다(195개 재생성). 기존 미커밋 변경을 보존했다.
