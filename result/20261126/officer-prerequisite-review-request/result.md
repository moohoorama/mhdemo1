# 장수별 선행 특성 검토

기준: 직전 이 세션이 삽입한 특성과 현재 데이터. `audit.txt`는 게임의 `PromotedAt`, `PlannedTraits`, 병종 상속 `AllPool`을 실제 호출하여 1·16·24·25·31·46·49·50·61레벨의 NPC 계획을 출력한 것이다. 개인 계획은 15레벨 간격으로 앞에서부터 열린다. 이는 NPC 출현 계획이며 플레이어가 특성치로 배우는 목록과 구별한다. 임시 조사 코드는 `audit.go`에 보존했다.

| 대상 | 직전 변경 | 병종 학습 목록과 중복 | 영향·검토 |
|---|---|---|---|
| 정욱 | 유계→독공→짐독→격파 | 독공 없음 | 개인 3→4개. 짐독은 16→31, 격파는 31→46으로 늦어짐. 사용자가 독공을 직접 지정한 인물. |
| 이유 | 간파→혼란→독공→짐독 | 독공 없음 | 개인 3→4개. 짐독 31→46으로 늦어짐. 사용자 요청의 일반 선행 검사로 발견했으나 기존 설계가 바뀜. |
| 심배 | 대비→중갑→군율→반계 | 대비 없음 | 개인 3→4개. 중갑 1→16, 군율 16→31, 반계 31→46으로 밀림. |
| 황보숭 | 백출→화계→화공→독려 | 화계가 경보병 계열 학습 목록에 있음 | 중복. 화공 16→31, 독려 31→46으로 밀림. |
| 허사 | 귀모→화계→화공→선견 | 화계가 무도가 계열 학습 목록에 있음 | 중복. 화공 16→31, 선견 31→46으로 밀림. |
| 번궁 | 보법→화계→화공 | 화계가 무도가 계열 학습 목록에 있음 | 중복. 화공 16→31로 밀림. 플레이어 합류자의 실제 습득은 개인 NPC 계획이 아니라 학습 시스템을 따름. |
| 순유 | 수계→수공→백출, 박학 별도 20 | 수계가 군사 계열 학습 목록에 있음 | 중복. 수공 1→16, 백출 16→31로 밀림. 병종 자동 계획은 책사 수계 15이나 16레벨에는 아직 서생이라 주의. |
| 법정 | 격파→지계→지공→보복→산악지형보조 | 지계가 군사 계열 학습 목록에 있음 | 중복. 지공 16→31, 보복 31→46, 산악지형보조 46→61로 밀림. |
| 하후연 | 저지 사격→저지 강화→추행진→기습, 저지 강화 별도 40 | 저지 사격이 노기병 계열 학습 목록에 있음 | 중복. 저지 강화 1→16, 추행진 16→31, 기습 31→46으로 밀림. 기존 40레벨 TraitAt의 저지 강화는 개인 계획과도 중복되어 실제 중복 지급되지는 않으나 설계가 혼란스럽다. |
| 육손 | 24레벨 대비 추가, 중갑·명가 25 유지 | 도독 학습 목록에는 대비 없음 | 개인 TraitAt 개수 2→3. 대비는 원래 없던 실제 추가이며 다른 개인 순서는 바꾸지 않음. |
| 연노병 | 49레벨 저격 추가, 50레벨 관통 유지 | 별도 고유 장수 특성이 아니라 병종 계획 | 병종 계획 항목 6→7. 이 병종의 모든 NPC에게 영향. 관통 전 선행이 없던 문제를 새 특성 추가로 해결했으므로 전체 병종 편성을 재조정할 필요가 있다. |

추가로 앞서 지적된 유벽 지계·유비 부관임명은 병종 학습 목록과 중복이며 고유 특성 순서를 한 단계씩 밀었다. 우금은 군율과 엄명 순서만 교환해 개인 특성 수는 늘지 않았다.

현재 검사에서 `AllPool` 중복 금지의 선행 예외는 이 세션이 잘못 추가한 것이므로 원복해야 한다. 그 다음 각 병종 계획의 특성 배치·장수 고유 특성 개수와 시점을 먼저 정하고 선행 존재·습득 순서·병종 중복 금지·레벨별 예상 구성을 함께 검사해야 한다. 무엇을 교체할지는 사용자 고유 특성 설계를 임의로 훼손할 수 있어 여기서 단정하지 않았다. 이번 작업은 조사만 했으며 게임 데이터는 변경하지 않았다.
