# 선행 특성·병종 중복 수정안

## 먼저 복구한 테스트

`TestOfficerReformBatch/personal traits do not repeat inherited class learning`에서 이 세션이 추가한 선행 특성 예외를 제거했다. 종래대로 `Traits`, `Learn`, `TraitAt`은 해당 장수 최종 병종과 이전 병종의 학습 목록 `AllPool`에 중복될 수 없다. 파일의 다른 미커밋 변경은 보존했다.

실행 결과는 **실패 8건**이다. 하후연 저지 사격, 허사 화계, 유비 부관임명, 황보숭 화계, 법정 지계, 유벽 지계, 번궁 화계, 순유 수계가 개인 계획에 들어가 있기 때문이다. 전체 출력: [overlap-test.log](overlap-test.log). 선행 존재·NPC 계획 검사는 현재 통과한다([prerequisite-test.log](prerequisite-test.log)). 즉 현재 데이터는 제가 추가한 중복으로 기존 규칙을 위반하며, 중복을 없애면 선행 순서도 다시 확인해야 한다.

## 원칙

1. 병종 학습 목록에 있는 특성을 개인 `Traits`/`Learn`/`TraitAt`에 적지 않는다.
2. 기존에 정한 고유 특성의 종류와 개수는 우선 보존한다. 정욱은 사용자가 명시한 독공을 반드시 포함한다. 새 특성을 더하려면 무엇을 교체하고 어떤 영향을 주는지 보여 준다.
3. NPC의 개인 계획은 1·16·31·46·61레벨에 순차 적용된다. 병종 `Pool`은 배울 수 있다는 뜻이며 NPC가 자동으로 갖는 `Plan`과 다르다. 승급 전후에는 현재 병종의 Plan으로 갈아타므로, 최종 병종의 낮은 레벨 항목이 그 레벨에 반드시 존재한다고 가정하지 않는다.
4. 계획에서 특성 수를 고정하려는 의도와 선행을 동시에 만족시키려면 순서를 조정하거나 일부 항목을 교체해야 할 수 있다. 병종 계획 교체는 그 병종의 모든 NPC에 영향을 준다. 시점과 실제 영향은 전투별 출현 레벨·플레이어 합류 여부를 계산해 검증한다.

## 대상별 제안

| 대상 | 제안할 개인 특성/계획 | 미리 확인해야 할 점 |
|---|---|---|
| 황보숭 | **화계 제거**, 원래 고유 3개 백출·화공·독려 유지. B02의 화계서는 그대로 둔다. | B02는 스폰에서 화신·백출과 화계서를 별도 지정하며, 화계서가 화신의 선행 화계를 제공한다. 보병 공통 계획을 바꿀 필요가 있다는 이전 제안은 B02 기준 오류였다. 장비 없는 다른 실제 출현은 따로 확인한다. |
| 허사 | 화계 제거, 원래 귀모·화공·선견 유지. NPC 순서 귀모→선견→화공. | 31레벨 권사 Plan에 화계가 없다. 권사 Plan에서 기존 항목을 화계로 교체할지, 화공을 늦출지 결정 필요. 권성에서만 화계를 앞당겨도 20~39레벨 권사는 해결되지 않는다. |
| 번궁 | 화계 제거, 원래 보법·화공 2개 유지. | NPC 계획상 화공이 16레벨인데 무도가 Plan에 화계가 없다. 무도가의 기존 계획 재배치, NPC 화공 시점 변경 또는 고유 특성 교체 중 선택이 필요하다. 플레이어는 병종 학습 목록에서 화계를 배울 수 있다. |
| 순유 | 수계 제거. 고유 수공·백출과 별도 박학은 유지. 예: `Traits`는 백출, `TraitAt`은 기존 박학(20)에 수공(20)을 추가해 고유 2개를 보존하는 안. | 20레벨 책사 승급 시 Plan의 수계(15)가 갖춰지는지 확인. 수공은 1→20레벨, 백출은 16→1레벨로 바뀐다. `TraitAt`도 고유 특성이며 새 특성 추가가 아니라 기존 수공의 배치 이동이어야 한다. |
| 법정 | 지계 제거. 원래 격파·지공·보복·산악지형보조 4개를 유지하되 NPC 순서를 격파→보복→지공→산악지형보조로 바꾸는 안. | 지공은 31레벨, 그때 책사 지계(20)를 가진다. 보복은 31→16으로 빨라진다. 실제 승급·스폰 덮어쓰기를 테스트. |
| 하후연 | 저지 사격 제거. 저지 강화·추행진·기습의 고유 종류를 유지. 기존 별도 저지 강화(40)를 살리고 개인 계획을 추행진→기습으로 두는 안. | 개인 계획에서 중복된 저지 강화를 빼므로 고유 *종류*는 3개지만 배열 구성은 바뀐다. 노기병은 저지 사격(40)을 갖고 저지 강화도 40에 열린다. 1레벨에 저지 강화가 있던 기존 설정은 포기한다. 실제 등장 레벨과 기습 시점 변화를 검증. |
| 유벽 | 지계 제거, 산악지형보조·지계강화 2개 유지. | 기존 순서면 16레벨 적병에서 지계강화가 먼저 나온다. 적병/흉적의 계획에 지계를 기존 항목과 교체해 선행으로 둘지, 지계강화 시점을 늦출지 선택해야 한다. 의적의 지계(30)만으로는 16레벨 문제가 해결되지 않는다. |
| 유비 | 부관임명 제거, 독려·의협·용인술·호운·패기 5개 유지. | 중보병/근위병 학습 목록에는 부관임명이 있지만 NPC 자동 Plan에는 없다. NPC 용인술 전에 병종 Plan에 제공하는 방법과 그에 따라 교체될 병종 항목을 결정해야 한다. 모든 해당 병종 NPC가 영향을 받는다. |
| 정욱 | 독공을 반드시 보유. 원래 3개를 유지하려면 예시로 유계→독공→짐독을 두고 격파를 뺀다. | **격파를 잃는 제안**이다. 정욱의 기존 3개를 모두 보존하면서 독공까지 두면 4개가 되므로 어느 쪽을 택할지 결정 필요. |
| 이유 | 예시: 간파→독공→짐독으로 3개 유지. | **혼란을 잃는 제안**이다. 간파를 뺄지 혼란을 뺄지 또는 4개를 허용할지는 정해야 한다. |
| 심배 | 예시: 대비→중갑→반계로 3개 유지. | **군율을 잃는 제안**이다. 군율을 남기고 다른 특성을 바꾸는 대안도 있다. NPC·플레이어 배치와 캐릭터 의도를 비교해야 한다. |
| 육손 | 기존 별도 고유 2개가 중갑·명가였고 제가 대비를 추가해 3개가 됐다. | 2개만 유지하려면 예를 들어 대비+중갑으로 하고 **명가를 빼거나**, 중갑을 빼고 명가를 남겨야 한다. 어떤 역할을 남길지 결정이 필요하다. |
| 우금 | 군율→엄명→호위. | 원래 3개를 유지하고 군율이 먼저다. 다만 엄명과 호위의 획득 시점이 바뀌었으므로 실제 등장 레벨을 검토한다. |
| 연노병 | 추가한 저격 49를 그대로 더하지 않고 기존 여섯 자리에서 배치하는 안: 공격명중률증가(10)·화시(20)·구휼(30)·저격(40)·관통(50)·원시(60). | **기존 연발(40)을 잃는 제안**이다. 연발을 보존하려면 다른 병종 특성을 교체하거나 총 7개를 허용해야 한다. 해당 병종 모든 NPC 영향. |

병종 계획에는 위 외에도 선행이 필요한 특성이 있으므로 교체안은 실제 전 데이터 검사를 다시 돌려야 한다. 예를 들어 중갑의 대비를 지우거나 옮기면 다른 선행 관계가 새로 깨질 수 있다. 한 인물의 문제를 고치려고 병종 Plan을 바꿀 때는 전체 병종 사용자와 레벨별 특성 수·빠지는 특성·실제 출현 레벨을 표로 보고, 예외 없이 중복·선행 두 테스트가 함께 통과해야 한다. 현재 여기는 제안이지 해결 완료가 아니다.

## 작업 범위와 현재 상태

- 실행 코드/게임 데이터는 이번 제안에서 수정하지 않았다. 복구한 중복 테스트만 바뀌었다.
- 고유 특성/병종 계획을 실제로 바꾸는 것은 제안에 대한 결정 이후다.
- 중복 검사 실패가 남아 있으므로 관련 테스트는 현재 실패 상태다. 이 실패를 감추거나 기존 검사를 다시 완화하지 않는다.

## 정정: 황보숭의 화계서

사용자가 지적한 대로 B02 황보숭은 화계서를 장착해 화계를 얻는다. 실제 스폰은 화신·백출을 별도 지정한다. 선행 테스트 설계에는 실제 스폰의 장비·특성 덮어쓰기와 등장 레벨이 반영되어야 한다. 자세한 확인은 [화계서 조사](../huangfusong-fire-manual-review/result.md).

## 2026-11-26 사용자 결정 반영

이전 표의 예시 중 정욱·이유·허사·순유·하후연·심배·육손·우금·연노병·B02 황보숭에 대한 최신 기준은 [사용자 결정 반영안](../trait-correction-user-decisions/result.md)을 따른다. 특히 저격은 궁병 학습 목록에 있고 승급 시 상속되며, NPC 병종 Plan과는 별도로 판정한다. 기존 표의 연발 교체는 사용자가 승인한 결정이 아니다.
