# 사용자 결정 반영: 특성 수정안

이전의 “수정안부터” 지시에 따라 제안·검토만 했으며, 아래는 아직 게임 데이터에 적용하지 않았다. 이름을 확인한 결과 귀모는 책략 사거리 +2, 선견은 전투 시작 병법치 1/4, 십자사격은 선택한 적과 상하좌우를 쏘는 병법이다. 십자사격은 원거리 기본 물리 공격을 십자로 만드는 사방격(원)과 다르다.

## 사용자 지정 고유 특성

| 대상 | 고유 특성 | 계획 시점 제안 / 검토 |
|---|---|---|
| 황보숭 B02 | 스폰 화신→화공, 백출 유지 | 화계서는 그대로 장착하므로 화공의 선행 화계가 있다. 일반 개인 목록에 잘못 넣은 화계는 뺀다. 보병 병종 전체의 화계 계획을 바꾸지 않는다. |
| 허사 | 화공·선견 | 귀모와 개인 화계를 제거. 2개를 1·16 중 어떻게 배치할지 및 NPC가 화공 전에 화계를 갖는지는 별도 검증 필요. 화계는 무도가 계열의 학습 목록이지만 NPC 자동 Plan과 다르다. |
| 순유 | 수공·백출·박학·귀모 | 책략 사거리 +2는 귀모가 맞다. 예시: 백출(1)·귀모(16)·수공(31), 기존 별도 박학(20). 31레벨 NPC는 책사 Plan의 수계(15)를 받는다. 실제 등장 레벨과 스폰 장비·덮어쓰기 확인 필요. |
| 하후연 | 기습·추행진·십자사격·저지 강화 | 예시: 기습(1)·추행진(16)·저지 강화(31)·십자사격(46). 저지 강화 선행 저지 사격은 궁기병 Plan 20에서 제공되는지 실제 승급과 출현 시점 검증. 기존 TraitAt 저지 강화(40)는 이 계획에선 중복이므로 정리 대상. |
| 정욱 | 격파·유계·독공 | 사용자 지정 3개. 짐독은 제외. 개인 계획 순서는 변경 영향 검토 후 결정한다. |
| 이유 | 간파·독공·짐독 | 사용자 지정 3개. 짐독은 독공 뒤로. 기존 혼란은 제외한다. |
| 심배 | 대비·중갑·반계 | 직전 수정안의 ‘군율을 빼고 대비·중갑·반계 3개 유지’를 사용자가 맞다고 한 것으로 해석. 대비는 중갑보다 먼저. |
| 육손 | 고유 중갑·명가 유지 | 잘못 추가한 개인 TraitAt 대비는 제거. 도독 병종에서 대비를 제공. |
| 우금 | 군율·엄명·진지고수 | 군율→엄명→진지고수로 3개. 호위 제외. |

최종 개인 Plan의 레벨은 사용자 지정 순서와 같아야 한다고 가정하지 않는다. 실제 등장 레벨, 선행 및 개인 특성 수를 기준으로 정하고 적용 전에 표를 보여야 한다. 플레이어블 장수는 NPC 계획대로 자동 취득하지 않는다.

## 도독의 대비

- `dudu.Pool`에 대비를 더해 플레이어가 배울 수 있게 한다.
- NPC 도독도 육손 중갑(25)보다 먼저 보유해야 하므로 `dudu.Plan`에 대비를 배치하고, 개인 TraitAt 대비는 제거한다. 예시 20레벨. 단, 기존 도독 Plan에 단순 추가하면 **도독 전체 NPC 특성 수가 하나 증가**하므로, 기존 자리와의 교체 또는 수 증가 허용을 결정해야 한다. 현재 도독 인물은 주유·육손·여몽이다. 이들을 모두 레벨별로 비교한다.

## 궁병 → 노병 → 연노병과 저격

- 궁병 `Pool`: 구휼·공격명중률증가·조준·저격. 노병과 연노병은 승급 계열의 학습 목록을 상속하므로 플레이어는 저격을 계속 배울 수 있다.
- NPC `Plan`은 별개다. 현재 궁병 Plan은 명중 증가(10), 노병 Plan은 명중 증가(10)·화시(20), 연노병 Plan은 그 뒤 구휼(30)·연발(40)·저격(49)·관통(50)·원시(60)이다. 49레벨 저격은 이 세션이 추가한 것이다.
- 사용자 지적대로 49에 별도 저격을 무조건 하나 더 넣은 것은 병종의 기존 6개 계획을 7개로 늘리는 잘못이었다. 49 추가를 우선 철회 대상으로 둔다. 단순 철회만 하면 NPC 연노병 관통(50)의 선행 저격이 실제 Plan에서 없어 테스트가 실패한다. `Pool`을 Plan 보유로 간주하는 것은 잘못이다.
- 따라서 6자리 안에서 NPC 저격을 관통보다 먼저 배치해야 한다. 예: 30레벨 구휼을 저격으로 바꾸면 6개가 되지만 연노병 NPC가 구휼을 잃는다. 40레벨 연발을 저격으로 바꾸면 연발을 잃는다. 또는 기존 특성 유지와 7개 허용 중 선택이 필요하다. 어느 것을 잃게 할지 사용자 결정 없이 확정하지 않는다.

## 기존 검사와 실제 등장

- 병종 학습 목록과 장수 개인 특성의 중복 금지 검사는 이미 복원했으며 현재 8건 실패 중이다. 실패를 감추지 않는다.
- 실제 스폰에서 선행을 검사할 때에는 `Traits`·`Equipment` 덮어쓰기, 장비 효과, 실제 등장 레벨·승급 병종을 함께 확인한다. B02 황보숭의 화계서가 해당 사례다. `1~99` 가상 개인 계획 검사만으로 실제 보유를 단정하지 않는다.
- 직접 지정하지 않은 유비·유벽·황보숭·번궁·법정 등의 이전 중복 수정안도 남아 있다. 개인 병종 중복을 먼저 제거하되, 보유 특성 수와 NPC 선행 충족이 어떻게 달라지는지 전후 비교한다.
- 구현 전 변경표에는 고유 수·개인/병종 Plan·TraitAt·대체되는 특성·영향받는 다른 인물·실제 등장 스폰을 함께 적고, 이후 복원된 중복 검사와 실스폰 선행 검사 양쪽을 돌린다.

## 연노병 사용자 결정 반영

연노병 NPC Plan은 사용자의 후속 지시대로 저격(50)·관통(60)·원시(70)으로 실제 수정했다. 49레벨 저격 추가안과 위에서 나열한 기존 항목 교체 예시는 더 이상 적용 대상이 아니다. [변경 결과](../repeating-crossbow-trait-order/result.md)
