## 바꾼 것
- 맵 분리: 여울을 하류로 14칸 더 내림. 둑 장면 → 여울 장면은 컷(1.6초). 두 곳은 한 화면에 안 잡힌다.
- 바위: 협곡 언덕과 둑을 물과 같은 높이장 도트로 그림. 절벽 타일·자루 그림 삭제.
- 관우·미축: 둑 위쪽 언덕 꼭대기에서 좌하단(SW)을 봄.
- 4배율: 둑 장면, 여울 장면 모두. 말풍선은 2배(`SpeechScale`).
- 병사 둘이 상류로 돌아서 "물이다!"(1.68초), "피해라!"(1.95초).

## 남은 점
- 언덕 위 관우·미축에 그림자가 없다(땅 높이 그림자가 바위에 가려짐).
- 외치는 병사는 우상단(상류)을 본다. 정확히 오른쪽은 아니다.
- 대사: 대본(c25-e06)은 "……터라.", 데모는 "무너뜨려라!". 미정.
- 대본은 밤 장면, 데모는 낮. 25장 이야기 장면에는 미연결.
- 시트 2048×1661, 재생 중 VRAM 약 14MB(계산값). 커밋 안 함.
