# 스크롤 입력 조사·부분 수정

- 공통 표 `drawTable`의 휠 영역 등록을 공통화해 저장·불러오기, 인수 대상, 소지품 등의 표에도 포인터가 표 위일 때 휠 입력을 연결했다. 부관 선택·출전 장수 표의 기존 중복 등록은 제거했다.
- 전투 기록 본문에서 마우스/터치 드래그로 내용을 스크롤하도록 수정하고, 드래그 방향·해제를 검증하는 테스트를 추가했다.
- 기존 공통 표·일반 목록·특성 카드·이동 지점 목록에는 본문 드래그 코드가 있고, 전투 기록은 이전에 휠·스크롤바만 지원했다. 터치 입력은 공통 포인터를 통해 왼쪽 버튼으로 전달된다.
- `go test -p 1 -run 'TestTable|TestBattleLog|TestBrowser|TestSortieDeputy' -count=1 ./internal/gui` 통과. HUD 화면 `capture/frame-0060.png`·`frame-0120.png` 캡처했으나 실제 터치 스와이프·휠 입력이나 관성은 캡처로 검증하지 못했다.
- 스크롤바가 나타나는 모든 화면의 입력 전수 점검과 터치에서 손을 놓은 뒤의 관성 스크롤은 아직 완료되지 않았다. 후속 요청에 명시했다.
