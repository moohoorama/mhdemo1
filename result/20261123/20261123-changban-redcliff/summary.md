# 연의 장판파와 적벽 개편 결과

기존 변경은 `fee63ab`에 체크포인트로 커밋했다. 새 구현과 검증 결과는 작업 트리에 남겼다. [구현 계획](../../../ver5/plan/changban-redcliff.md) · [요청 기록](../../../process/20261123-changban-redcliff/20261123-changban-redcliff.md)

- **장판파**에서는 조운과 장비가 필수이며 두 장수까지 더 출전한다. 유비는 출전하지 않는다. 잔류 보병 6기가 HP 66%로 시작한다. 장비는 다리에서 이동이 고정되고, 조운이 후방에 도착하면 하후돈이 나선다. 양쪽의 교전과 하후돈의 강릉 우회 뒤 장비가 진영에 도착하면 승리한다. 하후은 일기토로 청강검을 얻을 수 있다.
- **강하·번구** 왕복에서 부하 재회, 전갈, 오군과의 합동 작전 회의, 강하 관청의 정비 확인과 암전 두 차례를 연결했다. 출전 전에 관우·장비·조운은 전원 화용도 복병으로 떠난다.
- **적벽**에서는 황개의 화공과 동남풍, 오군 진격, 조조군 혼란과 북쪽 퇴각을 같은 전장에서 보여 준다. 장윤의 수군은 화공을 피하고 강하 앞 수로를 막는다. 조조가 탈출해도 기본 승리하고, 장윤 격파 보상은 소량으로 뒀다.
- **화용도 전투**는 삭제했다. 강하에서 유기 부상과 화용도 성과를 보고하고, 관우의 군령 위반과 유비·공명의 책임 인정, 잔치 뒤 2장을 닫는다. 제갈량의 무릎 꿇는 도트를 추가했다.

## 검증

- 보통 난이도 CLI 한 세이브에서 장판파 5턴 승리와 청강검, 적벽 7턴 승리, 군령 보고와 2장 종료를 확인했다. [장판파 로그](cli/changban.log) · [적벽 로그](cli/redcliff.log) · [이야기 로그](cli/story.log)
- 적벽의 장윤 격파와 수로 돌파를 별도 플레이로 확인했다. 대기만 한 밸런스 실행에서도 3시드 모두 조조 퇴각으로 승리했다.
- 장판파·적벽 회귀 테스트, 양 루트 캠페인 진행, 스테이지 순서 변경 후 저장 복원, GUI 문구·장면 동선·탐험, 스프라이트 내보내기 테스트가 통과했다.
- 실제 게임 화면에서 [장판교 교전](changban-final/frame-0520.png), [적벽 화공](redcliff/frame-0720.png), [유비와 제갈량의 무릎 꿇기](kneel/frame-0160.png)를 확인했다.

전체 스위트에는 기존 강하 일기토·웨이포인트 및 장면 배치 테스트 실패가 남아 있다. 공유 작업 트리의 수공 데모는 콘텐츠 독립성 검사에서 별도로 실패했다. Ollama 서버가 실행 중이지 않아 이야기 검색 인덱스 재생성은 완료하지 못했다. 개편 전 장판파·적벽 전투 중 저장에는 새 전장과 배치가 반영되므로 출전 전부터 다시 진행하는 편이 안전하다.
