## 남은 일

1. 스크롤바가 그려지는 모든 화면 목록 작성 (코드와 실제 화면 기준).
2. 화면별 본문 드래그, 터치 스와이프, 휠, 스크롤바 드래그 지원 여부 기록과 누락 수정.
3. 터치 후 관성과 경계 정지, 클릭과 스크롤 구분, 중첩 팝업 입력 충돌 확인.
4. 회귀 테스트와 대표 화면 게임 캡처.

## 확인이 필요한 점

- 범위가 크다. 전 화면을 모두 고칠지, 본문 목록이 있는 화면부터 할지 정해 주면 그 순서로 진행하겠다.
- 관성 스크롤은 기존 목록 코드에 없는 새 동작이라 설계 문서가 먼저 필요하다. 프로젝트 지침상 3개 이상 파일을 바꾸므로 설계 문서를 먼저 쓴다.
