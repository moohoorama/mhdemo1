# 계교 전투 문추 출연 조건 확인

- `ver5/assets/scenario/hero/stage10.json`의 `ambush`: 적군 차례가 시작되는 순간 유비·관우·장비·조운 중 한 명이 영역 1 안에 있거나 라운드가 4 이상이면 문추와 기병 셋이 등장한다. 4라운드 이전에는 해당 장수가 적군 차례 시작까지 영역 안에 있어야 한다.
- 영역 1은 여울 전체가 아니라 다리 동쪽 머리의 X 13~15, Y 6~10이다. 다른 장수는 해당 조건에 포함되지 않는다.
- 등장 지점은 문추 (8,15), 기병 (8,14), (8,16), (9,15)를 기준으로 가장 가까운 배치 가능한 빈 칸이다. 배치할 칸이 부족하면 이벤트가 보류된다.
- 이동 직후 아직 행동을 마치지 않았다면 이벤트 검사는 건너뛴다. 이 이벤트는 행동 종료뿐 아니라 적군 차례 시작도 필요하다.
- 검증: 스테이지 데이터와 전투 이벤트 규칙 문서를 확인했다. 실제 저장 상태와 게임 실행 화면은 확인하지 못했다. 조건 확인 요청으로 코드나 전투 데이터를 바꾸지 않았다.
- 기존 감시 프로세스가 요청을 중복 수신할 수 있어 요청 기록을 process/에 직접 남겼다.
