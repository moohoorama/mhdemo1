# 공통 스크롤 영역 검토와 HTML 시안

가능하다. `sortie_unified.go`의 출전 부대는 `listRows`에 pick=nil을 전달하며, `ui_kit.go`의 `listRows`는 pick이 있을 때만 행 드래그를 등록한다. 카드 내부의 별도 버튼이 선택을 처리하므로 출전 카드·빈 영역에서 본문 드래그가 시작되지 않는 원인이다. 휠 영역은 목록 전체에 등록되어 있지만, 실제 해당 화면·기기에서의 휠 동작은 실행해 확인하지 않았다.

공통 스크롤 영역이 스크롤 위치·범위, 휠, 본문 포인터 드래그, 스크롤바, 터치 관성 및 중첩 입력 우선순위를 관리하고, 짧은 누름만 자식 버튼으로 전달하는 방식을 제안한다. 기존 고정 헤더·역순 전투 기록·가변 높이 카드·중첩 창·텍스트 입력·스크롤 중 화면 전환을 고려해야 한다. 모든 화면이 같은 위치·방식으로 그리는 것은 아니므로 기존 목록·표·기록을 점진적으로 공통 입력 영역에 연결해야 한다.

`index.html`은 브라우저에서 휠·터치·마우스 드래그와 카드 선택을 시험하는 독립 시안이며, 실제 게임 화면이나 구현이 아니다. 브라우저 기본 터치 관성에 의존하므로 게임의 동일한 동작을 보장하지 않는다. 이전 전수 수정 요청은 `process/20261123-scroll-input-audit/`에 별도로 존재한다.
