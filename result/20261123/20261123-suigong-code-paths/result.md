# 수공 데모 코드 경로 확인 결과

요청은 조회 기록 문서였고 수행할 변경은 없었다. 요청에 적힌 경로가 디스크에 실제로 있는지만 확인했다.

- ver5/tools/floodsim.py (물 시뮬레이션·에셋 생성)
- ver5/internal/gui/uidemo_suigong.go (데모 구성)
- ver5/internal/gui/field_surge.go (물 연출 로딩·그리기)
- ver5/internal/gui/field_surge_test.go (관련 테스트)
- ver5/assets/graphics/effects/flood/ (생성 에셋)
- result/20261123/suigong-3sec-two-shots/suigong.mp4 (영상)

확인 결과 위 6개 경로 모두 존재한다. 바꾼 파일 없음, 테스트·빌드 실행 안 함.
