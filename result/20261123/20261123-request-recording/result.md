- 사용자가 요청할 때마다 `~/orca/mhdemo1/request/`에 알아볼 수 있는 이름의 Markdown 파일로 요청을 정리한다.
- 사용자가 특정 요청의 수행 방법이나 결과를 물으면 `~/orca/mhdemo1/result/YYYYMMDD/`의 해당 기록을 찾아 설명한다.

## 수행
- 이 요청은 앞으로의 작업 규칙을 알리는 내용이라 코드·데이터 변경은 없다.
- 이 규칙을 확인했고, 결과 폴더(`result/20261123/20261123-request-recording/`)에 이 기록을 남겼다.
- 확인한 현재 상태: `request/` 폴더는 비어 있고(처리된 요청은 `process/`로 이동됨), `result/20261123/`에는 `20261123-request-recording`, `request-recording`, `events-ui-fixes`, `suigong-3sec-two-shots`가 있다.
- 요청 파일은 `request-recording`이라는 이름의 결과 폴더도 지정했는데(`result/20261123/request-recording/`), 이번 지시의 결과 폴더는 `20261123-request-recording`이라 후자에 기록했다. 두 폴더가 따로 있는 점은 알려 둔다.
