# 스프라이트 제작 기준

스프라이트의 제작·수정·후보 비교 전에 이 문서와 대상 에셋의 설정을 읽는다.
공통 기준에 종류별 추가 규칙을 적용한다. 셀 크기나 특정 동작의 프레임 수는
공통 상수가 아니라 개별 에셋의 설정이다.

## 모든 스프라이트

- 셀 크기, 좌표 원점, 배치 기준점, 프레임 순서, 팔레트와 재생 시간을 명시한다.
- 기준점은 이미지 경계 상자의 중앙이 아니라 실제 부착·접지 위치다. 프레임마다
  자동 trim/중앙 정렬하지 않는다. 식물은 뿌리, 물건은 바닥 등 의미 있는 지점을 쓴다.
- 모든 프레임을 같은 좌표계에 배치한다. 의도한 동작의 이동과 정렬 오류를 구별한다.
  바닥에 붙어 있는 부분은 고정하고, 점프 등 의도한 이동은 설정에 기록한다.
- 같은 물체의 크기와 부피는 유지한다. 프레임별 바운딩 박스에 맞춘 개별 확대·축소를 금지한다.
- 기준 도트의 색과 픽셀 덩어리를 재사용한다. 거의 움직이지 않는 부분은 직전 프레임과
  같은 패턴을 유지한다. 정수 픽셀 이동을 우선하며, 큰 회전·가림에 필요한 변화만 허용한다.
- 작은 해상도의 완성 도트를 제작한다. 축소만으로 흐려진 결과를 완성본으로 삼지 않는다.
  확대 표시는 최근접 정수 배율을 쓰고, 임의의 새 색·블러·디더링을 추가하지 않는다.
- 배경은 실제 알파 투명이다. 투명처럼 보이는 체크무늬를 이미지에 그려 넣지 않는다.
  별도 반투명 효과가 없는 도트는 알파 0/255를 사용한다.
- 장비·효과·반동까지 셀 안에 들어가게 여백을 확보한다. 각 프레임의 가장자리 잘림과
  떨어진 잡픽셀을 확인한다.

## 캐릭터 추가 규칙

- 기준 머리 또는 투구 크기로 방향·프레임별 크기를 통일한다. 몸 전체 경계로 정규화하지 않는다.
  원근·방향에 따른 형태 차이는 허용하되 머리와 몸의 비율이 흔들리지 않아야 한다.
- 눈이 세로 2픽셀인 등 식별 특징은 작은 움직임 동안 그대로 유지한다. 머리·갑옷·장비를
  프레임마다 새로 그려 패턴이 깜빡이지 않게 한다. 약 15도 이상의 명확한 회전처럼
  투영이 바뀌는 경우에만 필요한 패턴을 수정한다.
- 발밑 배치 기준점을 고정한다. 걷기에서 발 자체의 의도한 보폭은 허용하지만 캐릭터 전체가
  좌우로 밀리는 정렬 오류는 허용하지 않는다.
- 대기는 기준 자세에 작은 호흡을 넣는다. 발을 고정하고 크기 변화 없이 상체만 움직인다.
- 걷기는 좌우 다리와 반대쪽 팔이 함께 움직인다. 발을 모으는 통과 자세를 포함하고,
  프레임 수만 늘린 두 자세의 반복이 되지 않게 한다.
- 피격은 피격 전·충격·회복이 구별되어야 한다. 반동은 관절과 자세로 표현하고 몸을 늘려
  대신하지 않는다. 공격과 혼동되는 검 휘두르기를 넣지 않는다.
- 탈진은 기준 자세를 유지한 가쁜 호흡으로 표현한다. 크기를 반복 확대·축소하지 않는다.
- 동작 이름, 순서, 프레임 수, 충격이 일어나는 프레임, 속도는 개별 에셋 설정을 따른다.

## 후보와 최종 결과 검수

후보도 최종본과 같은 셀·기준점·크기로 정렬한 뒤 보여준다. 생성 시트를 균등하게 잘랐다는
이유만으로 내부 캐릭터가 정렬되어 있다고 가정하지 않는다. 생성 결과는 먼저 실제 접지점과
머리 크기를 확인한다. 후보의 자세 선택과 최종 도트의 품질 검증은 별도로 수행한다.

기준점 표시, 정지 프레임 나열, 반복 재생으로 확인한다. 접지 부분 고정, 크기 일관성,
변하지 않는 부위의 픽셀 일치, 루프 연결, 투명도와 잘림을 검수한다. 픽셀 일치율을 계산할 때는
빈 배경을 제외하고, 움직이는 부위와 고정 부위를 구분한다. 전체 일치율만으로 움직임을 평가하지 않는다.

원본과 에셋 설정은 `tools/spritetool/assets/`, 최종 런타임 파일은 `assets/`에 둔다.
프로젝트 전용 제작 코드는 범용 `tools/spritetool` 코드 밖에 둔다.
