# 후보 A — 영걸전 클래식

정사각 탑다운 격자에 24×24 지형 타일을 쓰고 화면에서 정수 2배(48px)로 표시한다. 부대는 약 2.5등신 SD 캐릭터다. 색은 청람·옥록·황토·동금·상아에서 고른 제한 팔레트이고, 외곽선은 짙은 남색 1px로 통일했다. UI는 화면 하단 정보창(초상·이름·병종·Lv·병력/병법/경험 막대와 수치·능력치·공격 예상) 하나에 모으고, 행동 메뉴는 전장 왼쪽 위에 작은 창으로 띄운다. 좌우 여백은 지형 정보와 부대·전투 기록에 쓴다. 정보를 빨리 읽고 향수를 주는 것을 목표로 한다.

재생성: `python3 art-candidates/A/gen.py` (ver2/에서 실행, Python3 + Pillow, 결정적)

## 규격

| 항목 | 값 |
|---|---|
| 부대 셀 | 24×28, 원점 왼쪽 위 |
| 기준점 | (12, 25) — 발/말발굽 외곽선의 가장 아래 행. 타일 (12, 22)에 맞춰 배치하므로 머리는 타일 위로 4px 넘친다 |
| 지형 타일 | 24×24 |
| 표시 배율 | 2 (최근접) |
| 초상 | 32×36, 표시 배율 3 (하단 정보창에서 아래 수 px 잘림) |
| 방향 | 원화는 오른쪽을 본다. 적은 좌우 반전 |
| 알파 | 0/255만 사용 |

| 스프라이트 | 행 | 동작(시작 열, 프레임, ms) |
|---|---|---|
| infantry-ally (경보병, 청색, 검) | 0 | idle(0, 8, 140), walk(8, 8, 100) |
| cavalry-ally (경기병, 청색, 창, 갈색 말) | 1 | idle(0, 8, 150), walk(8, 8, 100) |
| bandit-enemy (황건 적병, 적색 상의, 황색 두건) | 2 | idle(0, 8, 140) |

- idle: 상체·머리만 1px 내려가는 호흡 `[0,0,0,1,1,1,0,0]`. 발 행(22–27)은 8프레임 모두 픽셀이 같다. 기병은 말 머리가 4–5프레임에 1px 숙인다.
- walk: 접지 → 내려감 → 통과(발 모음) → 올라감의 8프레임이다. 앞발 오프셋 `[3,2,0,-2,-3,-1,1,2]`, 뒷발은 4프레임 위상차, 앞으로 나가는 발은 1px 든다. 팔은 같은 쪽 다리와 반대로 흔든다. 말은 대각 쌍(뒤-근/앞-원)이 교대로 움직인다.
- 각 부위는 고정 픽셀 맵이나 선으로 그린다. 부위마다 1px 외곽선을 붙여 그리는 순서대로 합성하므로, 움직이지 않는 부위는 프레임 간 패턴이 같다.

## 화면 목업 (`out/screen.png`, 1280×850)

부록 B의 B01 황건적의 난(18×14) 맵 전체를 그렸고, 배치는 실제 데이터 좌표를 따른다. 예외로 `B01_troop_3`만 (9,6)에서 (8,6)으로 한 칸 옮겼다. 공격 예상을 보여 주려고 관우 이동 범위 안에 두기 위해서다. 화면에 담은 요소는 다음과 같다.
- 관우 선택 커서, 이동 5 범위의 청색 오버레이(지형 비용과 적 점유 반영), 이동 경로 점, 적색 공격 대상
- 행동 메뉴(공격 선택, 일기토 비활성), 피해 숫자 `-86`
- 행동을 마친 유비는 회색 처리
- 진영 깃발과 부대 아래 병력 막대

수치(병력 420 등)는 목업용 예시이며 런타임 공식으로 계산한 값이 아니다. 산 타일은 맵에 없어서 왼쪽 "지형 견본"에만 넣었다.

## 장점

- 타일 한 칸에 부대 하나가 또렷하게 들어간다. 2배 표시에서도 진영·병종·행동 완료 여부를 즉시 구분할 수 있다.
- 셀이 작아 8프레임×5동작 전장 원화와 장수별 변형을 만드는 비용이 낮다. 부위 조합 방식이라 일관성을 유지하기 쉽다.
- 정보창이 하단 하나여서 전장 면적이 넓고, 영걸전 특유의 깔끔한 화면 리듬에 가깝다.

## 한계

- 24px SD 해상도에서는 장수 개성(관우 수염, 장비 얼굴 등)이 전장 스프라이트에 거의 드러나지 않는다. 지금은 이름 있는 적도 일반 적병 원화를 쓴다.
- 조조전 수준의 정교한 갑옷 질감, 비스듬한 원근, 큰 공격 동작을 기대한다면 밀도가 부족하다.
- 초원이 대부분인 B01 맵에서는 화면이 단조롭다. 길·풀숲·지형 경계 전이 타일을 더 만들어야 한다.
- 초상은 32×36 도트로 소박한 편이다. 시나리오 대화창용으로는 더 큰 초상(예: 64×80)이 별도로 필요할 수 있다.
- 공격·피격·탈진 3동작은 아직 만들지 않았다(후보 범위 밖).
