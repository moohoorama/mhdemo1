# Southwest hit-reaction candidates

`SW-hit-options.png` is a built-in ImageGen comparison sheet, four columns by
four rows, based on `../knights-pixel-v3/SW-pixel.png`. This is an animation
concept preview, not the final native-resolution game atlas.

Rows: 1 backward arch, 2 sideways twisting flinch, 3 gut-hit knee buckle,
4 airborne knockback. Columns: neutral, neutral, impact, partial recovery.

Prompt specification: retain the southwest-facing knight's helmet, red plume,
blue armor, gold visor, brown shield/boots and passive sword. Create four
distinct exaggerated reactions to a blow coming from lower left. Keep poses
inside equal cells with actual alpha transparency. No blood, attack trails,
impact symbols, text, shadows or background. Maintain pixel-cluster styling;
articulate rigid parts rather than stretch the body.

Preview: `/knight-hit-candidates.html` at the repository's local HTTP server.
The existing runtime atlas remains unchanged pending the user's selection.
