# 기사 에셋 설정 · v4

먼저 [스프라이트 제작 기준](../SPRITE_ART_GUIDE.md)의 공통·캐릭터 규칙을 적용한다.

| 항목 | 값 |
|---|---|
| 종류 | 캐릭터, 기사 |
| 셀 | 48×48, 왼쪽 위 원점 |
| 발밑 배치 기준점 | (24,38), 방향·동작 공통 |
| 방향 순서 | N, NE, E, SE, S, SW, W, NW |
| 시트 | 방향별 4열×5행, 192×240 RGBA |
| 동작 행 | 대기, 걷기, 공격, 피격, 탈진 |
| 머리 기준 | v2에서 정규화한 투구, 기하평균 크기 10px; 방향별 원근 형태 보존 |
| 팔레트 | frames.json의 28색, 알파 0/255 |
| 런타임 | assets/knights.png, 16열×10행, 768×480 |

대기는 1px 호흡, 걷기는 좌우 접지·통과 4자세와 반대쪽 팔 움직임,
공격은 승인된 원본, 탈진은 첫 자세 기반의 빠른 1px 호흡이다.
이 네 동작은 v3에서 픽셀 그대로 보존한다.

피격은 사용자가 선택한 SW 후보 1번의 뒤로 젖힘이다. 1·2프레임은 같은 기준 자세,
3프레임은 큰 반동, 4프레임은 부분 회복이다. 하체·발은 그대로 두고 상체를
골반 중심으로 회전시킨다. 측면·대각선 충격 회전은 24도, 회복은 12도다.
정면·후면은 깊이 방향의 반동을 작은 세로 이동과 벌어진 팔로 표현한다.
큰 회전 부분은 최근접 회전으로 필요한 도트 변화가 생길 수 있으나 확대·축소하지 않는다.
후보 시트의 중심이나 크기는 복사하지 않고, 기존 네이티브 도트를 사용한다.

재생 간격(ms): 대기 400/400/400/400, 걷기 180/180/180/180,
공격 250/250/250/250, 피격 220/220/150/280, 탈진 180/220/180/220.

```sh
python3 tools/knight_hit_backarch.py
python3 tools/build_knights.py
```

원본 v3와 선택용 ImageGen 시트 `../knight-hit-candidates/SW-hit-options.png`는 보존한다.
제작 코드는 `tools/knight_hit_backarch.py`이며 범용 spritetool은 crop과 packing만 한다.
