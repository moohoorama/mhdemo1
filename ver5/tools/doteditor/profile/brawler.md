# 무도가 (`brawler`) 특징 프로필

## 1. 한 줄 요약

무도가(무도가 → 권사 → 권성의 첫 단계). 적병 도트(`units/bandit.yaml`, 56×46, 기준점 28,38)에서 그리는 전투 도트다.
요청: **대머리, 칼 없이 맨주먹, 근육질 팔(전완근·이두근·삼두근이 1px씩 두꺼워지는 방식으로 표현)**.
48px에서 보여야 할 것은 세 가지다. **① 머리카락과 두건이 없는 민머리, ② 칼 대신 쥔 주먹, ③ 적병보다 1px씩 굵고 굴곡이 보이는 팔**.
장수(관색·조창·허저·전위·주태·능통·하만 등)의 시작 병종이기도 해서, 진영색은 **허리 띠**로 옮긴다(두건이 없어졌으므로).

기준 시트는 **적병**이다. 적병의 머리 크기, 몸통 높이, 다리·발, 삼베 윗옷과 바지, 기준점, 외곽선을 그대로 쓰고, 아래만 바꾼다.

## 2. 색과 태그 배정

적병 도트 색 설정을 이어받는다(hair·themeA·themeC는 적병 값). 새로 바꿀 색은 없다.

| 부위 | 태그 | 비고 |
|---|---|---|
| 민머리 윗면·이마·얼굴·목·손·팔 | **피부** | 머리 윗면은 피부1(빛)·피부2. 머리카락 태그는 쓰지 않는다 |
| 허리 띠(1–2행 + 옆으로 늘어진 끝 2–3px) | **진영색** | 적병의 두건 자리를 이어받는 진영색. 허리에 한 줄로 크게 둬서 맵에서 진영이 읽히게 한다 |
| 소매 없는 삼베 윗옷, 바지 | **테마 C (삼베)** | 적병 그대로 |
| 발 감개, 신발 | **테마 A (가죽)** | 적병 그대로 |
| 외곽선 | 외곽선 | 1px 검정 |
| 입(피격·탈진) | 테마 B3 | 적병 그대로 |
| 공격 효과(속도선·충격) | 효과 1–3 | 적병의 효과 태그 사용 |

- 철 태그는 **쓰지 않는다**(칼이 없다). 방어구·투구·철물 없음.
- 머리카락 태그(`g h i`)는 쓰지 않는다. 적병의 산발과 두건 매듭은 모두 지운다.
- 진영색은 허리 띠에만 쓴다. 다른 재질에 쓰지 않는다.

## 3. 머리·몸·팔

- **머리**: 적병의 머리 위치와 크기를 유지하되 **산발 윗부분을 피부로 바꾼 민머리**로 그린다. 정수리는 피부1 1–2px 하이라이트, 나머지는 피부2, 귀 뒤·목선 쪽은 피부3. 둥근 두개골 실루엣이 읽혀야 하고 눈은 적병과 같은 세로 2px를 유지한다(표정 규칙). 두건 띠, 매듭, 머리카락 가닥은 전부 없다.
- **몸통**: 적병의 삼베 윗옷과 바지를 그대로 쓴다. 허리의 새끼줄 자리를 **진영색 허리 띠**로 바꾼다.
- **팔(핵심)**: 적병의 맨팔보다 **1px씩 굵게** 그린다.
  - **전완**: 손목 쪽보다 팔꿈치 쪽이 1px 굵은 쐐기 모양. 바깥 면에 피부1 한 줄, 안쪽에 피부3 한 줄.
  - **이두근(위팔 앞)**: 팔을 굽힐 때 위팔 앞면이 1px 볼록하게 솟는다. 볼록한 꼭대기에 피부1, 아래 경계에 피부3을 한 줄 둬서 전완과 구분한다.
  - **삼두근(위팔 뒤)**: 팔 뒤쪽 가장자리가 1px 두껍게 늘어난다. 이두근 반대쪽 외곽에 피부2–3로 면을 둔다.
  - 어깨는 적병과 같은 위치에서 시작한다. 몸통 폭은 바꾸지 않고 **팔만** 두꺼워진다.
  - 외곽선은 1px을 유지한다. 두꺼워진 팔이 몸통과 붙으면 외곽선 한 줄로 분리한다.
- **손**: **주먹**이다. 손바닥이 아니라 둥근 덩어리 2×2~3×3px로, 손등 쪽에 피부1, 손가락 접힌 쪽에 피부3 한 줄(마디 구분). 칼이나 칼자루가 없다.

## 4. 자세와 모션

| 동작 | 서술 |
|---|---|
| 대기 | 가드 자세. 적병의 칼 쥔 손 자리에 **주먹을 가슴 높이로 들고**(칼이 있던 자리), 반대 팔은 팔꿈치를 굽혀 **주먹을 옆구리 근처에 당겨 둔다**(허리 짚은 불량 자세가 아니다). 호흡은 적병처럼 주먹 쥔 팔이 1px 오르내린다. 몸·머리는 안 움직인다 |
| 걷기 | 적병의 보행을 그대로 쓰되 주먹 쥔 팔이 가드를 유지한다. 반대 팔은 당긴 자세에서 보폭에 맞춰 1px 흔들린다 |
| 공격 | **정권 지르기**. 1·2프레임 앞 주먹을 허리까지 당기고 몸을 비틀어 힘을 모은다. 3프레임 팔을 곧게 뻗어 주먹을 지른다(팔이 가장 길고 근육이 가장 도드라진다). 4프레임 팔을 당기며 가드로 돌아간다. 효과는 칼 궤적 대신 **주먹 뒤 속도선과 주먹 앞 작은 충격 쐐기**를 효과 1–3 태그로 그린다. 반대 팔은 허리에 당긴 채 유지한다 |
| 막기 | **두 팔 교차 막기**. 앞 팔을 얼굴·가슴 앞으로 올려 **전완을 세우고** 반대 팔 전완을 겹쳐 받친다. 무기·방패 없음. 1 준비 → 2 버팀 → 3 막는 순간(살짝 웅크리며 밀림) → 4 회복. 전완이 머리 앞을 지나므로 머리 위에 그린다 |
| 피격 | 적병과 같다. 3프레임에 상체가 뒤로 휘청, 팔이 늘어지며 주먹이 풀린다, 4프레임 회복. 눈 감고 입 벌림은 기본형 표정 |
| 탈진 | 적병과 같다. 주저앉고 숨이 가쁘며 팔을 무릎에 얹거나 늘어뜨린다 |

## 5. 방향별로 보이는 것과 가려지는 것

| 방향 | 얼굴 | 앞 주먹 | 당긴 팔 | 민머리·허리 띠 |
|---|---|---|---|---|
| S | 정면 | 화면 왼쪽(기본형 칼 자리) | 화면 오른쪽 옆구리 | 정수리 피부 하이라이트, 허리 띠가 가로로 보임 |
| SW | 보임 | 화면 왼쪽 위 | 몸 앞 가림 | 허리 띠 끝이 오른쪽 뒤로 늘어짐 |
| W | 옆얼굴 | 몸 앞 | 몸에 가려짐 | 뒤통수 둥근 선, 띠 끝 뒤로 |
| NW | 안 보임 | 몸 뒤로 가림(기본형과 같음) | 몸 가장자리에서 일부 | 민머리 뒷면과 허리 띠 뒷면 |
| N | 안 보임 | 몸 오른쪽 위 | 양쪽 가장자리 | 민머리 뒷면, 허리 띠 뒷면 중앙에 매듭 |
| NE·E·SE | SW·W·NW와 대칭 | 반대편 | 반대편 | 좌우 반전된 위치 |

(N·NE·NW는 얼굴이 없어 민머리 뒷면이 큰 피부 덩어리로 보인다. 정수리 하이라이트와 귀 뒤 그림자 한 줄로 형태를 읽히게 한다.)

## 6. 검수 체크 요약

- 철 태그와 머리카락 태그가 어디에도 남지 않았는지(`render.py recolor --groups iron,hair`).
- 진영색 recolor에서 **허리 띠만** 바뀌는지.
- 두 팔이 적병보다 굵고 이두·전완 구분이 읽히는지(방향별), 몸통과 외곽선으로 분리되는지.
- 주먹이 칼·칼자루처럼 보이지 않는지, 모든 프레임에 칼 픽셀이 없는지.
- 머리 크기·눈 규칙·기준점(28,38)이 적병과 같은지.
