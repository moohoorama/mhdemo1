# 일반 보병 비전투 (`infantry_noncombat`) 특징

## 1. 한 줄 요약

이름 없는 장수가 걸어 다니는 장면용 범용 도트. 경보병(`light_infantry`, 56x46, 기준점 28,38) 기반, 무기·갑옷 없음.
장면에서 개인 비전투 도트가 없는 장수(공손찬, 화웅, 이각, 원술류)는 이 도트로 대신한다. 전투 도트(기마)를 쓰지 않는다.
48px에서 보여야 할 것: **진영색 상의**, **삼베 두건과 틀어 올린 상투**, **평범한 맨손 차림**. 수염·귀·장식 같은 개인 특징은 넣지 않는다.

## 2. 색과 태그 배정

| 부위 | 태그 그룹 | 진영 따라 바뀜? | 비고 |
|---|---|---|---|
| 상투, 머리카락(뒷머리 포함) | 털 1-3 | 고정 | 짙은 갈색 `#5a4636 #3a2c24 #201814` |
| 얼굴, 목, 손 | 피부 1-3 | 고정 | 중립 살구 `#e6b484 #c88f5c #9a6340` |
| 눈 | 외곽선 | - | 세로 2px |
| 두건(이마 띠) | 테마 C 1-3 | 고정 | 아마색 `#ece4cc #c9bd98 #92876a` |
| 허리띠(앞 2행) | 테마 C 1-3 | 고정 | 두건과 같은 램프 |
| 상의, 소매 | 진영색 1-3 | **바뀜** | 왼쪽 1이 밝음, 가운데 2, 오른쪽·아래 3 |
| 옷자락 밑단 | 진영색 3 | **바뀜** | |
| 바지 | 테마 B 1-3 | 고정 | 삼베색 `#b0a07c #857757 #5c523c` |
| 신발 | 테마 A 1-3 | 고정 | 갈색 가죽 `#9a6a40 #6e4828 #432b18` |
| 외곽선 | 외곽선 | - | 1px 검정 |
| 철, 말, 안장, 효과 | 쓰지 않음 | - | 무기·갑옷 없음 |

장수별 `Look.Palette` 덮어쓰기: 머리카락=털, 피부=피부, 상징색=테마 A/B/C, 철은 해당 없음. 진영색은 바꾸지 않는다.

## 3. 옷과 신체

- 머리: 상투(2행, 털) + 둥근 머리카락 + 이마를 두른 아마색 두건 한 줄. 모자·투구 없음.
- 얼굴: 눈 2개(세로 2px), 코·입·귀·수염 없음. 3/4 시점 SW에서 오른쪽에 뒷머리 한 줄이 내려옴.
- 몸: 무릎 위 진영색 상의, 아마색 허리띠, 삼베 바지, 갈색 신. 어깨 갑옷 없음, 소매 끝에 맨손.
- 특징 없는 중립 인물: 장수 구분은 진영색뿐이다.

## 4. 방향별 가시성

| 방향 | 얼굴 | 두건 | 뒷머리 | 상투 | 손 |
|---|---|---|---|---|---|
| SW | 3/4, 눈 2개 | 이마 앞 | 오른쪽 한 줄 | 위 | 양쪽 허리 옆 |
| NW | 안 보임 | 뒷머리 위를 두름 | 목 위까지 덮음 | 위 | 양쪽 허리 옆 |

## 5. 비전투 프레임

- 대기: 두 팔을 몸 옆에 내린 자세.
- 걷기: 왼발 앞, 오른발 앞. 기본형 걷기 2장을 쓰되 무기·방패를 지우고 팔은 몸 옆에서 가볍게 흔든다.
- action: **포권(주먹 감싸기)**. 오른 주먹을 왼 손바닥으로 감싸 가슴 앞에 모으는 공손한 인사. 발은 대기와 같은 자리(기준점 고정).
  - SW: 두 소매가 가슴 앞으로 모이고 주먹+손바닥 2x2~3x2 덩어리가 턱 아래 22-26행에 보임.
  - NW: 등을 보인 채 팔꿈치가 몸 양옆에서 약간 벌어지고 손은 몸에 가려짐.
