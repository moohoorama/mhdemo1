# 손견 비전투 (`sunjian_noncombat`) 특징

경보병(`light_infantry`, 56x46, 기준점 28,38) 기반. 맨손으로 서 있는 평복 차림. 장면에서 말 탄 모습 대신 쓴다.
보여야 할 것: **붉은 머리띠(뒤로 늘어진 끝), 굵은 눈썹과 콧수염·짧은 턱수염, 상투, 진영색 상의에 어두운 가죽 어깨받이**.

자료: 전투 도트 `sunjian`(말 탄 형태라 참고 약함), 초상 `portraits/sunjian.png`(검은 상투, 콧수염과 짧은 턱수염, 붉은 테를 두른 어두운 갑옷), 연의의 붉은 두건(조무가 대신 쓴다).

## 옷과 몸

- 머리: 투구 없음. 이마에 붉은 머리띠 2행, 위에 상투(3x3), 뒤통수 쪽으로 띠 끝이 2-3px 늘어진다.
- 얼굴: 굵은 눈썹(털), 눈 1px 둘, 콧수염 1행, 입 주변과 턱을 감싸는 짧은 턱수염. 귀는 생략.
- 몸: 무릎 위까지 오는 진영색 짧은 상의, 어두운 가죽 어깨받이와 허리띠, 어두운 바지, 갈색 신발. 무기 없음.

## action 자세

수염을 쓸어내리듯 한 손을 턱에 대거나, 주먹을 쥐어 가슴 앞에 내미는 자세(호랑이의 기개). 1차 안: 오른손(화면 기준 안쪽 손)으로 턱수염을 쓰다듬고 다른 팔은 허리춤.
