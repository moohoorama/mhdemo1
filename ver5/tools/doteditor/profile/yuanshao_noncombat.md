# 원소 비전투 (`yuanshao_noncombat`) 특징

경보병(`light_infantry`, 56×46, 기준점 28,38) 기반, 무기 없이 걷는 사세삼공 명문의 군주.
읽혀야 할 것: **금빛 새 모양 관모**, **흰 도포 + 금빛 어깨·소매 끝·단 + 앞섶 금테**, **단정한 수염**, 진영색 허리띠.
근거: 초상(금관, 흰 도포에 금 자수, 단정한 콧수염과 턱수염), `docs/data-character.md` 168 "금빛 새 모양 관모, 흰 도포, 금빛 어깨, 수염을 단정히 기른 귀공자풍의 위엄".

## 색과 태그

| 부위 | 태그 | 비고 |
|---|---|---|
| 관모 몸체·뾰족한 꼭대기·어깨 판·소매 끝·앞섶 테·도포 단 | 테마 C 1–3 (기본값 금빛) | 한 램프로 함께 바뀐다 |
| 관모 이마 앞 보석 1px | 진영색 1 | |
| 허리띠 | 진영색 1–3 | 바뀌는 천은 이것뿐 |
| 흰 도포(몸, 소매) | 테마 B 1–3 (`#f8f4ea #d9d3c3 #a49e8e`) | 고정 상징색 |
| 머리카락·콧수염·턱수염 | 털 1–3 (`#5a4640 #33282a #1a1416`) | |

철은 쓰지 않는다. 진영색 1–3 색 값은 바꾸지 않는다.

## 머리·얼굴·옷

- 관모: 투구 대신 금빛 관모. 꼭대기가 뒤로 휘는 새 볏 모양이고 앞 테두리에 진영색 보석 1px. 아래 테두리는 C3.
- 얼굴: 관모 아래 그림자 한 줄, 눈, 볼. 콧수염은 가로로 입을 덮고 턱수염은 가슴 위로 3행 내려와 끝이 뾰족하다.
- 옷: 흰 도포가 어깨부터 발목까지 덮는다. 어깨와 소매 끝은 금빛. 허리에 진영색 띠. 단 끝은 금띠.
- 무기와 철 장식 없음. 팔은 몸 옆에 늘어뜨린다.

## 걷기·액션

- 걷기: 기본형 걷기 2장 기준. 도포 자락이 다리를 가린다.
- 액션: **한 손으로 수염을 쓸며 위엄 있게 서기**(초상의 자세). 오른손을 가슴 높이로 올려 턱수염에 대고 상체는 세운다. 발은 대기와 같은 자리.
