# 중보병 (`heavy_infantry`) 특징 프로필

## 1. 한 줄 요약

경보병 도트(`units/infantry.yaml`, 56×46, 기준점 28,38)에서 그리는 전투 도트. 경보병의 **철 투구·철 흉갑·철 어깨판을 모두 가죽과 나무 갑주로 바꾸고**, 더 두껍고 길게 입힌다.
48px에서 보여야 할 것: **① 나무 판을 가죽 끈으로 엮은 투구(볼 가리개 포함), ② 어깨를 덮는 큰 가죽 견갑과 허리까지 내려오는 길쭉한 나무·가죽 흉갑, ③ 경보병보다 육중한 실루엣**.
머리 크기·키·발·기준점은 경보병 그대로다(몸통만 좌우로 1–2px 넓다).
무기(칼)와 방패는 경보병 그대로 둔다(칼날만 철, 방패는 경보병 방패).

## 2. 색과 태그 배정

| 부위 | 태그 | 비고 |
|---|---|---|
| 가죽(견갑, 흉갑 테두리·끈, 투구 끈과 볼 가리개, 허리띠, 팔 보호대, 정강이 보호대, 신발) | **테마 A (가죽)** | 어두운 갈색 계열. 경보병의 신발 테마 A와 같은 램프 |
| 나무 판(투구 판, 흉갑 판·세로 쪽 판, 견갑 위 판) | **테마 C (나무)** | 가죽보다 밝은 황갈색. 영웅 램프로 나무 색(`#c9a266 · #9a7444 · #6a4c2c` 정도)을 지정해 가죽과 구분한다 |
| 투구 꼭대기 술, 소매, 바지 | **진영색** | 경보병 그대로 |
| 칼날 | **철** | 몸에는 철을 쓰지 않는다(철 태그는 칼날과 방패 징 한두 픽셀만) |
| 방패 | 경보병 그대로 | 테마 B 계열 붉은 방패 |
| 얼굴·손 | 피부 | 경보병 그대로 |
| 외곽선·입 | 외곽선·테마 B3 | 그대로 |

- 가죽(어두움)과 나무(밝음)의 **명도 차**로 구분한다. 한 덩어리가 한 재질이어야 하고, 판과 판 사이 경계는 가죽 끈 1px 줄로 그린다.
- 철 태그(`a b c`)가 칼날·방패 징 말고 남으면 안 된다.

## 3. 머리·몸

- **투구**: 경보병 둥근 철모 자리에, **나무 판 3~4장을 가죽 끈으로 세로로 엮은 투구**. 정수리 판 위에 진영색 술(경보병과 같은 위치). 이마 아래 가죽 테두리 1px, 양 볼을 덮는 **가죽 볼 가리개**(귀 앞에서 턱선까지, 폭 2px). 눈 규칙(테두리 → 그림자 한 줄 → 눈 세로 2px)은 유지한다.
- **견갑(어깨)**: 경보병의 어깨판보다 **좌우로 1–2px 더 크고 바깥으로 둥글게** 튀어나온 가죽 견갑. 위에 나무 판 1장씩 얹어 층이 보이게 한다. 이것이 중보병의 가장 큰 실루엣 차이다.
- **흉갑**: 경보병 흉갑보다 **4–5px 길게**, 허리 아래 골반까지 내려오는 **나무 판 + 가죽 테두리**. 가운데 세로 이음선 1px, 아래에 가죽 허리띠 한 줄, 그 밑에 짧은 **가죽 치마 가름(전면 2–3조각)**. 가슴판 가운데는 나무 밝은 면, 가장자리는 가죽 어두운 면.
- **팔·다리**: 소매는 진영색 그대로, 아래팔에 가죽 팔 보호대 2–3px, 정강이에 가죽+나무 정강이받이(경보병 정강이받이 자리).
- 전체 비율: 머리 크기와 키는 같다. 몸통 폭만 어깨에서 1–2px 넓어 단단해 보인다.

## 4. 자세와 모션

경보병과 같다(대기 가드, 걷기, 내려베기 공격, 방패 막기, 피격, 탈진). 가죽·나무 갑이 늘어나 움직임은 경보병보다 한 박자 느리고 무거워 보이면 되고, 새 포즈를 만들 필요는 없다. 새로 그린 갑주 픽셀이 경보병 칼·방패 위치와 겹치지 않게만 한다.

## 5. 방향별로 보이는 것과 가려지는 것

| 방향 | 보이는 것 |
|---|---|
| S | 투구 판, 볼 가리개 양쪽, 양 견갑, 흉갑 가운데 이음선, 허리띠와 치마 |
| SW·SE | 앞 견갑 크게, 흉갑 옆면, 방패가 몸통 한쪽을 가림 |
| W·E | 옆 견갑 한 개, 투구 옆판, 볼 가리개 한 장, 흉갑이 앞뒤로 두껍게 |
| N·NW·NE | 투구 뒷판과 목 가리개(가죽 늘어진 한 줄), 견갑 윗면, 등판 나무 판 + 가죽 끈 X자 또는 세로 줄 |

## 6. 검수 체크 요약

- 철 태그가 칼날·방패 징 외에 남아 있지 않은지(`render.py recolor --groups iron`).
- 가죽(테마 A)과 나무(테마 C) 램프를 바꿔 보면 구분되는 두 재질이 각각 한 덩어리씩 바뀌는지(`--groups themeA` / `themeC`).
- 진영색 recolor에서 술·소매·바지만 바뀌는지.
- 머리 크기·눈 규칙·기준점(28,38)이 경보병과 같은지, 견갑·흉갑이 경보병보다 눈에 띄게 큰지(방향별).
