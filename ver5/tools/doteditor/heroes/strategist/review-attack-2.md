# 문사 공격 검수 2차 (attack, 8방향 × 4프레임)

판정: **통과** (반드시 0 · 권장 0)

확인한 것:
- `render.py sheet strategist --anims idle,attack`
- 고친 프레임은 `render.py frame`(SE/2 · SE/3 · S/2 · S/3 · N/0 · N/3)
- `render.py recolor strategist --anims attack`(themeA · themeC · faction)
- 39행 아래 픽셀, 효과·철·테마 B 태그 사용

## 1차 지적 반영 확인

- attack/SE/2: 책이 팔 아래 배 앞(외곽선 x31–36, 30–36행)으로 내려왔다. 팔 아래 외곽선이 책 위 외곽선을 겸한다.
  얼굴 옆이 비어 턱·수염·속깃이 대기와 같다. 1→2→3에서 책이 가슴 → 배 → 배로 이어진다.
- attack/N/3: 손(x16–17)이 책 외곽선 x18에 바로 닿는다. 더 이상 떠 보이지 않고, 팔이 책 뒤로 지나가는 것으로 읽힌다.
- attack/S/3: 36행 자락이 x33까지 이어지고 신 두 짝(x23–26, x30–33, 37–38행)이 보인다. 팔 아래 몸이 잘려 보이지 않는다.
  신 위치는 기본형 S/3과 같은 높이다.
- 이중 외곽선: N/2·N/3·NW/2·NW/3의 39행, S/2·S/3의 40행 잔여 2px가 없어졌다.
  39행에 남은 것은 SE/2·SE/3과 S/2·S/3의 신 바로 밑 1px 바닥 외곽선뿐이다. 기본형 발 높이와 같다.
- attack/N/0(권장): 부채가 대기보다 4px 올라가고 소매가 어깨까지 이어진다. 1프레임의 높이 든 자세로 자연스럽게 이어진다.
- attack/SE/3(권장): 팔 아래 29행 x25–28에 늘어진 소매 `l`이 생겼다. SE/2 소매와 이어진다.

## 그대로 둔 것(받아들임)

- attack/S/2 책 높이: 바로 아래가 부채 면이라 내릴 자리가 없다. 48px에서 책·부채가 따로 읽히므로 그대로 둔다.
- attack/N/2–3 부채 방향(왼쪽): 기본형 N 휘두르기 방향을 따른 것이다. 1차에서도 선택 사항이었다.

## 전체

- 효과(E F G, 1–6) · 철 · 테마 B 픽셀은 32프레임 어디에도 없다.
- 재색 시트: 각 그룹이 맡은 부위만 바뀐다.
  - 테마 A: 관모, 신, 자루, 책 표지
  - 테마 C: 부채 면, 종이 단면, 속깃
  - 진영색: 도포, 비녀, 띠
  - 새로 그린 소매·책·신에도 다른 그룹 색이 섞이지 않았다.
- 머리 크기·패턴은 대기와 같다.
- SE는 0–1에서 넓은 소매를 화면 왼쪽에 늘어뜨리고, 2–3에서 팔 아래로 소매가 처진다. "D"자로 오목하게 들어간 실루엣이 없다.
- 8방향 모두 모으기 → 높이 듦 → 부채 내밂 → 가리킴이 한 몸의 동작으로 읽힌다.
