## 방법

- 윗몸(머리·관모·얼굴·수염·속깃·도포 몸통·소매·책·부채)은 모델 시트 idle 0 행을 같은 자리에 그대로 옮겼다.
  idle의 몸 전체 호흡(1·3프레임 1px 오르내림)은 걷기에 쓰지 않았다. 기본형 걷기처럼 몸은 그대로 두고 팔만 움직인다.
- **부채 팔**: 기본형 칼 팔처럼 1·3프레임과 0·2프레임 사이에 부채·자루·손이 1px 움직인다. 부채는 세운 채이고 면 크기·패턴은 모델 시트 그대로다.
  - S·SE·SW·N·NE: 1·3프레임에서 1px 올라간다(기본형 칼 팔과 같은 위상).
    SW·S는 소매 끝까지, SE는 손과 소매 입구 `l`까지 함께 올라간다. N·NE는 손 아래 소매 행이 한 칸 위로 이어진다.
  - E·W: 0·2프레임에서 1px 내려가고 1·3은 대기와 같다. E는 부채가 얼굴 앞이라 올리면 눈(x31) 옆 얼굴 픽셀이 덮인다.
    그래서 내리는 쪽을 택했다(내리면 18행 x32 얼굴 칸이 드러난다). W도 같은 위상으로 맞췄다.
  - NW: 부채는 보이지 않는다. 오른소매(x33)만 1·3프레임에서 1px 올라간다.
- **책 팔**: 모든 프레임에서 대기 0과 같다. 굽혀 안은 채 흔들지 않는다(기본형 방패의 1px 흔들림은 따르지 않음).
- **아래쪽**: 기본형 걷기의 발 위치·보폭·높이를 따랐다. 다리는 도포 속이라 자락 끝단과 신(테마 A `n o`)만 손으로 다시 그렸다.
  - 내딛는 쪽으로 자락이 1px 넓어지거나 1행 내려온다.
  - 신은 자락 아래로 1–2행만 보인다. 들린 발은 밑창 1행만 보이거나 자락에 가려진다.

## 방향별 (0 / 1 / 2 / 3)

- **SW**: 0 = 큰 보폭이다. 자락이 33–34행에서 양쪽 1px씩 넓어지고 신 두 짝이 35–36행에 보인다.
  1 = 통과 자세다. 앞발 x28–31만 36–37행에 보인다. 2 = 앞발 한 짝이 37–38행으로 내려오고 자락이 아래로 좁아진다.
  3 = 왼발 끝 x23–25(35행) + 오른발 x28–31.
- **SE**: 0 = 앞발 한 짝(x27–30, 37–38행)이고 자락 앞쪽이 36행까지 내려온다. 1 = 대기 다리보다 1행 위(들린 뒷발 밑창 `ooo`).
  2 = 큰 보폭(신 35–36행, x22–25 / x31–34). 3 = 왼발만 디딤.
- **S**: 0 = 왼발이 37–39행까지 내려오고 왼쪽 자락이 36행까지 내려온다. 오른발은 밑창만 보인다. 2 = 거울. 1·3 = 한 발을 1행 들어 올린다.
- **E**: 0 = 앞발(오른쪽) 디딤 + 뒷발 발끝이다. 자락이 32–34행에서 앞뒤로 넓어진다.
  1 = 신이 1행 짧다(들린 통과 자세). 2 = 뒷발 디딤 + 앞발 발끝이 자락 앞(34행 x32–33)으로 나온다. 3 = 대기 다리.
- **W**: E의 거울 구성이다. 기본형 위상대로 0 = 뒷발 디딤 + 앞발 끝, 2 = 앞발 디딤 + 큰 보폭, 1 = 대기 다리, 3 = 신 1행(들림).
- **N**: 0 = 왼쪽 자락·신이 37–39행까지 내려오고 오른발은 밑창이다. 2 = 거울. 1·3 = 한 발씩 1행 낮다.
- **NE**: 0 = 큰 보폭(신 36행 양쪽). 1 = 왼발 35행, 오른발 36행. 2 = 한 발이 38행까지 내려오고 자락이 좁아진다. 3 = 왼발이 34행으로 들리고 오른발은 36–37행에 디딘다.
- **NW**: 0 = 한 발이 37–38행으로 내려오고 자락이 좁아진다. 1 = 대기 다리. 2 = 큰 보폭(신 36행 양쪽). 3 = 왼발 신이 1행 짧다.

## 의도한 것 / 남은 의문

- 발이 기준점(38행)보다 아래로 내려가는 프레임(SW 2, SE 0, S 0·2, N 0·2, NE 2, NW 0)이 있다.
  반대로 기준점에 닿지 않는 프레임(SW 0·3, SE 1·2, E 0·1·2, W 0·2·3, NE 0·1, NW 2)도 있다. 둘 다 기본형 걷기의 발 높이를 따른 것이다.
- E·W 부채 위상은 다른 방향과 반대다(0·2 내림 / 1·3 대기). 방향마다 따로 재생되므로 문제는 없다고 봤다.
- idle W 0의 38행 x28 외곽선 1px(신 밑 점)은 걷기에 옮기지 않았다(떨어진 점으로 보임).
- 철 `a b c`·테마 B·효과 태그는 걷기 32프레임 어디에도 없다. 재색 시트에서 진영색은 도포·관모 띠·비녀만 바뀐다.
  테마 A는 관모·신·부채 자루·책 표지만, 테마 C는 부채 면·책 단면·속깃만 바뀐다.
- 넓은 SE 소매(늘어진 자락)는 고정이다. 손과 부채만 1px 움직인다. (검수 1에서 바뀜: 아래 참고)

## 검수 1 반영 (review-walk-1.md)

반드시
- **윗몸 전체가 한 동작으로 1px 오르내린다.** 위의 "부채 팔만 1px" 방식은 버렸다.
  - 머리·관모·얼굴·두 팔·소매·책·부채가 함께 움직이고, 몸에 대한 부채·책 위치는 대기 0과 같다.
  - 방법은 모델 시트의 idle 호흡과 같고, 해당 idle 프레임의 행을 같은 자리에 옮겼다.
  - S·SE·SW·N·NE·NW 1·3: 위로 1px. idle 1의 이음 행 W까지(SW·SE 33, S 32, N·NE·NW 30행)를 옮겼다. 이음 행이 한 번 더 쓰여 도포가 1행 늘어난다.
  - E·W 0·2: 아래로 1px. idle 3의 W+1행까지(E 31, W 32행)를 옮겼다. 도포가 1행 줄어든다.
  - 그 아래 자락 끝단·신은 그린 걸음 그대로다. 32프레임 모두 이음 행 아래가 걸음 그림이다.
  - 확인: S·SE·SW·N·NE·NW 1·3의 0–29행은 idle 1과 픽셀까지 같다.
  - 남은 것: E 3과 W 1은 여전히 대기 0과 같은 그림이다(W 1은 대기 0의 38행 점만 없다). 대기 높이 프레임이고, 다리도 기본형 걷기의 통과 자세(대기 다리)다. 앞뒤 프레임이 1px 내려가므로 재생하면 움직인다.
- **W 3**: 자락을 35행까지 늘였다(x25–30, 외곽선 x24·x31). 신 `nnoo`는 36행 x26–29, 밑 외곽선 `####`는 37행이다. E 1의 거울이다.

권장
- **SW 2**: 자락 끝단 폭을 대기와 맞췄다. 34–35행은 x23–33이다. 36행은 앞자락 x26–30만 1행 더 내려오고, 양옆은 밑 외곽선이다. 앞발 신은 37–38행 x26–29에 둔다(SE 0과 같은 구성).
- **NE 2**: 34–35행 x24–33으로 폭을 유지했다. 36행은 앞자락 x27–30만 내려오고, 신은 37–38행 x27–29에 둔다.
- **NE 3**: 들린 왼발 신을 지웠다. 자락을 34–35행 x25–32로 늘어뜨리고 밑 외곽선은 36행 x25–28이다. 오른발(36–37행)은 그대로다.
- 참고: NE 1(35행 x25–27 들린 왼발 `nno`)도 비슷한 구성이지만 지적이 없어 두었다.
