# 문사 막기(block) 검수 2

판정: **통과**

본 것: 8방향 모두 대기 0과 막기 0–3을 12배로 나란히 놓고 봄. 고친 SW·SE·S 1·2프레임은 따로 크게 봄. 각 지적은 review-block-1의 해당 항목과 grid를 대조함.

## review-block-1 반영 확인

- SW/SE/S 0–2: 부채가 대기 높이에서 얼굴 쪽으로 들어와 1·2프레임에 턱·입·수염을 덮는다. 손은 가슴(26–27행)으로 올라왔다.
  - 0→1→2→3의 부채 높이가 "안쪽으로 → 얼굴 앞 → 밀림 → 대기"로 이어진다. 내렸다 튀어 오르던 문제가 없어졌다.
  - 넓은 소매는 올린 팔뚝 아래로 세로로 처진다. SE에서 엉덩이 높이로 수평으로 뻗던 덩어리가 없어졌다. 몸 이동과 팔이 한 동작으로 읽힌다.
  - 수염 1px이 부채 옆에 남던 점도 사라졌다.
- S/2: 머리 0,−1, 도포 1행. 늘어나 보이지 않는다.
- W/0–2: 책이 2행만 내려와 허리~허벅지 위에 있다. 매달린 느낌이 없다.
- NE/N 1–2: 머리 오른쪽에 올린 손(2px×2행)과 소매 끝, 2px 폭 부채 가장자리가 보인다. 대기의 큰 부채가 손에 든 채 머리 뒤로 들어가는 동작으로 읽힌다. 잡픽셀로 보이지 않는다.

## 작가 의문점에 대한 판단

- SW·SE·S 1·2프레임에서 화면 왼쪽 눈이 부채 윗선에 묻히는 것: **문제없음.**
  - profile §6은 "눈 하나 이상"을 요구하는데, 화면 오른쪽 눈 세로 2px이 양옆·아래 피부로 깨끗하게 남는다.
  - 묻힌 눈은 부채 윗선의 일부로 읽혀 "부채 위로 한쪽 눈만 내다본다"가 된다. 막기 의도가 오히려 분명해졌다.
  - SE에서는 뒷머리 털·외곽선과 부채 윗선이 이어져 왼뺨 쪽이 조금 어둡다. 그래도 수염이나 얼룩으로 읽히지는 않으므로 지적하지 않는다.
- W 1프레임에서 부채 손이 책 윗부분을 가리는 것: **문제없음.**
  - W에서 부채 팔은 앞쪽(카메라 쪽)이라 손이 책 위에 덧그려지는 순서가 맞다.
  - 책은 아래 4행과 종이 단면이 보여 4×5 책으로 읽힌다. 자루–손–팔도 끊김 없이 이어진다.

## 문제없음

- 발 접지와 기준점(28,38)은 기본형과 같다. 머리 크기는 일정하다. 효과 픽셀과 철·테마 B 픽셀은 없다. 3프레임은 대기 0으로 이어진다.
- 색은 부채 면 C, 자루 A, 손 피부, 소매 진영색이다. 새로 그린 부분도 태그 배정이 profile §2와 같다.
- E·W·NW는 1차와 같고 문제없다.
