# 장비 걷기(walk) 작업 노트

기준: 기본형 경기병 걷기 각 프레임(말 걸음·타이밍 그대로), 모델 시트 = 대기 0프레임(`grid/idle/<dir>-0.txt`).

## 방법

- 기본형 걷기에서 기수 머리는 대기 0프레임에서 정수 이동한 자리에 있다(방향별 오프셋 아래 표).
  장비 머리·투구·수염·어깨판 덩어리와 사모(날·고리·술·자루·손·꼬리)를 대기 0프레임에서 **그 오프셋으로 통째 옮겨 찍었다**
  (스크래치의 `paste.py`/`shiftrows.py`, 내가 고른 상자만 정수 이동). 내가 이미 그린 걷기 프레임을 다른 프레임으로 1행 옮겨
  시작점으로 쓴 경우도 있다(`cpwalk.py`, 예: E1←E0, E3←E2, N·NE·NW·W 홀수 프레임).
- 몸통(가슴판·전포·띠·허벅지·장화)과 말과 겹치는 행은 **행 단위로 손으로 다시 썼다**(`setrows.py` = 내가 입력한 행 문자열을 그대로 넣는 것).
  기본형 걷기의 실루엣·외곽선을 따르고, 태그는 장비 규칙으로 바꿨다: 몸 `l`→`k` 바탕(그림자 쪽 `l`, 빛 쪽 가장자리 `j`),
  철 장화 `b c`→`n o`, 철 어깨→`m n o`, 허리 붉은 띠 `p q…`(+`r`), 기본형의 말 태그 손(`v`,`A`)→피부 `d e`, 말 태그 자루(`A`)→자루 `t`/꼬리 `u`.
- 처음에 기본형 대기와 기본형 걷기를 비교해 픽셀을 자동으로 고르는 모드(`move.py same`)를 SW 0에서 잠깐 시험했으나 결과를 버리고
  (`reset`) 다시 그렸다. 최종 프레임에는 그 모드의 결과가 남아 있지 않다. 이후 그 모드는 쓰지 않았다.
- 모든 32프레임을 `render.py frame`으로 렌더해 기본형과 나란히 봤고, 방향별 4프레임+대기 0을 확대 비교 이미지로 다시 확인했다.
  붙여 넣은 뒤 남은 기본형 잔픽셀(기본형 창 `o n a b c`, 말 태그 손, 철 장화)은 손으로 지웠다.

## 방향별 오프셋(대기 0 대비, x,y)과 내용

| 방향 | 머리·수염 | 사모·손 | 몸통·말 |
|---|---|---|---|
| SW | f0 (−2,0) f1 (−2,0) f2 (−2,−1) f3 (−2,0) | f0 (−2,−1), f1·f3 (−2,0), f2 (−2,−1) | f0·f2: 말이 1행 위(기본형) → 몸통 하단 1행 압축. f1·f3: 몸 하단은 대기 위치 |
| S | 0 / +1 / −1 / 0 (세로만) | 머리와 같음 | f0: 말 머리가 27행까지 올라와 띠가 가려져 왼쪽 2px(`pq`)만 보임(의도). 자루 꼬리 28–30행 |
| SE | (+2, 0/0/−1/0) | 머리와 같음(투구 왼쪽 바깥 x=45 수직, profile SE 예외 유지) | 말은 x 고정, 기수만 +2 → 고삐 손이 말 머리 앞, 말 머리가 띠 오른쪽을 가림 |
| E | (+3, −1/0/−1/0) | (+2, −1/0/−2/−1) — 검수 1 뒤 +1→+2로 옮김 | 자루가 수염 앞(대기와 같은 앞뒤). 손 (55–56) |
| W | (−3, −1/0/−1/0) | f0·f2 (−1,−1), f1·f3 (−1,0) | 자루는 수염 앞(profile W). 수염 왼쪽 1열과 가시 1개가 자루에 가린다 |
| N | (0, −2/−1/−3/−1) | 머리와 같음 | 자루 아래 토막은 기본형처럼 띠 아래 2행(`t u`)만 보임 |
| NE | (+2, −2/−1/−2/−1) | (+1, −1/0/−1/0) 기본형 창 위치 | f2·f3은 몸통이 1행 위 → 띠 행에 손 `e` 1px이 붙음 |
| NW | (−2, −2/−1/−2/−1) | (−1, −1/0/−1/0) | 자루는 머리 뒤. 투구 술 위로 날·고리·술·자루 1px만 보인다 |

## 의도된 것

- **W: 자루가 수염 앞**(profile 표대로). 수염 맨 왼쪽 1열과 왼쪽 가시 1개가 자루에 가려져 보이는 가시는 2개다.
- **NW: 자루 보이는 길이 1px.** 기본형 창이 머리보다 1px 덜 움직여 날이 대기보다 머리에 1행 가깝다. 날·고리·술은 모두 보인다.
- **S f0/f1: 말 머리가 띠를 덮는다**(기본형 그대로의 가림). 띠는 왼쪽 2px만 보인다.
- 사모 x 오프셋은 SW·SE·S·N에서 머리 오프셋을 그대로 썼다(기본형 창은 머리보다 1px 다르게 움직이지만 그러면 손이 수염에 붙어 모델 시트의
  1px 외곽선 간격이 사라진다). 세로 출렁임은 기본형 창을 따랐다.

## 남은 의문

- SW·SE 몸통 일부(허벅지)는 기본형 걷기 실루엣이 대기보다 1px 넓어 대기 모양과 1px 차이가 난다.

## 검수 1 반영 (review-walk-1.md)

- W 0–3: 날끝 위에 남아 있던 기본형 창끝 잔픽셀(f0·f2 5행 (40–41), 6행 (41–42), 7행 (42), 8행 (43); f1·f3은 1행 아래)을 지워
  대기 날을 사모 오프셋으로 한 번만 옮긴 모양(7행 날, 굽이 그대로)으로 되돌렸다.
- E 0–3: 자루를 수염 앞으로 다시 그렸다. 사모 오프셋을 +1에서 **+2**로 옮겨(날·고리·술은 같은 덩어리를 1px 오른쪽으로 정수 이동),
  대기처럼 자루가 코끝·수염 앞 외곽선 자리를 지나며 코 2px은 그대로 보인다. 자루가 수염 맨 앞 1열(턱 행 `i`)을 덮고, 오른쪽 가시와는
  나란히 닿는다(가시 아래는 외곽선). 손은 (55–56) 2행, 손 왼쪽은 소매 `k`로 이었고, 꼬리 `u`는 54→53열로 4행 이어진다.
- E 0: (49,24) 외톨이 진영색은 (49,25)를 `k`로 열어 아래 전포와 이었다.
- S 0·1: 사모 손 둘째 행을 `d e`로 되돌렸다(f0 (45–46,27), f1 (45–46,28)). 그 옆 띠는 `p` 1px만 보인다(말 머리에 가림).
- 고친 프레임(E 0–3, W 0–3, S 0–1)은 모두 `render.py frame`으로 다시 렌더해 봤다.

## 검수 2 권장 (E 코끝–자루 맞닿음)

E 0–3의 코끝 (57, f0·f2 20행 / f1·f3 21행)을 외곽선으로 바꿔 코를 1px로 줄인 안을 렌더해 대기와 나란히 비교했다. 1px 코는 옆얼굴 실루엣에서
코가 거의 사라져 대기(2px 코)와 달라 보였다. 그래서 **2px 코를 유지하고 자루와 외곽선 없이 맞닿는 것을 받아들였다**(자루 짙은 나무색과 피부색이
뚜렷이 달라 경계가 읽힌다). 격자는 검수 2 때와 같다.
