# 궁병 막기 독립 검수 1

판정: 통과. 반드시 0건, 권장 0건.

최신 모델·profile·`notes-block.md`를 읽고 `sheet-block-N_NE_E_SE_S_SW_W_NW.png`의 32프레임과 E·SE·SW 확대 시트를 직접 확인했다. faction/themeA/themeB/themeC/skin/iron 재질 변경 시트도 육안 확인했다.

- block/전체/0–3: 준비 → 활을 몸 앞에 올려 버팀 → 머리와 무릎을 낮춰 충격을 받음 → 활을 일부 내리는 회복 단계가 구별된다. 2번의 낮아진 머리에서도 크기가 유지되고 몸을 늘려 반동을 대신하지 않는다.
- block/전체/0–3: 승인 v4의 짧은 팔과 몸 가까운 손잡이가 유지된다. 손목·손·목재 연결이 이어지고 활채의 곡선이 끊기지 않는다. 얼굴·옷 앞의 시위와 활이 의도한 가림 순서로 보인다.
- block/전체/0–3: 등에 밀착한 화살통과 천 두건을 유지한다. 발 접지와 셀 여백이 유지되며 떨어진 잡픽셀은 보이지 않는다.
- block/전체/0–3: 재질 변경은 해당 천·가죽·시위·목재·피부·금속 부위에 한정되고 명암 구분이 유지된다.

격자와 yaml은 수정하지 않았다. 브라우저 재생 최종 확인은 통합 단계에서 수행한다.
