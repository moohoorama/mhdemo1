# 궁병 대기 호흡 독립 검수 1

최종 판정: 통과. 남은 반드시 0건, 권장 0건.

최신 모델·profile·`notes-idle.md`를 읽고 호흡이 추가된 `sheet-idle-N_NE_E_SE_S_SW_W_NW.png` 32프레임과 N 확대 시트를 확인했다. faction/themeA/themeB/themeC 재질 변경 시트도 직접 확인했다.

## 1차 지적과 수정 확인

- idle/N/1,3: 왼쪽 어깨 상단이 높이 1px 수평 가시처럼 옆으로 돌출되어 호흡 중 어깨 실루엣이 날카롭게 바뀐다. 아래 행과 연결된 두께의 어깨 덩어리로 다듬거나 옆 돌출을 줄여야 한다. 작가에게 전달했다.
- 재검수: 작가 수정 후 N 시트를 직접 다시 렌더해 확인했다. 1·3번의 돌출 아래가 천 픽셀로 이어져 2px 두께의 어깨가 되었고 가시처럼 보이던 부분이 해소됐다. 호흡의 작은 어깨 변화와 나머지 고정 부위는 유지된다.

## 나머지 확인

- idle/전체/0–3: 발·머리 크기·활·밀착 화살통이 고정되고 몸의 작은 명암/천 움직임으로 호흡을 표현한다. 승인된 짧은 팔과 목재 손잡이 위치가 유지된다.
- idle/전체/0–3: 재질 변경이 각 태그 용도에 맞고 활채 연결과 시위 구분이 유지된다. 위 어깨 지적 외 추가 수정 사항은 없다.
