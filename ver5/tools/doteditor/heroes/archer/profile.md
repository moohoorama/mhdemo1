# 궁병 / archer

경보병 원본의 56×46 셀, 발 기준점 (28,38), 약 10px 머리와 2.5등신을 유지하는 일반 궁병이다. 기존 ver2 궁병 SW 시트와 unit3d의 archer 정의를 참고했다. 기존 궁병의 진영색 옷, 나무 활, 등 뒤 화살통을 유지하고 장수 장식이나 수염은 넣지 않는다.

| 부위 | 태그 | 표현 |
|---|---|---|
| 낮은 천 두건, 상의, 바지 | faction1–3 / j k l | 쇠 투구의 술을 없앤 둥근 두건, 진영색 짧은 옷 |
| 얼굴·손 | skin1–3 / d e f | 일반 병사의 얼굴, 세로 2px 눈, 수염 없음 |
| 허리띠·장화·팔 보호대·화살통 | themeA1–3 / m n o | 갈색 가죽 |
| 활 시위·화살 깃 | themeB1–3 / p q r | 밝은 삼베, 시위는 1px |
| 활·화살대 | themeC1–3 / s t u | 갈색 목재, 내부 1–2px의 길고 완만한 곡선, 끝은 1px |
| 남은 소형 보호구 | iron1–3 / a b c | 팔·정강이 작은 철 보호구 |

활은 가운데 손잡이와 위아래 휘어진 활채가 이어진 하나의 나무 무기다. 활채와 시위 사이의 빈 공간은 의도한 공간이며 활채 자체는 끊기지 않는다. 검과 방패는 없다. 화살통 가죽 몸체는 등에 바로 밀착되고 어깨·등·가슴의 가죽 끈으로 메인다. 화살 깃은 세 개이지만 머리에 가려지는 방향에서는 일부만 보인다.

대기 v4는 팔꿈치를 몸통 옆으로 붙이고 허리 바로 옆의 짧은 전완과 2px 손으로 활채 중앙 목재 손잡이를 감싼 낮은 운반 자세다. 승인된 v3의 끝점 사이 약20px 높이 활채와 곡률을 유지하면서 몸 쪽으로 당겼다. 활은 발 쪽으로 약22–27도 대각선 기울며 끝으로 갈수록 가늘어진다. 시위는 두 끝점을 직접 잇는 1px 직선 계단이고 손잡이 안쪽의 열린 공간과 분리한다. 밝은 피부 손가락 2px와 어두운 목재 손잡이, 가죽 손목 보호대를 구분한다. 시위를 붙잡거나 손 둘레에 맞춰 굽히지 않는다. 하단 활채는 다리 앞에서 이어지고 끝은 발 접지 외곽 위에 둔다. 공격은 화살 얹기 → 당기며 조준 → 발사 → 팔을 낮추며 회복의 4단계로 예정한다. 막기는 활을 들어 몸 앞을 보호한다.

| 방향 | 얼굴 | 활 | 화살통 |
|---|---|---|---|
| S | 정면, 두 눈 | 몸 왼편 앞 | 오른쪽 어깨 뒤 가장자리 |
| SW | 왼쪽 3/4, 두 눈 | 왼편에 전면 노출 | 오른쪽 뒤 |
| W | 왼쪽 옆, 한 눈 | 왼편 전면 | 등 오른쪽 |
| NW | 얼굴 안 보임 | 왼쪽 외곽, 팔 일부 가림 | 등 가운데 |
| N | 얼굴 안 보임 | 오른쪽 허리 아래 | 등 가운데에 겹쳐 밀착 |
| NE | 얼굴 안 보임 | 오른쪽 외곽 | 등 왼쪽 |
| E | 오른쪽 옆, 한 눈 | 오른편 전면 | 등 왼쪽 |
| SE | 오른쪽 3/4, 두 눈 | 오른편 전면 | 왼쪽 뒤 |

대기 승인 전에는 다른 동작을 그리지 않는다. 첫 시트는 같은 자세의 고정 대기로 형태와 재질을 검토하며 호흡은 승인 후 필요한 경우 추가한다.
