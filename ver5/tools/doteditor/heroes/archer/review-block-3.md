다시 렌더해 직접 본 것은 다음과 같다.

- `render.py frame archer block <dir> <n>`: 32프레임 전부, 경보병과 나란히

좌표는 x = `NN|` 뒤 열 번호, y = 행 번호다.

## 회귀 확인

- 몸 픽셀이 투명과 바로 맞닿는 곳을 다시 나열했다(32프레임). 남은 것은 손 윗면, 화살통 가장자리, 손목 보호대뿐이다. 승인된 대기 0번에도 똑같이 있는 형태이고, 다리와 엉덩이에는 하나도 남지 않았다.
- 머리 크기와 두건 픽셀은 프레임마다 같다. 상체 이동량은 경보병 막기의 프레임별 머리 위치와 계속 맞는다. 발 접지는 8방향 모두 38행 기준점에 고정되어 있다(N/NE/NW f2의 뒷발 들림은 경보병과 같다).
- 활은 한 줄기 곡선이며 끊기거나 두 번 찍힌 곳이 없다. 시위는 직선이고 손은 손잡이를 쥔다. 화살통은 등에 붙어 있고 깃 3개가 유지된다. 뒷모습의 가림 순서(먼 활채와 시위가 머리·몸 뒤)도 바뀌지 않았다.
- 재질 치환 7개 시트를 모두 확인했다.
  - faction: 두건, 옷, 바지만 바뀐다.
  - themeA: 손목 보호대, 화살통, 허리띠, 장화만 바뀐다. W/E f2 뒷발 `no`도 포함된다.
  - themeB: 시위와 화살 깃만 바뀐다.
  - themeC: 활채와 화살대만 바뀐다.
  - skin: 얼굴과 손만 바뀐다.
  - iron: 정강이 보호구만 바뀐다.
  - outline: 외곽선이 닫힌 한 줄로 이어진다.
  - 다른 재질로 번진 곳은 없고 명암 순서도 유지된다.
