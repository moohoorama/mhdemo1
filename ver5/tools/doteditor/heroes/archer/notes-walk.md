# 궁병 보행

승인된 v4 가까운 운반 자세의 두건·얼굴·등 화살통·짧은 활팔을 유지했다. 경보병 원본 걷기의 다리 위치를 참고해 8방향×4프레임을 직접 그렸다. 상체는 대기 호흡과 같은 작은 어깨/천 움직임으로 연결하며 머리 크기와 발 기준은 유지한다.

- N·S: 한쪽 지지 다리와 올라간 반대 발 → 통과 → 반대 다리 지지 → 반대 통과로 교대한다.
- E·W: 벌어진 옆 보폭 → 몸 아래 통과 → 반대 옆 보폭 → 반대 통과로 교대한다.
- NE·SW: 대각선 두 발 보폭 → 교차 → 길게 뻗는 반대 발 → 반대 교차다.
- NW·SE: 길게 뻗는 대각 지지 발 → 교차 → 벌린 두 발 보폭 → 반대 교차다.

활 쪽 팔은 허리 가까이 안정시키고 반대편 손은 소매에 붙은 피부색 2px로 29→28→27→28행을 오간다. 다리 교대와 반대로 올라가며 화살통 뒤에 가려지는 곳에서는 드러난 손만 보인다. 시위는 승인된 직선 계단을 유지하고 목재 활채를 다리 앞에 겹쳐 이어 그렸다. 그 때문에 걷기의 정강이 일부가 활채/시위 뒤에 가려진다. 시위와 목재 사이의 열린 공간은 의도한 활의 공간이다.

32 보행 격자를 엄격 파싱하고 방향별 연속 시트 및 전체 idle/walk 시트, 재색칠을 직접 확인했다. yaml import와 게임 반영은 하지 않았다.
