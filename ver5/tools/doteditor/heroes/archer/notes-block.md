# 궁병 막기 제작 기록 (재작업)

사용자가 반려한 이전 막기 32프레임을 버렸다. 승인된 대기 0번(`grid/idle/<DIR>-0.txt`)에서 다시 시작해 손으로 편집했다. 이전 안은 몸이 움직이지 않았다. 이번에는 경보병 막기의 프레임별 상체 이동(버티기 → 뒤로 젖힘 → 맞는 순간 → 회복)을 따랐다. 기존 파일은 scratchpad의 `archer-block/old/`에 백업했다.

## 공통

- 방패 대신 활을 몸 앞에 세워 든다. 쥔 손 `udemn`/`nmedu`(목재 손잡이, 피부 2px, 가죽 보호대)을 대기보다 5px 올려 가슴 높이(행 22–23)에 두었다. 경보병이 방패 손을 드는 높이(행 19–22)에 맞춘 것이다. 팔뚝은 어깨에서 손잡이까지 수평으로 이어진다.
- 활 형태, 곡률, 1px 끝, `stu` 목재와 `p` 직선 시위는 대기 활 픽셀을 그대로 옮겼다. 위로 5px 올리고 몸 바깥쪽으로 1px 옮겼다. 위 활채는 두건 위로 솟는다(행 11). 아래 활채는 몸통 앞을 지나 엉덩이와 무릎 앞에서 끝난다. 시위는 얼굴 바로 앞 외곽선이나 코 위를 지나 몸 앞을 가로지른다.
- 원래 활에 가려졌던 다리는 경보병 다리 형태(`l` 바지, `bc` 정강이 보호구, `mn`/`no` 장화)로 새로 그렸다.
- 두건, 얼굴, 옷, 화살통, 화살 깃은 대기 0번의 행을 그대로 쓴다. 상체 전체를 한 덩어리로 옮겼고 픽셀 배치는 바꾸지 않았다.
- 태그는 기존 그룹만 사용했다. 재질 치환 시트에서 활은 themeC, 옷은 faction만 바뀌는 것을 확인했다.

## 방향별 프레임 (상체 이동량 dx, dy; 기준점 발 행 38 고정)

| 방향 | f0 버티기 | f1 젖힘 | f2 맞는 순간 | f3 회복 | 경보병 대응 |
|---|---|---|---|---|---|
| SW | 0,0 | +1,0 | +3,−1, 무릎 굽힘 | +1,−1 | 머리 기준 0 / +1 / +3,−1 / +1,−1 |
| W | 0,0 | +1,0 | +4,+1, 다리 사선, 발 1px 뜸 | +2,0 | +1 / +1 / +5,+1 / +2 |
| NW | 0,0 | +1,+1 | +3,+2, 웅크림 | +1,0 | 0 / +1,+1 / +3,+2 / +1,0 |
| S | 0,−1 | 0,0 | 0,−2, 발끝 들기 | 0,−1 | −1 / 0 / −2 / −1 |
| SE | 0,0 | −1,0 | −3,−1, SW 다리 좌우 반전 | −1,−1 | SW와 좌우 대칭 |
| E | 0,0 | −1,0 | −4,+1, W 다리 좌우 반전 | −2,0 | W와 좌우 대칭 |
| NE | 0,0 | −1,+1 | −3,+2, 웅크림 | −1,0 | NW와 좌우 대칭 |
| N | 0,0 | 0,+1 | 0,+3, 웅크림 | 0,+1 | 0 / +1 / +3 / +1 |

- SW, S, W, SE, E: 활 전체와 쥔 손이 몸과 얼굴 앞에 보인다. 시위가 얼굴 외곽선 1열 위를 지난다.
- NW, NE, N(뒷모습): 활은 몸 앞쪽, 즉 보는 사람에게서 먼 쪽에 있다. 그래서 두건과 몸통이 활을 가린다. 두건 옆 위 활채와 몸 옆으로 나온 손만 보이고, 시위와 아래 활채는 몸 뒤에서 생략했다. NE와 N에서는 가죽 보호대를 몸통에 가리고 `medu`/`edu`만 보인다.
- 머리가 위로 올라가는 프레임(dy < 0)에서는 다리와 허리 사이에 바지 행을 하나 더 넣었다. 웅크리는 프레임(dy > 0)에서는 다리 행을 줄였다.

## 의도한 차이와 남은 의문

- 활은 몸통 왼쪽 절반(오른쪽 방향은 오른쪽 절반)을 덮는다. 경보병 방패가 덮는 범위와 같다. 활을 몸 정중앙 가로로 드는 안은 대기 활 곡선을 다시 그려야 해서 쓰지 않았다. 사용자가 '가로 지팡이 막기'를 원하면 곡선을 새로 그려야 한다.
- 두 손으로 잡는 대신 활을 든 팔뚝 하나를 드는 방식을 택했다. 반대손은 대기처럼 화살통 쪽에 가려져 있다. 경보병 N 막기는 두 팔을 머리 옆으로 올리는데, 궁병 N은 왼팔을 내린 채로 두었다.
- f0과 f3이 같은 그림인 방향은 S(둘 다 −1)와 N(f1=f3)이다. 경보병도 같은 프레임의 머리 위치가 같다.
- W/E f2 다리는 검수 2에서 앞다리를 곧게, 뒷다리를 굽힌 모양으로 다시 그렸다(아래). NE f2의 웅크림은 검수에서 수용되었다.
- 렌더 중 `grid/attack/SW-1.txt`(다른 작가의 작업 중인 파일)의 폭 오류로 '건너뜀' 메시지가 나왔다. 막기와는 관계없다.

## 검수 2 반영 (review-block-2.md)

팔뚝 하나로 드는 방식과 N에서 내린 왼팔은 검수에서 수용되어 그대로 둔다.

반드시 9건: 상체만 옮긴 엉덩이·다리 이음매의 열린 외곽선을 모두 `#`로 닫았다. 옷과 다리 모양은 바꾸지 않았다.
- S/0–3: 왼다리 윗줄 왼쪽 위 (23–24, 활 끝 행)
- SW/1·3: 엉덩이 위 (24–25,30)/(24–25,29)
- SW/2: (34,32)
- W/3: (31,32)
- E/3: (25,32)
- SE/1·3: 오른쪽 엉덩이 (31,30)/(31,29)
- SE/2: (29–30,29), (22,32)
- NW/1: (25,31)
- NW/2: (27,32)
- NE/2: 오른발 아래 (32,38)

W/2와 E/2는 아래 권장대로 다리를 새로 그리며 함께 닫았다.

권장 반영:
- W/2, E/2: 4px 사선 띠를 없앴다. 앞다리는 대기 다리 픽셀(`#llll#`, `#bcc#`, `#nbcc#`/`#ccbn#`, `#nooo#`/`#ooon#`)로 기준점 위에 곧게 세우고, 허벅지만 1px 사선으로 엉덩이에 이었다. 뒷다리는 엉덩이 뒤에서 무릎을 굽혀 발끝(`no`/`on`)을 뒤로 든 모양이다. 38행 발끝 외곽선 (28,38)을 되살려 발을 접지시켰다. E/2는 W/2의 좌우 대칭이다.
- S/2: 3px 막대 장화를 버리고 f0과 같은 장화(`#mbcc###ccco#`, `#mmnoo##oooo#`)를 썼다. 머리 −2는 바지 행을 하나 더 늘려 무릎을 편 모양으로 표현한다.
- N/0–3: 몸 오른쪽 외곽선 밖으로 아래 활채 `t` 2px와 외곽선을 보였다(손 아래 두 행). 활을 세워 든 모양이 짧은 막대로 읽히지 않게 했다.
