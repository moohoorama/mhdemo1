# 궁병 공격 독립 검수 2

판정: 통과

재검토: 수정 후 공격 8방향 × 4프레임 전체 시트, NE·SE·NW 10배 확대 시트, 진영색·테마 A/B/C 재색칠 시트를 실제 이미지로 확인했다.

- 없음.

## 권장

- 없음.

## 1차 지적 재확인

- attack/NE·NW/0–1: 노출된 화살대와 화살촉이 위쪽 대각선으로 정렬돼, 2프레임의 발사 방향과 이어진다. 머리·손에 가리는 구간도 자연스럽다.
- attack/NE·SE·SW·NW/2: 발사 화살 전체가 활 바깥으로 이동해, 꼬리 깃과 활 외곽선 사이에 분명한 빈 간격이 보인다. 화살이 활의 가지처럼 붙어 보이지 않는다.
- attack/SE/2: 갈색 화살대와 철색 화살촉이 대각선으로 연결되어 하나의 화살로 읽힌다.

## 전체 확인

- 화살 얹기 → 볼 쪽으로 당긴 V형 시위 → 시위 복귀와 분리된 화살 발사 → 낮은 대기 자세 회복의 4단계가 구별된다.
- 8방향의 조준과 발사 방향이 맞으며, N/S의 세로 투영은 기록된 의도대로 읽힌다. N·NE·NW에서는 얼굴이 노출되지 않는다.
- 목재 중앙 손잡이와 손가락·손목·소매 연결, 머리와 몸통의 승인 모델 비율, 화살통 밀착과 발 접지가 유지된다.
- 재색칠은 지정 재질에만 적용되고 명암이 자연스럽다. 활채 잘림·분리된 잡픽셀·검/방패/베기 이펙트 잔재·셀 가장자리 잘림은 보이지 않는다.
- 수정된 화살 이외의 방향에서도 새 결함은 보이지 않는다. 픽셀 수정과 YAML import는 하지 않았다.
