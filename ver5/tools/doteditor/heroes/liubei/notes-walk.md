# 유비 걷기 (walk, 8방향 × 4프레임) 작업 노트

## 방법

- 기본형 걷기의 윗몸(머리·투구·주검·방패 팔)은 프레임 0·2에서 기본형 대기 0과, 1·3에서 기본형 대기 1과 픽셀 단위로 같다
  (행 10–27 이상이 일치한다). 걷기에서 팔이 흔들리는 것은 대기 1의 "손·칼 1px 위로"와 같은 움직임이다.
- 그래서 윗몸은 모델 시트(idle 0 / idle 1)를 그대로 옮겼다. 관모·매듭·뒷머리·귀·수염·금빛 어깨·도포·주검·부검이 대기와 같은 픽셀이다.
  부검은 1·3프레임에서 방패 팔처럼 1px 올라간다.
- 다리(대략 28–40행)는 기본형 걷기의 발 위치와 보폭을 따라 손으로 다시 그렸다.
  - 철 정강이 `b c` → 진영색 `k l`, 신 `m n o`(테마 A)는 그대로, 방패 아래 자락과 방패 원판은 지우고 도포 자락(`l`)과 외곽선으로 채웠다.
  - 기본형 3D 렌더의 잡픽셀(S·SE의 떨어진 외곽선, SE 1·3의 손 아래 `e k n o` 덩어리, 방패 끝 `n o`)은 옮기지 않았다.

## 방향별

- **SW**: 0 = 앞발(화면 왼쪽) 내딛고 뒷발 뒤꿈치 듦. 도포 자락 31행에서 끝나고 32행 외곽선 아래로 두 다리. 1·3 = 통과 자세(한 발 들기). 2 = 오른발이 앞으로, 왼다리는 자락 뒤로 1px만.
- **SE**: 0 = 앞발 한쪽만 보임(39행까지 내려감, 기본형과 같음). 2 = 큰 보폭(양다리 벌림). 1·3 = 대기 다리와 거의 같고 뒷발 밑창 `ooo`.
- **S**: 0·2 = 한 발이 1–2행 앞으로 내려오고(39행, 40행 외곽선 추가) 다른 발은 밑창만. 1·3 = 한 발 들기.
- **E/W**: 0·2 = 큰 보폭, 뒷발 밑창. 1·3 = 대기 다리와 같은 통과 자세. W의 부검(몸 앞, 아래로 뻗은 칼)은 대기 그대로이며 0프레임의 들린 앞발이 칼날 바로 오른쪽에 붙는다.
  E 0·1·3에서 기본형의 방패 손(x32–33, 28–29행)은 모델 시트대로 그리지 않았다(부검은 몸 뒤).
- **N/NE/NW**: 뒷모습. 다리만 기본형 걷기를 따라 바꿨다. NE 0, NW 2는 기본형처럼 몸통 뒤쪽이 1px 넓어진다(팔 흔들림).

## 의도한 것 / 남은 의문

- 아래쪽 발이 기준점보다 1–2행 내려가는 프레임(SE 0, S 0·2, SW 2, N 0·2, NE 2)은 기본형 걷기와 같다.
- S 0·2와 N 0·2의 맨 아래 신 밑에 외곽선 1px을 더했다(기본형에는 없음).
- 다리는 대기와 같은 `k l` 램프만 쓴다. 기본형 걷기의 3D 명암 일부(정강이의 밝은 면)는 단순화했다.

- SW 0: (33,31) → `#`. 도포 자락 끝과 뒷다리가 만나는 모서리를 닫았다.
- S 1·3: (28,33) → `#`. 가랑이 도포 밑단에 외곽선을 넣었다.

- E 3: (28,37) → `#`, (28,38) → `.`. (31,31)·(31,32) → `.`.
- W 1: (25,31)·(25,32) → `.`, (28,38) → `.`.
- W 3: (25,32)·(25,33) → `.`. (25,34)의 신 외곽선은 그대로 뒀다.

## v2 반영 (model-sheet v2: S 자세, SW·SE 머리, 연두 장옷)

- 32프레임 모두 idle v2 파일에서 다시 시작했다(0·2 ← idle 0, 1·3 ← idle 1). 다리(·단)가 시작되는 행 위로는 대기와 픽셀까지 같다.
  처음으로 달라지는 행: S 35–36, E·W 1·3 34, N 32–33, NE·NW·SE 30–32, SW 29–33, E·W 0·2 30.
- 다리는 v1 걷기 보폭을 그대로 쓰고, v2 몸 폭과 단(테마 B `p q r`)에 맞춰 손으로 다시 그렸다. 단 아래로는 진영색 바지(`k l`)와 신(테마 A)만 쓴다.
- **S**: 좌우대칭 대기 자세에서 시작한다(두 칼·손은 idle S 그대로). 0 = 왼발 내딛고(37–39행) 오른발 밑창, 2 = 거울. 1·3 = 한 발을 1행 들어 올린다.
- **SW·SE**: 머리가 1px 앞으로 간 v2 윗몸을 그대로 쓴다.
  - SW 0: 장옷 왼판과 단이 앞발을 따라 1px 앞(왼쪽)으로 나가고, 단 밑줄(32행 `rr`)이 앞다리 위에 온다.
  - SE 2: 큰 보폭이라 장옷 뒤판(31–32행 `qq`/`rr`)이 왼다리를 따라 벌어진다.
- **E·W**: 등판(뒤 자락)이 0·2에서 뒤로 1px 밀린다. E에서는 뒷다리를 따라 왼쪽으로, W에서는 오른쪽으로 밀리고, 끝단 `rr`/`rrr`이 뒷발 위에 걸린다. 1·3은 대기와 같은 통과 자세다.
- **N**: 0·2에서 내딛는 다리 쪽 단이 1행 더 내려온다(32행 `rrrrr`). NW 2는 뒷다리 쪽 단이 1px 넓어진다. NE 0은 등 단이 왼다리 쪽으로 1px 넓어진다.
- 대기 SW 1의 30–31행 오른쪽 x34 외곽선이 비어 있다. 걷기 1·3에서는 `#`로 닫았다(이 두 행은 걷기가 대기와 다르다). 대기 파일은 고치지 않았다.
- 검수: themeB를 바꾸면 장옷만 바뀌고, faction을 바꾸면 매듭·속옷·허리띠·바지만 바뀐다.
