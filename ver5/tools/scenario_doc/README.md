# 시나리오 문서 도구

`python3 tools/scenario_doc/build.py`는 이야기 대본을 문서로 만든다.

`python3 tools/scenario_doc/progression.py --through 11`은 각 장의 합류·지급·전투 보상·변경되는 부목표·탐험 이벤트·상점 신규 상품 후보를 마크다운으로 나열한다. 인자 없이 실행하면 모든 장을 출력한다.

결과는 JSON의 노드 배열과 파일 순서를 읽는 정적 목록이다. 갈림길의 실제 도달 여부, 탐험 대화의 선택 여부, 지급 전에 필요한 플래그, 승리 후 보상의 다음 전투 사용 가능 여부는 자동 판정하지 않는다. 전투 중 등장도 신규 합류와 복귀를 구분하지 않으며, 상점 첫 상품은 출력 순서상 첫 발견으로 구매 여부와 무관하다. 정확한 시점과 조건은 결과의 파일·노드 ID를 따라 확인한다. 장수 병종은 인물 데이터의 등록 병종이며 실제 합류 레벨의 병종을 계산하지 않는다. 아이템 도난·레벨업으로 열린 특성·장비 없이 사용 가능한 병종 기술은 추적하지 않는다.

`python3 tools/scenario_doc/trait_plans.py [--officers | --classes]`는 장수의 고유 특성 계획·`TraitAt`·`Learn`과 병종의 특성 계획·학습 풀을 데이터에서 마크다운 표로 만든다. `docs/logic-traits.md` 4.1절은 이 표를 옮기지 않고 이 스크립트를 가리킨다.
