# 배치·출전 통합과 가장자리 화살표 스크롤 설계

2026-10-30 · 상태: 구현됨 (커밋 전). 설계와 달라진 점은 9절.

## 1. 문제

1. **배치 중 원치 않는 스크롤.** `internal/gui/view.go:224`의 가장자리 스크롤은 전장 뷰포트
   가장자리 띠(창 너비 5%)에 마우스가 닿으면 바로 카메라를 민다. 배치 중에는 뷰포트 아래 끝이
   카드 바 윗선이라, 카드를 누르러 내려가는 길에 반드시 띠를 지나고 전장이 아래로 밀린다.
2. **전장을 본 뒤 출전을 바꿀 수 없음.** 출전 명단·장비·부관은 출전 준비 화면
   (`internal/gui/scenario.go:342` `preparation`)에서만 바꿀 수 있고, `start` 뒤 배치 단계에서는
   배치/해제만 된다. 배치 칸과 적 배치를 보고 나서 마음이 바뀌어도 돌아갈 길이 없다.

## 2. 결정 요약

- 출전 준비 화면을 없애고 **배치 화면 하나**에서 출전·배치·장비·부관을 모두 다룬다.
- 카드 클릭은 **출전/대기 토글**. 출전시키면 배치 칸에 자동으로 선다.
- 전장의 아군 클릭은 **선택** → 옮기기, 그리고 오른쪽 **장수 창**(정보 + 장비 + 부관).
- 전투 맵 가장자리 스크롤은 **커서가 화살표로 바뀌고 좌클릭해야** 움직인다.
  탐험·스토리 장면에는 없다.

## 3. 배치 화면

```
┌──────────────────────────────────────┬───────────────┐
│                                      │ [초상] 관우    │
│            전장 (배치 칸 밝게)         │ Lv5 · 경기병   │
│                                      │ 무력 · 통솔 …  │
│                                      ├───────────────┤
│                                      │ 무기   청룡도 ▸ │
│                                      │ 방어구 찰갑   ▸ │
│                                      │ 보조   콩주머니 ▸│
│                                      │ 부관   주창   ▸ │
├──────────────────────────────────────┴───────────────┤
│ [유비 필수] [관우 출전] [장비 출전] [간옹 대기] …  출전 3/5 │
└──────────────────────────────────────────────────────┘
```

### 3.1 카드 바 (아래)

- 출전 가능한 장수 전원을 보여 준다: 출전 중인 장수 먼저, 그 뒤 대기 장수(흐리게).
  사망 장수·부관으로 붙은 장수는 나오지 않는다(부관은 장수 창에서 다룬다).
- 카드 상태 표기: `필수` / `출전` / `대기`. 선택한 장수의 카드는 금색 테두리.
- **대기 카드 클릭 → 출전.** 스테이지 배치 칸(`stage.Allies`)을 **적힌 순서대로** 훑어 첫 빈칸에
  세운다. 맵을 만들 때 좋은 칸부터 적어 두는 것으로 자동 배치 순서를 조절한다.
  빈칸이 없으면 `NoDeploymentSpace` 메시지.
- **출전 카드 클릭 → 대기.** 전장에서 빠진다. 선택 중이던 장수면 선택도 풀린다.
- 군주·필수 장수 카드는 클릭해도 빠지지 않는다(“필수” 표기 유지).
- 인원이 찼을 때 대기 카드 클릭 → “출전 인원이 찼습니다”. 선택 장수와의 맞교체는 1차에 넣지 않는다.
- 오른쪽 아래 `출전 n / 최대`와 `전투 시작 Enter`. 출전 1명 이상·필수 충족이면 시작 가능
  (출전한 장수는 항상 서 있으므로 “모두 배치” 조건은 사라진다).
- 지금의 Tab(다음 미배치 장수)은 의미가 없어지므로 **다음 출전 장수 선택**으로 바꾼다.

### 3.2 전장 (위)

- 배치 칸만 밝게, 나머지는 어둡게 — 지금과 같다.
- **아군 클릭 → 선택.** 선택된 장수 발밑과 갈 수 있는 빈 배치 칸이 깜빡인다(지금의 하이라이트 재사용).
  - 밝은 빈칸 클릭 → 그 칸으로 옮긴다.
  - 다른 출전 아군 클릭 → 두 장수 자리를 맞바꾼다. 상대가 그 칸에 설 수 없는 지형이면 바꾸지 않고 선택만 넘긴다.
  - 같은 장수 다시 클릭 / 우클릭 / Esc → 선택 해제.
- 적이나 동맹 클릭 → 지금처럼 정보만(배치 대상 아님).
- 칸에 올려 둘 때 미리보기(반투명 유닛)는 지금 것을 유지.

### 3.3 장수 창 (오른쪽)

선택한 장수가 있을 때만 열린다. 없으면 지금처럼 오른쪽 패널(부대 요약 + 미니맵).

- 위: 초상, 이름, Lv·병종, 주요 능력치 한 줄, 특성 이름 몇 개 — 짧게.
  (`officerDetail`의 요약판. 자세한 건 부대 창으로.)
- 아래: **무기 · 방어구 · 보조** 세 줄, 각 줄 클릭 → 기존 장비 고르기 창(`updateEquipPicker`) 재사용.
- 그 아래 **부관** 한 줄, 클릭 → 부관 고르기. 대기 장수 중에서만 고른다.
  출전 중인 장수를 부관으로 붙이면 그 장수는 출전에서 빠진다.
- 장비를 바꾸면 전장의 유닛도 바로 바뀐다(무기 모양, 최대 체력). 배치 단계 유닛은 항상 체력 가득.
- 군량·도구 목록은 넣지 않는다. 부대 창의 소지품 탭에서 본다.

## 4. 흐름 변화

| | 지금 | 바뀐 뒤 |
|---|---|---|
| 전투 노드 진입 | 출전 준비 화면 | 곧바로 `start` → 배치 화면 |
| 출전 명단 | 준비 화면에서 `deploy` | 배치 화면 카드 토글 |
| 장비·부관 | 준비 화면 | 배치 화면 장수 창 |
| 첫 배치 | 장수마다 수동 배치 | 지난 출전 명단(없으면 군주 + 필수)이 자동 배치로 서 있음 |
| 패배 후 재시도 | 준비 화면으로 | 배치 화면으로, 마지막에 시작한 명단·장비 그대로 |
| 강제 출전 스테이지 | 자동 배치 후 바로 전투 | 그대로 |

## 5. 엔진 변경 (`internal/core`)

지금 유닛은 `place` 때 생기고(`deployment.go:59`), `start`에서 체크포인트를 만든다
(`engine.go:614`, phase `scenario` 스냅샷). 그 구조를 그대로 살려서:

1. **배치 단계에서 받는 명령 확장.** `deploy`(명단 토글), `equip`/`unequip`, `deputy`/`undeputy`를
   phase `deployment`에서도 받는다. 검사 규칙은 `prepare`의 것을 그대로 쓴다.
   - 명단에서 빠진 장수 → 서 있으면 `unplace`.
   - 명단에 든 장수 → 자동 배치 규칙(첫 빈칸)으로 `place`. 실패하면 명령 전체 실패.
   - 장비 변경 → 서 있는 유닛을 같은 칸·같은 방향으로 다시 세운다(체력 가득).
   - 부관 지정으로 출전자가 부관이 되면 명단에서 뺀다.
   - GUI가 토글을 쉽게 쓰도록 `deploy`에 `Actor` 하나만 주는 `sortie_toggle` 같은 명령을 따로 둘지,
     지금처럼 전체 명단을 보내게 할지는 구현 때 정한다(지금 `toggleDeploy`가 전체 명단을 만든다).
2. **자리 바꾸기.** `swap`(Actor, Target) 명령 추가: 두 칸 모두 서로 설 수 있을 때만.
   옮기기는 지금처럼 `unplace` + `place`.
3. **`start` 직후 자동 배치.** 강제 출전이 아니어도 명단 전원을 자동 배치로 세운다.
   지금 `DeploymentPlan`은 지형이 까다로운 장수를 위해 재배정을 하는데, 그대로 쓰되 마지막
   `deployment_finish`는 넣지 않는다.
4. **체크포인트 시점.** 재시도가 배치 화면에서 바꾼 장비·명단을 잃지 않도록,
   체크포인트를 `deployment_finish` 때 다시 만든다: 지금 체크포인트(phase `scenario`)에
   그 시점의 장수 장비·부관·창고·명단을 덮어쓴다. 재시도는 체크포인트 복원 후 바로 `start`.
5. **`deploymentReady`** 는 “명단 전원이 서 있음” 대신 “명단 1명 이상·필수 충족·전원 서 있음”.
   (자동 배치 때문에 전원 서 있음은 사실상 항상 참.)
6. 출전 준비 화면을 쓰던 `prepare`의 phase `scenario` 경로는 탐험 화면의 장비 변경이 쓰는지 확인하고,
   안 쓰면 `deploy`/`start`만 정리한다.

## 6. 가장자리 화살표 스크롤

전투 맵(phase `deployment`·`battle`)에서만. 탐험(`exploring()`)과 스토리 장면에서는 그리지도 움직이지도 않는다.

- **띠:** 지금과 같은 뷰포트 가장자리 5% 띠. 배치 중 아래 띠(카드 바 경계)도 포함.
- **커서:** 띠 안이고 그쪽으로 카메라가 더 갈 수 있으면 OS 커서를 숨기고
  (`ebiten.SetCursorMode(CursorModeHidden)`) 그 방향 화살표 그림을 커서 자리에 그린다.
  모서리(두 띠가 겹치는 곳)는 대각선 화살표. 8방향.
- **클릭:** 좌클릭을 누르는 동안 그 방향으로 스크롤(지금 속도 `12/zoom` 그대로).
  짧게 한 번 눌러도 최소 한 칸 거리만큼은 간다(부드럽게 미끄러지는 `g.pan` 재사용).
- **클릭 가로채기:** 화살표가 떠 있으면 그 좌클릭은 칸 선택·배치로 가지 않는다.
  카메라가 맵 끝에 닿아 그쪽으로 못 가면 화살표를 띄우지 않고 클릭은 평소대로 칸으로 간다
  → 맵 가장자리 칸·유닛도 누를 수 있다.
- **안 뜨는 때:** 카메라 잠금(`cameraLocked`), 오버레이·모달·입력 중, 드래그 중, 스크린샷 실행 중,
  커서가 HUD 패널 위.
- 지나가기만 해서는 움직이지 않으므로 1번 문제는 이걸로 해결된다.
- 방향키·우클릭 드래그·미니맵 클릭·휠 확대는 그대로.

### 6.1 화살표 그림

- 8방향 각각 따로 그린다(도트 그림을 45° 돌리면 뭉개진다). 크기 32×32 UI px 안팎,
  금색 몸통 + 진한 외곽선, 끝이 커서 핫스폿.
- UI 시트 `assets/graphics/ui/ui.png`/`ui.json`에 `cursor_arrow_n` … `cursor_arrow_nw`로 넣는다.
- 그리는 방법은 기존 UI 도트 관례(아스키 픽셀 시트 → 시트)를 따른다.

## 7. 작업 순서

1. 화살표 스크롤 (GUI만, 독립) — 그림 8장, `view.go` 가장자리 로직, 커서 그리기.
2. 엔진: 배치 단계 명령 확장, `swap`, `start` 자동 배치, 체크포인트 갱신 + 테스트.
3. GUI: 카드 바 토글, 전장 선택·옮기기·맞바꾸기, 장수 창(장비·부관).
4. 출전 준비 화면 제거, 전투 노드 진입 시 곧바로 배치 화면, 재시도 경로.
5. `_uidemo`로 배치 화면 캡처 확인, `srpg-cli` 배치 흐름·재시도 확인.

## 8. 남은 질문

- 부관을 장수 창에서 고를 때 후보 목록 모양(작은 목록 창 vs 장비 고르기 창 재사용).
- 출전 인원이 찼을 때 맞교체를 나중에 넣을지.

## 9. 구현 메모 (설계와 달라진 점)

- **`start`는 그대로 둔다.** 엔진의 `start`를 쓰는 곳이 테스트·도구에 54군데라, 전투 노드에 닿으면
  GUI가 `startSortie`로 곧바로 `start`를 보낸다(인원 초과면 군주·필수부터 남기고 자른 뒤).
  CLI·AI는 예전처럼 `deploy` → `start` → `place` 순서를 그대로 쓸 수 있다.
- **자동 배치는 `deploy`가 한다.** 배치 단계에서 받은 `deploy`는 명단에서 빠진 장수를 내리고,
  아직 서지 않은 장수를 배치 칸 순서대로 세운다. GUI는 배치 단계에 들어서자마자 같은 명단으로
  `deploy`를 한 번 보내 전원을 세운다(`placeSortie`). 따로 `sortie_toggle`은 만들지 않았다.
- **옮기기·맞바꾸기는 `reposition` 하나.** 서 있는 장수를 빈 배치 칸으로 옮기거나, 출전 아군이 선 칸이면
  자리를 바꾼다. 두 장수가 서로의 칸 지형에 설 수 있어야 한다. `LegalActions`가 서 있는 장수에게
  `unplace` 다음으로 갈 수 있는 `reposition`을 준다. CLI: `reposition 장수 x y`.
- **장비·부관 변경**은 배치 단계에서도 받고, 바뀐 장수는 같은 칸에 다시 선다(체력 가득).
- **체크포인트**는 `deployment_finish` 때 장수·창고·명단을 덮어써서(`keepSortie`), 재시도하면 마지막에
  시작한 그대로 배치 화면이 열린다. 패배 창 버튼은 “배치부터 재도전”.
- **장수 창**은 내용 높이에 맞춘다. 부관 줄은 부관을 둘 수 있는 장수만, “대기로 돌리기”는 필수가 아닌 장수만.
  장비 줄을 누르면 장비 창과 고르기 창이 함께 열리고, 고르기 창을 닫으면 장비 창도 닫힌다.
- **화살표**는 `edge_arrow` 8프레임(28×28 도트, `seed.py edge_arrow`), 1.5배로 그리고 끝이 커서 자리에 오게 한다.
  누르면 화면의 4분의 1만큼 미끄러지고, 0.3초 넘게 누르고 있으면 방향키 속도로 계속 간다.
  카메라가 끝에 닿은 쪽, HUD 위, 전투·배치가 아닌 화면(탐험·장면)에서는 뜨지 않는다.
- 출전 준비 화면(`preparation`, `toggleDeploy`)은 지웠다. 부대 창의 장수 상세(`officerDetail`)는 남는다.
- 확인: `go run ./cmd/_uidemo-vm -ui deploy -stage B09 -frames 235 -at 20,60,80,130,150,172,185,200,215,230`
