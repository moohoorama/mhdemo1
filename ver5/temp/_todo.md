2026-11-18 요구사항(R-01~R-72)과 그날의 후속 지시를 기준으로, 아직 안 됐거나 확인이 필요한 것을 모았다.
코드·시스템·전투 설계는 대부분 커밋됐고 전체 시험은 통과했다(패키지 14개 ok). 아래는 그 뒤에 남은 것이다.

## 1. 사용자가 정해야 하는 것

- [ ] **장무·진손을 산적(적병) 계열로 바꿀지** — "반란군은 전부 적병 계열"이었지만 장무(말 탄 일기토·적로 대사)와 진손(활 일기토 대사)은 병종에 연출이 얽혀 그대로 뒀다. 바꾸면 말·활 연출을 어떻게 할지 정해야 한다.
- [ ] **청홍검 25v장 대사** — "좋은 검이라 가져왔습니다" 뒤 유비의 "자룡이 거둔 것이니 자룡이 맡아 두게"가 어색하지 않은지(자동 착용이 없어졌다).
- [ ] **3장 시작 장 번호** — 장비 단계 표(`game.json` `Rules.GearTiers`)에 임시로 28장. 적벽 뒤 3장을 만들 때 맞추고, 강 계열 상점(`weapons_steel`)도 만든다. 연의 판은 "주유를 속이고 강릉·양양을 점거"로 본다.
- [ ] **17·18장 대장간** — "업(19장)부터 철 계열"이라 D 장비 그대로인데, 17장부터 적은 C 장비를 입는다. 이대로 둘지.
- [ ] **장비 등급 5 이상** — 지금은 "S"로 표시된다(현재 데이터 최대는 4=A). A+로 바꿀지.
- [ ] **장면 카메라 허용 영역 기본값** — 가로·세로 50%. debug 설정에서 바꿔 보고 정한다.
- [ ] **삼분지계 지도에서 마등 표현 여부** (R-41). 안 그리는 쪽을 권했다.
- [ ] **여남 남쪽 평지 범위** (R-01) — 남서 길뿐 아니라 남쪽 성 앞(y44~48)까지 바꿨다. 범위가 맞는지.
