# 22~27장 구현 중 내린 결정

`plan/_design_22_27.md`를 게임에 넣으면서 설계에 없거나 애매했던 것을 정한 기록이다.
항목마다 **무엇을 정했나 / 선택지 / 고른 것과 까닭**을 적는다. 구현하는 에이전트도 같은 형식으로 아래에 덧붙인다.

## 감독(메인 세션) 결정 — 2026-11-17

### D1. 모드 판정을 무엇으로 저장하나
- 선택지: (a) 플래그 하나 `flag-mode-virtual`(1=가상, 없으면 연의) (b) 플래그 둘 `flag-mode-yanyi`·`flag-mode-virtual` (c) 엔진에 모드 필드 추가
- 결정: (b). 24장 융중대에서 둘 중 하나를 반드시 세운다. 25장 이후 분기는 `flag:flag-mode-virtual`로 보고, 연의 쪽은 `flag:flag-mode-yanyi`로 다시 확인할 수 있게 둔다.
- 까닭: 기존 `set`/`branch` 노드로 충분하고 엔진·저장 형식을 바꾸지 않는다. 둘 다 세워 두면 "아직 안 정해짐"과 "연의"가 구별된다.

### D2. 가상모드 조건
- 결정: `party:gaoshun`(22장 시점 부대에 고순이 있음 = 「고순 생존」), `flag:flag-zhugexuan`(12장), `flag:flag-guanyu-mifang`(22장에서 새로 세우는 「관우·미방 화해」)을 모두 만족하면 융중대에서 빠른 길/느린 길 선택지가 뜨고, 하나라도 빠지면 선택지 없이 연의로 정한다.
- 까닭: fullstory.md 1절의 조건 그대로. 고순 생존은 12장 플래그(`flag-gaoshun`)보다 지금 부대에 있느냐가 맞다(18장에 떠났다 19장에 돌아오는 갈래가 있음).

### D3. 장 파일과 스테이지 ID
- 선택지: (a) 연의·가상을 같은 장 파일에 몰아넣기 (b) 가상을 따로 `story25v.json` 등으로
- 결정: (b). 장 ID `22`,`23`,`24`,`25`,`26`,`27`(연의), `25v`,`26v`,`27v`(가상). 스테이지 ID는 연의 `B25`·`B26`·`B27`, 가상 `B25V`·`B26V`·`B27V`. 연의 27장 마지막과 가상 27장 마지막은 각각 캠페인을 끝낸다(연의 27 끝에서 기본 순서로 25v로 흘러가지 않게).

### D4. 설계의 「정할 것」
- 서서: 연의는 26장(장판파) 뒤 `leave`(노모와 함께 조조군에 잡힘, 손건 대사). 가상은 남는다. — 설계 초안대로.

- 보상 미정 둘(연의 장판파 부목표, 가상 양양 채모 격퇴): 새 장비를 더 만들지 않고 이미 있는 아이템에서 고른다. 구체 아이템은 구현 에이전트가 고르고 아래에 적는다.
- 연의 장판파 본군: 다리를 건너 마중 나가도 된다(막지 않는다). — 막으려면 이동 금지 규칙이 새로 필요하고, 설계의 "다리를 건너 나가 길을 열어 줄 수도 있다"와 맞는다.
- 아두·미 부인: 연의 26장 전투 앞 장면에만. 설계대로.
- 강하의 상급 인수: 설계대로 둔다.
- 25장 S#1 유표: 평상에 기대앉음. 설계대로.
- 박망파: fullstory.md 24장의 옛 개요(하후란 설득·관평·진도 불 놓기) 대신 `_design_22_27.md`의 B24를 따른다(설계가 더 새것).

### D5. 품질 기준("어떻게든 27까지")
- 새 인물의 전투 도트·초상은 새로 그리지 않고 기존 병종 시트·비슷한 인물의 그림을 빌린다. 새 장비 아이콘도 기존 아이콘을 빌린다.
- 장면 맵은 기존 `S_*` 장면 맵을 다시 쓰고, 새 맵이 꼭 필요한 곳만 만든다.
- 전투 맵은 새로 만들되(설계 크기 기준) 지형 정밀도보다 이벤트·목표가 돌아가는 것을 먼저.
- 엔진 기능은 기존 이벤트(`spawn`·`buff`·`ai`·`terrain`·조건)로 표현되면 엔진을 고치지 않는다.

## 구현 에이전트 결정

### [장비] 옷·말 칸
- 선택지: 옷(비단 도포·학창의)과 말(적로)을 위한 칸을 새로 만든다 / 기존 세 칸에 맞춘다
- 결정: 옷은 `armor` 칸의 `robe` 형식, 말은 `accessory` 칸(형식 `any`)에 둔다.
- 까닭: 장비 칸은 `weapon`·`armor`·`accessory` 셋뿐이고 평복이 이미 `armor`/`robe`, 백마·절영·적토마가 `accessory`다. robe는 문관·적병·무도가 계열만 입는다.

### [장비] 청홍검은 기존 청공검
- 선택지: 청홍검을 새로 만든다 / 기존 `qinggang_sword`(청공검, 청공: 앞 대상 양옆 50%)를 쓴다
- 결정: 기존 장비를 쓰고 표시 이름만 `청홍검`으로 바꿨다. 특성 이름 `청공`과 효과는 그대로다.
- 까닭: 같은 칼(靑釭劍)이고 대본(22~27장)이 모두 청홍검이라 부른다. 이야기 데이터가 아직 이 이름을 쓰지 않아 바꿔도 깨지는 곳이 없다.

### [장비] 이미 있는 특성을 주는 장비
- 선택지: 장비마다 새 특성 / 같은 효과의 기존 특성을 준다
- 결정: 적로=질풍(`gale`, 이동 +2), 진법서=금쇄(`iron_lock`, 둘레 8칸 아군 방어 +20%), 백우선=백출(`half_cost`, 병법치 절반). 의천검은 그대로 두고(의천 `evade` 15) 보법(`evade` 15)과 합쳐 30%p가 되므로 코드를 고치지 않았다.
- 까닭: logic-traits 원칙 4(같은 효과를 이름만 바꿔 중복 만들지 않는다). 버프 크기 20%는 금쇄·중갑·선봉과 같다.

### [장비] 새 효과 키 다섯
- 선택지: 장비마다 엔진 분기 / 일반 효과 키
- 결정: `hit_status:<해로운 상태>`(값=턴, 유성추는 disarm 2), `double_ward`(연타 둘째 타 막기), `charm`(매력 +), `mana_max`(최대 병법치 +), `mana_plus`(차례마다 병법치 회복 +)를 `vocab.go`에 더했다. 금흉갑은 금강과 같은 `crit_immune`에 `double_ward`를 더한 특성 금흉.
