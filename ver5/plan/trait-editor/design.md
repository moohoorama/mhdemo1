# 특성 수정안 편집기

목적: `_newfeature.md`의 분류별 특성과 병종·장수 학습 목록을 브라우저에서 함께 수정하고, 장수별 선행관계를 즉시 확인한다. 결과물은 외부 라이브러리·서버가 필요 없는 `_newfeature-editor.html` 한 파일이다.

## 데이터와 연동

- 특성은 변경되지 않는 ID로 연결한다. 이름·설명·분류·발동·선행·장비를 편집한다. 이름 변경은 선행·배정·트리·내보내기에 즉시 반영하며, 본문 속 이름은 선택적으로 함께 치환한다.
- 학습 배정의 원본은 병종·장수별 특성 ID 목록이다. 특성의 학습 대상은 그 목록에서 역산한다. 특성 화면과 대상 화면 양쪽에서 배정을 바꿀 수 있다.
- 병종 승급 관계와 장수의 기본 병종은 현행 데이터에서 초기화한다. 장수 트리는 고유 학습과 선택 병종·하위 병종의 학습 풀, 재귀 선행을 함께 표시하며 미배정 선행을 구별한다. 병종 변경은 수정안 안의 값이다.
- 선행의 자기 참조·순환, 중복 이름·없는 ID를 검증한다. 복수 선행은 모두 필요한 AND 관계로 연결한다. 특성 삭제는 연결·배정 제거 범위를 보여 준 뒤 처리한다.

## 편집 화면

- 특성 검색·분류 필터·미배정 필터, 상세 편집과 선행·학습 대상 선택.
- 병종·장수별 학습 배정 편집과 동적 SVG 트리. 트리의 노드를 누르면 해당 특성을 편집한다.
- 브라우저 자동 저장, 실행 취소·다시 실행, JSON 저장·불러오기, 수정 HTML 저장, 분류별 Markdown 내보내기.
- 원본 안내·검토 문구는 별도 메모로 보존하고, 특성명을 바꿀 때 선택한 본문 치환을 메모에도 적용한다. 외부 파일·게임 데이터는 직접 덮어쓰지 않는다.

## 확인 기준

1. 초기 146개 특성·25개 병종·61명 장수와 원문의 배정·선행이 일치한다.
2. 이름·설명·선행·배정을 바꾸면 양쪽 목록과 트리에 함께 반영된다.
3. 순환 선행은 적용되지 않으며, 장수에게 없는 선행은 트리에서 표시된다.
4. 저장·재로드·JSON 및 HTML 재열기·Markdown 내보내기로 수정안을 보관할 수 있다.
5. 모델 검증과 브라우저 조작·화면 캡처로 동작과 배치를 확인한다.

## 사용법

1. 저장소 루트의 `_newfeature-editor.html`을 브라우저에서 연다. 설치나 서버가 필요 없다.
2. **특성 편집**에서 이름·본문·분류·발동·선행·학습 대상·장비를 수정한다. 텍스트 입력은 포커스를 옮길 때 반영된다. 이름 변경 시 설명·원문·메모의 같은 이름을 함께 치환할지 선택할 수 있다. 조사는 직접 다듬는다.
3. **병종·장수**에서 직접 배정된 학습 목록을 바꾼다. 병종 승급으로 이어받는 특성은 고유 배정과 구분한다.
4. 오른쪽 대상·병종 선택으로 고유 학습과 승급 전 병종의 풀을 포함한 트리를 확인한다. 주황 점선 노드는 선행으로 필요하지만 현재 학습 경로에는 없는 특성이다. 노드를 누르면 해당 특성을 편집한다.
5. **JSON 저장 / 불러오기**로 편집 상태를 이어 가거나 **HTML 저장**으로 수정안이 포함된 독립 파일을 만든다. **Markdown 내보내기**는 현재 배정에서 소유 목록을 다시 계산해 문서를 만든다. 원문·검토 메모는 별도로 편집한다.

브라우저 자동 저장은 같은 파일·브라우저에서의 작업을 돕는다. 다른 환경으로 전달하거나 장기 보관할 때는 JSON 또는 HTML을 저장한다. 수정안은 원본 Markdown이나 게임 데이터를 직접 덮어쓰지 않는다.

## 검증

- `node --test ver5/plan/trait-editor/editor.test.cjs`: 초기 원문과의 일치, 개명·본문 치환, 중복·순환 차단, 배정 역산, 장수 트리, 병종 상속, 삭제, Markdown, 잘못된 가져오기의 9개 회귀 검사.
- DOM 환경 검사: 편집 이벤트, 양방향 배정, 실행 취소·다시 실행, SVG 갱신, HTML 재열기와 브라우저 저장 복원 통과.
- 별도 Chrome 헤드리스 프로필에서 실제 HTML을 실행해 18개 편집·연동 항목 통과. 1600px 데스크톱과 600px 좁은 화면, 장수·승급 병종의 동적 SVG를 캡처해 확인.
