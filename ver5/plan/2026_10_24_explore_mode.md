# 탐험 모드 — 스토리를 걸어 다니며 진행하기 (1장 탁군 ~ 2장 영천 전투)

작성일: 2026-10-24
관련: [2026_10_23_story_impl.md](2026_10_23_story_impl.md)(1부 계획), [fullstory.md](../docs/fullstory.md)(전체 이야기), `cmd/_town2`·`internal/gui/tour.go`(형식 2 걷기 데모)

## 1. 목표와 범위

전투 사이 스토리를 장면만 이어 붙이지 않고, 유비가 형식 2 장면 맵을 걸어 다니며 진행한다.

- **탐험 모드**: 유비 혼자 걷는다. 클릭한 곳으로 걸어가고, 출구를 누르면 다른 지역(거리, 건물 안, 주둔지, 진영)으로 간다.
  NPC가 서 있거나 돌아다니고, 말을 걸 수 있다. 관우·장비도 NPC다.
- **이벤트 모드**: 지금의 장면 연출을 그대로 쓴다. 특정 NPC에게 말을 걸면 그 자리(지금 지역 맵)에서 대사·등장·이동·모션·효과가 펼쳐진다.
  끝나면 다시 탐험 모드다.
- **출진**: 심복(지금은 관우, 공명 출려 뒤엔 공명)에게 말을 걸면 "출진하시겠습니까?"를 묻는다. 예 → (출진 직전 이벤트) → 전투.
- **상점**: 무기점(기본 무기·기본 방어구), 도구점(보조도구·먹지 않는 소모품), 주점(콩·술). 재화는 **돈**이다. 품목은 지금 있는 것만으로 시작한다(부족한 상태로 둔다).
- **저장**: 탐험 중 어디서나 저장·불러오기가 된다.

이번 범위는 **1장 시작부터 영천 전투(지금 B01을 고친 것) 시작까지**다. 탁군 전투(새 B01)도 들어간다.

이 계획은 1부 계획 §1의 "엔진 신규 기능 없음"을 바꾼다. 탐험 모드는 core·content·GUI에 새 기능을 넣는다.

옛 마을 데모(`cmd/_town`, `internal/town`, `internal/gui/town.go`, `assets/towns/zhuo.json`, `_uidemo-vm -ui town`)는 폐기한다.

## 2. 동선

### 1장 도원결의 → 탁군 전투

| # | 지역 | 할 일 | 그 뒤 |
|---|---|---|---|
| 1 | 탁군 거리 | 시작. 백성들이 유주태수의 의병 모집 이야기를 한다(혼잣말·대화). 방문 앞에 장비. | |
| 2 | 탁군 거리 | 장비에게 말 걸기 → 짧은 이벤트: 함께 방문을 보고, 관우가 주점에 있다고 한다. | 장비가 거리에서 사라진다 |
| 3 | 주점 | 구석의 관우에게 말 걸기 → **이벤트 S#1**(원본 1장 S#1). 장비가 먼저 나간다. | 성문 밖 → 복숭아 숲 열림 |
| 4 | 복숭아 숲 | 성문 밖으로 나가면 숲. 술상 앞의 장비에게 말 걸기 → **이벤트 도원결의**(S#2). | 탁군 거리로 돌아온다. 숲은 다시 못 간다 |
| 5 | 의병 주둔지 | 성문 밖이 이제 주둔지다. 의병들, 장비는 훈련시키고(순찰·모션·혼잣말), 관우가 서 있다(심복). | |
| 6 | 의병 주둔지 | 관우에게 말 걸기 → 출진? 예 → **출진 직전 이벤트**(S#3: 정찰이 달려와 황건이 성으로 몰려온다고 알림) → **탁군 전투** | |

- 1장에는 "이튿날" 같은 시간 서술을 넣지 않는다. 주점에서 바로 숲으로 간다.
- 상점 셋(무기점·도구점·주점)은 처음부터 열려 있다. 시작 돈은 1000이다. 숲 판 돈은 의병을 모으는 데 쓰였으므로 유비에게 따로 돈을 주지 않는다.
- 장세평 저택은 잠가 둔다(탁군 거리 맵은 예시였으므로 쓰지 않는 건물은 잠긴 민가로 둔다).

### 2장 노식의 진영 → 영천 전투

| # | 지역 | 할 일 | 그 뒤 |
|---|---|---|---|
| 1 | 관청 | 전투 뒤 시작. 관청에 관우·장비·추정. 추정에게 말 걸기 → **이벤트 S#1**(추정이 태수를 대신해 치하, 유비는 벼슬을 사양하고 노식에게 가겠다고 한다). | 주둔지에 "노식의 진영으로" 출구 열림 |
| 2 | 노식의 진영 | 해자 옆에서 조는 병사들, 휘장 너머를 오가는 좌풍(순찰). 노식(막사 안)에게 말 걸기 → **이벤트 S#2**(원본 2장 S#2, 영천 급보). | 관우가 심복이 된다(출진 가능) |
| 3 | 노식의 진영 | 관우에게 말 걸기 → 출진 → **영천 전투** | |

- 노식의 진영에서 탁군으로 돌아갈 수 있다(상점 이용). 관우·장비는 유비가 지금 있는 곳 쪽에 선다(플래그로 정함).
- 유언은 나오지 않는다. 원본 2장 S#1의 유언 대사는 추정이 태수의 뜻을 전하는 말로 바꾼다.

## 3. 데이터

### 3.1 스토리 노드

새 노드 Kind 셋.

```json
{"ID": "c01-walk", "Kind": "explore", "Explore": "ch01"}
{"ID": "c01-e-tavern-end", "Kind": "back"}
```

- `explore`: 탐험을 연다. 플레이어가 출진할 때까지 여기서 멈춘다. 출진하면 이 노드 다음 노드로 간다(출진 직전 이벤트 → `battle`).
- 이벤트는 스토리 파일의 `Events` 목록에 둔다(`{"Nodes": [...], "Events": [...]}`): `scene` 노드로 시작해 `say`·`narrate`·`set`·`grant`·`join`·`branch`를 거쳐 `back`으로 끝난다. `back`은 탐험으로 돌아간다.
  `Events` 안에서는 다음 노드가 이어지고, 흐름(`Nodes`)으로는 닿지 않는다. 읽을 때 모든 이벤트가 `back`으로 끝나는지 검사한다.
- 이벤트를 다른 맵에서 펼칠 수 있다(장면의 `Map`이 지역 맵과 다르면 그 맵을 연다). 끝나면 유비는 이벤트를 연 지역·자리로 돌아온다. 이벤트가 유비를 옮겨야 하면 `back`에 `Area`·`At`을 준다(숲 → 탁군 거리).

### 3.2 탐험 파일 `assets/scenario/hero/exploreNN.json`

장 하나에 탐험 파일 하나. core가 조건·이벤트·출진·상점을 읽으므로 규칙 내용(`content`)에 넣는다. 좌표는 모두 **작은 칸**(`tour2.json`과 같다).

```
{ "Hero": "liubei", "Start": {"Area", "At": [U, V], "Face"},
  "Areas": { "<id>": {
    "Map", "Name", "Zoom"?, "Time"?, "At": [U, V],
    "Exits": [{"Name", "At", "Object"?, "To", "If"?: [조건], "Shut"?: [[화자, 대사]]}],
    "People": {"<표시 이름>": {
      "At", "Face", "Sprite"?, "Portrait"?, "Faction"?, "Pose"?,
      "If"?: [조건],                       // 이 조건일 때만 선다
      "Move"?: {"Patrol": [[U, V], ...]} | {"Wander": 반경(작은 칸)},   // 없으면 서 있음
      "Chatter"?: "줄|줄", "Play"?: 모션(되풀이),
      "Talk"?: [[화자, 대사], ...],         // 이벤트가 없을 때의 대사(상태를 안 바꿈)
      "Event"?: [{"If"?: [조건], "Node": 이벤트 첫 노드}],  // 위에서부터 첫 번째로 맞는 것
      "Sortie"?: {"If"?: [조건], "Ask": "출진하시겠습니까?"},
      "Shop"?: 상점 ID }},
    "Effects"?: [{"Effect": "fire", "At": [U, V]}],
    "Signs"?: [{"Name", "At", "Talk"}] } } }
```

- 조건은 `branch`와 같은 조건 문자열(`flag:…`, `!flag:…`)이다.
- 한 번만 일어나는 이벤트는 이벤트 안의 `set`으로 플래그를 세우고 `Event.If`에 `!flag:…`를 단다. 따로 Once 필드는 두지 않는다.
- 같은 사람이 플래그마다 다른 말을 하면 `People`에 같은 이름의 다른 키(`장비@훈련`)를 `If`로 나눠 둔다. 화면 이름은 `@` 앞이다.
- 출구 `To`가 플래그로 바뀌는 곳(성문 밖: 숲 → 주둔지)은 같은 자리에 `If`가 다른 출구 둘을 둔다.
- 이벤트가 끝난 뒤 NPC를 이벤트 끝 자리에 두지 않는다. 탐험 화면은 늘 플래그로 다시 배치한다. 그래서 저장에는 NPC 상태가 없다.

### 3.3 이벤트 연출 `assets/scenes/chNN.json`

지금 형식 그대로다(`Map`·`Cast`·`Beats`·`Ambient`, 좌표는 게임 칸). 다른 점:

- 이벤트의 `Map`이 지금 지역 맵이면, `Cast`에 없는 배우는 탐험 화면에 서 있던 NPC·유비를 그 자리 그대로 이어받는다. `Cast`에 적힌 배우는 그 자리로 옮겨진다(화면이 어두워졌다 밝아짐).
- 탐험 좌표(작은 칸)와 장면 좌표(게임 칸)는 `smallTile.cell()`로 바꾼다. 장면 좌표를 작은 칸으로 옮기는 일은 이번에 하지 않는다.

### 3.4 돈·상점

- `State.Money`. 캠페인 시작 돈 `Campaign.Money` = 1000.
- 얻는 곳: 스테이지 `Reward`의 `money`(전투마다 1000, 나중에 조정). `grant` 노드의 `Item: "money"`도 받게 해 두지만 이번 범위에선 쓰지 않는다.
- 상점 데이터는 `assets/data/shops.json`.
- 값: `equipment.json`·`items.json`에 `Price`. 파는 값은 사는 값의 절반(안).
- 상점 `game.json` `Shops`: `{"weapons": {"Name": "무기점", "Items": [...]}, "tools": ..., "tavern": ...}`.
  - 무기점: 지금 있는 기본 무기·방어구(철검 등).
  - 도구점: 지금 있는 보조도구 몇 개. 먹지 않는 소모품은 비워 둔다(나중).
  - 주점: 콩·술.
- 산 장비는 창고(`Warehouse`), 소모품은 `Inventory`로 간다(`grant`와 같은 규칙).

## 4. core

- `State`에 `Explore`(지금 탐험 노드 ID), `Area`, `At [2]int`, `Face`, `Money`.
- `Phase "explore"`: `enter()`가 `explore` 노드에서 멈추며 들어간다. 이벤트를 돌 때는 `Phase "scenario"`이고 `Explore`가 돌아갈 곳을 들고 있다.
- 명령(`Command`의 `Option`=지역, `X`·`Y`=작은 칸, `Target`=방향·사람, `Item`, `Count`)
  - `walk {Area, At, Face}`: 지역을 옮기거나 유비가 멈춘 자리를 기록한다. 출구 조건과 걸을 수 있는 칸인지는 core가 확인하지 않는다(맵 그림 규칙은 GUI 쪽 `scenemap`). 지역 이동만 출구 조건을 확인한다.
  - `talk {Person}`: 맞는 `Event`가 있으면 그 노드로 들어가 `Phase "scenario"`. 없으면 오류(대사만 있는 사람은 GUI만 보여 준다).
  - `sortie`: 심복의 `Sortie.If`가 맞으면 `explore` 다음 노드로 간다.
  - `buy`·`sell {사람, Item, Count}`: 그 사람의 상점에서. 파는 값은 절반.
  - `Engine.Visitors()`(지금 지역에 선 사람과 말 걸면 일어나는 일: event·sortie·shop·talk), `OpenExits()`, `ExploreNext()`(다음 이벤트, 없으면 출진까지 가는 명령들: 완주 테스트·자동 진행용).
  - `back` 노드: `Phase "explore"`로 돌아가고, `Area`·`At`이 있으면 그리로 옮긴다.
- 저장은 `State` JSON이므로 필드만 늘면 된다. `Format`을 올리고 옛 저장은 받지 않는다(재미용 프로젝트).
- 전투 승리 뒤 `continue` → 다음 `explore`에서 멈춘다.

## 5. CLI·테스트

- `srpg-cli`: 탐험을 번호 메뉴로 보인다 — 지금 지역, 갈 수 있는 출구, 말 걸 수 있는 사람(이벤트·출진·상점 표시), 상점 품목.
- `campaign_content_test`: 캠페인 완주를 탐험 구간까지 자동으로 넘긴다(맞는 이벤트를 모두 건 뒤 출진). 이벤트가 없어 막히는 탐험(출진 조건을 끝내 못 채움)을 오류로 잡는다.
- content 읽기 검사: 출구 `To`·이벤트 `Node`·상점 ID·조건 문자열·이벤트가 `back`으로 끝나는지.
- core 테스트: 대화 → 이벤트 → 복귀, 출진, 사고팔기·돈 부족, 저장·불러오기 왕복.

## 6. GUI

`internal/gui/tour.go`를 탐험 화면(`explore.go`)으로 키운다. `cmd/_town2`·`tour2.json`은 맵 둘러보기 도구로 남긴다.

- 탐험 화면은 `Phase "explore"`일 때 열린다. 지역 맵을 `openScene`으로 열고, 유비와 플래그에 맞는 NPC를 세운다.
- NPC 이동: `stand`, `Patrol`(작은 칸 경로를 오감), `Wander`(반경 안의 걸을 수 있는 작은 칸으로 가끔 걸어감). 유비와 NPC가 서로 칸을 막는다. 유비가 말을 걸면 멈춰 마주 본다.
- 사람 클릭: 옆 작은 칸으로 걸어가 마주 보기 → 이벤트가 있으면 `talk`, 없으면 `Talk` 대사를 대화창에 보인다. 심복이면 출진 확인창, 상점 주인이면 상점 창.
- `Effects`(화로 불 등)와 `Chatter`는 장면의 `Ambient`와 같은 그리기를 쓴다.
- 유비가 멈출 때와 지역을 옮길 때 `walk`를 보낸다.
- 탐험 중 메뉴: 장비·소지품, 저장, 불러오기, 설정. 화면 위에 지역 이름과 돈.
- 상점 창: 품목·값·가진 돈, 사기·팔기. 장비 창의 아이콘과 설명을 쓴다.
- 이벤트: `Phase "scenario"`가 되면 지금 장면 재생(`scene.go`)으로 넘긴다. 같은 맵이면 화면을 새로 열지 않고 배우를 이어받는다. `back`이 오면 탐험 화면으로 돌아온다.
- `_uidemo-vm -ui explore`: `-stage "walk:U:V,talk:이름,exit:이름,sortie"`로 동선을 주고 캡처한다(지금 `-ui tour` 확장).
