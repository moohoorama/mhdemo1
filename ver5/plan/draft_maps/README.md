# 1부 새 전투 맵 초안

계획: [../2026_10_23_story_impl.md](../2026_10_23_story_impl.md) §4.1~4.4. 아직 스테이지에 연결하지 않은 초안이다.

- 레이아웃(원본): `tools/mapgen/layouts/hero/draft/{zhuo,danyang,pengcheng,yingchuan_v2}.txt`
- 맵 문서: 이 폴더의 `*.json` (`python3 tools/mapgen/mapgen.py <레이아웃> plan/draft_maps/<이름>.json`). `assets/` 밖이라 게임·테스트는 읽지 않는다.
- 연결할 때는 레이아웃을 `layouts/hero/mapNN.txt`로 옮기고 `assets/scenario/hero/maps/mapNN.json`으로 다시 만든다.

좌표는 `(X,Y)` = (열, 행). 화면에서 (0,0)이 북쪽 모퉁이, (W-1,H-1)이 남쪽, (W-1,0)이 동쪽, (0,H-1)이 서쪽 모퉁이다(map01의 "북쪽 끝은 강"과 같은 약속). 방향 글자는 NW = -X, NE = -Y, SE = +X, SW = +Y.
Area는 `Rect {X,Y,W,H}`로 적는다.

통행 검사(보병 기준, 4방향): 네 맵 모두 아군 시작에서 지나갈 수 있는 칸 전부에 닿는다. 영천 v2만 닫힌 성문(`m`) 안쪽 25칸이 막혀 있다(지금 map01과 같다).

- 성문을 닫힌 `m`으로 두면 적이 들어올 수 없어 "성문 함락" 패배가 생기지 않는다. 그래서 관문 `ip-`로 두고 추정이 성문 안쪽을 지키게 했다. 등무 조는 성문에서 두 칸 떨어져 시작하므로 1~2턴에 추정이 무너지면 위험해진다. 수비병 체력과 등무의 `ai` 전환(3턴)으로 조절한다.

- 정원지 본진은 포위진 뒤(북쪽)에 있어 산에서 내려오면 바로 닿는다(첫 전투). 너무 쉬우면 본진을 (12,12) 쪽 포위선 안으로 한 칸씩 옮긴다.
- 포위진 목책은 성벽 쪽을 막고 북쪽은 비워 두었다. 목책 사이 틈은 모두 두 칸 넘는다.

- 동쪽 계곡 개울은 북쪽 절벽 밑에 둔다. 절벽 바로 남쪽 칸의 물은 절벽 그림에 가려 보이지 않아서다.

## 5. 성 안 도시 가옥 (새 구조물 그림)

성 바닥(`i`) 위의 마을(`v`)을 마을 그림 대신 기와집 그림으로 그린다. 규칙(지나감, 회복 10%)은 마을 그대로이고 레이아웃 글자도 `iv-` 그대로다.
지금 게임 맵 중 성 바닥 위 마을이 있는 맵은 없으므로(전 맵 검사) 기존 맵 그림은 바뀌지 않는다. 바깥 고을·단양 마을처럼 풀밭·황무지 위 `v`는 지금 마을 그림이다.

새 구조물 글자(`u` 등)를 더하는 안은 `game.json` Structures, `terrain.json` 병종 6개, GUI, 미니맵 색, 맵 에디터, 문서를 모두 고쳐야 해서, 그림만 바꾸는 이쪽이 덜 침습적이라 골랐다.

그림
- `tools/unit3d/town_houses.py`(새 파일): `sites.py`와 같은 카메라·축척·성 바닥 포장(draw_bricked)으로 3D 모델을 렌더한다. 회색 기와(성의 `TILE`), 회벽, 옻칠 기둥.
  - `town_a` 기와집: 칸 둘레 담, 앞 왼쪽 면에 대문, 뒤쪽에 긴 채
  - `town_b` 두 채: 뒤쪽 두 면에 ㄱ자로 두 채, 앞 오른쪽 짧은 담
  - `town_c` 가게: 뒤 오른쪽 가게채와 차양·계산대·독, 뒤 왼쪽 담
- `uv run --with pillow --with numpy python tools/unit3d/town_houses.py <out>` → `<out>/sites.png`(sites.py 시트 5칸 + 가옥 3칸; 앞 5칸은 지금 `assets/graphics/map/sites.png`와 픽셀이 같음을 확인), `sites.json`, `town_review.png`.
- 결과 사본: `plan/draft_maps/town/`.
- 손 리터칭은 하지 않았다. sites.py처럼 렌더 뒤 성 바닥 포장을 다시 칠하는 단계(draw_bricked)까지가 전부다.

게임에 넣을 때 바꿀 것(아직 레포에는 적용하지 않음, scratchpad 복사본에서만 적용해 찍었다)
1. `assets/graphics/map/sites.png` ← `plan/draft_maps/town/sites.png`(800x110, 칸 8개).
2. `assets/graphics/index.json`의 `sites.sprites`에 `"town_a": 5, "town_b": 6, "town_c": 7`을 더한다.
3. Go: `plan/draft_maps/town_house.patch`(4파일)
   - `internal/content/map_graphics.go`: `MapArt.SmallGrounds`(작은 타일마다 땅 글자)를 SmallTiles와 같은 고리에서 채운다.
   - `internal/gui/assets.go`, `internal/gui/editor.go`: 그 값을 GUI `MapArt`로 넘긴다(미리 구운 장면 맵 JSON에는 없으니 비어 있다).
   - `internal/gui/field_native.go`: `nativeSites`에서 `v` 칸의 땅이 `i`이면 `town_a/b/c` 중 하나(칸 좌표로 고정 선택)를 쓰고, 그림이 없으면 마을 그림으로 돌아간다.
   - 복사본에서 `go build ./...`, `go vet`, `go test ./internal/content/ ./internal/gui/` 통과.
4. 나중에 `sites.py`를 다시 돌리면 가옥 3칸이 빠지므로, 합칠 때는 `town_houses.py`의 TOWN을 `sites.py`의 SITES에 넣거나 빌드를 town_houses.py로 돌린다.
5. 그을음(불탄 칸)은 지금처럼 `burnt_village` 그림을 쓴다. 마을 연기(`scenery.json`의 `sites.village`)는 가옥에는 붙지 않는다.
