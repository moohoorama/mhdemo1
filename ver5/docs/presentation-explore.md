# 탐험 (전투 사이의 이야기)

범위: 전투와 전투 사이에서 유비가 지역(마을·주둔지·진영)을 걸어 다니며 사람과 이야기하고, 이벤트를 보고, 상점을 쓰고, 심복에게 말을 걸어 출진하는 화면.
기준: 값이 다르면 `internal/content/explore.go`, `internal/core/explore.go`, `internal/gui/explore.go`와 `assets/scenario/<id>/exploreNN.json`을 따른다.

## 흐름

- 이야기 노드 `{"Kind": "explore", "Explore": "explore01"}`에서 이야기가 멈추고 탐험이 열린다. 유비는 탐험 파일의 `Start`에 선다.
- 유비 혼자 걷는다. 관우·장비 같은 동료도 지역의 사람(NPC)이다.
- 이벤트가 걸린 사람에게 말을 걸면 이벤트가 열린다. 이벤트는 스토리 파일의 `Events` 목록에 있는 노드 묶음이고, `back` 노드로 탐험에 돌아온다.
- 심복(지금은 관우)에게 말을 걸면 "출진하시겠습니까?"를 묻는다. 예 → 탐험 노드 다음 노드로(출진 직전 이벤트) → 전투.
- 탐험 중에는 어디서나 저장·불러오기가 된다. 저장에는 지역, 유비의 작은 칸·방향, 돈, 플래그가 든다. 사람의 자리는 저장하지 않고 늘 플래그로 다시 세운다.

## 화면과 조작

- 지역 하나가 형식 2 장면 맵 하나다(`internal/scenemap`). 장면 화면(`scene.go`)을 그대로 쓴다: 맵·배우·말풍선·혼잣말·효과·시간대.
- 땅을 누르면 그 작은 칸(게임 칸의 반)으로 걷는다. 길은 u·v 네 방향 A*. 걸을 수 있는 칸은 `scenemap.Walkable`에 사람이 선 칸을 뺀 것이다.
- 사람을 누르면 한 칸(작은 칸 둘) 떨어진 자리로 걸어가 서로 마주 본 뒤, 그 사람에게 걸린 일을 한다: 이벤트, 출진 확인, 상점 창, 또는 `Talk` 대사(대화창, 클릭·Enter·Space로 넘김). 끝나면 잠깐 뒤 원래 방향으로 돌아선다.
- 출구의 이름판·자리·건물 그림을 누르면 출구까지 걸어가 어두워진 뒤 다음 지역의 "돌아오는 출구" 자리에 선다. 닫힌 출구는 `Shut` 대사를 보인다. 같은 자리에 조건이 다른 출구 둘을 둘 수 있다(탁군 성문 밖: 결의 전에는 복숭아 숲, 뒤에는 의병 주둔지).
- 표지(`Signs`)는 옆까지 걸어가 해설 줄을 보인다.
- 사람의 움직임: 없으면 서 있다. `Patrol`은 점들을 오가고, `Wander`는 `At`에서 그 거리 안의 칸을 가끔 걷는다. 서 있는 사람의 `Play`는 그 모션을 가끔 되풀이한다(장비가 의병을 훈련).
- 왼쪽 위에 지역 이름과 돈, 오른쪽 위에 `부대`(장수·능력치·장비 변경·부관)와 `메뉴`(저장·불러오기·설정). 휠은 확대, `R`·오른쪽 클릭은 걸을 수 있는 칸 보기.
- 이벤트의 장면 맵이 지금 지역 맵이면 무대를 새로 열지 않고 이어받는다(`adoptScene`): 배역 중 `Stay`인 사람은 탐험에서 서 있던 자리에 그대로, 다른 배역은 장면이 정한 자리에 선다. 이벤트가 끝나면 지역을 플래그로 다시 세운다(같은 맵이면 검은 화면 없이).

## 상점과 돈

- 재화는 돈(`State.Money`). 시작 돈은 `Campaign.Money`(1000), 전투 보상 `Reward`의 `money`(전투마다 1000), `grant` 노드의 `Item: "money"`.
- 상점은 `assets/data/shops.json`: 무기점(기본 무기·방어구), 도구점(보조도구; 먹지 않는 소모품은 아직 없다), 주점(콩·술). 값은 `equipment.json`·`items.json`의 `Price`. 파는 값은 절반이고, 값이 없는 물건(고유 장비 등)은 팔 수 없다.
- 산 장비는 창고, 소모품은 소지품으로 간다.

## 데이터 `assets/scenario/<id>/exploreNN.json`

```
{ "Hero": 걷는 인물 ID, "Start": {"Area", "At": [U, V], "Face"},
  "Areas": { "<지역 ID>": {
    "Map": 형식 2 장면 맵 ID, "Name": 지역 이름, "Time"?, "Zoom"?: 들어설 때 배율(기본 2),
    "At": [U, V](돌아오는 출구가 없을 때 서는 자리),
    "Exits": [{"Name", "At", "Object"?: [U, V](건물 물체의 기준 칸), "To", "If"?: [조건], "Shut"?: [[화자, 대사]]}],
    "People": {"<표시 이름>[@구분][#]": {"At", "Face", "Sprite"?, "Portrait"?, "Faction"?, "Pose"?, "If"?: [조건],
       "Move"?: {"Patrol": [[U, V], ...]} | {"Wander": 거리}, "Chatter"?, "Play"?, "Talk"?: [[화자, 대사]],
       "Event"?: [{"If"?, "Node": 이벤트 첫 노드}], "Sortie"?: {"If"?, "Ask"}, "Shop"?: 상점 ID}},
    "Effects"?: [{"Effect", "At"}], "Signs"?: [{"Name", "At", "Talk"}] } } }
```

- 좌표는 모두 작은 칸이다. 조건은 `branch`와 같은 조건 문자열(`flag:…`, `!flag:…`).
- `People`의 키는 화면 이름이다. `@` 뒤는 같은 사람의 플래그별 자리를 가르는 꼬리표, `#`이 든 키는 이름 없는 엑스트라다. 인물 데이터의 이름이면 그 인물의 장면 스프라이트·초상을 쓴다.
- 이벤트는 위에서부터 조건이 맞는 첫 것이 열린다. 한 번만 일어나는 이벤트는 이벤트 안의 `set`으로 플래그를 세우고 `If`에 `!flag:…`를 단다.
- `Talk`의 화자는 인물 ID나 화면 이름, 빈 문자열이면 해설이다.
- 읽을 때 검사: 출구의 지역, 이벤트가 모든 갈래에서 `back`으로 끝나는지, 상점 ID, 조건 문자열, 방향. 게임 시험(`TestExploreAreasCanBeWalked`): 지역 맵이 형식 2이고 출구·사람·표지에 걸어서 닿는지.

## 도구

- `go run ./cmd/_uidemo-vm -ui explore`(캡처): 1장을 처음부터 출진까지 걷는다. `-stage "start:c02-walk,talk:추정,exit:거리로,shop:주인,buy:bean,..."`로 시작 노드와 동선을 준다.
- `go run ./cmd/_walkmap S_militia_camp`: 맵의 걸을 수 있는 작은 칸과 물체 기준 칸을 글자로 찍는다(사람·출구 자리 정하기). `-fmt`는 맵 파일을 맵 파일 모양으로 다시 쓴다.
- `go run ./cmd/srpg-cli`: 탐험을 번호 메뉴로(말 걸기 ★는 이벤트, 출진, 상점, 출구).

## 형식 2 둘러보기 `cmd/_town2` (데모)

형식 2 장면 맵이 어떻게 그려지는지 걸어 다니며 보는 데모다. `go run ./cmd/_town2`(창), `go run ./cmd/_uidemo-vm -ui tour`(캡처, `-stage "walk:U:V,exit:이름,grid"`). 사람·대사는 없고 유비 혼자 걷는다. 데이터는 `assets/towns/tour2.json`(`{"Name", "Hero", "Start", "Areas": {"<id>": {"Map", "Name", "Zoom"?, "At", "Exits": [{"Name", "At", "Object"?, "To"}]}}}`). 걷기 계산은 탐험과 같다(`internal/gui/walkmap.go`).
