# 장판교·적벽·화용도 전장 개편

| 전장 | 지형 | 진행 |
|---|---|---|
| 장판교 B26·B25V | 굽은 강, 좁은 긴 목교, 낮은 여울, 피란민 둑과 무너진 마을 | 새 장면맵과 같은 축으로 다리를 건넌다. 기본 경로에서 조운은 목교와 여울 중 한 길로 본군에 닿는다. 대체 경로는 피란민의 이동과 마지막 다리 차단을 새 좌표에 맞춘다. |
| 적벽 B27R | 강 위의 두 물길, 중앙 사주, 불타는 오림 맞은편 나루 | 배 규칙으로 맞은편으로 나아가 채모의 수군을 물리고 유비를 오림 나루에 상륙시킨다. 뒤따르는 장면에서 화용도 추격을 의논한다. |
| 화용도 B27 | 오림에서 늪의 굽은 흙둑을 따라 산목으로 이어지는 전장 | 유비는 오른쪽 오림에서 출발하고 조조는 왼쪽 산목으로 달아난다. 기존 추격과 격퇴 보상은 그대로 이어지고, 전투 뒤 강하행은 반대편 둑을 따라 돌아간다. |

장판교의 두 경로와 화용도의 기존 전투 ID를 사용한다. 적벽을 기본 경로 장판파와 화용도 사이에 배치하므로 기존 성장 공식에 따라 화용도의 순번이 하나 늘어난다. 신규 스폰은 직급 및 기존 규칙을 적용하고, 점령·도달 조건과 강제 이동의 위치를 시험한 뒤 게임 화면을 캡처한다.

## 검증

- `srpg-cli` 쉬움 난이도에서 기본 장판파는 조운의 이동을 직접 지정해 12턴에 승리했다. 같은 도구로 대체 장판파는 14턴, 적벽은 3턴, 화용도는 3턴에 승리했다. 적벽에서는 유비가 (19, 5)로 상륙했다.
- `_balance -player ai -seeds 2` 보통 난이도에서 적벽과 화용도는 각각 2회 모두 승리했다. 장판파 두 분기에서는 자동 전투가 각각 2회 모두 패배했다. 기본 장판파에서 조운을 적진으로 보내는 자동 전투와 다리로 직접 이동하는 플레이의 차이가 컸다.
- 캠페인 기본·대체 경로와 장면 이동, 전투 데이터 및 UI 테스트를 통과했다. [전투 화면과 끊어진 장판교](../reports/southern-battles/index.html)를 캡처했다.
