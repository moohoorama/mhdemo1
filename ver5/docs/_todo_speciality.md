# 병종 학습 특성 구현 설계

[trait-design-v2.md](trait-design-v2.md) 8절 "병종별 학습 특성 현재안"을 현재 엔진(`rules-12`)에 구현하기 위한 설계다.
규칙 기준은 v2이고, 이 문서는 **어떤 데이터와 코드를 어떻게 바꾸면 되는가**만 다룬다. 전투 규칙 전반은 [battle.md](battle.md)를 따른다.

## 1. 범위

### 1.1 대상 병종

v2의 병종 이름과 실행 데이터의 id가 다르다. 이 문서는 실행 데이터에 있는 경로만 다룬다.

| v2 이름 | 데이터 id | 이번 범위 |
|---|---|---|
| 경보병 → 중보병 → 근위대 | `light_infantry` → `heavy_infantry` → `guards` | 포함 |
| 경기병 → 창기병 → 금위병 | `light_cavalry` → `heavy_cavalry`(중기병) → `royal_guard`(친위대) | 포함 |
| 궁병 → 노병 → 연노병 | `archer` → `crossbow` → `repeating_crossbow` | 포함 |
| 사마 계열(참모·군사·방술사·선술사) | `scholar` 외 | `부관임명`만 추가, 나머지 유지 |
| 적병 계열 | `bandit` → `ruffian` → `outlaw` | 풀은 유지, 공유 특성의 비용 변화만 영향을 받는다 |
| 궁기병·노기병, 장창병·전차대, 발석거, 무도가 | 데이터에 없음 | 제외 (v2 12절 미확정) |

- 상위 병종이 하위 병종의 학습 자격을 계승하는 구조는 이미 있다(`Class.AllPool`). 바꾸지 않는다.
- 승급 레벨은 v2의 Lv20·40이 아니라 데이터의 15·30(`PromoteLevels`)을 유지한다.
- 한 단계에 특성 3개를 둔다. 노병만 v2가 후보 4개라고 했으나 `부관임명`을 포함한 4개다. `부관임명`을 빼면 3·3·3이 된다.

### 1.2 하지 않는 것

- 장수 고유 특성(v2 10~11절: 황충·미방·유비)은 이번에 구현하지 않는다. 다만 고유 특성이 쓸 선행 특성(`조준`·`연발`·`경계`)은 이 설계로 생긴다.
- `강공`은 v2 6절 표에 있으나 8절의 어느 병종에도 없어 제외한다.
- 문관 계열 책략 구조(화·수·지 + 강화·확산)는 바꾸지 않는다.

## 2. 학습 풀 변경표

| 병종 | 현재 `Pool` | v2 목표 |
|---|---|---|
| 경보병 | 반격술·침착·험지이동 | **경계·화계·응급처치** |
| 중보병 | 철벽·간접공격면역·무쌍술 | **부관임명·대비·협동** |
| 근위대 | 수성·금강·양생 | **수성·철벽·공성** |
| 경기병 | 질주·백마·돌격 | **기마술·교란·도발** |
| 중기병(창기병) | 질풍·무쌍술·철벽 | **부관임명·찌르기·돌파** |
| 친위대(금위병) | 필살·공성·금강 | **질풍·돌격·연속찌르기** |
| 궁병 | 독공·원시·험지이동 | **구휼·저격·조준** |
| 노병 | 찔러공격·응사·신궁 | **부관임명·수계·화시·장전** (4개 유지, 12절 6번은 데이터 작업에서 결정) |
| 연노병 | 난사·사방격·심공 | **연발·독려·관통** |
| 참모·방술사 | (문관 풀) | 기존 풀에 **부관임명** 추가 |

## 3. 특성별 구현

비용·선행은 v2 표기를 따른다. `…`는 v2가 "후보"로 적은 선행이며 아래 9절에서 확정한다.
"재사용"은 효과가 이미 엔진에 있다는 뜻이고, "신규"는 코드가 필요하다.

### 3.1 보병 계열

| 특성 (id) | 비용 | 선행 | 종류 | 구현 |
|---|---|---|---|---|
| 경계 (`guard_prep`) | 500 | – | 병법 권한 | 신규. 병법 `guard`가 자신에게 `guard` 상태(2턴)를 건다 (5.1) |
| 화계 (`fire`) | 700 | – | 책략 권한 | 재사용. 기존 `fire`의 비용을 0 → 700으로 바꿔 학습 대상으로 만든다 (9절 1번) |
| 응급처치 (`first_aid`) | 1000 | – | 병법 권한 | 재사용. 병법 `first_aid`는 `Kind: heal`, `Mode: self`, `Effect: heal`, `Coeff: 3` (소보급과 같음) |
| 부관임명 (`deputy_appoint`) | 700~1000 → **800** | – | 패시브 | 신규 효과 `deputy_appoint`. 부관 임명 조건을 병종 단계에서 이 특성 보유로 바꾼다 (6절) |
| 대비 (`brace_prep`) | 700~1000 → **800** | 경계 | 병법 권한 | 재사용. 병법 `brace`는 `Kind: buff`, `Mode: self`, `Effect: defense`, `Duration: 2` (방어력 +20%) |
| 협동 (`assist`) | 700 → **1000** | – | 패시브 | 재사용. 비용만 바꾼다 |
| 수성 (`castle_defense`) | 700 → **1000** | 대비 | 패시브 | 재사용. 비용·선행만 바꾼다 |
| 철벽 (`ironwall`) | 500 → **1200** | – | 패시브 | 재사용. 풀을 중보병·중기병에서 근위대로 옮긴다 |
| 공성 (`siegecraft`) | 700 → **1500** | – | 패시브 | 재사용. 풀을 친위대에서 근위대로 옮긴다 |

### 3.2 기병 계열

| 특성 (id) | 비용 | 선행 | 종류 | 구현 |
|---|---|---|---|---|
| 기마술 (`dash`) | 300 → **1000** | – | 패시브 | 재사용. `dash`(질주, 이동력 +1)와 같은 효과다. v2 1절의 "같은 효과를 이름만 바꿔 중복하지 않는다"에 따라 새로 만들지 않고 이름을 **기마술**로 바꾼다 |
| 교란 (`disrupt_prep`) | 700 | – | 병법 권한 | 신규 상태 `disrupt`. 병법 `disrupt`는 근접 단일 대상에게 순발력·사기 −20%를 2턴 건다 (5.2) |
| 도발 (`provoke_prep`) | 500 | – | 병법 권한 | 신규 준비 상태 `provoke`. 병법 `provoke`가 자신에게 건다 (5.1) |
| 부관임명 | 800 | – | 패시브 | 3.1과 같다 |
| 찌르기 (`thrust_art`) | 700 | – | 병법 권한 | 신규 스킬 필드. 병법 `thrust`: 창을 든 근접 공격, 목표 뒤 1칸의 적이 50% 피해 (5.3) |
| 돌파 (`breakthrough`) | 1000 | 찌르기 | 패시브 | 신규 효과 `pierce_boost` 0.25. 병법의 관통 피해 비율에 더한다 (50% → 75%) |
| 질풍 (`gale`) | 700 → **1200** | 기마술 | 패시브 | 재사용. 비용만 바꾼다 |
| 돌격 (`charge`) | 400 → **1200** | – | 패시브 | 재사용. 비용만 바꾼다 |
| 연속찌르기 (`chain_thrust_art`) | 1500 | 돌파 | 병법 권한 | 신규 스킬 필드. 병법 `chain_thrust`: 한 번의 행동으로 2회 공격하고 찌르기 효과를 가진다 |

| 특성 (id) | 비용 | 선행 | 종류 | 구현 |
|---|---|---|---|---|
| 구휼 (`relief`) | 500 | – | 책략 권한 | 재사용. 기존 `relief`의 비용을 0 → 500으로 바꾼다. 소보급·헌책을 쓸 수 있다 |
| 저격 (`snipe_prep`) | 700 | – | 병법 권한 | 신규 준비 상태 `snipe`. 다음 원거리 공격의 사거리 +2 (5.1) |
| 조준 (`aim_prep`) | 1000 | – | 병법 권한 | 신규 준비 상태 `aim`. 다음 원거리 공격의 순발력·사기 +20% (5.1) |
| 부관임명 | 800 | – | 패시브 | 3.1과 같다 |

| 연발 (`rapid_art`) | 1000 | – | 병법 권한 | 신규 스킬 필드 `Strikes`. 병법 `rapid_fire`: 원거리 단일 공격을 2회로 한다 |

### 3.4 문관·적병 계열

- 방술사·참모의 풀에 `부관임명`만 더한다. 군사·선술사는 하위 풀을 계승한다.
- 책략 권한은 배워야 하는 특성이 되므로 문관 병종의 `Grants`(화계·수계·구휼·독려·견제·계략)를 없애고, 문사에게 기본 학습으로 준다 (3.5).
- 적병 계열 풀은 바꾸지 않는다. 의적의 `협동`(1000)·`돌격`(1200)과 흉적의 `기마술`(1000)은 비용이 공유되므로 올라간다(9절 4번).

### 3.5 문사의 기본 학습 (결정)

책략이 없으면 문사가 아무것도 못 하므로 책략 권한은 문사에게 처음부터 배워 둔 상태로 준다.

- 일반 병사 템플릿 `troop_scholar`와 문관 병종 장수는 **화계를 기본 보유**하고, 일부는 **수계도** 가진다.
- 보유 방식은 장수·템플릿의 `Traits`(고유 특성)다. 병종 `Grants`가 아니므로 병종이 바뀌어도 사라지지 않는다.
- 방술사·선술사 계열 장수는 화계 대신 **구휼**을 기본으로 두는 것을 제안한다. 같은 이유로 구휼이 없으면 아무것도 못 한다 (9절 12번).
- 기본 보유한 특성은 학습창에 나오지 않는다(이미 가짐). 문관 병종은 `Pool`의 강화·확산·허실 등으로 이어진다.
- 병종 `Grants`를 지우므로 문관 병종의 책략 병법은 이 `Traits`가 있어야 열린다. 데이터의 모든 문관 장수·템플릿이 하나는 갖는지 검증 테스트를 둔다.

## 4. 특성 이름·정리 대상

v2에서 빠진 특성의 정리다. 같은 효과나 같은 이름이 충돌하는 것만 지우고, 장수·장비·스킬이 쓰는 것은 남긴다.

| 특성 | 현재 사용처 | 처리 |
|---|---|---|
| `white_horse` 백마 | 경기병 풀 | **유지**(결정). 풀에서만 빠진다. 효과 키 `mounted_range`·`light_move`와 병종 태그도 그대로 둔다 |
| `pierce` 찔러공격 | 노병 풀 | **유지**(결정). 특성과 효과 키 `pierce`, `victims`의 해당 분기를 그대로 둔다. 찌르기·관통 병법의 `Pierce` 필드는 같은 분기를 같이 쓴다 (5.3). 어느 풀에 둘지는 정해지지 않았다 (9절 11번) |
| `divine_archer` 신궁 | 노병 풀 | v2 10절의 신궁은 "일반 공격 상시 2회"로 **효과가 다르다**. 이름이 충돌하므로 현재 `no_min_range` 특성은 **삭제**한다. 효과 키 `no_min_range`도 쓰는 곳이 없으면 지운다 |
| `return_fire` 응사, `vitality` 양생, `diamond` 금강, `missile_immunity` 간접공격면역 | 풀에서만 사용 | **유지**(결정). 풀에서만 빠지고 정의는 둔다 |
| `far_sight` 원시 | 궁병 풀 | v2 10절의 황충 고유 특성 후보. 풀에서만 뺀다 |
| `counter_art`·`sweep_art`·`composure`·`rough_terrain`·`deadly`·`volley`·`cross_strike`·`drain` | 장수·장비·스킬·적병 풀이 참조 | 풀에서만 뺀다 |

## 5. 엔진 변경

### 5.1 준비 병법 (경계·조준·저격·도발)

v2 5절: 병법은 한 행동에 하나만 쓰고, 일부는 직접 공격 대신 다음 공격·피격에 적용되는 준비 버프를 건다. 같은 버프를 다시 쓰면 갱신한다. 다른 준비 버프는 함께 유지된다. "다음 1회"는 개별 타격이 아니라 **하나의 공격 행동** 단위다.

새 상태 id를 `content.Statuses`·`SkillEffects`에 더한다.

| 상태 | 거는 병법 | 효과 | 소비 시점 |
|---|---|---|---|
| `guard` | 경계 | 근접 물리 피격의 명중률 0% | 그 공격 행동(`attackOn` 한 번, 연타 포함)이 끝날 때 |
| `aim` | 조준 | 순발력·사기 +`BuffPercent`% (`stats`에서 반영) | 자신의 다음 원거리 물리 행동이 끝날 때 |
| `snipe` | 저격 | `rangeFor`에서 최대 사거리 +2 | 자신의 다음 원거리 물리 행동이 끝날 때 |
| `provoke` | 도발 | 다음 물리 공격이 명중하면 대상에게 방어력 −`BuffPercent`% 2턴 (`applyStatus(v, "defense", 2, -p)`) | 자신의 다음 물리 행동이 끝날 때 (빗나가도 소비) |

- 병법은 `Kind: buff`, `Mode: self`, `Duration: 2`로 두고 기존 버프 경로(`spell`의 `default` 분기)로 상태를 건다.
- 소비는 `useSkill`에서 `physical` 호출 직후 한곳에서 처리한다. `guard`만 방어자 쪽이므로 `physical`의 `attackOn(u, q, …)` 직후에 `q`의 상태를 지운다. 반격·지원 공격(`derived`)은 소비하지 않는다.
- 지속: 2턴이면 건 진영 턴이 끝날 때 1이 되고, 상대 페이즈를 지나 자기 다음 턴까지 이어진다. 쓰지 않으면 자기 다음 턴 끝에 사라진다(v2 12절 10번의 기본안).
- `aim`은 능력치 버프라 자신이 피격될 때도 순발력·사기가 올라 있다. 단순함을 위해 그대로 두고 9절 3번에서 확인한다.
- 같은 병법 재사용은 `applyStatus`가 갱신하고, 서로 다른 준비 상태는 `Status` 맵에 함께 들어간다.

### 5.2 교란 (순발력·사기 약화)

- 상태 `disrupt`를 `Statuses`·`Harmful`·`SkillEffects`에 더한다. `stats`에서 `v[3]`(순발력)·`v[4]`(사기)에 `percent(v, -R.BuffPercent)`를 적용한다. 기존 `attack-down`·`defense-down`과 같은 방식이다.
- 병법 `disrupt`: `Kind: status`, `Mode: melee`, `Shape: single`, `Min/Max: 1`, 명중 80. 적 1기만 대상이다. 책략 `견제`와 겹치지 않는다(v2 8절).
- 약화량·지속은 v2 12절 5번이 미확정이라 −20%(`BuffPercent`)·2턴으로 시작한다.

### 5.3 관통·연타 병법

`content.Skill`에 필드를 더한다. 새 효과 키는 만들지 않고 병법 데이터가 정한다.

| 필드 | 의미 | 쓰는 병법 |
|---|---|---|
| `Pierce float64` | 목표 뒤 한 칸의 적이 받는 피해 비율 | 찌르기 0.5, 관통 0.75, 연속찌르기 0.5 |
| `Strikes int` | 2이면 연타 판정과 무관하게 항상 2회 | 연발, 연속찌르기 |
| `Weapon string` | 사용에 필요한 장착 무기 종류 | 찌르기·연속찌르기 `spear` |
| `MagicCoeff float64` | 물리 피해에 더하는 책략식 피해의 계수 | 화시 0.7 |

- `victims`: 단일 형태일 때 `max(fx(pierce), s.Pierce + fx(pierce_boost))`를 후방 피해 비율로 쓴다. 방향 계산은 기존 `FxPierce` 분기를 그대로 쓴다.
- `attackOn`: `double := s.Strikes > 1 || rand < doubleChance`로 바꾼다. 난수 호출 횟수는 그대로다.
- `validateSkill`: `s.Weapon`이 있으면 캐릭터의 `weapon` 슬롯 장비의 `Type`이 같아야 한다. 아니면 `WrongWeapon`으로 실패한다. v2 3절의 "찌르기: 창 계열 무기, 검술: 검 장착" 조건이며, 부관이 준 특성은 부대가 조건을 못 맞추면 쓰이지 않는다.
- 원거리 전용 병법(`Mode: ranged`)은 기존 `canRange` 검사로 v2 3절의 "원거리 공격 가능 부대" 조건을 이미 만족한다.
- 신규 오류 `WrongWeapon`은 GUI의 오류 문구 표에도 더한다.

### 5.4 화시

`damage`의 물리 분기 끝에 `if s.MagicCoeff > 0`일 때 책략식 `max(1, 정신 차이 + (Lv+10)×MagicLevelScale)`에 `MagicCoeff`를 곱해 더한다. 물리 부분은 `s.Coeff`(0.7)를 그대로 곱한다.
명중은 물리 판정, 치명타도 물리 판정을 쓴다. 속성 보정은 없다. 병법 데이터에는 `Element: fire`를 표시용으로만 쓰고 엔진이 읽지 않게 한다.

## 6. 부관임명 특성화

현재는 병종 단계(`DeputyMinTier: 1`)만 되면 자동으로 부관을 둘 수 있다. v2 3절은 2단계 병종부터 **학습 자격**이 열리는 특성으로 정한다.

- 효과 키 `deputy_appoint`와 특성 `deputy_appoint`(부관임명, 800)를 만든다.
- `assignDeputy`와 `api.go`의 해당 판정(`Tier < DeputyMinTier`)을 `e.hasTrait(o, "deputy_appoint")`로 바꾼다. `Rules.DeputyMinTier`는 쓰는 곳이 없어지므로 규칙값·검증과 함께 **삭제**한다.
- 특성은 영구 학습이므로 병종이 바뀌어도 유지된다.
- 이미 `Deputy`가 지정된 저장은 규칙 버전을 올려 무효로 한다.
- 데이터에 부관을 임명하는 장수가 있으면(캠페인 시작 편성) 그 장수에게 `Traits: ["deputy_appoint"]`를 준다. 현재 확인 필요 항목이다(10절).

### 8.1 테스트 목록

- 경계: 근접 공격은 명중률 0이 되고 원거리는 영향이 없다. 연타(두 번 공격)도 첫 행동 전체가 막히고 이후 소비된다. 쓰지 않으면 자기 다음 턴 끝에 사라진다. 반격은 소비하지 않는다.
- 조준·저격·도발: 다음 원거리(도발은 물리) 행동 후 상태가 사라진다. 근접 공격으로는 조준·저격이 소비되지 않는다. 도발은 빗나가도 소비되고 명중할 때만 방어력이 깎인다.
- 연발·연속찌르기: 연타 확률과 무관하게 두 번 공격한다. 첫 타로 대상이 쓰러지면 둘째는 나가지 않는다(기존 `attackOn` 동작).
- 찌르기·관통: 대상 뒤 한 칸의 적이 비율만큼 맞는다. 돌파가 있으면 비율이 25%p 오른다. 창이 아닌 무기로는 `WrongWeapon`이 난다.
- 화시: 피해가 물리 ×0.7과 책략식 ×0.7의 합이다.
- 부관임명: 특성이 있어야 임명되고, 병종이 바뀌어도 유지된다.
- 학습 풀: 각 병종이 v2 표의 특성을 정확히 배울 수 있고(선행 충족 시), 상위 병종이 하위 풀을 계승한다.
- 데이터 정합: 모든 병법의 `Requires`가 존재하는 특성이고, 모든 풀의 특성이 존재한다. 풀에서 빠진 특성이 장수·장비·스킬 참조에서 끊어지지 않는다.
