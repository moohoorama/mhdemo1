# 출전 준비와 이야기 연출 정리

- 출전 격자는 관우와 장비의 대기 스프라이트를 기준으로 원본 1픽셀을 UI 1픽셀로 그린다. 세로 공간이 부족할 때는 관우·장비의 높이를 기준으로 격자 전체에 같은 축소율을 적용한다. 현재 무기와 말 팔레트를 적용하고, 목록에서 출전·복병 행의 배경에 은은한 녹색을 넣는다.
- 출전 목록은 전투 엔진의 능력치 계산으로 장비와 부관을 반영한다. 부관을 뺀 경우와 비교해 달라진 수치는 최종값 옆에 증감량을 표시한다.
- 호로관의 합동 일기토를 시작한 아군 장수를 전투 엔진에서 결정한다. 화면, 기록과 일기토 보상이 이 장수를 사용한다. 전투 결과 처리와 보상량은 기존 규칙을 따른다.
- 장면 자동 포커스는 노드별 선택으로 두고 도원결의에는 세 사람이 선 줄 중앙에 카메라 지시를 둔다.
- 첫 실행 설정값은 재생 1배속과 지도 2배율로 두고 저장된 사용자 설정을 불러온다.

출전 준비와 도원결의는 UI 데모를 캡처한다. 규칙과 설정의 회귀는 관련 Go 테스트로 확인한다.
