# 영천 일기토 오류 수정

- 원인: `bocai-calls-liubei`가 파재의 병력만 보고 떨어진 유비와의 일기토를 강제한다. 화면 재생은 한 행동의 `duel`을 `speech`보다 먼저 처리해 대사도 뒤집힌다.
- 전투 데이터: 체력 조건 이벤트를 제거한다. 유비와 파재가 인접할 때 시작하는 기존 자동 일기토를 사용한다. 다른 장수가 파재를 공격해도 일기토가 열리지 않아야 한다.
- 화면 재생: `duel`을 이벤트 순서대로 처리한다. 공격 타격에는 일기토 전까지의 이벤트만 적용하고, 일기토 결과는 종료 뒤 적용한다. 이동·공격·대사·일기토의 순서를 유지한다.
- 일기토 미리보기: 앞의 공격·대사를 재생한 후 일기토가 열릴 때까지 기다린다.
- 확인: 실제 영천 데이터에서 멀리 있는 유비 대신 관우가 파재를 공격하는 회귀 시험, 관련 Go 시험, 전투 균형 측정과 CLI 진행, 화면 캡처.

## 확인 결과

- `go test ./internal/core ./internal/gui`: 통과.
- 영천 전투 균형 측정(시드 3개): rush 3/3, AI 3/3 승리.
- CLI JSON 진행(영천부터 시작하는 임시 데이터): 6라운드 승리, 유비·파재 일기토 한 번.
- 영천 일기토 단독 렌더 시험: 통과, 캡처에서 두 참가자 확인.
