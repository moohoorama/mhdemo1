# 장수별 말투

일기토·이벤트 대사를 쓸 때 장수마다 같은 말투를 유지하기 위한 기준이다. 장면에 맞는 새 대사를 쓰면 이 문서의 예시도 함께 늘린다. 일기토 대사는 스테이지 파일의 `Stage.Duels[].Beats`, 화자가 말풍선에 표시되는 규칙은 `docs/presentation-duel.md`를 따른다.

## 공통 규칙

- 말투는 **어미와 호칭**으로 드러낸다. 같은 뜻이라도 장수마다 끝맺음이 다르다.
- 대사는 짧게 쓴다. 말풍선 한 개에 한두 문장이며, 일기토 중에는 숨을 쉬듯 끊는다.
- 속말은 괄호로 쓴다. `(이 괴력… 보통내기가 아니다.)`
- 무기는 병종과 장비를 따른다. 장비는 사모, 관우는 청룡도, 유비는 쌍고검, 여포는 방천화극이다. 적병은 칼(검)이고 화웅·목순·무안국은 창이다.
- `block`·`dodge`·`yielding-block`·`critical-dodge` 대사는 **방어자**가 말한다. 공격자의 외침을 이 동작에 넣지 않는다.

## 호칭 표

| 말하는 사람 | 유비 | 관우 | 장비 | 여포 |
|---|---|---|---|---|
| 유비 | – | 운장 | 익덕 | 여포 |
| 관우 | 형님 | – | 익덕 | 여포 |
| 장비 | 형 | 둘째 형 (결의 전 운장 형) | – | 여포 이놈 |
| 여포 | 귀 큰 놈, 유비 | 수염 긴 놈 | 연인 장익덕, 검은 놈 | – |

장비는 형들을 `형`, 관우는 유비를 `형님`이라 부른다. 여포는 하후돈을 `애꾸`라 부른다.

## 장비 — 충청도 사투리, 가볍고 호방한 말투

**성격**: 호탕하고 단순하다. 화가 나면 곧바로 소리치고, 신나면 웃는다. 형들에게는 애교가 있고 적에게는 거침없이 욕한다.

**말투**
- 충청 방언 어미를 쓴다: `~유`, `~슈`, `~구먼`, `~는겨`, `~혀`, `~그려`, `~랴`. 문장마다 다 넣지 않고 한두 군데만 살짝 섞어 가볍게 읽히게 한다.
- 형들에게는 `형~`을 늘여서 부르고 말끝을 올린다. `형님`은 쓰지 않는다.
- 적에게는 `이 자식이!`, `이놈아!`, `~해 보랑께` 같은 거친 말을 쓴다. 지나치게 점잖은 표현은 쓰지 않는다.
- 감탄사가 많다: `허허`, `하하하!`, `으라앗!`, `이얏!`
- 문장은 짧고 직선적이다. 계산이나 작전 이야기는 하지 않는다.

**하지 않는 것**: 침착한 설교, 한자어 위주의 점잖은 문장, 비꼬는 존댓말.

**예시**

| 상황 | 대사 |
|---|---|
| 도발 | 여포! 연인 장익덕이 여기 있슈! 목 씻고 기다리랑께! |
| 도발(적병) | 이 자식아, 덤벼 보랑께! 사모 맛 좀 봐라! |
| 공격 | 으라앗! 이거나 먹어랏! |
| 방어 | 간지럽구먼! 그게 다여? |
| 방어(여유) | 이 정도로 이 몸이 눈 하나 깜짝할 줄 아슈? |
| 밀릴 때 | 이 자식, 힘 한번 세구먼… 그래도 안 져! |
| 피격 | 크윽! 이 자식이…! |
| 기세가 오를 때 | 하하하! 이거다! 이런 놈이랑 싸워 보고 싶었던겨! |
| 형제 합류 | 형~ 왔슈! 기다리고 있었슈! |
| 형제에게 | 형들만 믿슈! 이 자식은 내가 앞에서 막을 테니! |
| 조운의 말을 전할 때 | 조운이 할 말 있대유. |
| 승리 | 다음은 누구여! 어서 나와 보랑께! |
| 도발 받았을 때 | 뭐여? 방금 뭐라고 혔어? 다시 말해 보랑께! |

## 관우 — 침착하고 진중한 하오체·합쇼체

**성격**: 말수가 적고 무게가 있다. 위기에도 목소리가 흔들리지 않는다. 자신의 실력에 대한 자부심이 크지만 드러내지 않고 짧게 말한다.

**말투**
- 적에게는 `~하겠다`, `~이다`, `~느냐` 같은 낮추지도 올리지도 않는 단정형을 쓴다.
- 형님(유비)에게는 `~습니다`, `~하겠습니다`로 반드시 존대한다. `형님. 알겠습니다.`처럼 호칭 뒤에서 한 번 끊는다.
- 아우(장비)에게는 낮게 말하되 거칠지 않다: `익덕, 서두르지 마라.`
- 감정을 직접 표현하지 않는다. 놀라거나 화가 나도 한마디로 정리한다.
- 느낌표는 드물게 쓴다. 평소에는 마침표나 `…`로 끝낸다.

**하지 않는 것**: 큰 소리, 웃음소리, 욕설, 말장난, 방언.

**예시**

| 상황 | 대사 |
|---|---|
| 출전 | 소장이 나가 화웅의 목을 베어 오겠소. |
| 형님에게 | 형님. 알겠습니다. 다녀오겠습니다. |
| 도발 | 관운장이다. 그 입부터 닥치게 해 주마. |
| 방어(여유) | 가볍군. / 그것이 전부냐. |
| 방어(힘겨운 상대) | 과연 이름값은 하는군. |
| 공격 | 하앗! |
| 강공 | 받아라. |
| 틈을 볼 때 | 틈이 보이는군. |
| 장비에게 | 익덕, 흥분하지 마라. 호흡을 읽어라. |
| 합류 | 아우와 형님… 늦지 않으셨군. / 형님, 소장이 앞에 서겠습니다. |
| 승리 | 끝났다. / 적장은 쓰러졌다. |

## 유비 — 아우에게는 하게체, 남에게는 하오체, 윗사람에게는 합쇼체

**성격**: 어질고 겸손하다. 약해 보여도 물러서지 않는다. 형제를 먼저 생각하고, 적에게도 예의를 지킨다.

**말투** — 듣는 사람에 따라 높낮이를 바꾼다. 해라체(`~하자`, `~거라`)와 요즘 반말(`~야`, `~싫다`)은 쓰지 않는다.
- 아우들(결의 뒤의 관우·장비)과 아랫사람에게는 하게체: `~하게`, `~하세`, `~일세`, `~네`, `~는가`, `자네`.
  형으로서 무게를 두되 아우를 아끼는 말이다: `운장, 익덕. 낙양으로 가세.`
- 처음 보는 사람, 같은 처지의 사람, 결의 전의 관우에게는 하오체: `~하오`, `~시오`, `~겠소`, `그대`.
- 스승·장군·관리 같은 윗사람에게는 합쇼체: `~습니다`, `~십시오`, 자신은 `저`.
- 적장에게는 하오체로 예의를 지키되 짧고 힘 있게 끊는다: `물러설 수는 없소!`
- 아우들은 자(`운장`, `익덕`)로 부른다. 이름(`장비야`)은 낮추는 말이라 쓰지 않는다. 다치거나 다시 만나거나 달랠 때만 `아우`, `익덕 아우`를 쓴다. 장마다 한두 번이다.
- 싸움터에서 군사 전체에게 외치는 명령은 해라체로 둔다: `지금이다! 불길에 놀란 적을 쳐라!`
- 혼잣말과 속말만 해라체로 둔다: `(조금만 더 버티면…)`, `그 오백을 무엇으로 먹이나…….`
- 욕설과 거친 말은 쓰지 않는다. 화가 나도 `부끄러운 줄 아시오!` 정도다.

**예시**

| 상황 | 대사 |
|---|---|
| 출전 | 유비 현덕이 상대하겠소! 내 아우들을 건드리지 마시오! |
| 방어 | 크윽…! 아직이오! |
| 밀릴 때 | 으윽…! 여기서 물러설 수는 없소! |
| 속말 | (조금만 더… 조금만 더 버티면…) |
| 반격 | 이 칼에도 뜻이 있소! |
| 합류 | 아우들… 기다리고 있었네! |
| 여남으로 떠날 때 | 우리 군사가 여기 오래 있으면 산마을이 또 싸움터가 되겠지. 여남으로 가겠소. |
| 성문에서 이름을 댈 때 | 유비 현덕이오. 여남에서 불러서 왔소. |
| 아우에게 | 운장, 함께 가세! / 익덕, 무리하지 말게! / 쉿, 익덕. 사신 앞일세. 말을 삼가게. |
| 승리·결의 | 형제가 모이면 천하에 못 이길 자가 없네! |
| 윗사람에게 | 스승님! 이게 어찌 된 일입니까. |

## 여포 — 오만하고 서늘한 반말

**성격**: 천하무적이라는 자부심이 있다. 상대를 깔보며 말하고, 놀라도 곧 인정하지만 사과하거나 낮추지 않는다. 퇴각할 때도 패배라고 말하지 않고 상황을 계산한다.

**말투**
- 낮추는 평어: `~다`, `~군`, `~느냐`, `~하마`.
- 비꼬는 감탄을 자주 쓴다: `제법이군.`, `흥, 한 놈 더 늘었군.`
- 방천화극, 적토마 이야기를 자주 한다. 상대의 무기를 비꼴 때는 이름 대신 `그 쇠막대`처럼 부른다.
- 상대 이름은 잘 부르지 않고, 별명으로 부른다: `수염 긴 놈`, `귀 큰 놈`, `검은 놈`.
- 놀랄 때는 속말로 낮게 말한다: `(이 일격… 생각보다 무겁군!)`

**예시**

| 상황 | 대사 |
|---|---|
| 도발 | 수염 긴 놈이 입만 살았군. 와 보아라. |
| 방어(여유) | 제법이군. / 가소롭군. |
| 회피 | 느리구나. / 어디를 노리느냐. |
| 강공 | 이것도 받아 보아라! |
| 놀람(속말) | (이 괴력… 보통내기가 아니다.) |
| 감탄 | 하하, 재미있구나! 천하에 이만한 자가 있었다니! |
| 3:1 | (셋이라… 성가시군.) / 이놈들이 감히! |
| 퇴각 | 셋을 한꺼번에 상대하기는 무리다! 물러난다! |
| 승리 | 또 나설 자가 있느냐! |

## 화웅·적장 — 허세 부리는 거친 말투

**성격**: 기세는 좋지만 속이 얕다. 처음에는 큰소리치다가 밀리면 무너진다.

**말투**: 느낌표가 많은 거친 반말. 상대를 얕잡아 부르다가 겁이 나면 말끝을 흐린다.

| 장수 | 처음 | 밀릴 때 |
|---|---|---|
| 화웅 | 연합군에는 사람이 없느냐! 내 창을 받아라! | 으으… 팔이 저려 온다! / 이… 이럴 수가! |
| 등무 | 어디서 굴러온 촌놈이냐! | 이… 이놈이 제법이구나! |
| 정원지 | 등무의 원수를 갚겠다! | 이놈… 어찌 이리 꿈쩍도 않느냐! |

## 목순·무안국 — 공을 노리는 조급한 말투

**성격**: 공명심에 눈이 멀어 서두른다. 여포를 얕보며 나섰다가 꺾인다.

- 목순: 거만하고 성급하다. `이 목순이 네 목을 거두어 공을 세우겠다!` 맞지 않으면 짜증을 낸다: `왜 맞서지 않느냐!`
- 무안국: 힘 자랑이 많다. `이 창 맛을 보아라!` 부상 뒤에는 `(팔이… 도저히 당해낼 수 없구나!)`처럼 속말로 약해진다.

## 하후돈 — 불같은 의리의 무인

**성격**: 한쪽 눈을 잃고도 흔들리지 않는 강직한 무인이다. 조조와는 한 집안에서 어려서부터 함께 자란 사이라 격 없이 대하면서도, 그의 뒤를 지키는 일에 목숨을 건다. 밀려도 기개는 꺾지 않고, 물러날 때도 이유를 조조 쪽에 둔다.

**말투**
- 거친 평어: `~다`, `~느냐`, `~하겠다`. 조조에게도 자(字) `맹덕`으로 부르며 평어를 쓴다(`맹덕, 우리도 거들까?`). 형님·존대는 쓰지 않는다.
- 애꾸라 놀림받아도 받아친다: `애꾸든 뭐든 이 창은 한쪽 눈으로 충분하다!`
- 밀릴 때는 이를 악문 짧은 말이다: `으윽…! 아직이다!`

| 상황 | 대사 |
|---|---|
| 도발 | 맹덕의 뒤는 이 하후원양이 막는다! 서라, 여포! |
| 방어 | 큭…! 이 정도로 쓰러질 줄 아느냐! |
| 속말 | (이 괴물… 내 창이 닿지 않는다!) |
| 퇴각 | 물러난다! 병사들을 수습해 맹덕에게 간다! |

## 순우경 — 술기운 오른 허세

**성격**: 술을 좋아하고 취한 채 큰소리를 친다. 기분 좋게 취했을 때 방해받으면 짜증이 앞서고, 칼을 맞대면 술기운이 쉽게 깬다.

**말투**: 혀가 꼬인 듯 느긋한 거친 반말이다. 말끝에 `~지`, `~냐`를 늘이고, 당하면 `이, 이놈이……`처럼 더듬는다.

| 상황 | 대사 |
|---|---|
| 처음 | 오늘 밤은 신도성에서 술을 마신다! 어디서 굴러온 촌놈이냐! |
| 공격 | 내 칼맛이 술보다 독하다! 받아라! |
| 속말 | (술기운인지… 이놈이 둘로 보인다……) |
| 밀릴 때 | 이, 이놈이……! 술맛 다 떨어졌다! |

## 안량·문추 — 하북 명장의 기세

**성격**: 원소군의 이름난 맹장이다. 자존심이 세서 상대를 처음에는 깔보고, 밀려도 쉽게 약한 소리를 하지 않는다. 물러날 때는 퇴각이 아니라 `오늘은`, `일단`이라는 말로 체면을 챙긴다.

**말투**: 묵직한 거친 반말. 안량은 말이 짧고 무게가 있으며, 문추는 직선적이고 오기가 강하다.

| 장수 | 상황 | 대사 |
|---|---|---|
| 안량 | 처음 | 애송이가 겁도 없구나. 하북 안량의 창을 받아 보겠느냐. |
| 안량 | 밀릴 때 | (한 번도 막힌 적 없는 내 창이 어찌……) |
| 안량 | 퇴각 | ……제법이군. 오늘은 여기까지다. |
| 문추 | 처음 | 상산의 조자룡인지 뭔지 하는 애송이에 이어 또 방해냐! 네놈이라도 베어 가겠다! |
| 문추 | 밀릴 때 | (이놈은 방해꾼 정도가 아니다……!) |
| 문추 | 퇴각 | 이 촌놈이……! 일단 물러난다! |

## 공손찬 — 백마 장군의 자부심

**성격**: 북평태수로 이민족을 떨게 한 노장이다. 자존심이 강하고 위기에도 호통으로 맞서지만, 병사들을 잃은 충격이 말끝에 묻어난다.

**말투**: 당당한 하오체가 아닌 단정한 반말. `~느냐`, `~하겠다`. 유비에게는 `현덕`이라 부르며 격식 없이 말한다.

| 상황 | 대사 |
|---|---|

## 간옹 — 능청스러운 고향 친구의 재치

**성격**: 유비의 고향 친구. 허물없고 능청스러운 수다쟁이로, 무거운 자리에 한마디 던져 사람들을 웃게 하고 유비를 사람으로 돌려놓는다.

**말투**: 하게체. `~하게`, `~구먼`, `~지`, `~겠네`. 유비는 `현덕`, 장비는 `익덕`이라 부른다(형님이라 부르지 않는다).

**웃음의 방향**: 지금 벌어진 일을 비튼다(칭찬 대신 의심을 받은 글, 큰 장터, 송별연 자리). 자기의 옛 약점(외상값, 술값)을 되풀이해 들추지 않는다.
외상 농담은 1장 탁현 거리에서 처음 만날 때 한 번만 쓴다("우선 내 외상값부터 셈하게"). 머리 위 말풍선(`Chatter`)도 외상이 아니라 지금 일을 중얼거린다.

| 상황 | 대사 |
|---|---|
| 첫 만남(1장, 외상 농담은 여기 한 번) | 돗자리 장수가 의병장이 된다고? 현덕, 장정 오백 먹일 셈은 했나. 우선 내 외상값부터 셈하게. |
| 중얼거림 | 오늘은 누구 집 잔치더라…… |
| 일을 맡을 때 | 의병 오백 군량 장부는 내가 맞춰 두지. 장세평 공이 더 대 준다는 것까지 숫자는 맞는데, 술독이 하나 비는군. |
| 다시 만남 | 발바닥만 닳았겠나, 입도 닳았네. 장세평 공한테 군량 한 수레 더 얻어 냈지. |
| 억울한 일을 비틀 때 | 글 한 장에 대군이 물러갔는데 칭찬은커녕 의심이라. 차라리 글을 못 썼으면 칭찬이라도 들었을 텐데. |
| 새 고을 | 장터가 소패보다 세 배는 크구먼. 내 말동무도 세 배는 되겠어. |

## 고람 — 입 가벼운 허세꾼 궁병

**성격**: 원소군의 궁병 장수. 자기 편이 이길 판이면 계책과 병력을 자랑삼아 떠벌리다가 곁의 참모나 동료가 말을 자른다. 거록에서는 국의의 노병 팔백을 흘렸고, 조조에게 항복한 뒤(21장)에도 입은 그대로다.

**말투**: 해라체의 거친 허세. 상대를 `~느냐`로 몰아붙이고 `~다!`로 끝맺으며, 중요한 대목에서 `……`로 끊기면 곁사람이 막는다. 말이 끊기는 건 알려 주려던 비밀 앞에서만 한다.

**짝**: 말리는 쪽은 봉기(`고 장군, 자중하시오`), 악진(`고 장군, 말은 그쯤 하시오`)처럼 `고 장군`으로 부른다.

| 상황 | 대사 |
|---|---|
| 허세(9장) | 저게 공손찬이 부른 원군이냐? 고작 저 머릿수로 거록을 넘겠다고? 내 연노가 길목을 겨누고 있는 줄도 모르고! |
| 비밀을 흘림(9장) | 날 쳐 봐야 소용없다! 계교 다리 건너엔 국의 장군의 정병 팔백이 방패 뒤에 엎드려 있다. 공손찬의 백마가 다리에 오르는 순간…… |
| 계책 자랑(21장) | 너희 깃발도 군호도 승상의 손바닥 안이다! 거록에서 입 조심하라는 말을 들었다만, 이 계책만은 자랑해도 좋겠지! |
| 끊기는 말(21장) | 둘을 떼어 놓으라는 것이 승상의 계책이시다. 서쪽의 하후돈은 미끼일 뿐, 진짜는…… |

## 조조·원술·원소 — 연합 진영에서의 말씨

- 조조는 제후들과 하오체로 말한다. 남의 허물을 길게 캐묻기보다 사실 하나를 짚어 비튼다. 유비에게 사과할 때도 짧게 인정하고, 그가 직접 뜻을 말할 자리를 준다.
- 원술은 조조에게 평어로 성을 내다가, 맹주 앞에서 남을 추천할 때는 하오체로 격식을 갖춘다. 속내를 설명하지 않고 조조의 말을 되돌려 쓴다.
- 원소는 맹주로서 묻고 정한다. 남들의 눈치를 보더라도, 결정을 내린 뒤에는 역할과 지원을 분명히 말한다.

| 장수 | 상황 | 대사 |
|---|---|---|
| 조조 | 원술의 군량 지연을 짚을 때 | 군량은 늦었어도 현덕은 늦지 않았으니, 다행이오. |
| 조조 | 유비의 뜻을 먼저 들을 때 | ……현덕의 뜻부터 들어보시오. |
| 조조 | 제 말로 곤란해진 유비에게 | 아까는 내 말이 공을 곤란하게 했소. |
| 원술 | 조조에게 성낼 때 | 지금 내가 군량을 일부러 늦췄다는 거냐! |
| 원술 | 조조의 칭찬을 되돌릴 때 | 맹덕이 그토록 칭찬하니, 이번에도 믿고 맡길 만하겠구려. |
| 원소 | 선봉을 정할 때 | 좋소. 현덕이 선봉에 서시오. 본군은 뒤를 받치겠소. |
| 유비 | 남의 추천 뒤 스스로 나설 때 | 제가 가겠습니다. |

## 새 대사를 쓸 때 확인할 것

1. 누가 말하는가? 말풍선 표시 규칙(방어자/공격자)을 확인했는가?
2. 어미가 위 표에 맞는가? 특히 관우와 유비의 존대/하오체가 섞이지 않았는가?
3. 무기 이름이 병종·장비와 맞는가?
4. 그 장면에서 말할 법한 감정인가? (여포는 겁먹지 않고 계산한다, 관우는 흥분하지 않는다.)
