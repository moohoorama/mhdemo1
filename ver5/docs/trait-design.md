# 특성·책략 개편 설계

`_todo_speciality.md`를 정리하고, 레벨업 학습창과 선행 특성 구조를 더한 문서다.

## 방향

- 특성은 숫자 보정이 아니라 **규칙**을 바꾼다. 확정(반드시 치명타·반드시 성공), 행동 경제, 범위 확장, 변환, 권한 부여를 우선한다.
- 퍼센트 보정은 장비·병종·레벨에 맡긴다.
- **반격은 특수한 상황에서만 일어난다.** "반격받지 않음" 계열 특성은 만들지 않는다.
- 재이동, 은신, 지형 생성처럼 코드를 복잡하게 하고 버그를 만들기 쉬운 효과는 넣지 않는다.
- 이동을 막는 수단은 방해계 책략 **봉쇄** 하나만 둔다.

## 특성 습득

### 주어지는 특성과 학습 특성

특성은 얻는 방식에 따라 두 종류로 나눈다. 한 특성은 둘 중 하나에만 속한다.

| 종류 | 출처 | 유효 기간 |
|---|---|---|
| 주어지는 특성 | 병종, 장비 | 그 병종·장비인 동안만 |
| 학습 특성 | 레벨업 학습창 | 영구 |

- 주어지는 특성은 학습 대상이 아니다. 이미 가진 특성을 배워 아무것도 얻지 못하는 상황을 막는다.
- 예: 화계는 사마·참모·군사가 주는 특성이다. 사마가 방술사로 승급하면 화계가 사라져 화계 책략을 못 쓴다. 사마 때 배운 화계강화는 남지만 화계가 없으니 효과가 없다.
- 장비가 주는 특성이 병법을 쓰게 하는 구조(예: 장비 → 구휼 → 소보급)는 유지한다. 장비가 주는 책략 계통 특성은 뿌리 특성까지만이다.

### 레벨업 학습창

- 장수는 학습 특성 없이 시작한다. 처음 학습창이 뜰 때 플레이어가 특성이라는 개념을 자연스럽게 알게 한다.
- 학습창은 **전투 중 레벨업했고, 지금 특성치로 배울 수 있는 특성이 하나 이상 있을 때만** 뜬다. 메뉴에 별도의 학습 커맨드는 두지 않는다.
  - 가장 싼 특성이 300이므로 첫 학습창은 Lv4 무렵에 뜬다.
- 부관도 레벨업하면 자신의 특성치로 학습창을 띄운다.
- 학습창에는 지금 배울 수 있는 특성만 보인다. 조건은 아래와 같다.
  - 학습 풀(아래)에 있다.
  - 선행 특성을 모두 가지고 있다.
  - 아직 가지고 있지 않다.
- 특성치가 허락하는 만큼 여러 개를 배울 수 있다. 하나도 배우지 않고 **닫기**로 넘어갈 수도 있다. 남은 특성치는 이월된다.
- 한 행동으로 여러 번 레벨업해도 학습창은 한 번만 뜬다.
- 학습은 행동을 소비하지 않고 즉시 적용된다.

### 선행 특성

- 특성은 선행 특성을 가질 수 있다. 선행 특성을 모두 가져야(주어지는 특성 포함) 학습창에 나타난다.
- 이 구조 덕분에 초반 학습창에는 뿌리 특성 몇 개만 나오고, 배울수록 갈래가 열린다.
- 선행 특성은 학습 자격만 정한다. 배운 뒤에 선행 특성을 잃는 경우는 없다(습득 특성은 영구).
- 병법의 필요 레벨과 학습의 필요 레벨은 두지 않는다. 선행 특성이 그 역할을 한다.

### 학습 풀

장수 한 명이 배울 수 있는 특성은 **12~15개**(장수 고유 3~6 + 병종 3×3)다. 장착 중인 장비의 학습 자격이 여기에 더해질 수 있다.

| 출처 | 개수 | 내용 |
|---|---|---|
| 장수 고유 | 3~6개 | 장수 개성을 드러내는 특성 |
| 병종 | 단계마다 약 3개, 3단계 합계 약 9개 | 예: 경보병 3 + 중보병 3 + 근위대 3. 상위 병종은 같은 계열 하위 병종의 풀을 포함하므로, 승급 전에 못 배운 특성도 계속 배울 수 있다. 책략 계통의 강화·확산은 병종 풀에만 둔다 |
| 장비 | 장비마다 | 장착 중인 장비가 주는 학습 자격(design.md 9.2). 구현은 하되, 문제가 되면 데이터에서 비워 제외한다 |

- 주어지는 특성도 선행 조건을 채운다. 예: 참모는 주어지는 특성 화계가 있으므로 화계강화를 배울 수 있다.
- 공통 학습 풀(`CommonLearn`: 모든 장수가 병종과 상관없이 배울 수 있는 특성 목록)은 없앤다. 장수마다 성장 방향이 갈리게 하려는 것이다. 현행 공통 목록에서 계속 쓸 특성은 장수 고유나 병종 풀로 옮긴다.

### 특성치와 비용

- 특성치는 레벨업마다 +100이다(design.md 9.1).
- 학습 비용은 **300~1500**이다. 비용 예: 300, 300, 300, 400, 400, 500, 500, 700, 700, 1000, 1000, 1200, 1500.
- 목표 (대략):
  - 엔딩 무렵 레벨은 약 60(특성치 약 5,900)이다. 다 배우지 못하고 골라 배우게 한다.
  - 풀 비용 합계는 장수마다 다르다. 인기 장수는 배울 것이 많아 1만 대(대략 Lv110 상당), 비인기 장수는 병종 특성과 약한 고유 특성 몇 개라 1만보다 낮을 수 있다.

### 적·NPC 장수

적과 NPC 장수는 레벨업 학습을 하지 않는다. 데이터에 특성을 직접 지정한다.

| 양생 + 정병 | 양생 하나로 통합 |

| 산전, 삼림전, 매복, 축성, 수전, 신산, 무심, 명마술 | 삭제 |

| 구 견제, 구 계략 | 삭제. 같은 이름을 책략 계통 특성(디버프계·방해계)으로 다시 쓴다 |
| 독내성 | 삭제. 군율로 흡수 |

**유지 (효과 그대로):** 백출, 필살, 찔러공격, 독공, 심공, 침착, 위압, 부관, 반격술, 무쌍술

국사무쌍·부호는 행동 후 즉시 턴을 종료하는 규칙에 맞춰 제거했다. 공격·병법·도구 사용 뒤에는 이동이나 추가 행동을 할 수 없다.

## 공통 규칙

### 판정 충돌

- **공격 특성과 방어 특성이 충돌하면 방어가 우선한다.**
  - 반드시 명중·반드시 성공 vs 명중 0·면역 → 방어 우선
  - 허실(책략 100% 성공) vs 군율 등 면역 → 면역 우선. 허실과 간파는 지력 비교라 동시에 발동하지 않는다.
- **피해 처리 순서:** 치명타 판정 → 방어력(버프 포함) → 철벽 감소

### 2회 공격

- 2회 공격은 **2회 공격 확률**(design.md 2부 2.3, 순발 기반)로 판정한다. 연전·신장은 이 확률을 100%로 만든다. 확률 100%를 주는 특성이 여럿이어도 2회다.
- **판정 시점은 첫 타격 전이다.** 첫 타격의 명중·빗나감과 상관없이 두 번째 타격을 시도한다. 첫 타격으로 대상을 격파하면 두 번째 타격은 없다.
- 두 번째 타격도 명중·치명타를 따로 판정한다. 독공·찔러공격·심공 등 공격 특성도 모두 적용된다.
- 상대의 반격은 2회 공격이 모두 끝난 뒤에 한다.
- **반격도 그 부대의 2회 공격 확률로 다시 판정한다.** 2회 반격이 될 수 있다.
- 협동 공격도 2회 공격을 판정한다.

현행 design.md는 "모든 첫 타격이 끝난 뒤 대상마다 2회 공격 판정, 반격 제외, 반격은 대상마다 한 번만"이다. 판정 시점과 반격 2회를 이 문서대로 바꾼다.

### 추가로 일어난 공격

- 반격·협동·응사·반계로 생긴 공격은 다시 반격·협동·응사·반계를 일으키지 않는다.
- 협동은 아군이 직접 한 물리 공격에만 반응한다.

### 버프·디버프 수치

- 부대 능력치 버프는 **+20%**, 디버프는 **-20%**로 통일한다. 이동력·사거리처럼 고정치를 더하는 버프는 예외다.
- 특성이 자동으로 거는 버프(수성·신속·원시)의 유효기간은 **2턴**이다. 매 턴 다시 걸려 갱신된다.
- 버프는 한 번 걸리면 유효기간 동안 유지된다. 버프를 건 조건(예: 성)을 벗어나도 꺼지지 않는다.
- 신속 버프(이동력 +2)와 질풍(+2)은 서로 다른 출처라 함께 가지면 +4다.

### 배율

- 배율끼리는 **더한다.** 예: +100%, +100%, +100% → +300% (회복량 4배)

### 범위 용어

**단일**(대상 1칸), **십자**(대상 + 상하좌우, 5칸), **3×3**(대상 + 8방향, 9칸), **일자**(시전자에서 대상 방향으로 곧게 N칸). '4방'이라는 말은 쓰지 않는다.

## 특성 목록

선행 열이 빈 특성은 뿌리 특성이다. 선행 관계는 초안이다.

### 물리 공격

| 특성 | 선행 | 효과 |
|---|---|---|
| 용장 | | 자신보다 무력이 낮은 대상을 공격하면 반드시 치명타 |
| 연전 | | 2회 공격 확률 100% (두 번째 타격 시도가 반드시 일어남. 명중은 따로 판정) |
| 신장 | 용장, 연전 | 자신보다 무력이 낮은 대상을 공격하면 반드시 치명타 + 2회 공격 확률 100% |
| 투신 | | 자신보다 무력이 낮은 상대에게 공격받고 그 상대가 자신의 공격범위 안에 있으면, 반격 버프가 없어도 반드시 반격. 피해 계수 0.7 × 2 = 1.4 |
| 협동 | | 자기 진영 차례에, 자신의 공격범위 안의 적이 아군의 물리 공격을 받으면 같은 대상을 50% 피해로 공격. 공격 행동을 소모하지 않음 |
| 기습 | | 자신이 숲에 있으면 반드시 치명타 |
| 난사 | | 공격범위 안의 모든 적 공격. 원거리 전용, 피해 계수 0.5 (design.md 6.4) |
| 사방격 | | 물리 공격 범위가 십자가 됨. 주변 칸의 적은 75% 피해 |
| 팔방격 | 사방격 | 물리 공격 범위가 3×3이 됨. 주변 칸의 적은 75% 피해 |
| 공성 | | 대상의 지형 방어 보정 무시 |
| 회심 | (아이템 전용) | 일반 공격과 공격 책략이 치명타 확률과 상관없이 반드시 치명타. **아이템 '옥쇄' 전용** (필살·심모의 상위호환) |

- 사방격·팔방격: 적만 맞는다. 두 번째 타격과 반격·협동·응사에도 적용되고, 주변 칸 타격에도 독공·심공·필살 등 공격 특성이 적용된다. 둘 다 있으면 팔방격만 적용한다. 범위는 겹쳐도 넓어지지 않는다(발석거 십자 + 사방격 = 십자, 발석거 + 팔방격 = 3×3).
- 일기토는 스토리 이벤트로만 일어난다. 자신의 커맨드나 특성으로 일기토를 일으키지 않는다. 일기토 대상과 근접하게 이동한 뒤 행동을 종료하면 발생한다.
- 협동: 조건을 만족하는 협동 장수가 여럿이면 모두 협동한다. 적 차례에는 아군이 협동하지 않는다. 적도 협동 특성이 있으면 적 차례에 협동한다. 책략 공격에는 발동하지 않는다.

### 방어

| 특성 | 선행 | 효과 |
|---|---|---|
| 철벽 | | 한 번의 피격에서 자신의 최대 병력 10%를 넘는 피해는 절반만 받음 |
| 금강 | | 상대 공격이 치명타로 판정되면 그 타격을 무조건 막음(방어 성공). 반드시 치명타인 공격에는 오히려 강함 |
| 간접공격면역 (구 방패) | | 적의 원거리 공격이 자신에게 명중할 확률 0 (= 방어 성공) |
| 응사 (구 원거리방어) | | 적의 물리 공격이 빗나가면, 자신의 공격범위와 상관없이 공격자를 타격. 피해 계수 0.7 |
| 반계 (구 책략방어) | | 공격 책략을 받으면 같은 공격 책략을 시전자에게 되돌림 |
| 수성 (구 불굴) | | 성에 있으면 매 턴 방어력 +20% 버프를 자신에게 걺 |

- 철벽 예: 최대 병력 1000, 받는 피해 250 → 기준 100. 100 + (150 × 0.5) = 175를 받는다.
- 간접공격면역·금강으로 막은 공격은 방어 성공(빗나감)이다. 응사가 발동하고, 위압(빗나가도 50% 피해)도 적용된다.
- 간접공격면역 + 응사: 원거리로 공격해 온 적은 항상 빗나가고 항상 응사를 맞는다.
- 반계: 반계 부대가 적의 책략을 간파해 되받아치는 것이다. 명중·피해는 **반계 부대의 능력치**로 계산한다. 병법치를 소모하지 않고 사거리와 상관없다. 연환으로 추가로 맞은 대상도 반계한다.

## 책략 계통

책략은 계통 특성이 사용 권한을 준다. 책략마다 **필요 특성**이 있고, 필요 특성을 모두 가져야 쓸 수 있다. 책략 이름은 조조전 책략을 최대한 따른다.

### 3단 계통 (화·수·지·회복)

뿌리 특성 아래에 **강화**와 **확산** 두 갈래가 있다. 최상위 책략은 **뿌리 + 강화 + 확산**을 모두 가져야 열린다.

```
화계 ─┬─ 화계강화 ─┐
      └─ 화계확산 ─┴─ (둘 다) 폭염·화룡
```

| 계통 | 뿌리 (주어지는 특성) | 강화 (학습) | 확산 (학습) |
|---|---|---|---|
| 화염계 | 화계 | 화계강화 | 화계확산 |
| 수계 | 수계 | 수계강화 | 수계확산 |
| 토지계 | 지계 | 지계강화 | 지계확산 |
| 회복계 | 구휼 | 구휼강화 | 구휼확산 |

#### 공격 계통

| 필요 특성 | 화염계 | 수계 | 토지계 |
|---|---|---|---|
| 뿌리 | 초열 (명중률 +20%, 사거리 4) | 탁류 (명중률 +20%, 사거리 4) | 낙석 (명중률 +20%, 사거리 4) |
| 뿌리 + 강화 | 업화 (초열 피해 1.5배, 사거리 3) | 격류 (탁류 피해 1.5배, 사거리 3) | 산사태 (낙석 피해 1.5배, 사거리 3) |
| 뿌리 + 확산 | 화진 (초열 피해 0.7배, 십자, 사거리 4) | 수진 (탁류 피해 0.7배, 십자, 사거리 4) | 지진 (낙석 피해 0.7배, 십자, 사거리 4) |
| 뿌리 + 강화 + 확산 | 폭염 (초열 피해 1.2배, 일자 6칸, 사거리 2), 화룡 (초열 피해, 십자, 사거리 3) | 해일 (탁류 피해 1.5배, 사거리 7), 수룡 (탁류 피해, 십자, 사거리 3) | 거암 (낙석 피해 2배, 사거리 2), 지룡 (낙석 피해, 십자, 사거리 3) |

#### 회복계

| 필요 특성 | 책략 |
|---|---|
| 구휼 | 소보급 (단일 병력 회복), 헌책 (병법치 24 소모, 대상 아군 병법치 +24) |
| 구휼 + 구휼강화 | 중보급 (소보급 ×2), 각성 (모든 상태 해제) |
| 구휼 + 구휼확산 | 원군 (소보급, 십자) |
| 구휼 + 구휼강화 + 구휼확산 | 대보급 (소보급 ×3), 대원군 (중보급, 3×3), 수송 (중보급, 사거리 무한), 간언 (병법치 48 소모, 대상 아군 병법치 +48) |

### 2단 계통 (버프·디버프·방해)

뿌리 특성 아래에 **강화** 하나만 있다. 상위 책략은 뿌리 + 강화가 필요하다.

| 계통 | 뿌리 (주어지는 특성) | 강화 (학습) |
|---|---|---|
| 버프계 | 독려 | 독려강화 |
| 디버프계 | 견제 | 견제강화 |
| 방해계 (독 포함) | 계략 | 계략강화 |

독은 방해계에 넣는다. 독계 공격 책략(독룡 등)과 독술 특성은 삭제한다.

#### 버프계

| 필요 특성 | 책략 | 대상 능력 | 범위 |
|---|---|---|---|
| 독려 | 기민 | 민첩 +20% | 십자 |
| 독려 | 고양 | 사기 +20% | 십자 |
| 독려 | 분기 | 공격력 +20% | 단일 |
| 독려 | 견고 | 방어력 +20% | 단일 |
| 독려 + 독려강화 | 고무 | 공격력 +20% | 십자 |
| 독려 + 독려강화 | 강진 | 방어력 +20% | 십자 |
| 독려 + 독려강화 | 강행 | 이동력 +2 | 단일 |

#### 디버프계 (버프계와 대칭)

| 필요 특성 | 책략 | 대상 능력 | 범위 |
|---|---|---|---|
| 견제 | 둔화 | 민첩 -20% | 십자 |
| 견제 | 동요 | 사기 -20% | 십자 |
| 견제 | 쇠약 | 공격력 -20% | 단일 |
| 견제 | 약화 | 방어력 -20% | 단일 |
| 견제 + 견제강화 | 위축 | 공격력 -20% | 십자 |
| 견제 + 견제강화 | 와해 | 방어력 -20% | 십자 |

#### 방해계

| 필요 특성 | 책략 | 효과 | 범위 |
|---|---|---|---|
| 계략 | 봉책 | 책략 사용 불가 | 단일 |
| 계략 | 독연 | 독 | 단일 |
| 계략 | 혼란 | 혼란 | 단일 |
| 계략 + 계략강화 | 봉쇄 | 이동 불가 | 단일 |
| 계략 + 계략강화 | 봉격 | 공격 불가 | 단일 |
| 계략 + 계략강화 | 대혼란 | 혼란 | 십자 |
| 계략 + 계략강화 | 독무 | 독 | 십자 |

### 삭제하는 책략

풍계(풍진·회오리·천풍), 뇌계(뇌격·연뇌), 독계 공격(독룡), 화상(병법), 설파, 이간, 환술, 정신통일, 명상, 수호, 책략장벽, 호풍, 기우, 기마사, 그리고 현행 버프 병법(격려·분발·방진·철갑·대분발·대방진·정신강화·전이). 풍계·독술 특성도 삭제한다. 현행 소회복은 소보급, 해독은 각성으로 대체한다.

## 문관 계열 배정 (초안)

design.md 성장 트리는 `사마 → 참모 → 군사`(공격 책략)와 `사마 → 방술사 → 선술사`(버프·회복)다. 현재 데이터에는 방술사·선술사가 없다.

| 병종 | 주어지는 특성 | 병종 학습 풀의 계통 특성 |
|---|---|---|
| 사마 | 화계, 수계, 구휼 | 화계강화, 수계강화 |
| 참모 | 화계, 수계, 지계, 견제, 계략 | 사마 풀 + 화계확산, 수계확산, 지계강화 |
| 군사 | 참모와 같음 | 참모 풀 + 지계확산, 견제강화, 계략강화 |
| 방술사 | 구휼, 독려 | 사마 풀 + 구휼강화, 구휼확산 |
| 선술사 | 방술사와 같음 | 방술사 풀 + 독려강화 |

- 사마는 승급 방향에 따라 주어지는 특성이 바뀐다. 참모로 가면 구휼을, 방술사로 가면 화계·수계를 잃는다.
- 병종 학습 풀은 단계마다 약 3개다. 계통 특성으로 다 차지 않는 자리는 귀모·허실·심모·연환·의술·집중 등으로 채운다. 사마 풀의 화계강화·수계강화처럼 승급 후 쓸모가 없어질 수 있는 특성을 둘지는 데이터 작업 때 정한다.

## 장수 고유 특성

- 장수 고유 학습 특성은 **3~6개**다. 플레이어 장수의 시작 특성(`Traits`)은 비운다.
- 장수 개성은 고유 학습 특성의 구성과 선행 관계로 드러낸다. 예: 관우 용장 → 신장, 유비 인덕·용인술.
- 장수별 목록은 데이터 작업 때 정한다.

## Deprecated 물리 병법

새 설계에서 쓰지 않는다. 데이터에서 바로 지우지 않고 deprecated로 표시한 뒤 정리한다.

맹공, 저격, 관통사, 연노격, 무쌍격, 탈취, 복병, 창격, 돌파, 독시, 투석, 성벽파쇄, 연격, 기공, 금강신

## 결정이 필요한 것

1. **고육 (구 명경) 이름:** 병법치가 모자라면 병력으로 대신 내는 특성(지원·성장 표). 후보: 고육(고육지책), 사력, 혈책.
2. **장수·병종별 학습 풀과 비용 배정:** 위 목표에 맞춰 대략으로 데이터 작업 때 정한다.

## 작업 대상

- `design.md`: 1부 6.4·8.2, 2부 2.3(2회 공격 판정 시점·반격 2회), 2부 5장 특성 정의, 5.1·5.2, 6장 병법 표(7계통 재분류), 9장(레벨업 학습창·선행 특성·학습 풀). 돌격·신속·원시 병법 삭제, 팔진도 추가, 분기 → 무쌍.

  - `Equipment`: 삭제된 특성·병법 참조 제거, 주어지는 특성으로 병법 권한 유지
  - `CommonLearn`: 삭제 (필드와 코드 참조 모두)
- `internal/content/content.go`: 선행 특성·주어지는 특성·책략 필요 특성 필드와 검증(선행 순환 금지, 없는 특성 참조 금지, 주어지는 특성이 학습 풀에 없음)
- `internal/core`: 학습 가능 목록에 선행 조건 반영, 책략 사용 조건을 필요 특성으로 판정, 레벨업 시(부관 포함) 학습 단계 진입과 닫기, 학습 커맨드는 그 단계에서만 허용. 특성 판정과 2회 공격 흐름 교체. 3×3·일자 범위, 봉쇄·봉격 상태.
- `internal/ai`: 하드코딩된 특성 우선순위 교체. 적은 학습하지 않음.
- `internal/gui`: 레벨업 학습창, 학습 커맨드 제거, `help.go` `traitNotes` 갱신, 3×3·일자 범위 표시.
- 테스트: 선행 조건, 학습창 진입·닫기, 바뀐 특성별 판정.
- 기존 리플레이·세이브는 `RulesVersion`·`ContentHash`가 바뀌어 무효가 된다.
