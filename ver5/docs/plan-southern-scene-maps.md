# 장판교에서 화용도까지의 장면맵

25~27장에서 전장 밖에 쓰는 지형을 장소별로 만든다. 좌표는 기존 형식 2 장면맵과 탐험의 작은 칸을 사용한다.

| 장소 | 지형과 화면의 중심 | 조작과 배치 |
|---|---|---|
| 장판교 | 둑 사이의 좁은 목교, 다리 동쪽에 피란민과 급히 마련한 야영지 | 두 경로의 전투 뒤 장면을 같은 다리 동쪽에 두고, 한진행 탐험은 진영 바깥 흙길로 이어진다. |
| 한진 나루 | 굽는 물가와 좁은 판자 선착장, 일행을 기다리는 배 | 흙둑에서 뱃사공을 지나 강하행 배에 닿는다. |
| 강하 나루 | 포석으로 정비한 부두, 선착장 여러 곳과 군량 창고 | 유기가 상륙한 일행을 맞는다. 번구행은 부두 쪽에서 배를 탄다. |
| 적벽 | 강 한복판의 아군 배와 화광이 비치는 맞은편 절벽, 맞은편 불타는 선단 | 유비 일행은 넓은 갑판에 서고 유기는 선수 쪽으로 움직인다. |
| 화용도 | 늪물로 갈라진 땅과 굽은 좁은 둑길 | 유비는 둑길을 따라 강하 쪽 출구로 빠져나간다. |
| 여남성 | 북동쪽 성 밖에 성문으로 이어지는 흙길과 길가 지면 | 기존 검문 자리와 성 안 동선에 이어지는 바깥 지형을 넓힌다. |

맵 생성 스크립트에 배치와 지형을 함께 기록한다. 장면의 배역과 시선, 탐험의 출발·출구 좌표를 새 지형에 맞추고, 기본·대체 경로의 장면을 게임에서 캡처한다.

장판교에서 한진으로 피란하는 순서, 적벽의 화공과 화용도 퇴각은 게임의 이야기와 연의의 해당 대목을 참고했다. [연의 42회](https://zh.wikisource.org/wiki/三國演義/第042回) · [49회](https://zh.wikisource.org/wiki/三國演義/第049回) · [50회](https://zh.wikisource.org/wiki/三國演義/第050回)

맵 재생성은 `cd ver5 && python3 tools/scene_maps/southern_routes.py && python3 tools/scene_maps/runan.py`로 한다.
