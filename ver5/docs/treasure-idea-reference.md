# 보물 아이디어 레퍼런스

영걸전·조조전·조조전 MOD의 보물 이름과 효과를 참고해 이 프로젝트의 보물을 구상하기 위한 자료다.
첫 주제는 **여포에게 지속적으로 방어력 버프를 부여하는 갑옷**이다.

조사일: 2026-10-11. 아래 내용은 인터넷 공략과 위키의 설명을 정리한 것으로,
게임 데이터나 MOD 배포본을 직접 확인한 결과는 아니다. MOD의 효과는 버전에 따라 달라질 수 있다.
실제 작품의 보물과 이 프로젝트용 창작 후보를 구분한다.

## 1. 실제 작품에서 찾은 보물

### 원작 삼국지 영걸전

영걸전은 방어력을 높이는 보물을 병법서로 표현한다.

| 보물 이름 | 공략에 소개된 효과 |
|---|---|
| 손자의병법서 | 소유 시 방어력 상승 |
| 오자의병법서 | 소유 시 방어력 상승 |
| 맹덕신서 | 소유 시 방어력 상승 |
| 삼략 | 소유 시 방어력 상승 |
| 육도 | 소유 시 방어력 상승 |

갑옷 작명에는 조조전의 방어구가 더 직접적인 참고가 되지만,
병법서에 방어 효과를 주는 방식은 향후 보조 보물 구상에 활용할 수 있다.

출처: [삼국지 영걸전 공략 — 아이템 및 전투 소개](https://it.sssbrain.com/삼국지-영걸전-공략-아이템-및-전투-소개/)

### 원작 삼국지 조조전

| 보물 이름 | 특수 효과 | 아이디어 참고점 |
|---|---|---|
| 거울갑옷 | 간접 공격 방어 | 특정 공격 유형을 막는 갑옷 |
| 황금갑옷 | 회심 공격 방어 | 금빛의 화려한 외형과 강한 생존력 |
| 연환갑옷 | 연속 공격 방어 | 갑옷의 구조를 이름에 반영 |
| 용린갑옷 | MP 방어 | 신수의 이미지를 특별한 방어 능력과 연결 |
| 백은갑옷 | 책략 피해 경감 | 재질·색으로 보물의 인상을 구분 |
| 봉황깃옷 | 매 턴 HP 회복 | 매 턴 반복해서 발동하는 방어구 효과 |

원작의 황금갑옷·연환갑옷·용린갑옷은 **매 턴 방어력 버프를 주는 보물은 아니다**.
이름과 효과를 결합하는 방식, 봉황깃옷의 반복 발동 구조를 참고한다.

출처: [조조전 TIP — 아이템 일람](https://www.ggemguide.com/guide_pc_view.htm?uid=10)

### 조조전 MOD: 여포전

- 호로관 전투 공략에 황개 퇴각 시 **황금갑옷**, 정보 퇴각 시 **연환갑옷**을 얻는다고 기록되어 있다.
- 이어지는 형양 전투 공략에는 여포가 **황금갑옷 + 적토마**를 착용한 사례가 나온다.
- 이는 해당 공략의 장비 선택 사례이며, 여포 전용 장비라는 뜻은 아니다.

작명 참고: 여포에게 화려하고 묵직한 갑옷을 입히는 방향이 잘 어울린다.

출처: [여포전 — 호로관 전투](https://jojojo.tistory.com/129), [여포전 — 형양 전투](https://jojojo.tistory.com/131)

### 조조전 MOD: 영걸전 리메이크

입수 가능한 방어구 목록에 **용린갑옷·비룡도복·칠흑도복·봉황깃옷·백은갑옷·연환갑옷·거울갑옷·학창**이 나온다.
황금갑옷은 입수 불가능한 아이템으로 별도 기재되어 있다.

작명 참고: 기존 조조전 보물 이름을 계승해 영걸전 분위기와 연결하는 방식이다.
이 목록만으로 각 보물의 효과가 원작과 동일하다고 단정하지 않는다.

출처: [영걸전 리메이크 — 입수 가능한 아이템](https://seore.org/w/영걸전%20리메이크)

### 조조전 MOD: 황금투구전설

위키 소개에 따르면 조인에게 **용린갑옷**을 착용시키면,
MP 방어·MP 회복 외에 **매 턴 정신력 버프** 효과를 추가로 얻는다.

아이디어 참고: 특정 장수와 보물의 조합에 반복적인 능력치 버프를 부여하는 방식이다.
여포의 갑옷에 매 턴 방어력 버프를 주는 구상과 유사하지만,
이 자료에서 확인되는 버프는 방어력이 아니라 정신력이다.

출처: [황금투구전설 소개](https://tcatmon.com/wiki/황금투구전설)

## 2. 여포의 지속 방어 버프 갑옷: 창작 후보

**아래 이름은 이번 구상에서 새로 제안한 후보다. 위 작품들에 실제 등장한다고 확인한 이름이 아니다.**

| 후보 | 의도와 느낌 |
|---|---|
| **금강연환갑(金剛連環甲)** | 가장 추천. 금강의 견고함과 조조전 연환갑옷의 익숙한 인상을 결합 |
| **무쌍갑(無雙甲)** | 여포의 전용 보물이라는 인상을 강조. 방천화극·적토마와 함께 놓기 좋은 간결한 이름 |
| **금강갑(金剛甲)** | 단단한 방어구라는 효과를 직관적으로 전달하는 세 글자 이름 |
| **패왕금갑(霸王金甲)** | 여포의 위세와 금빛 갑옷의 화려함을 강조 |
| **용린금갑(龍鱗金甲)** | 용 비늘 같은 금빛 갑옷. 원작 용린갑옷을 연상시키는 이름 |

추천 방향:

- 갑옷 자체의 보물 이름과 고전 조조전 분위기를 중시하면 **금강연환갑**.
- 여포의 상징적인 전용 장비를 중시하면 **무쌍갑**.
- 짧고 효과가 명확한 이름을 원하면 **금강갑**.

## 3. 보물 설명과 효과 문구 초안

### 금강연환갑

> 금강처럼 단단한 고리를 엮어 만든 보갑. 전장에 나서면 호신의 기운이 끊임없이 솟아난다.

효과 문구는 실제 동작에 맞춰 선택한다.

| 동작 | 효과 문구 초안 |
|---|---|
| 매 턴 버프를 다시 부여해 유지 | 매 턴 시작 시 자신에게 방어력 상승 부여. |
| 매 턴 방어력 증가가 누적 | 매 턴 시작 시 방어력 증가. 최대 ○중첩. |

현재 의도인 ‘계속해서 방어력 버프가 걸리는 갑옷’에는 첫 번째 문구를 우선 후보로 둔다.
버프 수치·지속 시간·해제 후 재부여 시점·중첩 여부는 구현 시 별도로 확정한다.

이 문서는 보물 아이디어 참고 자료이며, 이름이나 효과를 게임 데이터에 반영한 것은 아니다.
