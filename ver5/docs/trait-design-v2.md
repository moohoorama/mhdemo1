# 특성·병종·부관 통합 설계 v2

> 기존 `trait-design.md`와 이후 대화에서 변경·확정된 내용을 통합한다.
> 후속 논의가 기존 문서보다 우선하며, 수치는 별도 표시가 없으면 밸런싱
> 초안이다.

## 1. 핵심 원칙

-   병종 특성은 평범한 병사의 전술 수단, 장수 고유 특성은 이를
    강화·변형·상시화하는 수단이다.
-   평범한 병사는 준비해서 해내고, 명장은 더 확실하게 또는 준비 없이
    해낸다.
-   같은 효과를 이름만 바꿔 중복 생성하지 않는다. 기존 특성/책략과 같은
    이름에 다른 효과도 금지한다.
-   `군율`, `금강` 같은 강한 면역·상시 규칙 변경은 일반 병종에 남발하지
    않는다.
-   병종과 고유 특성은 반드시 일치할 필요가 없다. 불일치를 스토리와
    육성에 활용할 수 있다.

## 2. 특성치·승급

-   레벨업마다 특성치 +100.
-   Lv20, Lv40에서 승급 가능.
-   학습 특성은 영구 보유. 현재 병종/무기 조건이 맞지 않으면 비활성화될
    수 있다.
-   상위 병종은 하위 병종의 학습 자격을 기본적으로 계승한다.

  단계                      권장 비용대 의도
  ----------- ------------------------- ----------------------------
  1단계                500 / 700 / 1000 승급 전 약 2개 선택
  2단계          700 / 1000 / 1000 전후 전문화와 부관임명이 경쟁
  3단계         1000 / 1200 / 1500 전후 강한 완성 특성
  장수 고유                  500\~1500+ 병종 특성과 동일 자원 경쟁

`수성` 정도의 상시 효과는 1000 이상을 기본으로 본다. 모든 상급 병종이
`군율`을 배우는 식으로 디버프 시스템을 무력화해서는 안 된다.

## 3. 부관 시스템

-   장수가 늘어날수록 버려지는 장수를 부관으로 흡수한다.
-   부관은 독립 출전 불가. 장수 복제는 없다.
-   2단계 병종부터 `부관임명` 학습 자격이 열리며 자동 획득이 아니다.
    비용 초안 700\~1000.
-   통솔/무력/지력/민첩/운/매력 중 부관이 주장보다 뛰어난 능력치는 부관
    능력치로 보정한다. 정확한 공식은 별도 밸런싱 대상이다.
-   주장과 부관의 학습 특성(장수 고유 특성 포함)을 함께 사용한다. 중복 특성은 기본적으로 한
    번만 적용한다.
-   학습 선행조건은 각 장수에게 독립 적용한다.
-   부관이 이탈·교체되면 그 부관이 제공하던 특성도 즉시 사라진다.

유명 장수는 고유 특성에 집중하고 부관이 병종 특성을 채울 수 있다. 특정
부관 의존 시 스토리상 이탈·전선 분리 때 전력이 흔들리는 것도 의도된 전략
요소다.

### 부관 특성 사용 조건

-   `경계`: 병종 무관 가능
-   `조준`, `저격`, `연발`, `원시`: 원거리 공격 가능 부대
-   `검술`: 검 장착
-   `찌르기`: 창 계열 무기
-   책략 계통: 해당 책략 사용 조건 충족

## 4. 승급과 무기 변경

-   경보병(검) → 중보병(검): 유지
-   경보병(검) → 장창병(창): 변경
-   경기병(창) → 궁기병(활): 변경

무기가 바뀌는 승급 시 현재 무기 자동 해제→창고 이동→새 병종 장착 가능
무기 팝업→플레이어 선택. 가능한 무기가 없으면 기본 무기를 지급한다. 기존
특성은 유지하되 현재 무기/병종 조건이 맞지 않으면 비활성화한다.

## 5. 일회성 물리 병법

병법은 한 행동에 하나만 사용하며 사용 후 행동이 종료된다. 준비 버프를
여러 턴에 걸쳐 유지할 수 있는지는 지속시간 규칙에서 별도로 정한다.

일부 물리 병법은 직접 공격 대신 다음 공격/피격에 적용되는 준비 버프를
건다. - `조준` → 다음 원거리 공격에 적용 후 제거 - `경계` → 다음 근접
피격의 명중률 0% 후 제거 - 서로 다른 준비 버프는 기본적으로 중첩 가능 -
같은 버프 재사용은 중첩하지 않고 갱신 - `다음 공격 1회`는 개별 타격보다
하나의 공격 행동을 기본 단위로 본다.

### 기존 책략 재사용

-   `구휼`: 소보급·헌책 사용 권한. 궁병은 별도 소보급 특성을 만들지 않고
    구휼을 배운다.
-   `응급처치`: 구휼과 달리 자기 자신만 회복하는 별도 병법.
-   `화계`: 경보병이 학습 가능.
-   `수계`: 노병이 학습 가능.
-   `독려`: 연노병의 상급 지원 선택지 후보.

## 7. 병종 성장 경로

  계열     1단계    2단계    3단계    역할
  -------- -------- -------- -------- ---------------------------
  보병     경보병   중보병   근위병   검, 범용·수비·공성
  창병     경보병   장창병   전차대   검→창, 야전 관통·범위
  창기병   경기병   창기병   금위병   창, 기동·찌르기·돌파
  궁기병   경기병   궁기병   노기병   창→활, 기동 사격
  궁병     궁병     노병     연노병   활, 사격·지원·연발
  포병     궁병     노병     발석거   활→투석, 장거리·범위·공성
  책사     사마     참모     군사     공격·방해 책략
  지원     사마     방술사   선술사   회복·버프
  적병     적병     흉적     의적     험지·기습·비정규전
  무도가   무도가   권사     권성     근접 개인전

궁기병은 승급 시 무기 변경 팝업으로 문제를 해결하므로 유지한다. 궁기병
자체가 활을 쓰므로 `백마`처럼 원거리 공격 권한을 해금하는 특성은
불필요하다.

## 8. 병종별 학습 특성 현재안

### 경보병

-   `경계` 500: 다음 근접 피격 1회 명중률 0%
-   `화계` 700: 화계 책략 사용 권한
-   `응급처치` 1000: 자신에게 소보급 상당 회복

### 중보병

-   `부관임명` 700\~1000
-   `대비` 700\~1000, 선행 `경계` 후보: 자신에게 방어력 버프
-   `협동` 1000: 아군 물리 공격에 제한 피해로 협공

### 근위병

-   `수성` 1000+, 선행 `대비` 후보: 성에서 매 턴 방어력 버프
-   `철벽` 1200: 큰 단발 피해 완화
-   `공성` 1500: 대상 지형 방어 보정 무시

`공성`은 보병에 둔다. 전차대나 기병에 억지로 배정하지 않는다.

### 경기병 --- 창기병/궁기병 공통

-   `기마술` 1000: 패시브 이동력 +1
-   `교란` 700: 적 1기의 민첩·운 디버프. 책략 계통 `견제`와 구분한다.
-   `도발` 500: 다음 공격 명중 시 상대 방어력 하락

경기병은 궁기병으로도 갈 수 있으므로 근접 전용 특성을 주지 않는다.

### 창기병

-   `부관임명` 700\~1000
-   `찌르기` 700: 후방 적까지 관통
-   `돌파` 1000, 선행 `찌르기`: 찌르기의 후방 피해 강화 등 관통 전문화

### 금위병

-   `질풍` 1200, 선행 `기마술`: 이동력 추가 강화
-   `돌격` 1200: 적 ZOC 무시 이동
-   `연속찌르기` 1500, 선행 `돌파`: 다음 공격 2회 + 찌르기 효과

현재 결정: **돌파는 창기병, 질풍은 금위병**.

### 궁병

-   `구휼` 500: 소보급·헌책 사용 권한
-   `저격` 700: 다음 원거리 공격 사거리 +2
-   `조준` 1000: 다음 원거리 공격 민첩·사기 강화

### 노병

-   `부관임명` 700\~1000
-   `수계` 500\~700: 수계 책략 사용 권한
-   `화시` 700\~1000: 물리+정신력 기반 화염 복합 공격
-   `장전` 1000: 분기처럼 자신에게 공격력 +20% 버프. 지속시간은 분기와
    같은 규칙을 사용한다.

후보가 4개다. 2단계 병종을 반드시 3개로 제한할지는 데이터 작업에서
결정한다.

### 연노병

-   `연발` 1000: 다음 원거리 공격 2회
-   `독려` 1200: 버프계 책략 사용 권한
-   `관통` 1500, 선행 `저격` 후보: 다음 공격이 후방 적까지 공격

상시 2회 공격은 병종에 주지 않는다. `연발`은 준비 기술이며 상시화는 고유
특성 영역이다.

### 궁기병·노기병

세부 특성은 미확정. - 경기병의 기마술/교란/도발 기반 - 궁기병 승급 시
창→활 - 조준·저격 등 원거리 조건 특성과 호환 가능 - 궁병보다 높은
기동력, 대신 지원·광역 선택지는 제한 - `백마` 특성은 사용하지 않음

### 장창병·전차대

세부 특성은 미확정. - 장창병: 찌르기·대열·대기병 - 전차대: 성 공격이
아니라 야전 진형 붕괴·범위·관통 - `공성`은 보병 계열에 둔다.

## 9. 문관 계열

기존 `trait-design.md`의 계통 구조를 기본 유지한다. - 사마→참모→군사:
화·수·지 공격계 + 견제/계략 - 사마→방술사→선술사: 구휼 + 독려 중심 -
`부관임명`은 참모/방술사에서 특성치로 학습 - `허실`, `심모`, `연환`,
`팔진도`, `간파`, `반계` 같은 강력한 특성은 일괄 배포하지 않고 희소성을
유지한다.

## 10. 장수 고유 특성과 병종 특성 연결

### 황충

  -----------------------------------------------------------------------
  고유 특성               선행                    효과
  ----------------------- ----------------------- -----------------------
  필중                    조준                    조준 상태의 원거리
                                                  공격은 명중률 100%

  신궁                    연발                    일반 공격이 상시 2회
                                                  공격. 연발 병법은
                                                  불필요하므로 사용 불가
                                                  처리 가능

  원시                    ---                     일반 공격 사거리 +3
  -----------------------------------------------------------------------

황충은 병종의 조준·연발을 배워야 고유 특성이 완성된다.

### 미방

  -----------------------------------------------------------------------
  고유 특성               조건/선행               효과
  ----------------------- ----------------------- -----------------------
  방패술                  경계                    경계 사용 시 근거리
                                                  방어 성공 1회 + 원거리
                                                  방어 성공 1회를 각각
                                                  부여

  검술                    검 장착                 공격 성공률 +10%, 피격
                                                  확률 -10%

  수비 계열 후보          보병/거점 조건          방어적 보병 성향 강화
  -----------------------------------------------------------------------

미방은 원래 보병 특성에 잘 맞지만 스토리상 관우에게 감화되어 기병이 되면
고유 특성이 무기·병종과 어긋나 성능이 애매해진다. 강릉 공격 시 보병으로
돌아오면 기존 특성이 다시 살아난다. 시스템으로 서사를 표현하는 사례다.

### 유비와 자웅일대검

자웅일대검의 방어 성공 시 반격·재반격 후보는 제외한다. 새 장비 효과는
미정이다. 주태 등에게 제안했던 `대신 맞기`도 채택하지 않는다.

## 11. 장수 등급과 고유 특성 수

현재 방향: - A: 고유 특성 5개 - B: 4개 - C: 3개 - D: 2개 - E: 1개 또는
전투성이 거의 없는 이벤트성 장수

등급은 연의·정사의 평가와 본편 서사 비중을 함께 본다. 등장 범위와 능력
등급을 혼용하지 않는다.

최근 조정 예: - 강유 B - 마초 B - 방통 B - 서서 C - 관흥 C - 장포 C -
사마가 C - 엄안 C - 학소 C - 미방 D - 저수 A - 유선 E
