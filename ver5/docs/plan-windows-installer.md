# Windows 설치 빌드

- 기존 `desktop-win`의 release 실행 파일을 사용하고 `windows-installer`에서 게임 에셋을 포함한 NSIS 설치 프로그램을 만든다.
- 사용자별 설치 경로와 시작 메뉴 바로가기, Windows 앱 제거 항목을 제공한다. 저장 데이터는 기존 사용자 설정 폴더에 두고 제거 시 보존한다.
- 바로가기나 임의 작업 디렉터리에서 실행해도 실행 파일 옆의 `assets/`를 찾도록 기존 macOS Resources 탐색을 확장한다.
- 경로 탐색 시험, 교차 빌드와 설치 파일 구성 확인을 수행한다. 실제 Windows에서의 실행·설치는 별도로 확인해야 한다.
