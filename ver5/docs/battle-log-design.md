# 전투 로그 창

- 왼쪽 아래에 검은색 반투명 창을 배치한다. 기본 높이는 200px이며 상단을 드래그해 80~440px로 조절한다. 폭은 480px로 고정한다.
- 최신 기록을 아래에 표시하고 긴 문장은 줄바꿈한다. 창 안의 휠은 과거 기록을 스크롤하며 새 행동이 기록되면 최신 기록으로 돌아온다. 창 조작은 지도 선택·이동·확대에 전달하지 않는다.
- 지형 정보는 로그 창 위로 옮긴다. 로그는 전투와 전투 결과 화면에 표시하며 메뉴·학습창은 그 위에 표시한다.
- 플레이어 명령과 AI 명령 모두 성공한 명령과 실제 엔진 이벤트를 기록한다. 상세 알림 설정과 무관하게 최근 300개 기록을 유지하며 새 게임·불러오기·재시도·타이틀 복귀 시 초기화한다.
- 일반 공격·병법·도구 사용을 먼저 기록한 다음 피해, 빗나감, 병법치 소모/회복, 효과, 경험치, 퇴각 등을 순서대로 표시한다. 이름은 데이터의 한글 표시명을 사용한다.
- 병법의 보급 효과 이벤트에 실제 병법치 회복량을 담는다. 도구도 각 대상의 실제 회복량을 기록한다. 기존 이벤트 형식과 전투 규칙은 유지한다. 병력 회복과 효과 적용이 중복되지 않도록 회복 병법의 일반 효과 문구는 생략한다.
- 경험치는 엔진의 실제 획득량으로 표시한다. 행동 해결 시 로그를 기록하며 애니메이션을 건너뛰어도 유지한다.

예시 (수치는 설명용):

```text
관우 → 황건적1: 일반 공격
관우 → 황건적1: 피해 320
관우: 경험치 +12
유비 → 유비: 반격 사용
유비: 병법치 -18
유비 → 유비: 반격 태세 적용
문사 → 관우: 헌책 사용
문사: 병법치 -24
문사 → 관우: 병법치 +24
문사: 경험치 +8
```

검증: GUI와 엔진 관련 패키지 테스트, 로그 문구·표시 줄 수·회복 상한 테스트, 기존 GUI 캡처 기능으로 렌더링 확인.
