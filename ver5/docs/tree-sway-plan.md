# 복숭아나무 8프레임 흔들림 시안

목표: `peach_bloom_0` 한 그루의 꽃과 가지가 바람에 천천히 움직이는 8프레임을 비교용 HTML로 보여준다. 게임 런타임 에셋은 이 시안에서 바꾸지 않는다.

1. `tools/unit3d/scene_props3d.py`의 복숭아나무 형태·카메라·시드를 사용한다. 줄기와 가지의 3D 면은 여덟 프레임 모두 같은 좌표로 두고 꽃·잎 면만 약하게 움직여 네 칸×두 줄 참조 시트를 렌더한다.
2. 3D 렌더를 직접 도트화하면 둥근 꽃 덩어리가 남으므로, 기존 복숭아나무 그림체로 꽃 표현을 다시 그린다. 고해상도 원화는 제작 중간 결과로만 보관한다.
3. 원화의 여덟 칸을 `ver5/tools/pixelize_tree.py`의 팔레트 매핑·외곽선 처리에 통과시켜 같은 93×96 캔버스와 (56, 91) 기준점에 놓는다. 생성 과정에서 달라진 줄기 픽셀은 첫 프레임의 줄기와 가지로 통일한다.
4. 원본, 3D 참조, 최종 도트의 8프레임과 반복 재생을 HTML에서 비교한다. 줄기 픽셀, 0↔7 연결, 팔레트, 투명도와 가장자리 잘림을 확인한다.

소스 그림과 시트는 `tools/spritetool/assets/scene-peach-sway/`에 둔다. 런타임 사용 여부는 시안을 본 뒤 결정한다.
