# 첫 패배까지의 캠페인 공동 학습

2026-11-15 사용자 요청: 화면 없이 첫 장부터 진행하고, 첫 패배 전에 연속으로 이긴 전투 수를 최우선으로 평가한다. 특성 학습과 장비 선택도 같은 결과로 학습한다.

1. `Run`에 첫 패배 기록과 연속 승리 수를 추가한다. `-tries 1` 평가/학습은 첫 패배에 종료한다. 기존 최대 5회 모드는 유지하되 재도전으로 첫 패배 기록을 지우지 않는다. 옛 보고서도 `Tries`와 `Won`으로 같은 지표를 계산한다. 조기 엔딩/스테이지 상한은 완주로 세지 않는다.
2. 전투 모델 묶음에 별도 준비 정책/가치망을 추가한다. 장비 유지·해제·창고의 호환 장비 선택, 특성 학습·포인트 저축을 후보로 제공한다. 장비는 반환 단계와 착용 단계에서 장수/슬롯마다 한 번씩 선택해 교환 루프를 막고, 특성은 실제 포인트와 선행 조건을 지킨다. 승급·편성·부관·상점·이야기는 현재 규칙을 유지한다.
3. 준비 특징에는 장수 능력/포인트/출전 여부, 장비와 특성의 실제 능력 변화·효과·열리는 병법·MP 사용 가능성을 넣는다. 특성 이름별 고정 구매 순서는 두지 않는다. 엔진 복사본에 적용해 유효한 실제 명령만 학습/게임에 사용한다.
4. 전투와 준비 결정을 함께 기록하고, 새 게임에서 첫 패배에 도달한 뒤 연속 승리 수로 PPO를 갱신한다. 전투별 보상을 합쳐 재도전 성공을 보상하지 않는다. 장수 성장/물자 지표는 같은 진척일 때만 쓰는 보조 정보다. 초기 준비망은 기존 선택 규칙의 실제 합법 명령을 모방해 시작하고 이후 캠페인 결과로 갱신한다.
5. 새 입력을 사용하는 전투망에는 병법 보유/MP 이용 가능성도 전달한다. 기존 가중치의 동작이 바뀌지 않도록 선택적 입력을 사용하며 추가 입력의 초기 가중치는 0으로 둔다. 병법/아이템을 엔진에서 금지하거나 스테이지별 행동을 강제하지 않는다.
6. 개발/최종 새 게임 시드를 분리하고 평균 연속 승리 수, 최솟값, 시드별 첫 패배 전투, 완주 수를 보고한다. 같은 시드의 기존 모델과 비교한다. 실제 준비와 전투를 모두 모델이 고르는 경로를 CLI/GUI에서 공유한다. 향상이 확인되지 않으면 결과를 명시하고 기존 배포 모델을 덮어쓰지 않는다.

검증은 첫 패배 이후 재도전이 지표를 늘리지 않음, 1탄 패배=0/완주=전체 전투 수, 장비/특성 명령 합법성·실제 포인트/재고 보존, 준비망 저장/로드·선택/학습, 공동 학습의 실제 새 게임 진행을 포함한다. 맵·밸런스·보상·술 사용 경험치 같은 게임 규칙은 변경하지 않는다.

추가 목표: 사용자의 요청에 따라 첫 패배 없이 10탄까지 이기는 결과를 확인할 때까지 병렬 실험한다. 전체 새 게임 학습과 함께 실제로 무패 진입한 실패 구간의 준비 전 스냅샷을 모아 집중 학습한다. 해당 스냅샷의 자원·경험치·RNG를 보존하고 탐색 교사의 성공 명령을 모방할 수 있다. 교사/구간 단독 승리는 무패 진척으로 집계하지 않으며, 전체 모델을 다시 새 게임부터 평가한 결과만 최고 기록으로 인정한다. 전투별 별도 가중치 외에 스테이지별 행동 강제는 넣지 않는다.

병렬 작업 중 다른 작업에서 맵/배치가 바뀌어 콘텐츠 해시가 달라졌다. 원본을 건드리지 않고 `reports/autoplay/campaign-learning/data-snapshot/assets/`의 데이터 복사본으로 비교 조건을 고정한다. 이전 모델을 새 데이터에서 시험할 때에는 `-transfer-content`를 명시하고 이전 해시를 `SourceContentHash`에 남긴다. 실제 GUI는 계속 해시 일치를 요구하며 자동으로 불일치를 무시하지 않는다.

8탄 무패 검증 뒤 도착형 목표에서 관측 부족을 확인했다. 선택적으로 전투 정책 입력에 엔진 `GoalMarks`의 승리 구역·대상 장수·거리·방향·진입 여부 8개를 추가한다. 목표 좌표나 이동 명령을 직접 정하지 않고 모든 합법 명령을 그대로 모델이 비교한다. 추가 입력 가중치는 0으로 시작해 기존 예측을 보존하고, 해당 관측을 사용한다고 기록한 모델만 확장된 차원을 요구한다. 준비망과 기존 배포망의 입력은 유지한다.

9탄 사례로 공통 준비망을 모방하면 앞 전투의 최고 진척도 8→5로 내려가는 망각을 확인했다. 전투별 전문가 안에 선택적 준비망을 보관해 해당 전투의 준비·전투 중 특성 학습만 함께 갱신할 수 있게 한다. 없으면 공통 준비망을 쓴다. 준비망 내부의 중첩은 계속 금지한다. 전투별 준비는 모두 동일한 합법 후보/특징/신경망 선택을 사용하며 아이템·특성의 고정 선택표를 추가하지 않는다. 교사 기록 재사용 시 준비 표본 키만 해당 전문가로 연결한다.

10탄 교사의 연속 실패로 이긴 표본이 없는 구간에는 선택적 보조 보상을 시험한다. 구간 패배끼리만 승리 대상/적의 실제 HP 감소와 도착 목표 접근을 최대 0.25점으로 구별한다. 한 탄 승리의 1점을 넘을 수 없고, 승리한 구간에는 정수 진척만 준다. 전체 새 게임의 학습·검증·최고 기록은 계속 정수 무패 진척이다. 보조 보상/탐색 온도는 명시적 구간 학습 옵션으로 남기며 실제 게임 판단에 보상 점수를 직접 더하지 않는다.

배포 조건 확인: 정상 새 게임 개발 시드 310004에서 11탄 무패·12탄 첫 패배, 현재 게임 데이터에서 별도 10탄 무패 재현, 미사용 8시드 평균 5.0→5.5·최고 6→8을 확인했다. 검증한 바이트를 `assets/autoplay/battle.json`에 옮기고 기존 배포는 보고서 폴더에 보존한다. GUI 준비망 경로를 실제 로딩·캡처로 확인하고 README/모델 설명/평가 기록에 낮은 안정성과 현재 가중치를 명시한다. 입력에서 공격/방어 강화의 일부 후보가 구분되지 않는 한계는 기록하며 이번 검증 가중치의 입력 차원을 추가 변경하지 않는다.
