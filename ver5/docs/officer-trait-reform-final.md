# 한실중흥 장수 능력치·특성 개편 최종안

2026년 11월 22일 기준. **반영 완료**는 게임 데이터나 코드에 적용한 항목, **채택**은 설계에 넣기로 한 항목, **후보**는 배치·수치 제안이다. 아래의 최신 배치가 이전 검토 문서에 우선한다.

## 반영 완료

| 책략 | 소모 병법치 | 대상당 피해 계수 | 범위 |
| --- | --- | --- | --- |
| 초열 | 24 | 1.00배 | 단일 |
| 화진 | 32 | 0.70배 | 십자 5칸 |
| 업화 | 38 | 1.50배 | 단일 |
| 화룡 | 40 | 1.00배 | 십자 5칸 |
| 폭염 | 48 | 1.20배 | 일자 6칸 |

화룡은 48 → 40, 폭염은 54 → 48로 적용했다. 업화 38은 현행 값이다. 초열의 병법치당 피해를 100%로 놓고 같은 조건으로 두 적을 맞히면 화진은 105%, 화룡·폭염은 각각 120%다. 업화는 한 적 기준 약 95%다. 이 값은 지형·약화·과잉 피해를 제외한 계수 비교다. 범위 피해를 추가로 내리는 수치는 미확정이다.

- **문무겸비**는 장비·부관·레벨을 반영한 공격력과 정신력 중 낮은 값에 차이의 절반을 더한다.
- **수호**는 같은 방식으로 방어력과 정신력을 비교한다. 기존 자기 방어 강화책략의 비용 절반 효과를 교체했다.
- 소수점은 버린다. 두 특성은 같은 보정 전 수치를 사용하고 둘 다 정신력을 올리는 경우 더 큰 보정만 적용한다. 주변·이동에 따른 전장 보정 및 일시 강화·약화는 이후 적용한다. 예를 들어 공격 100·방어 140·정신 160은 두 특성으로 130·150·160이 된다.

## 곽가·방통 · 반영 완료

곽가는 세객 → 종횡가 계통으로 배치하고 개인 특성은 논변만 준다. 논변은 단일 혼란을 확정 명중시키고 기존 면역 판정은 유지한다. 조조의 허실은 공격 책략으로 범위를 좁혔다. 제갈량의 기본 목록에서는 허실을 회수했다.

방통은 군사로 등록하고 연환·화공·이동속도 저하를 개인 목록과 학습 후보에 둔다. 화공은 화계 공격 책략의 치명타를 보장한다. 이동속도 저하는 공격 책략으로 실제 피해를 입힌 적에게 다음 자기 차례 이동력 −2를 준다. 연환으로 두 번째 적을 맞히면 그 적도 같은 조건으로 적용한다. 능력치는 기존 개편안의 88/35/96/70/32/82를 초기값으로 사용한다. 장수 등록, 특성 동작, 가상 경로 합류 이벤트까지 반영했다.

## 일괄 적용 완료

장수·특성 데이터, 세객·책사·군사의 학습 및 전투 처리, 연노병과 방어 강화 변경을 게임에 반영했다. 플레이어 학습·NPC 해금·장비를 함께 대조했다. 미정이었던 시험값은 약화 −20%·3턴, 대혼란 기본 명중 30·해금 1,500, 군사 지형 직격 0.25배·2라운드, 감군 강화 3턴이다. 폐기한 책략은 기존 저장에서도 선택 목록에서 숨긴다.

세객의 약화·혼란 개편에서는 기존의 혼란 중 이동·지원·반격 제한을 유지했다. 능력치 약화와 방어 강화의 기존 부호 상쇄 규칙은 보존했고, 파진이 있으면 먼저 강화부터 제거한다. 감군 인내·교변은 단일 20, 구휼확산과 함께 쓰는 십자형은 40 병법치다. 확산의 플레이어 학습은 B21 이후 열린다.

## 세객과 종횡가 · 반영 완료

세객은 초열·탁류 등 **공격 책략에 능력치 약화를 실어** 명중한 적마다 적용한다. 민첩·사기를 함께 배우면 한 번의 명중에 둘 다 붙는다. 같은 능력치의 저하를 겹칠 때 수치는 중첩시키지 않고 지속시간을 갱신하는 것을 초기안으로 둔다. 기존과 같은 저하 −20%·기본 3턴은 시험값이다.

| 특성 | 특성치 | 효과 |
| --- | --- | --- |
| 민첩 저하 · 사기 저하 | 각 700 | 명중한 적의 해당 능력치를 낮춤 |
| 공격력 저하 · 방어력 저하 · 정신력 저하 | 각 1,200 | 명중한 적의 해당 능력치를 낮춤 |
| 파진 | 1,500 | 명중한 적의 강화를 제거. 새 약화에 앞서 처리하는 안 |
| 장구 | 1,000 | 약화와 혼란 지속 +2턴. 기존 강화 지속 효과는 선술사의 강화 연장으로 보존 |
| 약점공략 | 현행 1,200 | 이미 능력치가 약화된 적에게 치명타. 처음 약화를 거는 타격과 혼란만 걸린 적은 적용 제외 |

**혼란과 대혼란은 별도로 시전한다.** 세객은 단일 혼란, 종횡가는 상급 십자 5칸 대혼란을 해금하는 배치안이다. 혼란에 걸리면 받는 공격은 명중률 100%, 하는 공격은 성공률 0%라는 설계다. 기본 지속 1턴, 장구가 있으면 3턴이다. 둘 다 병법치 60이며, 기본 명중은 혼란 40·대혼란 30이다. 대혼란은 기본 명중 30, 해금 특성치 1,500, 시전 병법치 60으로 적용했다. 면역과 확정 차단 우선순위, 이동·지원 가능 여부, 연속 재부여는 구현에서 결정한다. 장료의 료래는 별도 개인 특성으로 유지한다.

- **정리 대상인 독립 책략**은 둔화·동요·쇠약·약화·위축·와해, 봉책·독연·봉쇄·봉격·독무다. 현행 이동 봉쇄의 이름은 봉쇄다.
- 교란·압박·참언은 선택 목록에서 제거했고 제갈량의 복합 책략 팔진도는 유지했다. 독공·유성·이벤트의 상태이상과 물리 명중형 약화는 별도 경로다.
- **물리 특성**은 호통·함진·사기꺾기를 유지한다. 호통·함진은 특성치 900, 사기꺾기는 700이다. 화시는 정신력 피해가 섞여도 물리 병법으로 취급한다.

## 책사와 군사 · 반영 완료

- 현행 서생 → 참모 → 군사의 중간 이름을 **책사**로 정리한다. 책사는 집중·확산·화계강화·수계강화·지계강화를 맡고 군사는 이를 상속한다.
- 군사는 원소별 **3×3 지형 조성**을 맡는다. 빈칸을 포함해 지정한 3×3에 불씨·물웅덩이·돌무더기를 만든다. 낮은 직격 피해와 지형 설치를 조합한다. **지형 조성**, **방화·수몰·낙진**, 피해 0.25배, 흔적 2라운드를 초기 적용값으로 삼았다. 현행 치명타는 맞힌 칸에만 흔적을 3라운드 남기며 불씨 칸에는 병력 피해가 있어, 광역 설치의 위력은 직격과 별도로 확인한다.
- **삼략**은 제갈현이 13장에서 주는 장비다. 확산을 **명상**으로 교체한다. 명상은 최대 병력 5%를 써서 최대 병법치 20%를 회복한다. 플레이어가 확산을 처음 접하는 시점은 형주의 이적·서서·제갈량 구간으로 잡는다. 삼략 외의 책사 승급·학습 경로도 같이 제한해야 한다.
- **분기**는 받는 부대가 부채 병종이면 정신력 +20%, 그 외는 공격력 +20%로 3턴 적용한다. 분발까지 같은 규칙을 쓸지는 미정이다.

| 항목 | 배치와 효과 | 상태 |

| 곽준 | 진지고수 · 금쇄 | 반영 완료. 근위병 학습과 중복되는 대비·중갑을 교체 |
| 제갈량 | 팔진도 중심. 파진·심모·귀모·간파는 기존 배치 후보 | 조조 전용 허실과 방통 전용 연환 제외. 백출은 백우선이 제공 |
| 저수 | 감군 | 감군 · 간파 · 독려로 등록. 파진은 세객 계통에서 획득 |

방통은 화계 단일 책략으로 인접 적까지 노린다. 연환으로 두 번째 적에게 실제 피해를 입히면 그 적도 이동력 저하를 받는다.

고유 특성은 지정 병종의 상속 학습까지 대조한다. NPC 자동 획득 특성과 플레이어 학습은 따로 확인한다. 예를 들어 서황의 충격은 전차대 학습에는 있지만 NPC 자동 계획에는 없다. 이전 데이터 감사에서는 장수 28명에서 이 종류의 중복을 찾았다. 교체 후보 목록은 [개편 검증 기록](officer-trait-reform-preview.html#audit)에 있다.

## 앞선 개편에서 유지하는 특성

| 특성 | 효과와 미정 사항 |
| --- | --- |
| 심공 | 실제로 입힌 물리 피해의 10%만큼 병력 회복. 여몽에게 배정하고 권사·의적의 병종 풀에도 둔다 |
| 료래 | 장료 전용. 물리 치명타 명중 시 혼란. 공격 책략에 혼란을 실어 나르는 공용 효과와 별개이며 지속·면역 처리 확인 |
| 금범적 | 감녕 전용. 물리 명중 시 적 최대 병법치의 50% 이내에서 현재 병법치를 깎고 실제 감소량의 50%를 흡수. 소수점 버림. 직접 첫 타에만 적용 |
| 추행진 | 자신과 주변 8칸 아군 이동력 +2. 기존 급행 통합. 사마의·마초·하후연 배정안이며 상급 병종 진형 시스템은 범위 밖 |
| 지구전 | 이동하지 않은 차례에 병법치 회복 2배. 차례 시작 회복과 직전 이동 기록의 연결이 필요 |
| 교화 | 육손이 자신과 주변 8칸 아군의 능력치 약화를 차례마다 해제 |
| 인내 · 교변 | 각 특성치 1,000. 차례마다 자신에게 각각 물리 피해 −20%, 책략 피해 −20% 강화 |
| 근성 | 병력 50% 미만에서 공격·방어 상승, 병력 1%에서 1.5배. 50%에서 1%까지 선형으로 증가하고 1% 이하는 1.5배로 제한 |
| 감군 | 특성치 1,000. 인내·교변을 아군에게 쓰고 구휼확산과 결합하면 십자형 사용. 단일 20·십자 40 병법치. 자기 편 대상으로 3턴 |
| 박학 · 명가 | 각각 최대 병법치 1.5배, 최대 병력 1.5배. 순유의 박학, 원소·육손의 명가 배치 |
| 논변 | 단일 혼란 명중률 100%. 대혼란은 일반 명중 판정. 반영 완료. 곽가 개인 특성 |
| 허실 | 반영 완료. 조조 전용 공격 책략 명중률 100%. 혼란·대혼란은 포함하지 않으며 기존 면역은 유지 |
| 금강 | 치명타로 판정된 공격을 차단하는 현행 효과 유지. 장료의 새 배치에는 없고 감녕 배치안에는 있음 |

관우의 **위진화하**, 조운의 **일신시담**, 유비의 **용인술**, 조조의 **허실**은 개인 전용 배치 원칙을 유지한다. 명분·청렴은 효과 미정, 덕망·강직·언변은 별도 채택하지 않았다.

## 적용 전 확인

- 확산의 형주 해금, 혼란 판단과 장구의 지속, 적별 명중 약화와 면역, 군사 지형 생성의 빈칸 지정·수명은 각각 전투에서 확인한다.
- NPC 고유 목록 순서 및 별도 해금, 플레이어 학습 선행 조건, 장비, 스테이지 재정의와 기존 저장의 삭제 특성·학습 데이터를 점검한다. 이적이 NPC 보병으로도 화진을 쓰는 경로를 확인한다.
- 이번 최종안의 확정과 후보는 위의 상태 표기를 따른다. 게임 반영 완료 항목은 맨 위에 모았다.
