# 하비 미씨 저택 A안 적용

사용자가 고른 A안은 저택 부지를 유지하고 대문을 장터 쪽 담으로 옮기는 안이다. 남서쪽 옛 대문 앞의 미축도 새 출입구 옆으로 옮겨야 한다.

- `tools/scene_maps/xiapi_town.py`: 비교 HTML의 A안과 같은 대문 `(13,34)`, 안채·별당·나무·등·깃발 및 장터 연결 포석을 생성한다. 기존 부지와 이웃 집·울타리는 유지한다.
- `assets/graphics/maps/S_xiapi.json`: 생성 스크립트를 실행해 런타임 맵을 갱신한다. 후보 `reports/xiapi-manor-options/a.json`과 구성 요소가 같은지 대조한다.
- `assets/scenario/hero/explore18.json`: 미축을 `(7,39)`에서 새 대문 옆 `(16,35)`로 옮기고 `NE`로 장터에서 오는 사람을 보게 한다. 문 가운데 `(13,34)`와 연결길의 통행을 비워 두며 대사는 유지한다. 다른 NPC는 이 부지 변경의 영향을 받지 않는지 확인한다.
- `docs/history.md`: 적용과 검증 결과를 기록한다.

검증: 맵·탐험 배치 관련 기존 시험, 후보와 생성 결과 대조, 기존 탐험 데모로 북문에서 미축에게 걸어가 대화하고 새 대문 앞까지 가는 실제 GUI 캡처. 미축·유비가 마주 보고 대문·깃발에 가리지 않는지 화면으로 확인한다. 탐험의 기존 문 경계 규칙은 유지한다.
