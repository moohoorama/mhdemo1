# 계교 전투 원소 퇴각 조건 정리

- 변경: `yuanshao-retreat` 전투 이벤트를 삭제한다. 기존 `defeated:yuanshao` 승리 조건은 유지한다.
- 영향: 인접하거나 체력이 50% 미만이어도 원소가 남아 전투한다. 원소의 체력이 0이 되면 일반 퇴각 처리와 함께 승리한다.
- 확인: 실제 B10 데이터에서 중간 체력·인접 시 전투 지속, 체력 0에서 승리하는 시험. 전투 균형 측정은 별도로 기록한다.

## 확인 결과

- 계교 전투 회귀 시험과 관련 핵심 시험 통과.
- 균형 측정(시드 3개): rush·AI 모두 0/3승. 세 판 모두 조운이 초반에 퇴각해 패배했으며, 이 스테이지의 기존 배치 문제로 원소 격파까지 진행되지 않았다.
