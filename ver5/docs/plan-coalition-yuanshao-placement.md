# 반동탁연합 진영 원소 배치 수정

`assets/scenario/hero/explore06.json`의 원소가 작은 칸 `(37,38)`에 서 있는데 `S_coalition_camp`의 화로가 같은 위치에 있다. 5장은 `(40,40)`으로 다르며, 7장 탐험에는 원소가 없다.

6장 원소를 맹주 막사 앞의 빈 땅으로 옮긴다. 화로·울타리·통로·다른 인물과 이름표의 간격을 확인하고, 막사 앞에 나와 방문자를 맞는 `SE` 방향으로 둔다. 5장 원소의 기존 위치도 캡처로 비교한다. 대사·장면·스프라이트·맵 그림은 수정하지 않는다.

기존 `explore` 데모의 `start:c06-walk,talk:원소`로 수정 전후를 캡처하고, 해당 진영의 접근성·인물/이름표 간격 검사를 실행한다. 변경 파일과 의도·검증 결과는 `docs/history.md`에 남긴다.
