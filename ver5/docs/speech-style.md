# 장수별 말투

일기토·이벤트 대사를 쓸 때 장수마다 같은 말투를 유지하기 위한 기준이다. 장면에 맞는 새 대사를 쓰면 이 문서의 예시도 함께 늘린다. 일기토 대사는 `assets/duels.json`, 화자가 말풍선에 표시되는 규칙은 `docs/duel-animation.md`를 따른다.

## 공통 규칙

- 말투는 **어미와 호칭**으로 드러낸다. 같은 뜻이라도 장수마다 끝맺음이 다르다.
- 대사는 짧게 쓴다. 말풍선 한 개에 한두 문장이며, 일기토 중에는 숨을 쉬듯 끊는다.
- 속말은 괄호로 쓴다. `(이 괴력… 보통내기가 아니다.)`
- 무기는 병종과 장비를 따른다. 장비는 사모, 관우는 청룡도, 유비는 쌍고검, 여포는 방천화극이다. 적병은 칼(검)이고 화웅·목순·무안국은 창이다.
- `block`·`dodge`·`yielding-block`·`critical-dodge` 대사는 **방어자**가 말한다. 공격자의 외침을 이 동작에 넣지 않는다.

## 호칭 표

| 말하는 사람 | 유비 | 관우 | 장비 | 여포 |
|---|---|---|---|---|
| 유비 | – | 운장 | 익덕 | 여포 |
| 관우 | 형님 | – | 익덕 | 여포 |
| 장비 | 형님 | 둘째 형님 | – | 여포 이놈 |
| 여포 | 귀 큰 놈, 유비 | 수염 긴 놈 | 연인 장익덕, 검은 놈 | – |

## 장비 — 충청도 사투리, 가볍고 호방한 말투

**성격**: 호탕하고 단순하다. 화가 나면 곧바로 소리치고, 신나면 웃는다. 형들에게는 애교가 있고 적에게는 거침없이 욕한다.

**말투**
- 충청 방언 어미를 쓴다: `~유`, `~슈`, `~구먼`, `~는겨`, `~혀`, `~그려`, `~랴`.
- 형들에게는 `형~`, `형님~`을 늘여서 부르고 말끝을 올린다.
- 적에게는 `이 자식이!`, `이놈아!`, `~해 보랑께` 같은 거친 말을 쓴다. 지나치게 점잖은 표현은 쓰지 않는다.
- 감탄사가 많다: `허허`, `하하하!`, `으라앗!`, `이얏!`
- 문장은 짧고 직선적이다. 계산이나 작전 이야기는 하지 않는다.

**하지 않는 것**: 침착한 설교, 한자어 위주의 점잖은 문장, 비꼬는 존댓말.

**예시**

| 상황 | 대사 |
|---|---|
| 도발 | 여포! 연인 장익덕이 여기 있슈! 목 씻고 기다리랑께! |
| 도발(적병) | 이 자식아, 덤벼 보랑께! 사모 맛 좀 봐라! |
| 공격 | 으라앗! 이거나 먹어랏! |
| 방어 | 간지럽구먼! 그게 다여? |
| 방어(여유) | 이 정도로 이 몸이 눈 하나 깜짝할 줄 아슈? |
| 밀릴 때 | 이 자식, 힘 한번 세구먼… 그래도 안 져! |
| 피격 | 크윽! 이 자식이…! |
| 기세가 오를 때 | 하하하! 이거다! 이런 놈이랑 싸워 보고 싶었던겨! |
| 형제 합류 | 형~ 왔슈! 기다리고 있었슈! |
| 형제에게 | 형님들만 믿슈! 이 자식은 내가 앞에서 막을 테니! |
| 승리 | 다음은 누구여! 어서 나와 보랑께! |
| 도발 받았을 때 | 뭐여? 방금 뭐라고 혔어? 다시 말해 보랑께! |

## 관우 — 침착하고 진중한 하오체·합쇼체

**성격**: 말수가 적고 무게가 있다. 위기에도 목소리가 흔들리지 않는다. 자신의 실력에 대한 자부심이 크지만 드러내지 않고 짧게 말한다.

**말투**
- 적에게는 `~하겠다`, `~이다`, `~느냐` 같은 낮추지도 올리지도 않는 단정형을 쓴다.
- 형님(유비)에게는 `~습니다`, `~하겠습니다`로 반드시 존대한다. `형님. 알겠습니다.`처럼 호칭 뒤에서 한 번 끊는다.
- 아우(장비)에게는 낮게 말하되 거칠지 않다: `익덕, 서두르지 마라.`
- 감정을 직접 표현하지 않는다. 놀라거나 화가 나도 한마디로 정리한다.
- 느낌표는 드물게 쓴다. 평소에는 마침표나 `…`로 끝낸다.

**하지 않는 것**: 큰 소리, 웃음소리, 욕설, 말장난, 방언.

**예시**

| 상황 | 대사 |
|---|---|
| 출전 | 소장이 나가 화웅의 목을 베어 오겠소. |
| 형님에게 | 형님. 알겠습니다. 다녀오겠습니다. |
| 도발 | 관운장이다. 그 입부터 닥치게 해 주마. |
| 방어(여유) | 가볍군. / 그것이 전부냐. |
| 방어(힘겨운 상대) | 과연 이름값은 하는군. |
| 공격 | 하앗! |
| 강공 | 받아라. |
| 틈을 볼 때 | 틈이 보이는군. |
| 장비에게 | 익덕, 흥분하지 마라. 호흡을 읽어라. |
| 합류 | 아우와 형님… 늦지 않으셨군. / 형님, 소장이 앞에 서겠습니다. |
| 승리 | 끝났다. / 적장은 쓰러졌다. |

## 유비 — 부드럽고 정중한 하오체

**성격**: 어질고 겸손하다. 약해 보여도 물러서지 않는다. 형제를 먼저 생각하고, 적에게도 예의를 지킨다.

**말투**
- `~하오`, `~시오`, `~겠소`, `~소` 체를 기본으로 한다.
- 아우들에게도 반말을 쓰지 않고 부드러운 `~하오`, `~다오`를 쓴다.
- 결의나 각오를 말할 때는 간단하고 힘 있게 끊는다: `물러설 수는 없소!`
- 속말이 많다. 기도처럼 `(조금만 더 버티면…)` 하고 속으로 되뇐다.
- 욕설과 거친 말은 쓰지 않는다. 화가 나도 `부끄러운 줄 아시오!` 정도다.

**예시**

| 상황 | 대사 |
|---|---|
| 출전 | 유비 현덕이 상대하겠소! 내 아우들을 건드리지 마시오! |
| 방어 | 크윽…! 아직이오! |
| 밀릴 때 | 으윽…! 여기서 물러설 수는 없소! |
| 속말 | (조금만 더… 조금만 더 버티면…) |
| 반격 | 이 칼에도 뜻이 있소! |
| 합류 | 아우들… 기다리고 있었소! |
| 아우에게 | 운장, 우리가 함께하오! / 익덕, 무리하지 마오! |
| 승리·결의 | 형제가 모이면 천하에 못 이길 자가 없소! |

## 여포 — 오만하고 서늘한 반말

**성격**: 천하무적이라는 자부심이 있다. 상대를 깔보며 말하고, 놀라도 곧 인정하지만 사과하거나 낮추지 않는다. 퇴각할 때도 패배라고 말하지 않고 상황을 계산한다.

**말투**
- 낮추는 평어: `~다`, `~군`, `~느냐`, `~하마`.
- 비꼬는 감탄을 자주 쓴다: `제법이군.`, `흥, 한 놈 더 늘었군.`
- 방천화극, 적토마 이야기를 자주 한다. 상대의 무기를 비꼴 때는 이름 대신 `그 쇠막대`처럼 부른다.
- 상대 이름은 잘 부르지 않고, 별명으로 부른다: `수염 긴 놈`, `귀 큰 놈`, `검은 놈`.
- 놀랄 때는 속말로 낮게 말한다: `(이 일격… 생각보다 무겁군!)`

**예시**

| 상황 | 대사 |
|---|---|
| 도발 | 수염 긴 놈이 입만 살았군. 와 보아라. |
| 방어(여유) | 제법이군. / 가소롭군. |
| 회피 | 느리구나. / 어디를 노리느냐. |
| 강공 | 이것도 받아 보아라! |
| 놀람(속말) | (이 괴력… 보통내기가 아니다.) |
| 감탄 | 하하, 재미있구나! 천하에 이만한 자가 있었다니! |
| 3:1 | (셋이라… 성가시군.) / 이놈들이 감히! |
| 퇴각 | 셋을 한꺼번에 상대하기는 무리다! 물러난다! |
| 승리 | 또 나설 자가 있느냐! |

## 화웅·적장 — 허세 부리는 거친 말투

**성격**: 기세는 좋지만 속이 얕다. 처음에는 큰소리치다가 밀리면 무너진다.

**말투**: 느낌표가 많은 거친 반말. 상대를 얕잡아 부르다가 겁이 나면 말끝을 흐린다.

| 장수 | 처음 | 밀릴 때 |
|---|---|---|
| 화웅 | 연합군에는 사람이 없느냐! 내 창을 받아라! | 으으… 팔이 저려 온다! / 이… 이럴 수가! |
| 등무 | 어디서 굴러온 촌놈이냐! | 이… 이놈이 제법이구나! |
| 정원지 | 등무의 원수를 갚겠다! | 이놈… 어찌 이리 꿈쩍도 않느냐! |

## 목순·무안국 — 공을 노리는 조급한 말투

**성격**: 공명심에 눈이 멀어 서두른다. 여포를 얕보며 나섰다가 꺾인다.

- 목순: 거만하고 성급하다. `이 목순이 네 목을 거두어 공을 세우겠다!` 맞지 않으면 짜증을 낸다: `왜 맞서지 않느냐!`
- 무안국: 힘 자랑이 많다. `이 창 맛을 보아라!` 부상 뒤에는 `(팔이… 도저히 당해낼 수 없구나!)`처럼 속말로 약해진다.

## 새 대사를 쓸 때 확인할 것

1. 누가 말하는가? 말풍선 표시 규칙(방어자/공격자)을 확인했는가?
2. 어미가 위 표에 맞는가? 특히 관우와 유비의 존대/하오체가 섞이지 않았는가?
3. 무기 이름이 병종·장비와 맞는가?
4. 그 장면에서 말할 법한 감정인가? (여포는 겁먹지 않고 계산한다, 관우는 흥분하지 않는다.)
