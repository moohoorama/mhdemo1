# 한실중흥 개편 · 일괄 적용 이후 남은 항목

2026년 11월 22일 기준. 합의된 게임 규칙과 장수 데이터는 [최종안](officer-trait-reform-final.html)에 정리했다.

## 뒤쪽 캠페인 연결

가상 경로의 방통 합류는 양양 공방전 이후에 연결했다. 장임·방덕·마초·마대·저수와 후반 후보 장수들은 장수 데이터에 등록했다. 이들이 처음 등장할 후속 전투와 연의 경로의 방통 합류는 캠페인 후속 장에서 연결한다. 이번 변경에서 새 전투맵이나 대사, 장수 전용 그림은 추가하지 않았다.

## 수치와 이름이 남은 후보

| 항목 | 남은 결정 |
| --- | --- |
| 범위 피해 계수 | 기존 피해 계수로 실전 데이터를 모은 뒤 추가 하향 여부를 결정 |
| 군사 지형 조성 | 방화·수몰·낙진은 작업 이름. 피해 0.25배와 흔적 2라운드를 게임에서 시험 |
| 분발과 마초의 잔여 슬롯 | 분기는 부채 병종을 대상으로 정신력을 올린다. 십자 분발의 적용 범위와 마초의 추가 특성은 미정 |
| 명분 · 청렴 | 전투 효과 미정 |
| 남은 개인 슬롯 | 여몽·장임·사마의·노숙 등의 추가 특성은 결정 전까지 현재 적용 목록 사용 |
| 궁수 후보 | 별도 엄호 사격·제압 사격·사격 후 재배치는 이전 아이디어로 보류 |

## 적용한 시험값의 확인

- 감군은 단일 20·십자 40 병법치, 유지 3턴이다.
- 료래는 물리 치명타로 혼란을 1턴 걸고, 금범적과 저지 사격은 직접 첫 타격에만 발동한다.
- 지구전은 직전 자기 차례의 이동 기록을 사용한다. 여몽의 심공은 실제 물리 피해의 50%를 회복한다.
- 전 장수의 기본 고유 특성·별도 해금·개인 학습과 상속 병종 학습을 다시 검사했다.
