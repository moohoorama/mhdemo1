# 나무 움직임 두 가지 비교 시안

기존 전체 나무 시안은 보존하고, 두 나무만 따로 비교한다. 재생은 4프레임·250ms다.

1. `stree_broad_0`: 기존 3D 모델의 보이는 면에서 카메라 공간 법선 벡터를 뽑아 원본 도트 캔버스에 맞춘 normal map을 만든다. 나무의 모든 픽셀 위치는 고정하고 햇살 방향을 작은 각도로 바꿔 기존 녹색·나무색 팔레트 안에서 명암만 바뀌는 네 프레임을 만든다.
2. `stree_willow`: 기존 3D 모델에서 줄기·가지는 고정하고 잎 면만 현재 시안 진폭 0.12의 ⅓인 0.04로 변형해 네 프레임을 다시 렌더한다. 기존 팔레트·외곽선으로 도트화하고 뿌리와 줄기 픽셀을 맞춘다.
3. HTML에서 각각 원본, normal map 또는 3D 참조, 네 프레임과 250ms 재생을 보여준다. 잎 흔들림 비교에는 현재 진폭 0.12 시안도 나란히 둔다.

게임 런타임 에셋은 바꾸지 않는다. 소스와 결과는 `tools/spritetool/assets/tree-motion-experiments/`에 둔다.
