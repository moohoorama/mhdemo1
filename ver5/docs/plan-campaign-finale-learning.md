# 최종 20전투 무패 완주 학습

사용자 요청: 현재 11탄 최고 기록의 특성·장비·전투 공동 학습 모델에서 이어서 최종전까지 20전투를 모두 이긴다. 경험치 배율은 사용자의 플레이와 같은 게임 기본 80%다.

- 목표 판정은 정상 새 게임, 매우 어려움, 재도전 1회 제한으로 전체 20전투를 이기고 `Cleared=true`인 보고서다. 구간/교사 승리는 무패 완주로 세지 않는다.
- 현재 배포 모델과 게임 데이터를 보존하고, 실제 무패 진입한 B12 준비 전 상태부터 실패 구간을 병렬 학습한다. 이후 최고 기록이 늘면 다음 실패 구간을 같은 방식으로 수집한다. 돈·장비·소모품·성장·전투 RNG와 데이터 규칙을 조정하지 않는다.
- 준비/전투 전문가와 성공 기록 재학습을 사용해 앞서 배운 구간의 가중치를 보존한다. 신경망이 선택할 모든 실제 합법 행동은 유지한다. 교사의 순서·위험 계수·후보 탐색은 성공 사례 수집에만 사용한다.
- 필요한 경우 병법의 강화 효과/아이템의 실제 양을 구별하는 관측을 추가한다. 현재 가중치의 예측을 보존하는 0 가중치 입력 확장, 실제 성공 명령 재생에 의한 특징 재생성, 저장/로드·명령/결과 일치 검사를 먼저 수행한다. 모델 관측과 보상을 바꿔도 실제 게임 규칙은 바꾸지 않는다.
- 최종 모델을 고정해 정상 새 게임에서 재현하고 별도 미사용 시드로 일반화 범위를 기록한다. 목표 달성과 안정적인 승률을 구별한다. 향상이 확인된 검증 모델만 GUI 기본에 적용한다.
- 매분 최고 무패 진척, 이번 새 게임 수집/학습 시도와 구간 반복 수를 보고한다. 전체 실험은 `reports/autoplay/goal20/`에 보존한다.

실행 감독 도구는 구간별 교사/직접 학습을 병렬 시작하고, 신경망 승리 기록을 별도 모방하는 작업을 추가한다. 개발 평가의 진척이 늘면 해당 가중치를 복사해 `_autoplay -tries 1` 정상 새 게임으로 다시 검증한다. 재현 보고서에서 확인된 첫 패배를 다음 구간으로 삼는다. `Cleared=true`·20개 모두 첫 시도 승리일 때만 감독 도구가 완료 상태를 기록한다. 감독 도구는 배포 파일을 수정하지 않고 자신의 학습 프로세스만 중단한다.

관측 보완은 새로 학습할 전투 전문가에서만 `EffectInputs`로 선택한다. 공격/방어/정신/민첩/사기 강화, 상태, 지속 시간·계수·HP 비용·관통·타격 수, 아이템 원래 양·가격·재고, 대상의 같은 효과 값·남은 턴 16개를 추가한다. 기존 전투/준비 가중치와 입력은 유지한다. 새 입력 가중치 0으로 이전 예측이 같음을 시험하고 새 교사·신경망 기록으로 학습한다. 이 입력에서 차원이 맞지 않는 옛 표본은 학습 전에 거부한다. 기존 성공 기록을 쓸 때는 입력 확장 없이 재사용하거나 추후 실제 명령 재생으로 다시 생성한다.

학습 도중 `explore06.json`·`explore18.json`의 인물 위치가 바뀌어 콘텐츠 해시가 e59a78…→a7d4af…로 달라졌다. 옛 조건에서 17탄 무패를 확인하고, `-transfer-content -warm 0 -episodes 0`으로 가중치를 유지한 채 현재 데이터에서 같은 17탄 기록을 확인했다. 모든 정책/가치 가중치가 같음을 대조했다. 이후에는 `reports/autoplay/goal20/data-snapshot/assets/data` 복사본(a7d4af…)으로 자동 반복하고 최종 현재 데이터도 다시 확인한다. 게임 파일의 위치 변경을 되돌리거나 조정하지 않았다.

완주 뒤 현재 데이터 e3dff5…에서도 무학습 전이로 20전투 완주를 두 번 확인했다. 그 뒤 별도 작업에서 16탄 파일을 수정하면서 데이터 로딩 오류가 생겼다. 검증 데이터 e3dff5…를 `final-data-snapshot`에 보존하고 GUI 캡처 도구에 선택적 `-root`를 전달해 그 복사본을 실제 렌더링한다. 기본 GUI와 데이터 검사는 유지하며 진행 중인 게임 자료를 되돌리지 않는다. 배포 가중치는 검증한 해시에만 연결한다.
