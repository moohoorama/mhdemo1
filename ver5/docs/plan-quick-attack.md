# 이동 후 일반 공격 단축

부대 선택 시 실제로 이동 후 일반 공격할 수 있는 적의 칸을 표시한다. 적을 누르면 현재 위치 또는 이동 가능한 칸 중 가까운 곳으로 임시 이동하고 기존 일반 공격 대상 선택으로 진입한다. 기존 샌드박스와 명령 검증, 취소 흐름을 사용하며 병법과 책략은 포함하지 않는다. GUI 회귀 시험과 전투 화면 캡처로 확인한다.

## 선택 처리 최적화

전투 엔진에서 이동 범위를 한 번 구하고, 각 칸과 적의 좌표로 일반 공격 가능 여부를 판정한다. 이동 비용이 같으면 기존의 위에서 아래, 왼쪽에서 오른쪽 순서를 유지한다. 이동으로 결과가 달라질 수 있는 퇴각 칸은 실제 가상 이동으로 판정한다. 화면 표시와 이동 클릭은 같은 이동칸 목록을 사용하고, 실제 임시 이동과 명령 검증은 기존 경로를 사용한다. 기존 구현과 대상 및 출발 위치를 비교하고 벤치마크와 화면 캡처로 확인한다.
