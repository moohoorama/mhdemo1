# 에디터 도구

범위: 맵 에디터(게임 안)와 도트 에디터(브라우저)의 실행법·조작·저장 위치.
기준: 맵 에디터는 `internal/gui/editor.go`·`editor_ui.go`, 도트 에디터는 `tools/doteditor/index.html`을 따른다.

맵 문서 형식은 [data-map.md](data-map.md), `.spr` 형식과 빌드는 [presentation-sprite.md](presentation-sprite.md), 안드로이드 빌드는
[tools-build.md](tools-build.md)에 있다. 장수 도트를 에이전트가 그리는 절차는 `tools/doteditor/HERO_DESIGN.md`와 `hero-sprite` 스킬이 정한다.

## 맵 에디터

### 실행과 화면

```sh
cd ver5
go run ./cmd/srpg-gui -debug   # 시작 메뉴 → 맵에디터 → 전투맵 목록에서 고른다
```

- 목록은 데이터 묶음의 모든 전투(이름과 `ID · 가로×세로`)다. 현재 UI 크기를 따르는 최대 960×720 판에서 휠·드래그·스크롤바로 끝까지 읽는다. 고르면 그 맵 문서의 복사본을 편집하고, 목록으로 돌아오면 읽던 위치가 남는다. 오른쪽 아래 `닫기`로 시작 메뉴로 나간다.
- 편집 화면은 1280×850 고정 캔버스다. 위쪽 버튼: `저장`·`다른 이름`·`시험 전투`·`영역 맞춤`(전체 전투 영역 보기)·`맵 목록`·`나가기`(시작 메뉴로).
  가운데가 지도, 오른쪽이 정보·상세 패널, 아래가 `타일`/`병력` 탭의 브러시 줄이다.
- 지도에는 커서가 가리키는 칸(대타일)의 마름모 테두리가 보인다. 외곽(전투 영역 밖)은 어둡게 그려지고
  `외곽 어둡게 보기 전환` 버튼으로 원래 그림을 볼 수 있다. 외곽은 칠할 수 있지만 병력은 놓을 수 없다.
- 오른쪽 패널은 커서 위치의 칸 좌표, 땅·구조물·상태, 합친 지형 회복량을 보인다. 한 칸이 땅·구조물·상태 세 층이라는 규칙은 [data-map.md](data-map.md)에 있다.

### 조작

| 입력 | 동작 |
|---|---|
| 좌클릭·드래그 | 타일 탭: 칸 칠하기(지나간 칸을 이어서 칠한다, 드래그 한 번이 실행 취소 한 번). 병력 탭: 배치 |
| 타일 탭 우클릭 | 그 칸에서 지금 고른 브러시 층(땅·구조물·상태)의 값을 브러시로 가져오기 |
| 병력 탭 우클릭 | 그 칸의 병력 제거(아군 배치 칸 모드에서는 칸 제거) |
| `1`~`9`,`0`,`q`~`p`,`a`~`l`,`z`~`m` | 순서대로 브러시 선택(브러시 줄의 글자 표시, 목록은 `assets/data/mapeditor.json`의 `Brushes`) |
| `Tab` | 타일 ↔ 병력 탭 |
| 휠 | 지도에서는 확대·축소(0.1~3배), 아래 브러시 줄에서는 목록 스크롤, 팝업에서는 페이지 |
| 우드래그·가운데 버튼·`Space`+좌드래그 | 지도 이동. 지도 가장자리 8px에 커서를 대도 이동한다(팝업·크기 조절 중 제외) |
| `Ctrl`/`Cmd`+`S` | 저장 |
| `Ctrl`/`Cmd`+`Z`, `+Shift+Z` | 실행 취소(최대 20단계)·다시 실행 |
| `Esc` | 팝업을 닫는다. 팝업이 없으면 `나가기`와 같다. 저장하지 않은 변경이 있으면 `맵 목록`·`나가기`·`Esc` 모두 `저장 후 이동`·`버리고 이동`·`취소`를 묻는다 |
| `F12` | 현재 화면을 PNG로 저장 |

숫자 입력 창(레벨·HP·MP·맵 ID·이름 검색)이 열려 있는 동안은 지도·브러시 단축키가 동작하지 않는다. `Enter`로 적용, `Esc`로 취소한다.

### 타일 탭

- 브러시 줄: 땅(초원·황무지·물·성벽·성문·성내·절벽)·구조물(나무·마을·주둔지·성·관문·다리·울타리와 구조물 없음)·상태(불씨·화염·그을음·손상·파괴와 상태 없음) 브러시(11개씩 보이며 휠로 넘긴다)와 브러시 크기 `1×1`·`2×2`·`4×4`·`8×8`(칸 기준)이다. 브러시는 자기 층만 칠한다. 구조물은 놓을 수 있는 땅 위에만 놓이고, 땅을 칠했을 때 그 위의 구조물이 새 땅에 설 수 없으면 구조물이 지워진다. 그림 영역 밖은 칠하지 않는다.
- 금색 네 꼭짓점을 끌어 전투 영역 크기를 바꾼다(각 변 4~64칸, 반대 꼭짓점은 고정). 놓으면 항상 `예/아니오`를 묻고, `예`일 때만
  영역 밖의 적 배치·고정 아군·아군 배치 칸을 지운다. 크기 변경 전체가 실행 취소 한 번이다.
- `승리 조건 / 일기토` 버튼: 승리 조건(보스 격파·적군 전멸), 보스, 일기토 목록을 편집한다.

### 병력 탭

- 모드: `아군 배치 칸`(좌클릭·드래그로 추가, 우클릭으로 제거, 이동할 수 없는 지형은 거부), `일반병`, `장수 선택`.
- 계열 버튼(보병·기병·궁병 등)과 그 계열의 병종 버튼, 레벨 `−`/`+`, 초기 방향 그림(눌러서 `NE`·`SE`·`SW`·`NW`로 돌린다)이 있다.
  데이터에 없는 병종은 `(미구현)`으로 보이고 고를 수 없다. 계열·병종 목록은 `mapeditor.json`의 `Families`다.
- 일반병은 병종·레벨·방향을 정하고 빈 칸을 누르면 배치된다(연속 배치). 병력이 있는 칸은 건너뛴다(그 칸을 누르면 선택).
- `장수 선택`은 초상화 목록 판을 연다. 진영 탭, 계열·병종 필터, 이름 검색, 병종·진영별 인원수가 있다. 장수·병종·특성·장비·일기토 편집 목록은 휠·드래그·스크롤바로 넘기고 오른쪽 아래 `닫기`로 닫는다. 검색·필터를 바꾸면 목록 맨 위로 돌아간다. 장수는 한 번만 배치할 수 있고
  아군 출전 명단의 장수와도 겹칠 수 없다. 장수의 병종은 같은 계열 안에서만 바꾼다.
- 배치된 적을 클릭하면 오른쪽에서 병종·레벨·방향·HP·MP·특성·장비를 편집한다. `적용`을 눌러야 문서에 반영되고 `초기화`는 기본값으로 되돌린다.
  HP·MP는 시작 현재값이며(비워 두면 HP는 최대, MP는 기존 초기값), 최대값은 엔진이 계산한다. 특성은 장수의 기본 특성에 병종·장비가 주는 특성이 합쳐진
  목록에서 고르고, 병종·장비가 주는 특성은 해제할 수 없다(해당 병종·장비를 바꿔서 조정한다).
- 고정 아군(`Stage.Party`)은 칸을 비켜 가며 별도 편집 기능이 없다.

### 저장과 시험 전투

- `저장`은 문서를 검증한 뒤 `<ver5>/assets/scenario/<시나리오>/stageNN.json`과 `maps/mapNN.json`을 임시 파일 작성 후 교체한다(글꼴 파일 위치의 세 단계 위를 ver5 루트로 본다).
  실패하면 기존 파일과 편집 내용이 그대로 남는다. 성공하면 데이터 묶음을 다시 읽어 실행 중인 캠페인에도 적용한다.
  같은 ID로 저장한 기존 전투는 이후 시작하는 전투부터 수정본을 쓰고, 이미 시작한 전투는 영향이 없다.
- `다른 이름`은 새 맵 ID(영문·숫자·`-`·`_`, 기존 ID와 겹치면 거부)를 입력받아 그 ID로 저장하고 이어서 그 맵을 편집한다. 새 ID는 맵 목록과 시험 전투에
  나타난다. 캠페인에 새 전투로 잇는 시나리오 노드는 `assets/data/script.json`에서 따로 추가한다.
- 저장하면 데이터 묶음의 해시(맵 파일 포함)가 바뀌므로 이전 자료로 만든 세이브·리플레이는 호환 검사를 통과하지 못한다([system-save.md](system-save.md)).
- `시험 전투`는 저장하지 않은 현재 문서로 출전 준비 화면부터 시작한다. 캠페인의 로스터에 더해 이 맵에 고정되지 않은 모든 플레이 가능
  장수가 선택 대상이 되고, 저장 폴더는 임시 폴더라 캠페인 진행·세이브와 완전히 분리된다. 오른쪽 위(배치 중에는 오른쪽 아래)의 `에디터로 돌아가기`로 돌아온다.
- 검증 오류(크기, 배치 범위, 중복 장수, HP·MP 초과, 보스·일기토 참조 등)가 있으면 저장과 시험 전투가 막히고 첫 오류가 메시지로 나온다.

### 검사

```sh
go test ./internal/mapedit -cover
SRPG_RENDER_TEST=1 go test ./internal/gui -run TestRenderedEditorAndStatuses -count=1
```

둘째 줄은 실제 창을 열어 `reports/editor-regression/`에 화면을 저장한다. 운영체제 입력을 합성하지는 않는다.
에디터 화면을 캡처하려면 `cmd/_uidemo-vm`의 `editor` 데모를 쓴다([presentation-ui.md](presentation-ui.md)).

## 도트 에디터

유닛 도트를 한 픽셀씩 칠하는 브라우저 도구다. 서버 없이 `index.html`을 열어도 되지만 그러면 유닛 목록을 읽지 못하므로 `YAML 불러오기`를 써야 한다.

```sh
cd ver5/tools/doteditor
python3 -m http.server        # 또는 make serve → http://localhost:8000
```

### 화면

- 위쪽: 기본형 버튼(`중보병`·`경기병`), `동작 미리보기`(`preview.html`), `유닛 선택`(라이브러리), 편집/전체 보기 전환, 전체화면, `YAML 불러오기`, `YAML 저장`.
- 라이브러리는 `units/<id>.yaml`을 읽어 검색할 수 있게 보인다. 기본형을 복제해 새 캐릭터로 만들 수 있다(`현재 유닛으로 새 캐릭터 만들기`).
- 방향·동작을 고르고 프레임 줄에서 프레임을 고른다. 도구는 연필·지우개·채우기·스포이트이고 각 픽셀은 색과 재질 태그를 함께 가진다.
  태그 팔레트(1 밝음 → 3 어두움)에서 태그를 고르고 칠하면 픽셀이 그 태그에 묶인다. 태그 색은 유닛의 기본색이고, 게임은 진영색과 캐릭터의 `Look.Palette`로
  태그 그룹별로 덮어 그린다([presentation-sprite.md](presentation-sprite.md)의 색 규칙).
  `원본색 → 태그 연결`은 원본 색을 모든 프레임에서 태그로 바꾼다.
- 비교 레이어(최대 8개)로 다른 유닛·프레임·수정 전 이미지를 반투명하게 겹쳐 볼 수 있고, `현재 프레임에 복제`는 기준점을 맞춰 덮어쓴다(좌우 반전 선택 가능).
- 미리보기 패널은 현재 동작을 재생한다. `PNG`로 현재 프레임이나 전체 시트를 내보낸다.

### 단축키

| 키 | 동작 |
|---|---|
| `B` / `E` / `F` / `I` | 연필 / 지우개 / 채우기 / 스포이트 |
| `Ctrl`/`Cmd`+`Z`, `Ctrl`+`Shift`+`Z`(또는 `Ctrl`+`Y`) | 실행 취소·다시 실행 |
| `Ctrl`/`Cmd`+`S` | `YAML 저장` |
| `Space` | 재생·정지 |
| `←` / `→` | 이전·다음 프레임 |

입력칸에 커서가 있으면 단축키는 동작하지 않는다.

### 저장과 게임 반영

- `YAML 저장`은 브라우저 다운로드로 `<id>.yaml`을 내려받는다. 편집기는 `units/`에 직접 쓰지 못하므로 받은 파일을 `tools/doteditor/units/`에 덮어 넣는다.
  저장하지 않은 변경이 있으면 창을 닫을 때 경고한다.
- 게임이 읽는 파일은 `assets/sprites/<id>.spr`이다. YAML에서 만든다.

```sh
make -C tools/doteditor apply                       # units/*.yaml 전부
python3 tools/spritebuild/build.py tools/doteditor/units/liubei.yaml
```

- 빌드 옵션·`.spr` 구조·비전투 스프라이트 펼치기(NE·SE 반전, `walk` 4칸)는 [presentation-sprite.md](presentation-sprite.md)에 있다.
- 같은 폴더의 `viewer.html`(장수 도트 뷰어: 8방향×동작 전부를 재생하고 태그 색을 바꿔 봄)과 `progress.html`(에이전트 작업 진행판)은 보기 전용이다.
