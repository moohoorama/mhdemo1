# 전투 UI

범위: 전투 화면의 HUD 패널, 명령 흐름, 팝업·모달, 피해 숫자·상태 아이콘·턴 배너·말풍선, 배치 화면, UI 배율, 화면 캡처 방법.
기준: 값이 다르면 `internal/gui/*.go`를 따른다(패널 `hud_panel.go`, 명령 `command.go`, 창 `windows.go`, 배율 `skin.go`).

규칙·공식은 [logic-combat.md](logic-combat.md), 일기토 화면은 [presentation-duel.md](presentation-duel.md), 적 페이즈 재생은
[presentation-replay.md](presentation-replay.md), 이야기 장면·대화창은 [presentation-scene.md](presentation-scene.md)에 있다.
확정한 연출 시안과 타이밍 기준은 [ui-mockup/README.md](ui-mockup/README.md)다. 화면의 글자는 한국어만 쓴다(한자 인장·한자 메뉴 없음).

## 좌표와 UI 배율

- 좌표계는 둘이다. UI px(HUD·창·대화·배너)와 월드 px(타일·유닛·이펙트, 카메라 줌이 위에 곱해진다). 가로세로 비율은 같다.
- `base = min(창폭/1280, 창높이/850)`이다. 월드 px은 `base`, UI px은 `base × UI 크기`다. 창이 1280×850과 다른 모양이면 레터박스 없이
  더 많은 맵과 UI 캔버스(`uiW×uiH`)가 보인다.
- UI 크기는 설정의 `UI 크기`이며 80·100·115·130·145·160% 중 하나다(`settings.json`의 `ui_scale`, 0이면 기본값).
  기본값은 데스크톱 100%, Android 130%(`gui.DefaultUIScale`)다. 한 번에 모든 UI가 같이 커진다.
- 맵 위 한 점에 붙는 UI(명령 메뉴, 공격 예측, 피해 숫자, 말풍선)는 위치를 월드 좌표에서 따와 `worldToUI`로 UI 공간에 옮겨 그린다.
- 창·타이틀·출전 준비·결과처럼 1280×850 설계로 짠 화면은 `inFrame`/`popup`이 한 장에 그린 뒤 가운데에 놓고, 화면이 작으면 줄인다.
- 타이틀 배경은 대화창과 같은 용무늬(`dragon.png`, 청록)가 대각선으로 천천히 흐르고 가장자리가 어둡다.
- 맵 편집 캔버스와 일기토 재생은 1280×850 고정 캔버스를 가운데에 그리고 UI 100%로 고정한다(`fixedLayout`). 맵 목록·일기토 감상 목록은 현재 UI 크기를 따르는 최대 960×720 판이며 제목·하단 `닫기` 사이의 목록만 휠·드래그·스크롤바로 스크롤한다. 항목을 열고 돌아와도 읽던 위치를 유지한다.
- 글꼴은 `assets/fonts/`의 `NotoSansKR`(UI 글자), `NanumBrushScript`(피해 숫자·턴 배너·첫 등장 이름의 붓글씨), `NotoSerifKR`(대화창·턴 배너 부제)다.
- 입력은 마우스·터치 공용이다. 한 손가락은 클릭·드래그, 두 손가락은 지도 이동·핀치 확대(`pointer.go`), Android 뒤로 가기는 `Esc`와 같다.

## 전투 화면

전투 중 맵이 창 전체를 쓴다. 위에 덮는 것은 두 모서리 판(왼쪽 위 진행판, 오른쪽 위 HUD 패널)과 맵 위 요소(커서 카드, 명령 메뉴, 예측 창, 알림)뿐이다.
상단 바·이름패·하단 로그·지형 패널은 없다. 전투 HUD에는 단축키가 없고 모든 조작이 클릭으로 된다.

그리는 순서는 맵 계층(`layerMap`) 다음 UI 계층(`layerUI`)이다. 일기토 전환은 두 계층을 따로 흐리게 한다.

### 카메라

- 이동: 왼쪽·오른쪽 버튼 드래그, 창 가장자리(8px), 화살표 키. 드래그 중 4px 넘게 움직이면 이동이고, 아니면 클릭이다.
- 확대: 1·2·4배 세 단계이고 전장은 2배로 연다. 휠은 한 단계씩 오가며 전환은 0.5초이고 전환 중 휠 입력은 건너뛴다.
  핀치는 손가락을 벌린 만큼 따라가다가 떼면 가장 가까운 단계로 맞춰 붙는다(`zooms`, `nearestZoom`).
- AI 진영 차례와 그 재생 동안에는 이동·확대·미니맵 클릭·일람 행 이동이 모두 잠긴다(`cameraLocked`). 클릭으로 부대를 고르는 것은 된다.
- 다른 곳에서 부르는 이동: 일람 행 클릭(`focusOfficer`)은 부드럽게 이동하고, 말풍선·적 페이즈는 아래에 적었다.
- 전장이 처음 만들어질 때 이미 1턴 아군 차례의 전투 단계이면(1턴 자동 저장 불러오기 등) `전투 목표` 모달이 자동으로 열린다. 이벤트 `goals`가 목표를 바꾸면 재생이 그 이벤트에 이르렀을 때 다시 열린다.
  배치를 거쳐 시작하는 흐름에서는 자동으로 열리지 않으며 진행판의 `전투 목표`로 연다.

### 모서리 판

이야기·탐험·배치·전투 모든 화면의 두 위쪽 모서리에 같은 모양의 판이 있다(`hud_corner.go`). 판마다 머리줄(34px)과 버튼 줄이 있고,
버튼은 아래 순서를 지키고, 그 화면에 없는 버튼은 빼고 남은 것만 붙여 놓는다. 왼쪽 판은 남은 버튼과 머리줄 글자가 들어갈 만큼만 넓다. 버튼은 높이 34, 15px 가운데 정렬
(`centeredBtn`)이고, 켜고 끄는 것은 토글(`toggleBtn`: 켜면 금빛으로 눌림, 끄면 튀어나온 버튼에 회색 글씨)이다. 판마다 접기 버튼이 있어 접으면 머리줄만 남는다.

- 왼쪽 위 진행판(폭은 버튼 수에 맞춤, 최대 540, `leftPanel`): 머리줄에 접기 버튼, 장소(탐험은 지역, 장면은 장면 맵 이름의 괄호 앞, 전투·배치는 스테이지 이름), 장(`N장`)
  또는 `배치 N / M`, 탐험에서는 오른쪽 끝에 돈. 아래 버튼은 이 순서이고 표의 `—`는 그 화면에 없어 빠진다.

  | 칸 | 장면 | 탐험 | 배치 | 전투 |
  |---|---|---|---|---|
  | `배속 ×N` (`×1 → ×2 → ×4 → ×8`, `F` 키와 같음) | ● | ● | ● | ● |
  | `확대 N배` (1·2·4배, 휠과 같음, 전투는 카메라가 잠긴 동안 흐림) | — | ● | ● | ● |
  | `자동 넘김` 토글 | ● | ● | — | — |
  | `장면 넘기기` | ● | — | — | — |
  | `전투 목표` | — | — | ● | ● |
  | `진영 종료` (아군 차례에 재생이 끝났을 때만 눌림, 행동하지 않은 부대가 남았으면 확인) | — | — | — | ● |

  debug에서는 가장 오른쪽에 `자동실행`이 붙는다. 켜면 `자동 중지`, 계산 중이면 `계산 중지`로 보이며 다시 누르거나 Esc로 멈춘다. 바로 왼쪽의 `학습(시험)`이 기본이며 전투 명령만 신경망이 고른다. 중지 중 누르면 기존 `전투: 탐색`으로 바뀌며 자동실행 중에는 변경할 수 없다. 이야깃길·상점 구매·장비·승급·특성 학습은 두 모드 모두 기존 준비 규칙이 맡고, 준비에서는 실제 장수 창·특성 창·승급 창을 보여 준다. 출전 준비 화면에는 장수 목록 밑에 모드 선택과 같은 토글이 있다. release에는 두 버튼이 없다. 학습 모델은 아직 시험용이며 실패할 때 탐색 전투로 자동 대체하지 않는다.

  장면은 카메라 배율을 연출이 정하므로 확대가 없다. 전투 대사는 스스로 넘어가므로 자동 넘김이 없다. 창이 좁아 두 판이 나란히 들어가지 않으면
  진행판이 줄고 칸이 두 줄 이상으로 접힌다.
- 오른쪽 위 판(폭 320): 머리줄에 부대 요약(`장수 N · 소지품 M`)과 끝에 접기 버튼, 아래 `부대`·`메뉴`. `부대`는 탐험에서 걸을 때만 부대 창을 연다
  (장면·대화 중에는 흐림). 전투에서는 이 판이 HUD 패널이 되어 머리줄이 차례·턴으로 바뀌고 아래에 탭이 붙는다.
- 판 위 클릭은 아래 맵·탐험 걷기로 넘어가지 않는다.

### HUD 패널

폭 320으로 둘로 나뉜다(`hud_panel.go`). 오른쪽 위(오른쪽 12px, 위 10px)는 머리줄과 `관리`·`메뉴` 줄, 오른쪽 아래(아래 12px)는 정보 패널(탭 줄과 탭 내용, 기록 탭이면 위에 12px 손잡이 띠)이다.
정보 패널의 높이는 탭 내용이 정하고, 위쪽으로 부드럽게 늘고 준다. 오른쪽 위 판 밑 6px까지 커질 수 있다.

- 머리줄(34px): `○○군 차례`(아군은 군주 이름, 적은 `적군 차례`, 동맹은 `동맹군 차례`)와 턴(`N턴`, 제한이 있으면 `N/M턴`),
  끝에 접기 버튼. `진영 종료`는 왼쪽 위 진행판에 있다.
  AI 진영의 재생 중에는 규칙 상태가 이미 다음 진영으로 넘어갔어도 재생 중인 진영과 턴을 보인다(`shownTurn`).
- `부대`는 전투에서 `병력일람` 창을 연다. `메뉴`는 메뉴 창이다.
- 접기: 머리줄의 삼각형으로 접으면 머리줄만 남고 정보 패널도 사라진다.
- 투명: 마우스가 정보 패널 밖에 있으면 정보 패널을 약 55% 투명으로 그린다. 터치 화면에서는 흐리지 않는다. 클릭을 막는 영역은 그린 패널 영역뿐이다.
- 탭은 `미니맵`·`장수`·`일람`·`기록`·`기타` 다섯이다. 고른 탭은 `hudBase`에 남는다.
- `장수` 탭은 늘 누를 수 있다. 장수를 선택하면 자동으로 이 탭이 보이고, 선택한 장수가 없을 때 고르면 `선택한 장수가 없습니다`가 뜬다.
  선택 중 다른 탭을 누르면 그 탭을 잠깐 보기만 하고(`hudPeek`), `장수`를 누르면 돌아온다. 선택이 끝나면 `hudBase`(손으로 고른 탭, `장수` 포함)로 돌아간다.
- AI 진영(적·동맹) 차례가 되면 `기록`으로 바뀌고, 아군 차례로 돌아오면 이전 탭으로 돌아간다.
- 전투 단계가 아닌 때(대화·결과)는 그리지 않는다. 배치 단계는 아래 절을 본다.
- 패널 왼쪽 영역이 명령 패널의 오른쪽 한계다(`panelBounds`).

탭 내용은 다음과 같다.

| 탭 | 내용 | 높이 |
|---|---|---|
| 미니맵 | 맵 전체, 유닛 점(아군 파랑·적 빨강), 현재 화면 사각형. 클릭하면 카메라가 그 위치로 간다 | 미니맵 높이 + 40 |
| 기록 | 전투 기록. 줄 색, 휠·스크롤바, 정보 패널 위쪽 18px를 끌어 높이 조절 | 기본 260(120~화면 한도) |
| 일람 | 부대 목록(아래) | 행 수에 맞춤, 화면 한도까지 |
| 기타 | `위협 범위`·`자동 전투`(아군 차례도 AI가 둔다) 토글(켜면 ●), `병력일람` | 220 |
| 장수 | 선택한 부대(아래) | 400 |

**기록** 탭: 이벤트를 한국어 한 줄로 바꿔 쌓는다(`events.go`). 한 화면 프레임에 한 항목씩 나타나고 300항목까지 보관한다.
다른 전투로 넘어가면 기록과 대기 항목을 비운다. 읽는 위치를 올려 둔 동안 새 줄이 들어와도 그 위치를 지킨다.
색은 피해·격파(주홍)·회복·획득(초록)·행동 장수 이름(옅은 금색)·나머지(흰색)다. 설정의 `전투 기록`이 `주요 사건만`이면 상세 줄을 거른다.

**일람** 탭: 한 부대가 한 줄이다. 장수명·병력·병법치·명령(O/X)만 보인다. 필터는 `아군`·`적군`·`전체`(기본 아군).
머리 칸을 누르면 `무정렬 → 내림 → 오름`이 돌아간다. 퇴각한 부대는 맨 아래로 간다. 행을 누르면 카메라가 가고 그 부대를 선택하며,
명령할 수 있는 아군이면 명령 흐름이 시작된다.

**병력일람** 창: `부대` 버튼이나 `기타` 탭의 `병력일람` 버튼으로 연다. 화면을 거의 채우는 오버레이이고 한 부대가 한 줄, 글씨는 17이고 모든 칸이 가운데 정렬이다.
같은 필터·정렬을 쓰고 보기 네 개를 고른다: `기본`(병종·레벨·병력·병법치·명령), `전투력`(공격·방어·정신·순발·사기·병법회복),
`열전`(통솔·무력·지력·민첩·운·매력), `장비`(무기·방어구·장신구·특성 수·기술 수·특성치). 휠로 스크롤하고, 행을 누르면 창을 닫고 그 부대로 이동한다.

**장수** 탭: 초상·이름·병종·레벨·상태(`동맹군 · AI`/`행동 완료`/`이동함`)·남은 특성치, 병력·병법치·경험치 막대를 보인다.
병력·병법치 옆의 `+n`은 지금 위치에서 다음 자기 차례에 회복할 양이다. 아래에 하위 탭 넷이 있다.
`능력`은 능력 육각형(공격·방어·정신·순발·사기·병력)과 상태 이상 글자, `특성`은 보유 특성 목록(누르면 설명 모달),
`장비`는 무기·방어구·장신구의 아이콘·이름과 특성 표식(누르면 특성 모달), `열전`은 여섯 능력과 열전 글이다. 육각형의 바깥선은 이 전투 부대의 최고치이고
흰 선이 현재, 회색 선은 상태 효과 적용 전 값이다. 능력 탭의 육각형은 패널이 낮으면 줄어 상태 이상 줄이 늘 보인다.

### 맵 위 카드와 알림

- 커서 카드(`brief`): 커서가 칸 위에 있으면 오른쪽에 뜬다. 유닛이 있으면 이름·레벨·병력·병법치(아군은 경험치)를 위에, 지형 이름·좌표와
  지형 효과(병종 보정·이동 비용·회복)를 아래에 보인다. 대상을 고르는 단계에서는 예측 창이 대신한다.
- 칸 커서: 칸마다 맥동하는 마름모 테두리. 적을 선택하면 그 적의 위협 범위(빨강)를, `위협 범위` 토글을 켜면 적 전체의 범위를 겹쳐 그린다.
- 알림(`toast`): 화면 위쪽 가운데에 잠깐 뜬다. 오류, `슬롯 N 저장 완료`, `불러오기 완료`, `재생 속도 ×N`에 쓴다.
  전투 이벤트는 알림 없이 기록에만 남는다. 최대 4개이고 3.5초 뒤 사라진다.
- 진행판의 `전투 목표` 버튼은 `전투 목표` 모달을 연다. 모달 아래쪽 `목표 안내` 토글이 목표 안내를 켜고 끈다(기본 켜짐, 켜지면 금빛으로 눌린 버튼, 꺼지면 튀어나온 버튼에 회색 글씨, 설정 `no_goal_guide`로 저장). 켜면 승리·패배 조건과 남은 일기토가 가리키는 것을 바닥(타일 위, 유닛·지형물 아래)에 선으로 그린다(`Engine.GoalMarks`·`DuelMarks`, `field_goals.go`). 승리 조건은 초록 실선(칸 크기), 패배 조건은 빨강 실선(작게), 일기토는 점선(그 사이 크기)이다. `defeated:X`는 X의 발밑 마름모, `at:X:N`은 지역 N의 바깥 테두리에 X가 아군이면 X의 발밑 마름모까지, 군주(유비)는 늘 빨강. 일기토는 장수를 공유하는 대진끼리(대신 나설 `Supports` 포함) 한 색이고(`Stage.DuelGroups`), 색은 초록·빨강과 먼 노랑·하늘·보라·분홍·흰색을 돌려 쓴다. 모달의 일기토 줄 앞에도 같은 색 점선 마름모가 붙는다. 치른 일기토와 아직 등장하지 않은 장수는 그리지 않는다. 같은 목표에 `flag`·`round` 조건이 아직 안 섰으면 흐리게 그린다. 이벤트 `goals`가 목표를 바꾸면 선도 바뀐 목표를 따른다. 선은 천천히 맥동하고 걷는 유닛을 따라간다. 확인: `go run ./cmd/_uidemo-vm -ui goals -stage B01`.
- 승리 순간에는 가운데에 `승리` 띠가 2초 뜬다.

## 명령 흐름

아군 차례에 명령할 수 있는 아군을 누르면 시작한다(`order`: `move` → `menu` → `sub` → `target`).

```
부대 클릭 → 이동 범위(파랑) → 칸 클릭 → 임시 이동 → 행동 메뉴(공격·병법›·도구›·대기)
  ├ 우클릭/Esc: 한 단계 뒤로 (임시 이동이면 원위치)
  └ 공격/병법/도구 → 사거리(빨강)·대상 표시 → 대상에 마우스: 예측 창 → 클릭: 확정
확정 = 세션에 이동(있으면) → 행동 → 대기(남은 행동이 없으면)
```

- 임시 이동은 `core.Restore`로 만든 샌드박스 엔진에 적용하고 걷기만 재생한다. 메뉴의 합법 행동과 예측은 샌드박스에서 계산한다.
  취소하면 샌드박스를 버린다. 세션으로는 확정할 때만 간다.
- 이미 이동한 부대는 `menu` 단계에서 시작한다. 행동 메뉴는 유닛 옆에 위에서 펼쳐지고, 쓸 수 없는 항목은 흐리게 남는다.
  항목에 마우스를 올리면 설명이 뜬다. `병법`·`도구`는 옆에 하위 목록이 열린다(병법치·소지 수 표시, 공간이 없으면 왼쪽).
- 자기 대상 병법은 목록을 누르면 바로 확정한다. 일기토는 명령이 아니다. 정해진 상대를 공격하면 예측 창에 `일기토 발생`이 뜬다.
- 대상 단계에서 대상이 아닌 칸을 누르면 한 단계 뒤로 간다. 메뉴 밖 클릭도 같다. 범위 병법은 커서 기준 영향 칸을 색으로 보인다.
- 예측 창: 대상 옆에 뜨며 양쪽의 병력·병법치·경험치가 보통 타격과 치명 타격 뒤 어떻게 되는지, 명중·치명·2회 확률, 반격, `격파!`를 보인다.
- 모든 아군에게 명령을 내리면 `턴을 넘기겠습니까?`를 한 번 묻는다(턴마다 한 번).
- `Space`는 추천 한 명령(AI), `F`는 재생 속도, `Enter`는 재생 건너뛰기, `F5`/`F9`는 마지막으로 쓴 수동 슬롯의 저장·불러오기,
  백틱은 CLI 문법 입력줄이다. 나머지 전투 단축키는 없다.
- 레벨업으로 특성치가 쌓이면 관리 창이 그 장수의 특성 탭으로 열리고, 닫기 전까지 다른 명령은 받지 않는다([logic-traits.md](logic-traits.md) 2.3). 특성 탭의 설명 칸에 `배우기` 버튼이 있다. 따로 된 학습 창과 특성 배우기 버튼은 없앴다.

## 창과 모달

- 장수·부대·특성 창(`관리`·`부대`·`부관 임명`·`장비`)은 폰 914×411 기준의 판이다(`ui_kit.go`, 설계는 [plan-party-ui.md](plan-party-ui.md)). 폭은 `min(화면-16, 960)`, 높이는 `min(화면-16, 720)`이다. 넓은 화면(PC·폰 160%)에서는 960 폭으로 가운데 놓이고, 좁은 화면에서는 꽉 찬다. 레벨 업 창처럼 원래 작은 창은 제 크기다.
  제목 판과 오른쪽 위 `닫기`가 없다. 누르는 것은 높이 48 이상(목록 줄 56, 특성 칩은 보이는 40 + 여백), 본문 글자 14·이름 16·가장 작은 글자 12다.
  창을 닫는 버튼은 모든 창에서 오른쪽 아래 끝의 `닫기` 하나다(레벨 업 학습도 `닫기`). 그 밖의 할 일은 `닫기` 왼쪽에 조금(24) 떨어져 한 줄로 서고, 주 행동(금빛 테두리)이 `닫기`에 가장 가깝다.
  옛 창(메뉴·저장·불러오기·설정·상점·병력일람·장면 이동·난이도)도 내용 밑 띠의 오른쪽 아래에 `닫기`를 두고, 저장은 `저장`, 불러오기는 `불러오기`, 상점은 `N개 사기`/`N개 팔기`를 그 왼쪽에 둔다. 설명 창·특성·승급 모달도 `닫기`.
- 오버레이(`메뉴`·`저장`·`불러오기`·`설정`·`확인`·`장비`·`부관`·`부대`·`상점`·`병력일람`)는 쌓인다. 창에서 연 창은 그 위에 뜨고, 닫으면
  밑의 창으로 돌아간다(`부대` → `장비 변경` → 닫기 → `부대`). 맨 위 창만 입력을 받는다. 저장·불러오기를 마치면 모두 닫힌다.
- 모달(`전투 목표`·`레벨 업`·`특성`)은 재생이 끝난 뒤 순서대로 하나씩 뜨고 `Enter`/`Space`로 닫는다. `레벨 업`·`특성`은 아무 곳이나 클릭해도 닫히고, `전투 목표`는 안에 토글이 있어 `확인` 버튼으로만 닫힌다. `Esc`는 오버레이·모달·행동 단계를 한 단계씩 닫고, 아무것도 없으면 메뉴를 연다.
- 창은 위에서 작은 오버슈트로 내려오며 가운데 선에서 펼쳐지고, 닫을 때는 말려 올라간다. 뒤 화면이 같이 어두워진다.
  클릭은 첫 프레임부터 최종 자리에 닿으므로 연출이 입력을 늦추지 않는다(`window_anim.go`).

### 장비 창

장수 창의 `장비 변경`이나 장비 칸, 출전 준비의 `장비`, 부대 상세의 `장비 변경`이 연다(`equipment_window.go`). 화면을 채우는 판 하나다.

- 왼쪽: 무기·방어구·장신구 슬롯 줄(72). 아이콘·이름·보정 등급. 누르면 그 슬롯을 고른다(처음은 무기).
- 가운데: 고른 슬롯에 들어갈 장비 줄(56). `장비 벗기`(착용 중일 때), 착용 중인 것(금색 `(착용)`), 창고의 장착 가능한 장비 순. 아이콘·이름·보정 등급·특성 이름. 휠·끌기로 스크롤.
- 오른쪽: 고른 장비의 아이콘·이름·슬롯, 보정과 그 장수에게 더하는 값, 지금 장비와 견준 변화(오름 초록, 내림 빨강), 주는 특성 칩(누르면 설명 창).
- 할 일 줄: `닫기`, `○○로 바꾸기`(또는 `장비 벗기`). 능력치는 게임 사본에 해제·장착을 적용해 계산한다(리비전·장수·칸·장비별 캐시).
- `전투 목표`: 승리 조건, 패배 조건, 턴(현재/제한), 일기토 대진(대신 나설 수 있는 `Supports`도 `장비·관우·유비 대 여포`처럼 함께, 세 건까지, 나머지는 `외 N건`).
- `설정`: AI 차례(동시에 보기/하나씩 보기), 전투 기록(상세/주요 사건만), 대사 속도(한 글자씩/즉시, 기본 한 글자씩), 재생 속도(×1·2·4·8), UI 크기, 그리고 `-debug`(검증 모드)에서만 데미지 배율·경험치 배율(둘 다 60·70·80·90·100%, 기본 80%; 검증 모드가 아니면 기본값으로 고정)과 장면 카메라 가로·세로(중앙 허용 영역 크기, 화면 대비 20·35·50·65·80%, 기본 50%, `cam_zone_w`·`cam_zone_h`). 항목 이름이 위에 있고 선택지가 아래 버튼 줄로 놓이며, 지금 고른 선택지는 눌린 채(금색 글씨)로 보인다. 조작 안내문이 붙는다.
- `저장`/`불러오기` 창은 탭(자동·일반)과 정렬되는 표로 슬롯을 보이고, 줄을 고른 뒤 `확인`으로 실행한다([system-save.md](system-save.md)). 확인: `go run ./cmd/_uidemo-vm -ui saves -frames 200 -at 60,120,190`.
- 결과 창: 승리는 그 전투의 경험치(`State.Merit`, 저장에 남는다) 순으로 공훈 시상대를 세운다 — 3위 오른쪽 아래, 2위 왼쪽 아래, 1위 위 가운데가 차례로 떨어지며 메달 색으로 번쩍이고(`result_merit.go`), 4위부터는 이름·레벨 변화·경험치 한 줄씩, 그 아래 획득(돈, 스테이지 보상과 부목표 보상), `다음 이야기`. 창을 누르면 연출을 건너뛴다. 직접 조작하는 아군만 보인다.
  패배는 사유(군주 퇴각 또는 턴 제한 초과)와 `출전 준비부터 재도전`·`불러오기`·`시작 메뉴`를 보인다. 재도전은 [system-save.md](system-save.md)의 재도전 체크포인트를 쓴다.

## 맵 위 연출

### 밤

`Stage.Night`인 전투는 전장 위에 푸른 어둠을 깔고(`field_night.go`), 화염 칸(반지름 150 월드 px)·불씨 칸(95)·`Stage.Lights` 횃불(80) 둘레만
부드럽게 뚫고, 유닛마다 들고 있는 횃불처럼 작은 빛(62)을 둔다(누가 어디 있는지 보이게). 빛 둘레는 땅처럼 납작하고 조금씩 흔들리며, 불 위에는 주황 빛을 더한다. 불이 번지면 밝은 곳도 늘어난다. HP 막대와 상태 아이콘은
어둠 위에 그린다. 커서·효과·말풍선 같은 맵 위 연출도 어둠 위다.

### 유닛 막대와 상태 아이콘

HP 막대는 유닛 폭의 약 1.2배(24×7 게임 픽셀)이고 네 칸 눈금, 진영색 채움, 맞으면 남는 흰 잔상을 가진다. 얇은 병법치 줄이 그 아래에 붙는다.

배로 건너는 전투(`Boats`)의 배(`field_water.go` `boat`): 물 칸 위의 유닛은 배에 탄 정지 자세로 배와 함께 미끄러지고 걷기 프레임을 쓰지 않는다. 땅→물 걸음에서는 물 칸에 배가 먼저 떠 있다가 유닛이 걸어 들어와 타고(땅 쪽 절반은 걷기, 물 쪽 절반은 정지), 물→땅 걸음에서는 배가 물 칸에 남은 채 유닛이 땅 쪽 절반을 걸어 나가며 가라앉는다. 땅 위 걸음에는 배가 없다. 배와 유닛의 자리는 `afloat{dx, dy}`로 따로 계산한다. 발걸음·말발굽 소리(`stepCue`)는 물 칸에서 물 칸으로 가는 걸음에서 배 소리(`boat`, 받은 `boat_wave.mp3`의 2.5초 구간: 0.35초에 걸쳐 부풀고 0.6초까지 그대로, 그 뒤 2.5초까지 완만하게 줄어듦. 걸음마다 한 번 재생되어 0.28초 간격으로 겹쳐 하나의 파도 소리로 이어지고, 이동이 끝나도 꼬리가 울림)로 바뀌고, 땅↔물 경계 걸음은 땅 쪽 반 걸음을 걷는 모션에 맞춰 소리가 난다.
막대 아래에 상태 아이콘이 한 줄로 나란히 붙는다(HP바 → MP바 → 아이콘 순서). 이상 상태는 9×9 도트
(독·속박·봉격·화상·혼란·봉책)이고, 강화·약화는 같은 종류에 위·아래 화살표 두 벌이다(공격 빨강·방어 파랑·정신 초록·순발과 사기 노랑·이동 흰색).
아이콘 원본은 `assets/graphics/status/icons.png`와 `icons.json`이다.

혼란·봉격·봉책·속박(봉쇄)·독에 걸린 유닛은 그 표시가 머리 둘레를 돈다. 스프라이트 꼭대기를 중심으로 한 아이소 타원 궤도(반지름 13 맵 단위, 1.2초에 한 바퀴)를 공전하되 표시 자체는 돌지 않고 늘 똑바로 선다(상태 표시의 기본 규칙, 사용자 11-16). 몸 뒤로 지나는 절반은 유닛보다 먼저 그려 가려진다. 표시는 혼란 노란 물음표, 봉격 칼 위 빨간 X, 봉책 부채 위 빨간 X, 속박 신발 위 빨간 X, 독 초록 물방울(독 아이콘의 물방울 그대로)로, 모두 1px 어두운 외곽선의 9~13×11 도트다. 상태가 여럿이면 한 궤도에 번갈아 섞는다: 하나면 넷, 둘·셋이면 종류마다 둘, 넷 이상이면 하나씩(둘씩이면 궤도가 꽉 차서 겹친다). 높이를 달리하면 머리 위가 탑처럼 쌓이고 말 탄 유닛은 더 높아져서 한 궤도를 골랐다. 원본은 `tools/spellsim_confuse.py`의 `MARKS`, 시트는 `effects/spells/status_mark_<상태>`, 그리기는 `status_visual.go`의 `drawStatusMarks`.

### 피해·회복 숫자

숫자는 붓글씨 느낌으로 크게 튀어나와 기울어진 채 자리 잡고 위로 흐른다. 피해는 주홍 숫자에 베기 자국·먹 튐·화면 번쩍임,
치명은 거기에 `치명` 글자와 금빛 고리가 붙는다. 회복은 `+N` 초록 숫자에 빛 입자가 오른다. 같은 유닛에 연달아 뜨면 줄을 나눈다.
숫자 크기는 카메라 줌을 따르고 UI 배율도 곱해진다.

### 턴 배너

`turn` 이벤트를 재생할 때 나온다. 화면이 어두워지고 먹 띠 두 줄이 왼쪽에서 쓸려 오며, `제N턴`이 붓글씨로 왼쪽부터 써지고,
`○○군의 차례`가 진영색으로 나타나 같은 색 밑줄이 그어진다. 약 2.6초이고 재생이 빠르거나 자동 전투이면 2배 빠르다.
낮은 화면에서는 높이에 맞춰 줄어든다.

### 말풍선

전투 이벤트의 대사는 해당 유닛 머리 위에 말풍선으로 뜬다(일기토 대사와 같은 10조각 풍선 렌더러). 풍선끼리 겹치면 위로 밀어 올리고,
화면 밖으로 나가지 않게 한다. 말하는 유닛들의 가운데로 카메라가 이동한다. 이야기 장면의 말풍선(말하는 동안 점, 감정 표시)은
[presentation-scene.md](presentation-scene.md)에 있다.

### AI 진영 차례

AI 진영(적·동맹)의 차례는 규칙이 한 번에 다 정하고(`ResolvePhase`), 화면은 보이는 곳에서만 재생한다(`ai_view.go`).

- 행동은 앞서 보여야 할 행동(`After`)이 끝났고, 그 행동이 닿는 칸(출발·이동·대상)이 모두 화면 안이며 HUD에 가리지 않을 때 시작한다.
  화면 밖 행동은 기다린다.
- 재생 중인 행동이 없는데 화면 안에 시작할 행동도 없으면, 시작할 수 있는 행동 중 카메라에 가장 가까운 것의 칸 가운데로 카메라가 옮겨 가고,
  도착하면 그 행동이 (다 들어오지 않아도) 시작한다. 그 주변의 다른 부대도 함께 움직인다. 카메라 이동은 재생 속도를 따른다.
- 설정 `AI 차례`: `동시에 보기`(기본)는 화면 안의 행동을 0.2초 간격으로 겹쳐 시작하고, `하나씩 보기`는 앞 행동이 끝나야 다음을 시작한다.
  둘 다 저절로 이어지며 적·동맹에 똑같이 쓴다.
- 전투 기록은 행동이 시작될 때 쓴다. 건너뛰면(`Enter`) 남은 행동의 기록을 한꺼번에 쓴다.
- 병력이 나타나거나 불 같은 지형이 바뀌면 그 장면 전에 카메라가 먼저 그곳으로 간다. 차례 배너와 HUD 머리는 진영 이름(`Armies`의 `Name`,
  없으면 진영색 이름 + 군)을 그 진영색으로 쓴다.

## 장수 창

탐험의 `관리`가 연다(`officer_window.go`). 왼쪽 위의 전환 탭 `목록`·`표`·`소지품`이 세 보기를 바꾼다(늘 같은 자리).
목록 보기는 왼쪽에 장수 목록(줄 56: 얼굴·이름·병종·레벨, 오른쪽에 특성치 — 지금 배울 수 있는 특성이 있으면 초록), 오른쪽에 고른 장수의 탭 넷이다.

- 전투력: 큰 육각형(장부의 최고치가 바깥선)과 그 오른쪽에 일곱 전투 능력(값과 장부 최고치 대비 막대), 이동·사거리, 경험치. 숫자는 부관 없이 장수 혼자의 값이다. 열전 능력(통솔·무력…)은 열전 탭에 있다.
- 특성: 선반 셋 — 고유, 병종, 장비(입은 장비가 주거나 가르치는 특성; 다른 선반과 겹쳐도 다시 보인다). 배운 것 금빛 실선, 지금 배울 수 있는 것(선행을 갖췄고 특성치가 넉넉함) 초록 점선, 나머지 어둡게 테두리 없이.
  칩을 누르면 아래 설명 카드가 바뀌고, 못 배우는 이유(선행·모자란 특성치)나 특성치 변화가 나온다. 할 일 줄의 `○○ 배우기 · 비용`이 배운다.
- 열전: 열전 글, 여섯 능력, 고유 특성과 그 효과.
- 장비: 슬롯 카드 셋. 카드를 누르면 그 슬롯으로 장비 창이 열린다. 할 일 줄에 `장비 변경`.
- 표: 한 줄에 장수 하나(48), 전환 탭 오른쪽의 보기 넷(기본·전투력·열전·장비)으로 칸 묶음을 바꾼다. 줄을 누르면 목록으로 돌아가 그 장수를 고른다.
- 소지품: 거르기 탭, 물건 표(줄 48), 오른쪽에 고른 물건 설명과 `장비 바꾸기`. 지금 쓸 수 있는 물건(누군가 받을 수 있는 인수)만 진하게, 나머지는 여린 글씨·흐린 아이콘(`insu.go`).
  쓸 수 있는 인수를 누르면 인수 쓰기 보기로 바뀐다: 머리 `○○ 인수 — 누구에게 쓸까요?`, 장수 표(이름·병종·레벨, 줄 48, 스크롤; 받을 수 있는 장수가 위에 진하게, 나머지는 여리고 고를 수 없음), 오른쪽 카드에 인수와 고른 장수·갈래 병종. 할 일 줄 `승급하기`·`닫기`(소지품 목록으로). 갈래가 여럿이면 병종 카드가 뜨고(밖을 누르면 돌아감), 승급하면 승급 창(전후 모습·능력)이 이 창 위에 뜬다. 전투 중 도구 메뉴의 인수는 고르면 "인수는 탐험과 출전 준비의 소지품에서 쓸 수 있습니다" 알림만 뜬다. 확인: `go run ./cmd/_uidemo-vm -ui insu`(출전 준비에서: `-node c14-battle`).
- 초록 안내: 탐험 이벤트가 주인 있는 장비를 주거나, 인수 승급으로 무기가 벗겨지면(그 칸에 맞는 장비가 창고에 있을 때, 장비 창에서는 목록 전체에 테두리) 그 지역(또는 그 전투의 출전 준비)에 있는 동안 `관리` → 주인 줄 → `장비` 탭 → 그 칸의 `바꾸기` → 장비 창의 그 장비 → `○○로 바꾸기`에 차례로 초록 테두리(이름판 초록, 숨 쉬듯)가 붙는다. 다른 장수의 장비 창이면 `닫기`, 표·소지품 보기면 `목록` 탭. 출전 준비 화면이면 그 장수의 줄 → `장비` 탭 → `바꾸기`. 지역·출전 준비를 나가거나 다 차면 사라지고, 설정 `길 안내`가 끄면 보이지 않는다(`gear_guide.go`). 확인: `go run ./cmd/_uidemo-vm -ui gearguide`.
- 레벨 업 학습: 전투 중 레벨 업으로 배울 것이 남은 장수가 있으면 이 창이 특성 탭으로 열린다. 목록은 배울 장수만, 머리에 `레벨 업` 표. `닫기`가 모두의 학습을 끝낸다.

## 출전 준비

스토리의 전투 노드에 닿으면 열린다(`sortie.go`). 강제 출전 스테이지(`Stage.Forced`)는 이 화면 없이 바로 배치로 간다.

- 왼쪽: 장수 줄(56). 맨 앞 상태 칸(64×40, 누르는 범위 줄 높이)이 `출전`·`필수`·`부관`(아래 줄에 상관 이름)·`대기`를 보이고, 누르면 출전 ↔ 대기(군주·필수 장수는 그대로, 부관은 출전할 수 없음, 인원이 차면 알림).
  장수 줄은 두 줄: 이름(16)과 오른쪽 `Lv`(12) / 병종(12, 빠진 장비 아이콘이 그 뒤)과 오른쪽 `특성치`(12, 배울 것 있으면 초록).
  머리에는 `출전 준비`와 `출전 n / m`만, `목표`·`메뉴`는 목록 밑(할 일 줄 높이)에 둔다.
- 복병(`Stage.Reserve`): 줄의 상태 칸이 `복병`(금색), 줄의 `특성치` 자리에 `복병 · 전투 중 출현`이 보이고, 누르면 "복병은 전투 중에 나타나 반드시 출전합니다" 알림만 뜬다(필수와 같이 뺄 수 없다). 장비·특성 탭은 다른 장수와 같아서 장비를 준비할 수 있다. 머리의 `출전 n / m`에는 복병을 세지 않고 `(복병 제외)`를 붙인다. 배치 화면(`출전 배치 화면`)은 복병을 목록·`배치 n / m`·Tab 순환에서 뺀다. 부관 후보 표에서는 필수와 같은 이유(`필수 출전·복병 장수`)로 부관이 될 수 없다.
- 부관 표시(장수 창 목록·출전 준비·부관 후보 표 공통, `pillDep`·`depRim`): 누구의 부관인 장수의 줄은 파란 바탕에 왼쪽 파란 띠(고르면 띠만 금색), 이름 옆 파란 `부관 · 상관` 표(출전 준비에서는 상태 칸이 대신 말함). 부관을 거느린 장수는 이름 옆 파란 `부관 이름` 표.
- 오른쪽: 고른 장수의 이름과 탭 넷 `열전`·`특성`·`장비`·`부관`. 할 일 줄은 탭의 행동(`부관 해임`·`○○ 임명`, `○○ 배우기`)을 왼쪽에, 조금 띄워 `소지품`·`출진 ›`을 오른쪽 끝에.
- 부관 탭(안 4 「후보 표」): 후보를 표로(줄 48) — 후보(얼굴·이름)·지금(`대기`·`출전`·`누구 부관`, 지금 부관은 파란 `현재 부관` 표)·매력·가중치(막대와 %)·오르는 능력(가장 많이 오르는 열전 능력과 `외 n`)·특성 수.
  머리를 누르면 정렬(처음은 가중치 ▾). 지금 부관은 맨 위에 파란 바탕·왼쪽 파란 띠, 고른 후보는 금 테두리, 임명할 수 없는 후보는 흐리게 맨 아래.
  표 밑 카드에 고른 후보의 이름·병종·Lv·가중치, 임명하면 생기는 일 또는 못 하는 이유, 더해지는 특성을 작은 칩(30)으로 줄바꿈해 다 보인다. 탭의 절반에 안 들어가면 마지막 칩이 `+n`(누르면 다 보이고 `접기`), 칩을 누르면 특성 설명 창.
- 짧은 화면(폰 914×411)에서 열전 탭은 얼굴을 작게 하고 병종·이동·사거리를 그 옆에, 육각형은 이름표까지 카드 안에 들게 줄이며, 장비 탭은 합계 카드를 빼고 슬롯 카드가 폭을 다 쓴다(장비 특성은 등급 옆 작은 칩).
- `출진`은 출전 인원을 스테이지 한도로 자르고(군주·필수 먼저) 배치로 간다. 그 왼쪽 `소지품`은 장수 창을 소지품 보기로 열어 전투 전에 인수를 쓰게 한다.
- 확인: `go run ./cmd/_uidemo-vm -ui sortie-deputy -node c20-battle -frames 225 -at 30,55,85,100,128,134,140,146,180,220 -size 2400x1080 -uiscale 207`(폰 914×411, 130%·1280×850도).

## 부대 상세

출전 준비의 `상세`가 연다(`unit_window.go`). 머리에 `‹ 고순대 ›`(출전한 부대를 넘김)와 탭 넷.

- 머리(전투력·열전): 주장·부관 얼굴, `부관 가중치 69% = (주장 매력 × 2 + 부관 매력) ÷ 300`(인덕은 주장 매력 +20).
- 전투력: 부대의 전투 능력만 — 육각형(흰 선 부대, 금색 점선 주장 혼자)과 전투 표(혼자·보정·부대, 보정 초록).
- 특성: `주장 · 고유·병종·장비` / `부관 · 부관 고유·병종` 둘로 나눠 본다. 부관 쪽을 배우면 부관의 특성치를 쓴다.
- 열전: 열전 능력 표(주장·부관·부대, 부관에게서 오른 칸 초록)와 주장·부관의 열전 글. 장비: 주장의 슬롯 카드(부관은 장비를 들지 않음).
- 할 일 줄: `장비 변경`, `부관 바꾸기`, `부관 해임`, `닫기`, (특성 탭에서) `○○ 배우기`.

## 부관 임명

부대 상세의 `부관 바꾸기`가 연다(`deputy_window.go`). 왼쪽은 출전 준비 부관 탭과 같은 후보 표(정렬·현재 부관 파랑·고른 후보 금 테두리).
오른쪽은 고른 후보로 바뀌는 전투 능력(혼자·보정·부대)과 부대에 더해지는 특성(작은 칩, 넘치면 `+n`). 할 일 줄 `부관 해임`·`○○ 임명`, 조금 띄워 `닫기`.

## 출전 배치 화면

출전 준비에서 `출진`을 누르면 배치 단계로 간다. 맵이 화면을 다 쓰고, 판은 전투와 같은 자리에 놓인다.

- 왼쪽 위 진행판: 스테이지 이름과 `출전 n / m`, `배속`·`확대`·`전투 목표`.
- 오른쪽 위(폭 320): `배치 n / m`, `메뉴`, `전투 시작`(모두 배치하면 눌림, `Enter`/`E`).
- 복병은 이 목록에 줄이 없고 칸에 놓을 수도 없다(출전 준비 문단).
- 오른쪽 아래(폭 300): 출전 부대 줄(48). 얼굴·이름·부관 이름·`배치됨`/`미배치`/`선택`. 줄을 누르면 그 장수를 고르고 카메라가 간다. 길면 스크롤.
- 장수를 고르면 맵의 배치 가능 칸이 1초 주기로 맥동한다. 칸을 누르면 옮기고, 다른 아군을 누르면 그 장수를 고른다. 커서가 배치 가능 칸에 있으면 그 병종 그림이 미리 보인다.
- 왼쪽 아래 도움말: 조작과 커서 칸의 지형. `Tab`은 다음 장수, 우클릭·`Esc`는 선택 취소, `Space`는 추천 한 명령이다. 출전 여부·장비·부관은 출전 준비에서만 바꾼다.

## 화면 캡처

화면은 코드만 읽고 짐작하지 말고 캡처로 확인한다. `cmd/_uidemo-vm`은 `internal/gui/uidemo_*.go`의 이름 붙은 데모를 창 없이 재생해
PNG 프레임이나 60fps MP4로 저장한다. `ver5/`에서 `caffeinate -d -i`로 감싸 실행한다.

```sh
caffeinate -d -i go run ./cmd/_uidemo-vm -ui dialogue -frames 300 -at 30,96 -mp4 reports/uidemo/dialogue.mp4
caffeinate -d -i go run ./cmd/_uidemo-vm -ui uiscale -frames 760 -size 2400x1080 -uiscale 160 -at 380,720
caffeinate -d -i go run ./cmd/_uidemo-vm -ui uiscale -frames 760 -sheet -at 260,380,720
```

- `-ui` 데모 이름, `-frames` 재생 프레임 수(1프레임 = 1/60초), `-at 30,96`은 저장할 프레임, `-every N`은 N프레임마다 저장,
  `-mp4`는 모든 프레임을 MP4로, `-size 2400x1080`은 화면 크기(폰), `-uiscale 160`은 UI 크기(%), `-stage`·`-duel`은 데모가 쓸 전투·일기토.
  기본 출력은 `reports/uidemo/<ui>`다.
- `-sheet`는 기준 화면 넷(폰 2400×1080 130%·160%, 4:3 태블릿 2048×1536 130%, 데스크톱 1280×850 100%)에서 같은 프레임을 찍어 한 장에 놓는다.
  UI를 고친 뒤 이 네 화면에서 겹침이 없는지 본다.
- 데모: `uiscale`(이야기와 전투 HUD, 폰 배율 확인), `popups`(타이틀·창·모달·출전 준비), `title`(타이틀 화면에 머묾), `equip`(장비 창·고르기·특성 설명, `-frames 335 -at 100,160,200,240,280,330`), `hudpanel`(패널 탭), `menu`(명령 메뉴),
  `damage`, `turn`, `dialogue`, `intro`, `deploy`, `sortie-deputy`(출전 준비 부관 탭·부관 표시, `-node c20-battle`), `duel`, `duel-list`·`map-list`(감상·맵 목록, 20프레임은 처음·60프레임은 끝), `editor`, `editor-choices`(장수·장비·특성·일기토 편집 선택, `-frames 220 -at 20,60,100,140,200`), `aiturn`·`aiturn-one`(아군 진영 종료 뒤 동맹·적 차례를 동시에/하나씩 보기로 재생, `-stage B02`), `outside`(맵 밖 지형), `fonts`,
  `fire`(불씨·화염 칸), `marks`(책략 치명타 흔적 불씨·물웅덩이·돌무더기를 초원·황무지에 십자로 깔고 가까이 본다. `-frames 210 -at 25,55,85,115,145,175,205`), `mapfx`(1장 맵에 성문·울타리·불타는 숲·마을·성벽, 그을음, 다리 온전·손상·파괴를 그려 넣고 카메라가 60프레임씩 돌며 보인다. `-frames 360 -at 30,90,150,210,270,330`),
  `scenemap`(장면 맵 하나를 장면 카메라 배율로 보인다. `-stage S_castle_out`처럼 맵 ID를 준다).
- 맞는 데모가 없으면 `internal/gui/uidemo_<이름>.go`를 추가해 `init()`에서 `demos["이름"]`에 등록한다. `cmd/_uidemo`는 같은 데모를 창으로 띄운다.
- 실제 게임 창에서는 `F12`가 현재 프레임을 `reports/gui/screen-NNNNNN.png`로 저장한다(`-audit <dir>`로 위치 변경, `-shots 600,1200`은 자동 진행 중 그 틱에 저장).
