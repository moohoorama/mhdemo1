# 전투 UI

범위: 전투 화면의 HUD 패널, 명령 흐름, 팝업·모달, 피해 숫자·상태 아이콘·턴 배너·말풍선, 배치 화면, UI 배율, 화면 캡처 방법.
기준: 값이 다르면 `internal/gui/*.go`를 따른다(패널 `hud_panel.go`, 명령 `command.go`, 창 `windows.go`, 배율 `skin.go`).

규칙·공식은 [logic-combat.md](logic-combat.md), 일기토 화면은 [presentation-duel.md](presentation-duel.md), 적 페이즈 재생은
[presentation-replay.md](presentation-replay.md), 이야기 장면·대화창은 [presentation-scene.md](presentation-scene.md)에 있다.
확정한 연출 시안과 타이밍 기준은 [ui-mockup/README.md](ui-mockup/README.md)다. 화면의 글자는 한국어만 쓴다(한자 인장·한자 메뉴 없음).

## 좌표와 UI 배율

- 좌표계는 둘이다. UI px(HUD·창·대화·배너)와 월드 px(타일·유닛·이펙트, 카메라 줌이 위에 곱해진다). 가로세로 비율은 같다.
- `base = min(창폭/1280, 창높이/850)`이다. 월드 px은 `base`, UI px은 `base × UI 크기`다. 창이 1280×850과 다른 모양이면 레터박스 없이
  더 많은 맵과 UI 캔버스(`uiW×uiH`)가 보인다.
- UI 크기는 설정의 `UI 크기`이며 80·100·115·130·145·160% 중 하나다(`settings.json`의 `ui_scale`, 0이면 기본값).
  기본값은 데스크톱 100%, Android 130%(`gui.DefaultUIScale`)다. 한 번에 모든 UI가 같이 커진다.
- 맵 위 한 점에 붙는 UI(명령 메뉴, 공격 예측, 피해 숫자, 말풍선)는 위치를 월드 좌표에서 따와 `worldToUI`로 UI 공간에 옮겨 그린다.
- 창·타이틀·출전 준비·결과처럼 1280×850 설계로 짠 화면은 `inFrame`/`popup`이 한 장에 그린 뒤 가운데에 놓고, 화면이 작으면 줄인다.
- 타이틀 배경은 대화창과 같은 용무늬(`dragon.png`, 청록)가 대각선으로 천천히 흐르고 가장자리가 어둡다.
- 맵 에디터와 일기토 감상 화면은 1280×850 고정 캔버스를 가운데에 그리고 UI 100%로 고정한다(`fixedLayout`).
- 글꼴은 `assets/fonts/`의 `NotoSansKR`(UI 글자), `NanumBrushScript`(피해 숫자·턴 배너·첫 등장 이름의 붓글씨), `NotoSerifKR`(대화창·턴 배너 부제)다.
- 입력은 마우스·터치 공용이다. 한 손가락은 클릭·드래그, 두 손가락은 지도 이동·핀치 확대(`pointer.go`), Android 뒤로 가기는 `Esc`와 같다.

## 전투 화면

전투 중 맵이 창 전체를 쓴다. 위에 덮는 것은 우상단 HUD 패널 하나와 맵 위 요소(커서 카드, 명령 메뉴, 예측 창, 알림)뿐이다.
상단 바·이름패·하단 로그·지형 패널은 없다. 전투 HUD에는 단축키가 없고 모든 조작이 클릭으로 된다.

그리는 순서는 맵 계층(`layerMap`) 다음 UI 계층(`layerUI`)이다. 일기토 전환은 두 계층을 따로 흐리게 한다.

### 카메라

- 이동: 왼쪽·오른쪽 버튼 드래그, 창 가장자리(8px), 화살표 키. 드래그 중 4px 넘게 움직이면 이동이고, 아니면 클릭이다.
- 확대: 1·2·4배 세 단계이고 전장은 2배로 연다. 휠은 한 단계씩 오가며 전환은 0.5초이고 전환 중 휠 입력은 건너뛴다.
  핀치는 손가락을 벌린 만큼 따라가다가 떼면 가장 가까운 단계로 맞춰 붙는다(`zooms`, `nearestZoom`).
- AI 진영 차례와 그 재생 동안에는 이동·확대·미니맵 클릭·일람 행 이동이 모두 잠긴다(`cameraLocked`). 클릭으로 부대를 고르는 것은 된다.
- 다른 곳에서 부르는 이동: 일람 행 클릭(`focusOfficer`)은 부드럽게 이동하고, 말풍선·적 페이즈는 아래에 적었다.
- 전장이 처음 만들어질 때 이미 1턴 아군 차례의 전투 단계이면(1턴 자동 저장 불러오기 등) `작전 개요` 모달이 자동으로 열린다. 이벤트 `goals`가 목표를 바꾸면 재생이 그 이벤트에 이르렀을 때 다시 열린다.
  배치를 거쳐 시작하는 흐름에서는 자동으로 열리지 않으며 `기타` 탭에서 연다.

### HUD 패널

위치는 오른쪽 위(오른쪽 12px, 위 8px), 폭 320이다. 구성은 머리줄, 탭 줄, 탭 내용이다. 높이는 탭 내용이 정하고 바뀔 때 부드럽게 늘고 준다.

- 머리줄(36px): 접기 버튼, `○○군 차례`(아군은 군주 이름, 적은 `적군 차례`, 동맹은 `동맹군 차례`)와 턴(`N턴`, 제한이 있으면 `N/M턴`),
  `진영 종료` 버튼. 버튼은 아군 차례에 재생이 끝났을 때만 눌린다. 행동하지 않은 부대가 남았으면 확인을 묻는다.
  AI 진영의 재생 중에는 규칙 상태가 이미 다음 진영으로 넘어갔어도 재생 중인 진영과 턴을 보인다(`shownTurn`).
- 접기: 머리줄의 삼각형으로 접으면 머리줄과 탭 줄만 남는다.
- 투명: 마우스가 패널 밖에 있으면 약 55% 투명으로 그린다. 클릭을 막는 영역은 그린 패널 영역뿐이다.
- 탭은 `미니맵`·`장수`·`일람`·`기록`·`기타` 다섯이다. 고른 탭은 `hudBase`에 남는다.
- `장수` 탭은 늘 누를 수 있다. 장수를 선택하면 자동으로 이 탭이 보이고, 선택한 장수가 없을 때 고르면 `선택한 장수가 없습니다`가 뜬다.
  선택 중 다른 탭을 누르면 그 탭을 잠깐 보기만 하고(`hudPeek`), `장수`를 누르면 돌아온다. 선택이 끝나면 `hudBase`(손으로 고른 탭, `장수` 포함)로 돌아간다.
- AI 진영(적·동맹) 차례가 되면 `기록`으로 바뀌고, 아군 차례로 돌아오면 이전 탭으로 돌아간다.
- 전투 단계가 아닌 때(대화·결과)는 그리지 않는다. 배치 단계는 아래 절을 본다.
- 패널 왼쪽 영역이 명령 패널의 오른쪽 한계다(`panelBounds`).

탭 내용은 다음과 같다.

| 탭 | 내용 | 높이 |
|---|---|---|
| 미니맵 | 맵 전체, 유닛 점(아군 파랑·적 빨강), 현재 화면 사각형. 클릭하면 카메라가 그 위치로 간다 | 미니맵 높이 + 40 |
| 기록 | 전투 기록. 줄 색, 휠·스크롤바, 아래 가장자리 18px를 끌어 높이 조절 | 기본 260(120~화면 한도) |
| 일람 | 부대 목록(아래) | 행 수에 맞춤, 화면 한도까지 |
| 기타 | `위협 범위`·`자동 전투`(아군 차례도 AI가 둔다) 토글(켜면 ●), `작전 개요`, `병력일람`, `메뉴` | 220 |
| 장수 | 선택한 부대(아래) | 400 |

**기록** 탭: 이벤트를 한국어 한 줄로 바꿔 쌓는다(`events.go`). 한 화면 프레임에 한 항목씩 나타나고 300항목까지 보관한다.
다른 전투로 넘어가면 기록과 대기 항목을 비운다. 읽는 위치를 올려 둔 동안 새 줄이 들어와도 그 위치를 지킨다.
색은 피해·격파(주홍)·회복·획득(초록)·행동 장수 이름(옅은 금색)·나머지(흰색)다. 설정의 `전투 기록`이 `주요 사건만`이면 상세 줄을 거른다.

**일람** 탭: 한 부대가 한 줄이다. 장수명·병력·병법치·명령(O/X)만 보인다. 필터는 `아군`·`적군`·`전체`(기본 아군).
머리 칸을 누르면 `무정렬 → 내림 → 오름`이 돌아간다. 퇴각한 부대는 맨 아래로 간다. 행을 누르면 카메라가 가고 그 부대를 선택하며,
명령할 수 있는 아군이면 명령 흐름이 시작된다.

**병력일람** 창: `기타` 탭의 `병력일람` 버튼으로 연다. 화면을 거의 채우는 오버레이이고 한 부대가 한 줄, 글씨는 17이고 모든 칸이 가운데 정렬이다.
같은 필터·정렬을 쓰고 보기 네 개를 고른다: `기본`(병종·레벨·병력·병법치·명령), `전투력`(공격·방어·정신·순발·사기·병법회복),
`열전`(통솔·무력·지력·민첩·운·매력), `장비`(무기·방어구·장신구·특성 수·기술 수·특성치). 휠로 스크롤하고, 행을 누르면 창을 닫고 그 부대로 이동한다.

**장수** 탭: 초상·이름·병종·레벨·상태(`동맹군 · AI`/`행동 완료`/`이동함`)·남은 특성치, 병력·병법치·경험치 막대를 보인다.
병력·병법치 옆의 `+n`은 지금 위치에서 다음 자기 차례에 회복할 양이다. 아래에 하위 탭 넷이 있다.
`능력`은 능력 육각형(공격·방어·정신·순발·사기·병력)과 상태 이상 글자, `특성`은 보유 특성 목록(누르면 설명 모달),
`장비`는 무기·방어구·장신구의 아이콘·이름과 특성 표식(누르면 특성 모달), `열전`은 여섯 능력과 열전 글이다. 육각형의 바깥선은 이 전투 부대의 최고치이고
흰 선이 현재, 회색 선은 상태 효과 적용 전 값이다.

### 맵 위 카드와 알림

- 커서 카드(`brief`): 커서가 칸 위에 있으면 오른쪽에 뜬다. 유닛이 있으면 이름·레벨·병력·병법치(아군은 경험치)를 위에, 지형 이름·좌표와
  지형 효과(병종 보정·이동 비용·회복)를 아래에 보인다. 대상을 고르는 단계에서는 예측 창이 대신한다.
- 칸 커서: 칸마다 맥동하는 마름모 테두리. 적을 선택하면 그 적의 위협 범위(빨강)를, `위협 범위` 토글을 켜면 적 전체의 범위를 겹쳐 그린다.
- 알림(`toast`): 화면 위쪽 가운데에 잠깐 뜬다. 오류, `슬롯 N 저장 완료`, `불러오기 완료`, `재생 속도 ×N`에 쓴다.
  전투 이벤트는 알림 없이 기록에만 남는다. 최대 4개이고 3.5초 뒤 사라진다.
- 왼쪽 위에 재생 속도 버튼(92×60) 하나가 늘 있어 지금 속도(`×N`)를 보이고, 누르면 `×1 → ×2 → ×4 → ×8 → ×1`로 돈다(`speedButton`). `F` 키와 같다.
- 그 오른쪽 `목표` 버튼은 목표 안내를 켜고 끈다(기본 켜짐, 꺼짐은 회색 글씨, 설정 `no_goal_guide`로 저장). 켜면 승리·패배 조건이 가리키는 것을 바닥(타일 위, 유닛·지형물 아래)에 선으로 그린다(`Engine.GoalMarks`, `field_goals.go`): 승리 조건은 초록, 패배 조건은 빨강. `defeated:X`는 X의 발밑 마름모, `at:X:N`은 지역 N의 바깥 테두리에 X가 아군이면 X의 발밑 마름모까지, 군주(유비)는 늘 빨강. 초록 마름모는 칸 크기, 빨강은 그보다 작아 한 유닛에 둘이 겹쳐도 보인다. 같은 목표에 `flag`·`round` 조건이 아직 안 섰으면 흐리게 그린다. 이벤트 `goals`가 목표를 바꾸면 선도 바뀐 목표를 따른다. 선은 천천히 맥동하고 걷는 유닛을 따라간다. 확인: `go run ./cmd/_uidemo-vm -ui goals -stage B01`.
- 승리 순간에는 가운데에 `승리` 띠가 2초 뜬다.

## 명령 흐름

아군 차례에 명령할 수 있는 아군을 누르면 시작한다(`order`: `move` → `menu` → `sub` → `target`).

```
부대 클릭 → 이동 범위(파랑) → 칸 클릭 → 임시 이동 → 행동 메뉴(공격·병법›·도구›·대기)
  ├ 우클릭/Esc: 한 단계 뒤로 (임시 이동이면 원위치)
  └ 공격/병법/도구 → 사거리(빨강)·대상 표시 → 대상에 마우스: 예측 창 → 클릭: 확정
확정 = 세션에 이동(있으면) → 행동 → 대기(남은 행동이 없으면)
```

- 임시 이동은 `core.Restore`로 만든 샌드박스 엔진에 적용하고 걷기만 재생한다. 메뉴의 합법 행동과 예측은 샌드박스에서 계산한다.
  취소하면 샌드박스를 버린다. 세션으로는 확정할 때만 간다.
- 이미 이동한 부대는 `menu` 단계에서 시작한다. 행동 메뉴는 유닛 옆에 위에서 펼쳐지고, 쓸 수 없는 항목은 흐리게 남는다.
  항목에 마우스를 올리면 설명이 뜬다. `병법`·`도구`는 옆에 하위 목록이 열린다(병법치·소지 수 표시, 공간이 없으면 왼쪽).
- 자기 대상 병법은 목록을 누르면 바로 확정한다. 일기토는 명령이 아니다. 정해진 상대를 공격하면 예측 창에 `일기토 발생`이 뜬다.
- 대상 단계에서 대상이 아닌 칸을 누르면 한 단계 뒤로 간다. 메뉴 밖 클릭도 같다. 범위 병법은 커서 기준 영향 칸을 색으로 보인다.
- 예측 창: 대상 옆에 뜨며 양쪽의 병력·병법치·경험치가 보통 타격과 치명 타격 뒤 어떻게 되는지, 명중·치명·2회 확률, 반격, `격파!`를 보인다.
- 모든 아군에게 명령을 내리면 `턴을 넘기겠습니까?`를 한 번 묻는다(턴마다 한 번).
- `Space`는 추천 한 명령(AI), `F`는 재생 속도, `Enter`는 재생 건너뛰기, `F5`/`F9`는 마지막으로 쓴 수동 슬롯의 저장·불러오기,
  백틱은 CLI 문법 입력줄이다. 나머지 전투 단축키는 없다.
- 레벨업으로 특성치가 쌓이면 `특성 학습` 창이 열리고 닫기 전까지 다른 명령은 받지 않는다([logic-growth.md](logic-growth.md)).

## 창과 모달

- 오버레이(`메뉴`·`저장`·`불러오기`·`설정`·`확인`·`장비`·`부관`·`부대`·`상점`·`병력일람`)는 쌓인다. 창에서 연 창은 그 위에 뜨고, 닫으면
  밑의 창으로 돌아간다(`부대` → `장비 변경` → 닫기 → `부대`). 맨 위 창만 입력을 받는다. 저장·불러오기를 마치면 모두 닫힌다.
- 모달(`작전 개요`·`레벨 업`·`특성`)은 재생이 끝난 뒤 순서대로 하나씩 뜨고 아무 곳이나 클릭하거나 `Enter`/`Space`로 닫는다. `Esc`는 오버레이·모달·행동 단계를 한 단계씩 닫고, 아무것도 없으면 메뉴를 연다.
- 창은 위에서 작은 오버슈트로 내려오며 가운데 선에서 펼쳐지고, 닫을 때는 말려 올라간다. 뒤 화면이 같이 어두워진다.
  클릭은 첫 프레임부터 최종 자리에 닿으므로 연출이 입력을 늦추지 않는다(`window_anim.go`).

### 장비 창

출전 준비의 `장비 변경`이 연다(`equipment_window.go`).

- 무기·방어구·장신구 카드 세 장. 카드마다 장비 아이콘(32 UI px, 빈 칸은 흐린 대표 아이콘), 이름, 그 장수에게 더하는 능력치(칸을 비웠을 때와 견준 값),
  특성 표식(분류 아이콘 + 이름, 착용 중 배울 수 있는 특성은 뒤에 `배움`)을 보인다. 누르면 설명 창(제목 `특기 · 방어` 식)이 뜬다.
  특성 아이콘은 모양이 분류(책략 두루마리·전법 교차한 무기·특기 메달), 색이 효과(공격 빨강·회복 흰색·강화 초록·약화 검정·방어 파랑·이동 노랑·책략술 보라)다
  ([logic-traits.md](logic-traits.md) 3.1.1, `trait_icon.go`). HUD 특성 탭·특성 모달·학습 창·출전 준비의 습득 특성에도 같은 아이콘이 붙는다.
- 카드를 누르면 그 칸의 고르기 창이 뜬다. 행은 `장비 벗기`(착용 중일 때), 착용 중인 장비, 창고의 장착 가능한 장비, 병종에 맞지 않는 장비(흐리게, 사유 표시) 순이다.
  행도 카드와 같이 아이콘·이름·수량·능력치·특성 표식을 보이고, 오른쪽에 지금 장비와 견준 변화(오름 초록, 내림 빨강)를 쓴다.
  목록은 휠이나 끌기로 스크롤하고, 누른 자리에서 끌지 않고 떼면 그 행을 고른다. `확인`이 장착/해제 명령을 보내고 `취소`·`Esc`가 닫는다.
- 능력치는 게임 사본에 해제·장착을 적용해 계산한다(리비전·장수·칸·장비별 캐시). `Esc`는 설명 창 → 고르기 창 → 장비 창 순서로 닫는다.
- `작전 개요`: 승리 조건, 패배 조건, 턴(현재/제한), 일기토 대진(세 건까지, 나머지는 `외 N건`).
- `설정`: AI 차례(동시에 보기/하나씩 보기), 전투 기록(상세/주요 사건만), 대사 속도(한 글자씩/즉시, 기본 한 글자씩), 재생 속도(×1·2·4·8), UI 크기, 데미지 배율·경험치 배율(둘 다 60·70·80·90·100%, 기본 80%). 항목 이름이 위에 있고 선택지가 아래 버튼 줄로 놓이며, 지금 고른 선택지는 눌린 채(금색 글씨)로 보인다. 조작 안내문이 붙는다.
- `저장`/`불러오기` 슬롯 목록은 [system-save.md](system-save.md)에 있다. 각 슬롯에 장·전투 이름·턴·저장 시각이 보인다.
- 결과 창: 승리는 부대별 레벨 변화·경험치와 최다 공훈, 획득 물품, `다음 이야기`를 보인다(직접 조작하는 아군만 5명씩 페이지).
  패배는 사유(군주 퇴각 또는 턴 제한 초과)와 `출전 준비부터 재도전`·`불러오기`·`시작 메뉴`를 보인다. 재도전은 [system-save.md](system-save.md)의 재도전 체크포인트를 쓴다.

## 맵 위 연출

### 밤

`Stage.Night`인 전투는 전장 위에 푸른 어둠을 깔고(`field_night.go`), 화염 칸(반지름 150 월드 px)·불씨 칸(95)·`Stage.Lights` 횃불(80) 둘레만
부드럽게 뚫고, 유닛마다 들고 있는 횃불처럼 작은 빛(62)을 둔다(누가 어디 있는지 보이게). 빛 둘레는 땅처럼 납작하고 조금씩 흔들리며, 불 위에는 주황 빛을 더한다. 불이 번지면 밝은 곳도 늘어난다. HP 막대와 상태 아이콘은
어둠 위에 그린다. 커서·효과·말풍선 같은 맵 위 연출도 어둠 위다.

### 유닛 막대와 상태 아이콘

HP 막대는 유닛 폭의 약 1.2배(24×7 게임 픽셀)이고 네 칸 눈금, 진영색 채움, 맞으면 남는 흰 잔상을 가진다. 얇은 병법치 줄이 그 아래에 붙는다.
막대 아래에 상태 아이콘이 한 줄로 나란히 붙는다(HP바 → MP바 → 아이콘 순서). 이상 상태는 9×9 도트
(독·속박·봉격·화상·혼란·봉책)이고, 강화·약화는 같은 종류에 위·아래 화살표 두 벌이다(공격 빨강·방어 파랑·정신 초록·순발과 사기 노랑·이동 흰색).
아이콘 원본은 `assets/graphics/status/icons.png`와 `icons.json`이다.

### 피해·회복 숫자

숫자는 붓글씨 느낌으로 크게 튀어나와 기울어진 채 자리 잡고 위로 흐른다. 피해는 주홍 숫자에 베기 자국·먹 튐·화면 번쩍임,
치명은 거기에 `치명` 글자와 금빛 고리가 붙는다. 회복은 `+N` 초록 숫자에 빛 입자가 오른다. 같은 유닛에 연달아 뜨면 줄을 나눈다.
숫자 크기는 카메라 줌을 따르고 UI 배율도 곱해진다.

### 턴 배너

`turn` 이벤트를 재생할 때 나온다. 화면이 어두워지고 먹 띠 두 줄이 왼쪽에서 쓸려 오며, `제N턴`이 붓글씨로 왼쪽부터 써지고,
`○○군의 차례`가 진영색으로 나타나 같은 색 밑줄이 그어진다. 약 2.6초이고 재생이 빠르거나 자동 전투이면 2배 빠르다.
낮은 화면에서는 높이에 맞춰 줄어든다.

### 말풍선

전투 이벤트의 대사는 해당 유닛 머리 위에 말풍선으로 뜬다(일기토 대사와 같은 10조각 풍선 렌더러). 풍선끼리 겹치면 위로 밀어 올리고,
화면 밖으로 나가지 않게 한다. 말하는 유닛들의 가운데로 카메라가 이동한다. 이야기 장면의 말풍선(말하는 동안 점, 감정 표시)은
[presentation-scene.md](presentation-scene.md)에 있다.

### AI 진영 차례

AI 진영(적·동맹)의 차례는 규칙이 한 번에 다 정하고(`ResolvePhase`), 화면은 보이는 곳에서만 재생한다(`ai_view.go`).

- 행동은 앞서 보여야 할 행동(`After`)이 끝났고, 그 행동이 닿는 칸(출발·이동·대상)이 모두 화면 안이며 HUD에 가리지 않을 때 시작한다.
  화면 밖 행동은 기다린다.
- 재생 중인 행동이 없는데 화면 안에 시작할 행동도 없으면, 시작할 수 있는 행동 중 카메라에 가장 가까운 것의 칸 가운데로 카메라가 옮겨 가고,
  도착하면 그 행동이 (다 들어오지 않아도) 시작한다. 그 주변의 다른 부대도 함께 움직인다. 카메라 이동은 재생 속도를 따른다.
- 설정 `AI 차례`: `동시에 보기`(기본)는 화면 안의 행동을 0.2초 간격으로 겹쳐 시작하고, `하나씩 보기`는 앞 행동이 끝나야 다음을 시작한다.
  둘 다 저절로 이어지며 적·동맹에 똑같이 쓴다.
- 전투 기록은 행동이 시작될 때 쓴다. 건너뛰면(`Enter`) 남은 행동의 기록을 한꺼번에 쓴다.
- 병력이 나타나거나 불 같은 지형이 바뀌면 그 장면 전에 카메라가 먼저 그곳으로 간다. 차례 배너와 HUD 머리는 진영 이름(`Armies`의 `Name`,
  없으면 진영색 이름 + 군)을 그 진영색으로 쓴다.

## 출전 배치 화면

출전 준비에서 `출  전`을 누르면 배치 단계로 간다. 이 단계에는 HUD 패널이 없다. 강제 출전 스테이지(`Stage.Forced`)는 이 화면 없이 바로 전투로 들어간다.

- 위에 40px 막대(`아군 배치 · 맵 이름   배치 N / M`)와 우상단 `메뉴` 버튼, 우상단에 미니맵이 있다. 아래 212px(`Height/4`)가 장수 카드 줄이다.
- 카드(폭 172)는 초상·이름·레벨·병종·상태(`미배치`·`배치됨`·`선택`)를 보인다. 가로 스크롤은 하단 휠이나 양끝 `‹` `›` 버튼이다.
- 카드를 고르면 맵의 배치 가능 칸이 1초 주기로 맥동한다. 칸을 누르면 배치하고, 배치한 장수나 카드를 다시 누르면 해제한다. 커서가 배치 가능 칸에
  있으면 그 병종 그림이 미리 보인다. 고정 아군은 카드에 나오지 않는다.
- 모두 배치하면 `전투 시작 Enter`가 눌린다. `Tab`은 다음 미배치 장수, 우클릭·`Esc`는 선택 취소, `Space`는 추천 한 명령이다.
- 메뉴에서 저장·불러오기가 된다.

## 화면 캡처

화면은 코드만 읽고 짐작하지 말고 캡처로 확인한다. `cmd/_uidemo-vm`은 `internal/gui/uidemo_*.go`의 이름 붙은 데모를 창 없이 재생해
PNG 프레임이나 60fps MP4로 저장한다. `ver5/`에서 `caffeinate -d -i`로 감싸 실행한다.

```sh
caffeinate -d -i go run ./cmd/_uidemo-vm -ui dialogue -frames 300 -at 30,96 -mp4 reports/uidemo/dialogue.mp4
caffeinate -d -i go run ./cmd/_uidemo-vm -ui uiscale -frames 760 -size 2400x1080 -uiscale 160 -at 380,720
caffeinate -d -i go run ./cmd/_uidemo-vm -ui uiscale -frames 760 -sheet -at 260,380,720
```

- `-ui` 데모 이름, `-frames` 재생 프레임 수(1프레임 = 1/60초), `-at 30,96`은 저장할 프레임, `-every N`은 N프레임마다 저장,
  `-mp4`는 모든 프레임을 MP4로, `-size 2400x1080`은 화면 크기(폰), `-uiscale 160`은 UI 크기(%), `-stage`·`-duel`은 데모가 쓸 전투·일기토.
  기본 출력은 `reports/uidemo/<ui>`다.
- `-sheet`는 기준 화면 넷(폰 2400×1080 130%·160%, 4:3 태블릿 2048×1536 130%, 데스크톱 1280×850 100%)에서 같은 프레임을 찍어 한 장에 놓는다.
  UI를 고친 뒤 이 네 화면에서 겹침이 없는지 본다.
- 데모: `uiscale`(이야기와 전투 HUD, 폰 배율 확인), `popups`(타이틀·창·모달·출전 준비), `title`(타이틀 화면에 머묾), `equip`(장비 창·고르기·특성 설명, `-frames 335 -at 100,160,200,240,280,330`), `hudpanel`(패널 탭), `menu`(명령 메뉴),
  `damage`, `turn`, `dialogue`, `intro`, `deploy`, `duel`, `editor`, `aiturn`·`aiturn-one`(아군 진영 종료 뒤 동맹·적 차례를 동시에/하나씩 보기로 재생, `-stage B02`), `outside`(맵 밖 지형), `fonts`,
  `fire`(불씨·화염 칸), `marks`(책략 치명타 흔적 불씨·물웅덩이·돌무더기를 초원·황무지에 십자로 깔고 가까이 본다. `-frames 210 -at 25,55,85,115,145,175,205`), `mapfx`(1장 맵에 성문·울타리·불타는 숲·마을·성벽, 그을음, 다리 온전·손상·파괴를 그려 넣고 카메라가 60프레임씩 돌며 보인다. `-frames 360 -at 30,90,150,210,270,330`),
  `scenemap`(장면 맵 하나를 장면 카메라 배율로 보인다. `-stage S_castle_out`처럼 맵 ID를 준다).
- 맞는 데모가 없으면 `internal/gui/uidemo_<이름>.go`를 추가해 `init()`에서 `demos["이름"]`에 등록한다. `cmd/_uidemo`는 같은 데모를 창으로 띄운다.
- 실제 게임 창에서는 `F12`가 현재 프레임을 `reports/gui/screen-NNNNNN.png`로 저장한다(`-audit <dir>`로 위치 변경, `-shots 600,1200`은 자동 진행 중 그 틱에 저장).
