# 6장 진영 대화 A안 반영

사용자 선택: `docs/story-ch06-camp-options.html` A안. 고정도 지급 뒤 조조·원술 대화와 여포 급보 사이의 막사 이동·암전을 없애고, 조조의 칭찬을 원술이 선봉 추천으로 되받는 인과를 한 장면으로 보여 준다.

## 변경 범위

- `assets/scenario/hero/story06.json`: A안 대사와 입장·전령·시선·수락·퇴장 서술. 기존 `c06-start`부터 이어지는 진행 순서와 출진 흐름을 유지하고 중간 `c06-council` 장면 노드는 제거한다.
- `assets/scenes/ch06.json`: 두 장면을 `S_coalition_camp`의 한 장면으로 합친다. 원소·조조·원술·유관장·전령, 시선을 피하는 교모·한복, 막사 위병 둘. 등장·시선·양보·퇴장 동작과 카메라를 지정한다.
- `assets/scenario/hero/explore06.json`: A안의 후속 조조·유비 대화를 반영하고 “저 안” 같은 실내 회의 전제 표현을 고친다. 원소의 수정된 `(40,40)` 배치는 유지한다.
- `docs/fullstory.md`·`data-speech-style.md`: 확정 대본 및 새 대사 예시를 동기화한다. 안량·문추 이야기는 기존 선택 대화에 남긴다.
- `assets/scenes/ascii/c06-start.txt`·`c06-council.txt`: 옛 전체 칸 배치·없어진 실내 장면의 도면 제거. 현재 규칙의 .25/.75 좌표는 옛 `scene_ascii dump`가 거부하므로 실제 배치를 반올림하지 않고 이 문서의 좌표표·도면을 쓴다.
- `docs/story-ch06-camp-options.html`·`history.md`: A안 선택·적용과 전후 게임 캡처·검증을 기록한다.

전투 앞뒤의 대사·퇴각 결과·고정도 조건을 대조했다. B05/B06 전투 명령·적 수·직급·보상·승리 조건은 변경하지 않는다. 고정도 유무와 무관하게 6장 대화가 이어진다.

## 무대와 방향

낮, 맹주의 큰 막사 앞 십자 대로. 아래 표는 **게임 칸**, 작은 칸은 `(2u+0.5, 2v+0.5)`로 대응한다. 원소는 막사 쪽, 유비 일행은 큰길로 들어온다. 위병은 문 양옆을 지킨다. 화로의 작은 칸 `(37,38)`·`(42,38)`에는 사람을 두지 않는다.

| 배역 | 처음 자리 | 방향·역할 |
|---|---|---|
| 원소 | (19.75,17.25) | SE로 제후들을 보다가 전령이 오면 SW |
| 조조 | (22.25,16.25) | 원술을 SE로 봄. 끝에 옆으로 물러남 |
| 원술 | (23.75,16.25) | 조조를 NW로 봄. 추천할 때도 조조를 봄 |
| 유비 | 큰길에서 (23.75,18.25)로 입장 | NW. 수락할 때 (22.25,18.25)로 나서 원소를 NW로 봄 |
| 관우 | 큰길에서 (25.25,17.25)로 입장 | NW |
| 장비 | 큰길에서 (25.25,18.75)로 입장 | NW |
| 교모·한복 | (17.25,17.75)·(17.25,18.75) | SE로 원소 쪽을 봄. 선봉 물색 때 시선을 피함 |
| 위병 둘 | (18.75,16.75)·(20.75,16.75) | SW로 길을 경계 |
| 전령 | 남쪽 큰길 (19.75,29.75)에서 (19.75,18.75)로 | NE로 원소에게 보고, 뒤에는 (18.75,19.75)로 비킴 |

```
                         맹주의 막사
                    위병             위병
                             원소             조조 ↔ 원술
                  교모                                  관우
                  한복        ↑ 전령                    유비 ← 큰길
                                                           장비
                         화로       화로
                              남쪽 길
```

## 비트 순서

1. `a1`: 유비·관우·장비가 큰길에서 서로 다른 줄로 걸어온다. 원술은 이들을 보고, 조조가 맞아 돌아선다.
2. `a1b`~`a3`: 원술의 빈정거림 → 조조의 칭찬 → 원술의 분노. 조조·원술을 마주 보게 한다.
3. `a4`~`b2`: 전령이 남쪽 큰길로 달려들고, 모두 보고를 향해 돈다. 원소가 되묻는다. 맵·장면 ID·시간대 전환이 없다.
4. `b2b`~`b3`: 원소가 제후를 둘러보고 교모·한복이 시선을 피한다. 전령은 옆으로 비킨다.
5. `b4`~`b5b`: 원술이 유비를 추천하면서 조조를 본다. 조조는 원술을 보며 유비의 뜻부터 묻는다.
6. `b5c`~`b6`: 유비가 앞으로 나서 수락하고, 원소가 선봉을 정한다.
7. `b7`: 유비가 예를 표하고 조조가 원술을 본 뒤 길을 내준다. 마지막 줄 뒤 제후들이 길을 따라 물러나고 유비 일행이 남는다. 탐험 재배치에는 기존 종료 전환만 사용한다.

## 검증

원본 장면을 먼저 실제 `explore` 데모로 캡처했다. 적용 후 배치 검사·장면 데이터/보행/문구 검사·관련 엔진 시험을 실행하고, 5장 보상 유무에서의 6장 진입과 탐험·출진까지 진행을 확인한다. `storydb.py index`·`jargon`을 실행한다. PC·폰 게임 캡처와 영상으로 시선·걸음길·중간 암전 부재를 확인하고 선택 HTML에 전후 화면과 도면을 붙인다.
