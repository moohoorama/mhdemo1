# Windows 단일 실행 파일

- 기존 파일 경로 기반 로더를 유지하기 위해 빌드된 Windows release 실행 파일 뒤에 에셋 ZIP을 붙인다. `make windows-portable-plain`은 garble 없이 단일 exe를 만든다.
- 실행 시 exe 해시로 구별되는 사용자 캐시에 에셋을 원자적으로 풀고 그 경로에서 읽는다. 저장·설정은 기존 사용자 설정 폴더에 그대로 둔다. 임시 디렉터리와 동시 실행을 처리하고 ZIP 경로 이탈을 거절한다.
- 설치형 빌드 및 명시적인 콘텐츠·폰트 경로는 유지한다. 압축 구성과 추출·경로 검증을 시험하고 Windows 파일 형식과 아이콘을 검사한다.
