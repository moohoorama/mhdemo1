# 잘못 누름·취소 효과음 전수 조사

요청 범위는 현재 소리가 나는 조건의 조사다. 게임 동작을 바꾸기 전에 `ui-denied`의 모든 재생 지점·상위 오류 알림·비활성 메뉴 생성 경로와 취소음 원본을 쓰는 `close`를 추적한다.

1. LSP 참조와 소스 검색으로 직접 재생, 오류 알림, 비활성 메뉴 및 `close` 호출을 전부 목록화한다. 일반 요청 실패는 session·core·storage 오류를 함께 조사한다.
2. 조사 시험으로 비활성 메뉴 클릭의 실제 효과음 순서, 모든 탐험 영역의 8방향 위치 기록, 모든 탐험 출구, 모든 출진 질문의 기준 화면별 배치와 일기토 목록을 확인한다. 장면 종료·자동 처리·확인 창 경로는 기존 회귀 시험도 실행한다.
3. 정상 거부, 시스템 오류, 정상 동작에서 부적절하게 들릴 수 있는 소리를 구분해 `docs/audit-denied-sound.md`에 조건·소스 위치·재현 증거·미검증 범위를 기록한다. 화면 관련 판단은 게임 캡처로 확인한다.
4. `docs/history.md`에 조사 파일과 목적 및 결과를 남긴다. 이번 조사에서는 발견한 동작을 임의로 변경하지 않는다.
