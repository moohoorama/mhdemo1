# 일기토 규칙

이 문서가 맡는 범위: 일기토가 발생하는 조건, 결과의 적용, 경험치, 저장 상태. 연출은 맡지 않는다.
값이 다르면 `internal/core/formation.go`(`duelFor`, `duel`)와 맵 데이터(`assets/data/maps/*.json`의 `Stage.Duels`)가 기준이다.

연출 규격(비트·대사·렌더링)은 [presentation-duel.md](presentation-duel.md), 맵 데이터 구조는 [data-map.md](data-map.md), 경험치 일반은 [logic-growth.md](logic-growth.md)가 맡는다.

## 1. 발생 조건

- 스테이지가 지정한 두 장수(`Ally`·`Enemy`) 중 한쪽이 인접(거리 1)한 상대를 일반 공격이나 물리 병법으로 치면, 그 공격 대신 일기토가 벌어지고 공격한 쪽의 행동이 끝난다. 적이 먼저 공격해도 같다.
- 책략·회복·버프 같은 비물리 병법과 거리 2 이상의 공격은 일기토를 일으키지 않는다.
- 같은 일기토는 한 번만 벌어진다(`Executed`의 `duel-<ID>`). 공격은 비용(MP)을 쓰지 않고 일기토로 대체된다.
- 엔진은 명령이 일기토를 일으키는지 `DuelFor`로 미리 알려 준다. 화면 표시는 UI가 맡는다.
- 일기토가 끝났는지는 전투 이벤트 트리거(`duel`)의 조건으로 쓰인다.

## 2. 결과

결과는 맵 데이터가 정한다. 무작위 판정은 없다.

| 필드 | 의미 |
|---|---|
| `Outcome` | 아군 기준 승·패·무승부. 연출을 정한다 |
| `AllyResult`·`EnemyResult` | 각 장수의 결과. `stay`(잔류), `retreat`(퇴각), `death`(영구 사망) |
| `Text` | 전투 로그에 남는 문장 |

- 퇴각·사망한 쪽은 병력이 0이 된다. 살아남은 쪽에 퇴각 추격 특성이 있으면 추격이 발동한다.
- 일반 퇴각과 영구 사망은 다르게 저장한다. 사망한 장수는 이후 출전하지 못한다. 플레이어 쪽 사망자의 장비는 창고로 가고 부관 관계는 풀려 부관은 명단에 돌아온다.

## 3. 경험치

- 일기토에서 살아남은 아군(AI 조종 제외)은 레벨 한 칸(경험치 +100%)을 받는다. 부관이 있으면 주장이 받은 양의 85%를 받는다.
- 일기토는 이벤트 키로 한 번만 확정되므로 재로드해도 중복 지급되지 않는다.

## 4. 연출과의 관계

연출은 규칙 상태와 난수를 바꾸지 않는다. 화면 없는 시뮬레이션도 같은 결과를 따른다.
