# 특성 대결 시뮬레이션

범위: 특성 하나가 싸움을 얼마나 바꾸는지 같은 병종끼리의 대결로 잰 방법과 결과(2026-11-01). 특성 규칙은 [logic-traits.md](logic-traits.md), 피해·명중은 [logic-combat.md](logic-combat.md)가 맡는다. 도구는 `cmd/_traitsim`(임시)이다.

## 1. 재는 법

- 같은 병종끼리 평지(`i--`, 지형 배율 1)에서 1:1·3:3·5:5로 붙이고, 한쪽 전원에게만 특성 하나를 준다. 선행 특성이 있으면 함께 준다(독려강화는 독려와 함께).
- 양쪽 모두 대결용으로 똑같이 만든 장수(일반 병사 틀, Lv30)다. 병종 특성 계획(`Class.Plan`)·승급·회복 아이템은 끈다. 병종에 맞는 기본 무기(보너스 1, 특성 없음)를 든다.
- 병종 특성은 그 특성을 배우는 병종으로 싸운다(무쌍술은 전차대, 돌진·충격은 중기병, 원시는 발석거). 장수 개인 특성은 그 계열의 첫 병종(경보병·경기병·궁병·서생)으로 싸운다.
- 양쪽 모두 게임의 적 AI(`ai.Player = nil`, 탐욕 정책)로 움직인다. 병법치는 가득 찬 채 시작하고, 공격하지 않고 차례를 끝내려는 유닛은 아직 걸리지 않은 자기 강화 책략(대비·장전·집중·반격 등)을 쓴다. 이 버프 사용은 도구 안에서만 그렇고 게임 AI는 그대로다.
- 진형은 두 가지다. 붙임: 같은 편이 세로로 붙어 선다. 띄움: 한 칸씩 띄운다.
- 두 줄 사이 빈 칸은 6칸과 12칸을 섞는다. 칸마다 시드 30 × 특성 쪽 선공/후공 × 거리 2가지 = 120판.
- 병력 차이: 끝났을 때 특성 쪽에 남은 병력 비율 − 상대에 남은 병력 비율(%p). 특성이 없으면 0, 승률 50%다. 선공/후공을 반씩 섞으므로 먼저 때리는 쪽의 이점(같은 조건에서 80~95%)이 지워진다.

```text
go run ./cmd/_traitsim -class light_infantry,light_cavalry,archer,scholar -j 6 -json out.json
go run ./cmd/_traitsim -class chariot -traits sweep_art -sizes 3 -formations tight -show   # 한 판의 타격 기록
```

## 2. 읽을 때 주의할 점

- AI는 피해를 주는 기술·회복·(도구가 시킨) 자기 강화만 쓴다. 아군 버프(독려)·방해 책략(교란·도발)·무쌍·난사·연발은 거의 쓰지 않아 0으로 나온다. 약해서가 아니다.
- 기습·돌진·충격·일기당천처럼 움직임이나 고립에 따라 세지는 특성은 AI가 일부러 노리지 않아 실제보다 약하게 나올 수 있다.
- 같은 병종 거울전이라 상성 특성은 과장되거나 0이 된다. 노기병끼리의 간접공격면역(+99%p)은 상대의 공격이 모두 원거리라 한쪽이 한 대도 못 맞히는 것이고, 공성·침착·응징은 평지 거울전에서 발동할 일이 없다.
- 최대 병법치는 레벨이 아니라 병종 `MPBase`와 통솔로 정해진다. 일반 병사의 경기병은 47이라 무쌍(54)을 쓸 수 없다. 전차대(59)는 쓸 수 있지만 AI가 일반 공격을 고른다.

## 4. 읽은 것

- 확정형 공격 특성이 가장 세다. 필살(경기병 +40%p, 전차대 +27%p), 연전(+35%p).
- 회복이 세다. 구휼강화·구휼확산(방술사 +40%p대), 구휼(서생 +30%p), 의협(최대 병력 10%, +19%p).
- 주변까지 치는 특성은 붙인 진형에서만 산다. 사방격(발석거) 띄움 0 → 붙임 +20%p, 화계확산 +7 → +31%p, 대각공격 +5 → +16%p, 도술 +2 → +10%p.
- 먼 거리에서 첫 사격을 앞당기는 특성이 의미 있다. 저격(궁병) +19%p, 관통(연노병) +20%p, 원시(발석거) +31%p.
- 약한 쪽: 일당백·일기당천(+3%p), 위압(+1%p), 돌진(+5%p), 충격(0). 조건이 잘 맞지 않는다.

## 5. 1차 측정(Lv15, 띄움, 거리 2·6칸)과 다른 점

1차는 Lv15에서 모든 특성을 계열 첫 병종으로, 띄운 진형만 쟀다. 그때 플레이어 쪽 AI(`ai.Player`)가 적 AI보다 약해 양쪽을 적 AI로 맞췄고, 문관이 병법치 0에서 시작해 책략을 못 써 가득 찬 병법치로 시작하게 했다. 1차에서 양생+의협이 +42%p로 가장 셌는데(양생만 +18%p), 이것이 옛 의협을 지우고 양생을 의협으로 바꾼 계기다.

## 6. 측정 뒤 바뀐 것

이 결과를 보고 데이터가 바뀌어, 위 표의 일부는 지금 데이터와 다르다.

- 관우의 `Learn`에서 연전을 뺐다(필살 +40%p·연전 +35%p로 관우만 두드러짐). 연전 특성 자체는 남아 있다.
- 수계 책략의 물가 조건을 지웠다. 위 표에서 수계 계통이 0인 것은 그 조건 때문이며, 지금은 평지에서 화계·지계와 비슷하게 쓰인다(서생 3:3 붙임 수계 +5.0%p, 화계 +5.5%p).
