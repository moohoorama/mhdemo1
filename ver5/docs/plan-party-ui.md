# 장수·부대·특성 UI 개편

시안: https://claude.ai/artifact/NoGMT68ae94T4zaANt8nXZ (폰, dp 기준). 이 문서가 구현 기준이고, 시안과 다르면 이 문서를 따른다.

## 왜

- 화면마다 조작·출처·좌우·위아래 문법이 달랐다(관리 창, 출전 배치의 장수 창, HUD 장수 탭, 부관 창, 장비 창, 레벨 업 학습).
- 폰에서 누르고 읽을 수 없는 크기였다. 2400×1080 폰은 914×411dp인데, 버튼이 약 25dp, 글자가 약 11dp였다.
- 출전 준비가 엔진에는 있는데 GUI가 건너뛰고(`startSortie`) 배치 화면이 출전·장비·부관을 함께 맡아 아래 띠가 맵을 덮었다.

## 크기 규칙 (UI px, 폰 914×411 기준)

- 누르는 것(버튼·줄·탭·칩): 높이 48 이상. 칩은 보이는 높이 40 + 위아래 여백 4.
- 글자: 본문 14, 이름 16, 제목 18~20, 가장 작은 글자 12. 12보다 작은 글자는 없다.
- 목록 줄 56(얼굴 40, 이름 16, 아래 줄 12). 표 줄 48. 누르지 않는 표 줄은 24.
- 화면 전체를 쓰는 판(시트): `min(uiW, 1180) × min(uiH, 720)`, 가운데. 914×411에서도 들어가게 짠다.
- 할 일 버튼은 판의 오른쪽 아래 한 줄. 맨 오른쪽이 주 행동(금색), 그 왼쪽이 닫기·취소. 판의 오른쪽 위에는 버튼을 두지 않는다.
- 전투·배치: 왼쪽 위 보조(배속·확대·전투 목표·메뉴), 오른쪽 위 차례 + 진영 종료(배치는 `배치 n/m` + 전투 시작), 오른쪽 아래 정보 패널(폭 300).

## 흐름

스토리·탐험(장수 창: 보기·특성·장비) → 출전 준비(출전·부관·장비·특성) → 출진 → 배치(자리만) → 전투(레벨 업 때만 특성 학습).

- 출전 준비는 노드 종류 `battle`일 때 그린다. 엔진은 이 단계에서 `deploy`·`equip`·`unequip`·`deputy`·`undeputy`·`learn`을 받는다(`prepare`, `CanLearn`).
  `출진`이 지금의 `startSortie`(`deploy` + `start`)를 보낸다. 강제 출전 스테이지(`Stage.Forced`)는 지금처럼 바로 넘어간다.

## 조각 (여러 화면이 같이 쓴다)

| 조각 | 내용 | 쓰는 곳 |
|---|---|---|
| 장수 줄 | 얼굴 40, 이름, 병종·레벨, 특성치(배울 것 있으면 초록) | 장수 창, 출전 준비(앞에 상태 칸), 부관 후보 |
| 장수 상세 탭 | 전투력(육각형·전투 능력·열전), 특성(선반 셋), 열전, 장비(슬롯 셋) | 장수 창, 레벨 업 학습, 합류 |
| 부대 상세 탭 | 전투력(가중치·혼자/보정/부대), 특성(주장 / 부관 나눠 보기), 열전, 장비 | 출전 준비, 전투 "자세히"(버튼 없음) |
| 특성 선반 | 고유·병종·장비(+부관 고유·병종). 배움 실선, 배울 수 있음 초록 점선, 못 배움 어둡게. 칩을 고르면 아래 설명 | 위 둘, 레벨 업 |
| 특성 창 | 아이콘·이름·분류·출처·설명, 배우기 또는 못 배우는 이유 | 모든 칩(길게 누름/오른쪽 클릭) |
| 간단 보기 | 이름·부관 얼굴·병력/병법치 막대·육각형·특성 아이콘 | 출전 준비 오른쪽, 전투 HUD 장수 탭 |

## 단계 (기능당 커밋 하나, 따로 되돌릴 수 있게)

1. 바탕: 크기 상수와 위젯(`mBtn` 48, 탭 줄, 목록 줄, 칩 40, 할 일 줄, 시트 판), 특성 선반·특성 창 조각.
2. 장수 창: 관리 창의 장수 탭을 목록 + 상세(탭 넷)로. 특성 배우기·장비 변경 가능. `표로` 보기(보기 넷). 소지품은 목록 머리의 버튼.
3. 출전 준비: 노드 종류 `battle`에서 새 화면. 상태 칸(출전 ↔ 대기, 부관·누구), 간단 보기, 장비·부관·특성·상세, 출진.
4. 부대 상세: 탭 넷, 전투력 탭의 부관 가중치와 혼자/보정/부대.
5. 부관 임명·장비 창: 목록 + 오른쪽 미리보기 + 할 일 줄로.
6. 배치: 아래 카드 띠를 없애고 오른쪽 아래 출전 부대 패널, 오른쪽 위 `배치 n/m` + 전투 시작, 왼쪽 위 보조.
7. 전투 HUD: 정보 패널을 오른쪽 아래로, 오른쪽 위는 차례 + 진영 종료, 왼쪽 위에 메뉴. `자세히 보기`는 부대 상세(버튼 없음).
8. 레벨 업·승급·합류: 레벨 업 창에 배울 수 있는 특성 칩과 `나중에`/`특성 배우기 ›`, 학습은 장수 상세 특성 탭. 승급은 새 병종 특성 칩, 합류는 장수 상세 열전 탭.
9. 문서: presentation-ui.md, history.md.

## 검증

- 단계마다 `go build ./...`, 관련 테스트(`deployment_test`, `modal_flow_test`, `layout_overlap_test`).
- `cmd/_uidemo-vm`으로 914×411에 맞는 화면(2400×1080, UI 262%)과 1280×850(UI 100%)에서 캡처해 겹침·잘림을 본다. 데모는 한 번에 하나씩.
- `TestNoOverlappingButtons`에 새 화면(장수 창, 출전 준비, 부대 상세, 배치)을 넣는다.
