# 전장 HUD 통합 패널

전투 화면이 가장자리 UI(상단 바, 명패, 우측 미니맵·정보창, 우하단 독, 좌하단 기록·지형 패널)로 가려진다.
우상단에 패널 하나를 두고 상황에 따라 내용을 바꿔 보여 주어, 맵을 거의 전부 되찾는다.
마우스 클릭만으로 모든 조작이 가능해야 한다(장기적으로 조이패드: LB/RB 탭 전환, 십자키 목록). 그래서 전투 HUD 단축키는 없앤다.

## 화면

```
┌ 우상단 패널 (폭 infoW=320) ──────┐
│ ● 유비군 차례 · 3턴  [진영 종료] │  머리줄: 항상 보임
├──────────────────────────────────┤
│ 미니맵 │ 기록 │ 일람 │ 기타 │ 장수 │  탭 줄 (장수는 선택했을 때만 켜짐)
├──────────────────────────────────┤
│ 탭 내용 (탭마다 높이가 다름)      │
└──────────────────────────────────┘
```

- 상단 바, 명패, 두루마리, 독, 좌하단 기록 패널, 지형 패널, 우측 열의 `lowScreen` 분기를 없앤다.
  패널은 화면 크기와 무관하게 우상단 한 곳이다. 맵 뷰포트는 화면 전체가 된다.
- 머리줄: `○○군 차례 · N턴`(제한 턴이 있으면 `N/M턴`)과 `진영 종료` 버튼.
  내 턴이고 `idle`일 때만 버튼이 눌린다. 나머지는 비활성. 적 턴에는 `적군 차례`와 비활성 버튼.
- 탭 전환은 클릭. 선택 중 상태 전이는 아래.

## 패널 상태

`hudTab`: `minimap` | `log` | `units` | `misc` | `unit`.

- `g.hudBase`는 사용자가 고른 일반 탭(처음 `minimap`). 탭을 누르면 바뀐다.
- 장수를 선택하면(`g.selected != ""`, 아군·적 모두) 표시 탭은 `unit`. 선택이 끝나면(완료·취소·해제) `hudBase`로 돌아온다.
  일람에서 장수를 골라 명령을 내리고 취소해도 일람으로 돌아와 이어서 고를 수 있다.
- 장수 선택 중에도 탭 줄은 그대로 보이고 `장수`가 5번째 탭으로 강조된다. 다른 탭을 누르면 선택은 유지한 채 그 탭을 잠깐 본다
  (`g.hudPeek`). 장수 탭을 누르면 돌아온다. 선택이 없으면 `장수` 탭은 비활성(회색)이다. 장수 탭을 직접 눌러 여는 건 안 된다.
- 적 턴에는 `log`로 자동 전환하고, 내 턴이 시작되면 `hudBase`로 복귀한다(적 턴 중 사용자가 탭을 직접 누르면 존중).
- 대화·결과·배치 등 `battle` 단계가 아닐 때 패널은 그리지 않는다(배치 단계는 기존 화면 유지, 미니맵만 이 패널 틀로 옮길지는 4단계에서 정한다).

## 탭 높이

탭마다 내용에 맞춘 높이를 쓰고, 상단에 고정해 높이가 바뀔 때 부드럽게 늘고 줄게 한다(`window_anim.go`의 이징 사용).

| 탭 | 높이 |
|---|---|
| 미니맵 | 미니맵 높이 + 여백 (지금 `minimap()`) |
| 기록 | 화면 높이 안에서 사용자가 끌어 조절(지금 `logHeight`와 같은 드래그), 내부 스크롤 |
| 일람 | `uiH - 24`까지, 내부 스크롤 |
| 기타 | 항목 수만큼 |
| 장수 | 내용 높이. 능력 탭 기준 고정, 특성·장비·열전은 내부 스크롤 |

장수 탭의 길쭉함은 `detailRect`가 `uiH-240`·`uiH-12`로 잡혀 내용 아래에 큰 빈칸이 생기는 것이 원인이다.
1단계에서 캡처로 확인하고 먼저 고친다.

## 탭 내용

### 일람
명패와 `부대 일람` 오버레이(`windows.go: unitList`)를 대체한다.

- 필터: `아군` · `적군` · `전체`. 기본은 아군.
- 보기: `기본` · `부대` · `열전` · `장비`. 한 행은 두 줄이고, 왼쪽 1×2칸은 부대명(1줄 이름, 2줄 병종), 오른쪽 3×2칸은 보기별 값 6개다.

| 보기 | 3×2 (윗줄 / 아랫줄) |
|---|---|
| 기본 | 병력, 병법치, 명령(O/X) / 레벨, 경험치, 위치 |
| 부대 | 공격, 방어, 정신 / 민첩, 사기, 회복 (`Stats`; 이름은 `statRows` 따른다) |
| 열전 | 통솔, 무력, 지력 / 민첩, 운, 매력 |
| 장비 | 무기, 방어구, 장신구 (이름이 길면 칸 안에서 줄임) |

- 머리줄도 같은 3×2 두 줄이다. 칸 하나가 정렬 버튼이며 삼각형도 칸마다 붙는다. 부대명 칸은 이름순.
- 병력 칸은 숫자 아래에 가는 막대를 깐다.
- 명령 가능 여부는 모든 보기에서 부대명 칸 오른쪽 위 점과 행 밝기로 보인다. 명령 열 정렬은 기본 보기에서 한다.
- 명령 가능한 부대는 밝게, 불가는 흐리게. 퇴각한 부대는 맨 아래에 흐리게.
- 열 머리를 누르면 `무정렬 → 오름 → 내림`. 오름은 위가, 내림은 아래가 뾰족한 삼각형(벡터로 그림).
- 정렬 기준 칸은 값을 굵게 쓰고 옅은 배경을 깐다. 정렬 중인 칸이 바뀐 보기에 없으면 무정렬로 돌린다.
- 행을 누르면 그 장수를 선택하고 카메라를 옮긴다(`focus`).
- 한 행이 두 줄이라 한 화면에 15행쯤 보이고 나머지는 내부 스크롤(적군이 많을 때).

### 기타
버튼 목록. 토글은 누르면 바로 바뀌고 켜짐 표시(●)가 붙는다.

- `위협 범위` (토글, `g.threatAll`)
- `자동 진행` (토글, `g.autoplay`)
- `작전 개요` (팝업)
- `메뉴` (기존 메뉴 오버레이: 저장·불러오기·설정·시작 메뉴·종료)

### 작전 개요 팝업
지금 있는 `objective` 모달(`windows.go: modalWindow`)을 확장한다. 전투 시작 때 자동으로 한 번 뜨는 동작은 그대로 둔다.

- 승리 조건, 패배 조건, 제한 턴(현재 턴 포함), 일기토 정보(이 전투의 `Duels` 목록).
- 이름을 `전투 목표`에서 `작전 개요`로 바꾼다(`overlayTitles`와 제목 문자열).

### 기록
`battleLogRect`/`drawBattleLog`를 패널 탭으로 옮긴다. 줄 색, 스크롤바, 높이 조절을 유지한다. `기록` 오버레이는 없앤다.

## brief 카드에 지형 정보

- 유닛 위로 마우스를 올리면: 지금처럼 부대 정보 카드 아래에 지형 정보.
- 유닛 없는 칸: 지형 정보만.
- `terrainPanel`과 좌하단 패널을 없앤다. 지형이 부대 병종에 주는 효과 줄(`terrainInfoLines`)은 그대로 쓴다.

## 없애는 것

- 입력: `U`, `L`, `T`, `P`(전투 중), `E`, `Tab`(다음 미행동 장수). 조작 안내문(`windows.go`)도 같이 고친다.
  남기는 것: Esc(취소·메뉴), Space(추천 명령), F(재생 속도), Enter, F5/F9, 백틱 — 모두 디버그·접근 보조용이다.
- 그리기: `topBar`와 `objectiveScroll`, `nameTags`/`tagIDs`/`maxTags`, `dock`, `terrainPanel`, 좌하단 기록, `lowScreen`/`dockRight`/`dockLeft`.
- 오버레이: `units`, `log`.
- `nameTags`를 지우면 `재생 ×N` 표시와 `menuButtonRect`(메뉴 버튼, 배치·타이틀에서도 쓴다)를 정리해야 한다.
  `menuButtonRect`는 배치 단계에서 쓰므로 그 단계가 끝나기 전에는 지우지 않는다.
- `docs/plans`의 이전 계획(`PLAN_battle-ui-refresh.md` 8·9번)은 되돌린 것이 아니라 대체된 것이다. 이 문서에 그 사실만 한 줄 남긴다.

## 맵 위 보조

- 패널이 열려 있는 영역은 카메라 가장자리 여백으로 처리한다: 클램프 영역 우측을 패널 폭만큼 넓혀, 맵 끝 칸도 패널 밖으로 밀어낼 수 있게 한다.
- 접기: 패널 오른쪽 위 작은 삼각형으로 접고 펴며, 접으면 머리줄과 탭 줄만 남는다.
- 마우스가 패널 밖에 있고 패널을 쓰지 않는 동안은 약 55% 투명으로 그린다. 투명·접힘 영역은 클릭을 막지 않는다(`g.block`을 그린 영역만 건다).

기능 하나에 커밋 하나. 각 커밋이 `go test ./internal/gui/... && go vet ./...`를 통과한다. 되돌리기는 뒤에서부터.

| # | 커밋 | 고치는 곳 |
|---|---|---|
| 0 | docs: 이 계획 | docs/plans |
| 1 | 장수 정보창 길쭉함 수정 | hud.go(detailRect, detail), 캡처로 전후 확인 |
| 2 | 통합 패널 틀: 머리줄, 탭 줄, 미니맵·기록·기타 탭, 장수 탭 자동 전환, 독과 단축키 제거, 적 턴 기록 전환 | 새 hud_panel.go, hud.go, battle_log.go, game.go, windows.go |
| 3 | 일람 탭(필터, 보기 4종, 정렬)과 명패·상단 바 제거 | 새 hud_units.go, top_bar.go, windows.go |
| 4 | brief에 지형 정보 합침, 지형 패널 제거 | hud.go |
| 5 | 작전 개요 팝업 | windows.go |
| 6 | 접기, 반투명, 카메라 가장자리 여백 | hud_panel.go, view.go |

데모: `ver5/internal/gui/uidemo_hudpanel.go`에 `hudpanel`을 등록한다. 장면: 일반 → 일람 → 장수 선택 → 취소 → 적 턴 → 접기.
`caffeinate -d -i go run ./cmd/_uidemo-vm -ui hudpanel -frames ... -at ...`로 PNG를 뽑아 확인하고, `-size 2400x1080 -uiscale 160`
(`-sheet`로 4개 기준 화면)에서도 패널이 화면 안에 들어오는지 본다.
