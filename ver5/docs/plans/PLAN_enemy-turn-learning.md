# 적 턴 중 아군 학습

적 공격으로 아군이 레벨업하면 `Learning`이 열리지만, 세션의 적 AI 반복문은
이를 AI 학습 명령으로 처리한다. 동시에 플레이어 명령은 적 턴이라는 이유로 거부된다.

- `ResolvePhase`는 학습창이 열리면 현재까지의 행동만 연결·저장하고 반환한다.
- `AdvanceEnemies`와 적 턴의 `auto`도 학습창에서 멈춘다. 적 한 명령인 `ai`는
  학습 대기 중 `LearningPending`을 반환한다.
- 적 턴에도 플레이어의 `learn`·`learn_close`는 코어 검증을 거쳐 허용한다.
- 학습을 마치면 기존 GUI 자동 진행이 나머지 적 행동을 이어간다.
  명시적인 아군 자동 진행과 GUI 전체 자동 플레이의 학습 보조는 유지한다.

방어 경험치로 학습창이 열리는 재현 테스트에서 자동 처리 중단, 선택·닫기,
저장 복원, 적 행동 재개를 검증한다.
