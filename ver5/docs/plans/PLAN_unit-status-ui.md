# 부대 상태 표시 정리

- 지도 유닛의 HP바 아래에 같은 폭의 파란 MP바를 추가한다. 화면용 MP 값은 실제 명령의 비용·회복·도구 사용 시점에 갱신하며 재생 완료 시 엔진 관측값과 동기화한다.
- 능력치 강화·약화 아이콘의 검은 바탕과 부가 그림을 제거하고 색상 화살표만 가로·세로 절반으로 표시한다. MP바 아래 중앙 정렬한다. 모든 상태는 작은 수제 도트 아이콘으로 교체한다.
- 우상단 육각형은 현재 능력치를 흰색으로 표시한다. CharacterStats로 얻은 상태 효과 적용 전 능력치가 다르면 회색 육각형을 함께 표시한다. 병종·장비·부장·레벨은 원래 능력치에 포함한다.
- 현재값과 원래값은 동일한 축 척도를 사용하고, 전투의 현재값·원래값 중 최고치로 정규화한다. 툴팁에도 원래값과 현재값을 표시한다.
- 관련 GUI 테스트와 실제 렌더링으로 화살표 투명 배경·배율·HP/MP/화살표 순서와 육각형 비교를 검증한다.

## 도트 자산 재설계

- 9×9 상태 도트와 5×6 능력치 화살표를 투명 PNG 시트로 제작한다. 어두운 외곽선과 제한 팔레트를 사용하고, 벡터·안티앨리어싱·검은 사각 배경을 없앤다.
- 중독은 독방울, 속박은 사슬, 봉격은 붉은 X, 화상은 불꽃, 혼란은 물음표, 봉책은 부적으로 구분한다. 몸 위의 그물·선 효과는 제거하고 중독 색조만 약하게 남긴다.
- 상태가 있는 유닛은 바 위치를 위로 올려 HP→MP→상태 한 행을 머리 위에 확보한다. 여러 상태는 같은 행에서 중앙 정렬한다.
- 원본과 팔레트·앵커·프레임 설정은 `../tools/spritetool/assets/ver5-status/`, 전용 빌더는 `tools/build_status_icons.py`, 런타임 시트와 인덱스는 `assets/graphics/status/`에 둔다.
- 실제 `.spr` 유닛과 런타임 렌더러로 상태별 1배/3배 예제와 강화·약화 견본을 캡처한다. 일반 GUI 테스트, 자산 투명도 검사, 선택적 네이티브 렌더링 테스트로 검증한다.
