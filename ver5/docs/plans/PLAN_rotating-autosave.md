# 턴 시작 자동 저장

수동 슬롯 1~10과 별개로 자동 슬롯 auto1~auto4를 둔다. 전투 배치 완료 후 첫 아군 턴, 이후 매 라운드 아군 턴 시작에 한 번 저장한다. 적군·동맹군 차례, 이동·공격·관찰·불러오기는 슬롯을 회전시키지 않는다.

저장 봉투에 자동 저장 순번을 함께 기록하고 원자적으로 교체한다. 네 슬롯에서 가장 큰 순번을 읽어 다음 슬롯을 결정하므로 재실행과 과거 저장 불러오기 뒤에도 회전 순서는 유지된다. 저장 실패는 순번을 소모하지 않는다. 수동 저장 명령으로 자동 슬롯을 덮어쓸 수 없다.

모든 세션 명령과 AI 일괄 진행은 공통 Apply 경로를 사용한다. 엔진 변경 후 자동 저장이 실패하더라도 명령 결과와 리플레이 이벤트는 유지하며 실패 메시지를 반환한다. 기존 매 명령 자동 저장은 제거한다. CLI 종료 시 사용자가 저장을 선택하면 수동 슬롯을 지정한다.

불러오기 창에 자동 슬롯 네 개와 수동 슬롯 열 개를 구별해 표시한다. 자동 저장의 전투명·라운드·시각을 표시한다. 수동 저장 창은 수동 슬롯만 표시한다.

검증: 순환 덮어쓰기, 재시작, 수동 슬롯 보존, 실패 후 회전 유지, 배치 완료·턴 시작 저장, AI 단일/일괄 경로, 불러오기 시 비회전, 자동 슬롯 수동 저장 금지 및 불러오기 화면의 버튼 배치.

## 검증 결과

storage/session/gui/cli/content/replay 검사와 관련 go vet 통과. 6개 턴 저장으로 슬롯 순환과 수동 슬롯 보존을 확인했고, 세션의 AI 단일 명령·자동 진행·진영 일괄 진행 모두 같은 시작 상태를 저장했다. 동맹군 차례에서 슬롯이 회전하지 않는 검사, 과거 저장 불러오기 후 순서 유지, 자동 슬롯 수동 덮어쓰기 거부, 저장 실패 시 진행·회전 보존 검사도 통과했다.

실제 창에서 자동 슬롯 4개와 수동 슬롯 10개의 배치, 수동 저장 화면의 자동 슬롯 제외, 자동 슬롯 4 불러오기를 확인했다. 화면은 reports/autosave/load.png 및 save.png에 저장했다. srpg-gui 빌드 성공.
