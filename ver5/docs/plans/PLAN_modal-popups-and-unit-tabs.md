# 전투 팝업과 장수 상태 탭

레벨업 알림 → 특성 선택 → 턴 종료 확인 순서로 진행한다. 기존 알림 큐를 유지하고, 알림이나 학습이 남아 있으면 새 확인창과 배경 조작을 차단한다. 턴 종료 확인은 실제 열린 뒤에만 해당 턴에 표시했다고 기록한다. 자동 진행의 학습 처리 흐름은 유지한다.

우상단 장수 패널은 공통 초상·병력·병법치·경험치 아래 네 탭을 둔다. 육각 능력치, 스크롤 가능한 특성 목록, 현재 장착 장비와 효과, 기본 능력치와 열전이다. 패널 높이는 하단 명령창을 침범하지 않도록 고정한다. 장수 콘텐츠에 Biography를 추가하고 docs/officers.md의 기존 열전을 옮긴다. 저장 상태에는 새 필드가 필요 없다.

최종 행동 후 레벨업/학습 중 확인창을 차단하고 학습 종료 후 턴 종료를 다시 제안하는 회귀 테스트를 작성한다. 네 탭은 네이티브 렌더링으로 크기·내용·스크롤을 확인한다.

검증 완료: gui/content/core/session 패키지 테스트 및 gui/content vet 통과. 네이티브 `TestRenderedUnitTabs`는 네 탭과 특성 스크롤, 레벨업 알림 → 특성 학습 닫기 → 턴 종료 확인 → 진영 전환을 실제 버튼으로 확인했다. 캡처는 reports/unit-tabs에 저장하고 화면 잘림과 팝업 겹침이 없는 것을 확인했다. 장수 30명의 열전을 연결했다.
