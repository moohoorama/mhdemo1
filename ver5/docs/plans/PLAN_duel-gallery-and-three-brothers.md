# 삼영전여포와 일기토 감상 모드

장비·관우·유비마다 공방과 감정을 다르게 표현하고, 나머지 두 형제가 실제로 합류한 뒤 여포가 직선 퇴각한다. 장비는 대등한 격전, 관우는 막기 힘든 강공, 유비는 뒤로 밀리며 방어·회피하는 버티기다. 셋 모두 맵 결과는 아군 유지·적 퇴각으로 맞춘다.

타임라인과 렌더러를 주역 둘과 지원군 둘까지 확장한다. 지원군 신원은 JSON 데이터에 기록하고 엔진에는 인물명을 넣지 않는다. 강공 회피·밀리는 방어·지원군 합류·단독 직선 퇴각을 추가한다. 샘플링은 재현 가능하며 규칙 상태·난수를 변경하지 않는다.

시작 메뉴에 일기토 목록을 추가하고 같은 데이터와 렌더러로 독립 재생한다. 감상 도중 대사와 건너뛰기만 표시한다. CLI의 직접 선택·장면 캡처는 srpg-gui로 옮기고 중복 srpg-duel 명령은 제거한다. 제작 스킬과 실행 문서를 갱신한다.

검증: 장수별 공방·지원군 등장 시점·직선 퇴각 상태와 JSON 검증, 본편의 세 조합 발동 및 퇴각·후속 이벤트, 감상 모드의 캠페인 상태 불변, 실제 창 렌더링 캡처, 관련 패키지 테스트·vet·빌드.

완료: 관련 duel·GUI·core·content·session·sim·replay 테스트, vet와 GUI 빌드, 프로젝트 스킬 검증 통과. 실제 창에서 여섯 본편 일기토와 적 선공의 종료·건너뛰기·퇴각 후속 결과 및 확대 렌더링을 검증했다. 시작 메뉴·여섯 감상 목록·재생 중 건너뛰기·메뉴 복귀도 검증했다. 관우·유비 전개의 장면별 캡처는 `reports/duel-gallery/`, 본편은 `reports/duel-integration/`에 저장했다. 독립 명령 두 파일을 제거했다.
