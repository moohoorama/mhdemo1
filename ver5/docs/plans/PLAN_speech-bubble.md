# PNG 10조각 말풍선 시제품

흰색 바탕과 얇은 먹색 윤곽의 둥근 말풍선을 PNG 10개로 구성한다. UI 도형은 정확히 맞물리는 코드 기반 원본으로 제작하며 기존 초상·병사 애셋은 수정하지 않는다.

- 모서리 4개는 16×16px로 고정한다.
- 상하 변은 1×16px, 좌우 변은 16×1px로 만들어 길이 방향만 늘린다.
- 중앙은 단색 1×1px를 늘린다.
- 꼬리는 24×20px로 고정한다. 좌하 모서리 바로 오른쪽의 하단 변 일부를 대체해 연결선이 보이지 않게 붙인다.
- 출력 순서는 타일 → 모든 유닛 그림자 → Y순 유닛 스프라이트 → 말풍선 → 글자다.

원본·생성 스크립트는 `tools/illustrations/ui/speech-bubble/`, 런타임 PNG는 `assets/graphics/ui/speech-bubble/`에 둔다. `cmd/srpg-duel`에 `-bubble-preview <PNG>`를 추가해 실제 타일·장수 위에 짧은 한 줄과 긴 두 줄 말풍선을 렌더링한다. 기존 본편 대화창은 이 시제품에서 변경하지 않는다.

검증은 실제 Ebitengine PNG 렌더링으로 모서리와 꼬리의 고정 크기, 늘어난 변의 이음새, 꼬리 연결, 대사 가독성과 출력 순서를 확인한다.

검증 완료: PNG 10개의 치수 확인, 실행파일 빌드·`go vet ./cmd/srpg-duel` 통과, `reports/speech-bubble/preview.png` 실제 렌더링과 육안 검토 완료. 250×88px와 364×116px 말풍선 모두 같은 16px 모서리와 24×20px 꼬리를 사용한다.

## 일기토 적용

`bubble_preview.go`의 16px 모서리·24×20px 꼬리 조립 코드를 `internal/duelview`로 옮겨 미리보기, 독립 데모, 본편 일기토가 공유한다. PNG는 기존 런타임 경로에서 한 번 로드한다. 일기토의 기존 벡터 말풍선을 흰색 PNG 말풍선과 먹색 이름·대사로 교체한다. 대사 크기에 맞춰 변과 중앙만 늘리고 장수 위에 배치한다. 관련 빌드·검사와 기존 본편 렌더링 테스트 및 미리보기 캡처로 검증한다.

적용 검증 완료: 관련 테스트·빌드·vet 통과. 본편 네 일기토와 적 선공의 각 장면을 실제 창에서 렌더링했고, PNG 말풍선의 이름·대사·꼬리를 육안 확인했다. 미리보기와 스토리 데모도 캡처했다. 등무는 장비와 함께 중앙으로 나와 호기롭게 대치한 뒤 첫 합의 섬광과 결정타로 패한다. 데모 조작 버튼은 말풍선을 가리지 않도록 하단으로 옮겼다.

현재 미리보기는 본편으로 통합했다. `go run ./cmd/srpg-gui -duel B01-duel-1 -duel-capture reports/speech-bubble`로 공통 말풍선을 확인한다. 독립 명령은 제거했다.
