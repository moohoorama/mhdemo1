# 행동 완료와 턴 회복 표시

## 규칙

- 이동은 한 번 가능하고, 공격·병법·도구·대기를 성공하면 즉시 `Moved`, `Acted`, `Done`을 모두 켠다. 제자리에서 행동해도 이동까지 종료한다. 실패한 명령은 상태를 바꾸지 않는다.
- 일기토로 대체된 공격과 승급 도구도 같은 규칙을 따른다. 반격·지원 공격은 명령을 내린 유닛의 행동 종료와 구분한다.
- 추가 행동을 주는 `free_skill`, `free_item` 효과와 국사무쌍·부호 특성은 새 규칙과 충돌하므로 데이터 및 엔진에서 제거한다. 관련 인물과 병종의 특성 목록에서도 제거한다.
- 규칙 버전을 올린다. 이전 규칙 또는 데이터의 저장은 기존 호환성 검사에 따라 불러올 수 없다.

## 화면

- 현재 진영의 생존 유닛 중 행동이 남은 유닛만 대기/탈진 애니메이션을 재생한다. 행동 완료, 상대 진영, 전투 종료 상태에서는 해당 애니메이션의 0번 프레임만 표시한다. 이동·공격·피격 애니메이션은 정상 재생한다.
- 리플레이에서 한 유닛의 행동이 끝나면 해당 유닛의 대기 애니메이션도 멈춘다. 다음 자기 진영 턴에는 다시 재생한다.
- 행동을 완료하면 선택을 해제한다. 우상단 정보창은 명시적으로 선택한 살아 있는 유닛에만 표시한다.
- 선택한 유닛의 병력·병법치 게이지에 다음 자기 진영 턴의 회복 예상량을 `+XX`로 표시한다. 병법치는 항상 표시하고, 병력은 회복 지형 또는 예상 회복이 있을 때 표시한다. 현재 위치와 상태를 기준으로 하며 이후 공격이나 이동은 예측하지 않는다.

## 회복 예상 API

- 엔진이 복사본에서 다음 자기 진영 턴까지 턴 전환을 실행하고 `recover-hp`, `recover-mp` 이벤트를 합산한다. 지형·회복 특성·오라·상태 지속시간·최대치 제한 등은 실제 회복 규칙과 같고 원본 RNG/상태는 바뀌지 않는다.
- GUI는 엔진·리비전·선택 유닛별 결과를 보관해 매 프레임 계산하지 않는다. 임시 이동 중에는 이동 후 위치를 담은 샌드박스 엔진을 사용한다.

## 검증

- 공격·병법·도구 후 모든 추가 명령 차단, 이동 후 행동 및 제자리 행동, 실패한 행동의 상태 유지, 다음 턴 행동 재개를 확인한다.
- 기존 반복 전투 테스트는 매회 새 턴 상태로 초기화한다. 추가 행동 특성의 기존 테스트는 새 규칙 테스트로 대체한다.
- 회복 예상값과 실제 다음 턴의 회복 이벤트를 비교하고 원본 상태 불변을 확인한다.
- 행동 완료 및 상대 진영 유닛의 0번 프레임 고정과 행동 가능 유닛의 애니메이션 재생을 확인한다. GUI 캡처로 게이지 수치 배치를 확인한다.
