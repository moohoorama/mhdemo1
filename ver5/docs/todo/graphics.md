# 해야 할 일: 그래픽

범위: [conceptual_scenario.md](../conceptual_scenario.md) 1~20을 올리는 데 필요한 그림 작업.
실제로 시작할 때는 `docs/temp/`에 plan을 쓰고, 끝나면 결과를 해당 분야 문서(`presentation-*.md`)에 현재형으로 옮긴 뒤 이 항목을 지운다.

## 일러스트

- 낙양 피바다 장면(2)과 영웅론의 젓가락 장면(16) 등 이벤트 CG.
- 스타일과 원본은 `tools/illustrations/README.md`의 수묵 담채를 따른다.

## 초상화

- 신규 인물 약 55명. 수묵 담채. 목록은 [data.md](data.md)의 장수 항목.
- 범용 무명 초상: 전령, 병사, 노인, 피난민.

## 스프라이트

- **병종**: 새로 그리지 않는다. 진영색·팔레트로 해결한다.
  - 백마의종: 기병 + 흰색 진영색
  - 쇠뇌 노병대: 기존 노병
  - 함진영: 색을 바꾼 창병
- **비무장(장면용)**: 새로 그리지 않는다. 기존 병종 도트에 옷색·진영색만 바꾼다(`cast`의 `스프라이트`, `Look.Palette`).
  - 서복·선비: 서생 + 옷색
  - 피난민·촌민·노인: 서생 또는 경보병 + 칙칙한 옷색
  - 병사: 경보병
  - 전령: 경보병 또는 경기병 + 옷색
- **장수**: 전용 도트는 비중이 큰 인물만 그린다. 조조, 여포, 원소, 조운, 공손찬, 손견, 고순, 원술, 동탁(배불뚝이 체형), 헌제, 허저, 문추.
  나머지는 병종 도트 + 팔레트로 쓴다. 전투용만 그리고 `_noncombat` 시트는 장면에서 어색한 인물이 생길 때 추가한다.
  그리는 방법은 `hero-sprite` 스킬을 따른다.

## 배경

- 장면 맵은 통합해 약 8~9장. 막사류, 성내류(신도성·북해성·서주성), 궁궐류(낙양·허도)는 하나로 쓰고, 동승의 집·조조의 후원 등만 따로 만든다. 후보 장면 14개는 이미 `graphics/maps/S_*.json`으로 들어와 있다([presentation-scene.md](../presentation-scene.md)). 남은 일은 낮·저녁·밤 색, 하늘, 불빛, 조건에 따른 변형(성문 열림 등)이다.

## 타일

- 시나리오에 필요한 표현: 화재 불길과 그을음은 들어왔다(불·연기 그림, 불탄 마을·숲, 그을음 덧씌움, 다리 손상·파괴). 성문은 닫힌 성문 땅만 있고, 열리는 성문(`gate_*`·`sgate_*`의 열린 그림)은 아직 게임 규칙에 연결되지 않았다.
