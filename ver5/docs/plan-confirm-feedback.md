# 승인·확인 시 취소음 제거

확인 질문의 ‘예’가 공통 창 닫기를 먼저 호출해 취소음이 나고, 획득 이외 안내 모달도 같은 소리를 쓴다. 사용자는 승인·확인 효과음이 있는 경우 취소음이 함께 나지 않도록 요청했다.

- `internal/gui/windows.go`·`game.go`: 확인 질문 승인 처리를 한 함수로 모은다. 승인 동작 안의 창 정리는 무음으로 하고, 구매·저장·출진 등의 효과음이 있으면 그대로 쓴다. 별도 효과음이 없으면 `ok`를 한 번 재생한다. 실패 효과음이 났다면 확인음을 덧붙이지 않는다. 승인 처리가 끝나면 보통 닫기·취소는 다시 `close`를 쓴다.
- `internal/gui/windows.go`: 전투 목표·레벨업·승급·특성·획득 안내 확인은 `ok`, 획득 위 설명 창 닫기는 `close`를 쓴다.
- `internal/gui/sound_test.go`·`sound_audit_test.go`: 승인 전후·중첩 창 정리·자체 효과음·실패·순수 취소·안내 확인 경로를 검사하고 조사 시험도 실제 승인 함수를 사용한다.
- `docs/audit-denied-sound.md`·`history.md`: 조사 당시 결과와 이번 수정 결과를 구분해 기록한다.

관련 GUI 시험·vet 및 기존 `sound-audit`·획득 데모 캡처와 효과음 기록으로 확인한다. 비활성 메뉴 클릭의 두 효과음 중복은 이번 승인/확인 수정 범위에 포함하지 않는다.
