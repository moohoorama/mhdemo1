# 장비 추천 표시

- 출전 준비와 관리창은 같은 장비 추천 판정을 사용한다. 창고 재고와 실제 장착 규칙을 확인한 뒤 현재 장비와 교체 결과를 비교한다.
- 능력치·이동력이 내려가거나 현재 특성·사용 가능한 기술·특성 학습 기회를 잃는 교체는 추천에서 제외한다. 빈 슬롯도 같은 기준으로 평가한다.
- 장수 이름, 장비 탭, 슬롯의 바꾸기 버튼, 장비 행에 녹색 테두리를 표시한다. 후보에는 실제로 얻는 효과를 적는다. 창고 재고를 공유하는 후보는 장착 직후 다시 계산한다.
- 비교와 재고 갱신을 회귀 테스트로 확인한다. 출전 준비와 관리창 및 장비 선택창을 게임 캡처로 확인한다.
