# 대사·나레이션·중앙 창 HTML 시안

## 범위

- `story-ui-proposal.html`에서 네 화면을 전환해 본다: 여의운문 대사창, 용무늬 중앙 나레이션, 어두운 갈색 수자문 작전 개요, 어두운 갈색 수자문 출진 확인.
- 실제 장면 캡처를 배경으로 쓰고 현재 게임의 1280×850 UI 치수를 기준으로 배치한다. 게임 렌더러와 로더는 이 단계에서 바꾸지 않는다.
- 나레이션 창은 화면 중앙에 놓고 배경판만 약 80% 불투명하게 한다. 텍스트는 불투명하게 유지하고 별도 '해 설' 표기는 두지 않는다. 진입은 화면 높이 5% 아래에서 올라오며 페이드 인, 퇴장은 같은 거리만큼 내려가며 페이드 아웃한다. 우하단 그림자를 둔다.
- 대사는 고정 공간에서 줄바꿈·높이를 측정해 넘치면 로딩 거부로 표시한다. 전투목표와 출진 확인은 문구에 따라 창을 키우되 화면 폭과 높이의 80%를 상한으로 두고, 넘으면 거부로 표시한다.
- 샘플 문구를 편집하고 짧은/긴/초과 예문으로 결과를 비교할 수 있게 한다. 작성 지침 `AGENTS.md` 초안도 데모 안에 적는다.

## 구현 전 확인할 점

- 브라우저의 글꼴 측정은 게임의 `wrapWidth`·Go 텍스트 렌더링과 픽셀 단위로 같지 않다. 실제 거부 검사는 게임이 로딩할 때 같은 글꼴·줄바꿈·UI 배율로 해야 한다.
- 전투목표는 `Victory`, `Defeat`, `Sub`, 장수 이름과 상태 문구를 합쳐 화면에 표시한다. 원본 필드만 검사하면 실제 창이 넘칠 수 있다.
- `AGENTS.md`는 작성 규칙을 알려 주지만 로더 검사를 대체하지 못한다. 두 곳을 함께 적용한다.

## 게임 반영 설계

- 런타임용 여의운문·수자문 타일을 `assets/graphics/ui/`에 두고 `Assets`에서 읽는다. 대화창은 여의운문, 나레이션은 기존 회색 용무늬, 작전 개요·출진 확인은 어두운 갈색 수자문을 쓴다.
- `say`와 `narrate` 렌더링을 나눈다. 나레이션은 중앙에서 화면 높이의 5%를 위로 이동하며 나타나고, 다음 노드로 넘어갈 때 같은 거리 아래로 내려가며 사라진다. 본문 외 표기는 두지 않는다.
- 대사·나레이션은 실제 `wrapWidth`와 글꼴 치수로 표시 가능 여부를 검사한다. GUI 초기화 때 시나리오·전투 이벤트·탐색 대사를 살피고, 지나치게 긴 내용은 ID를 포함한 오류로 중단한다.
- 작전 개요·출진 확인은 전체 표시 문자열의 줄바꿈을 먼저 계산하고 내용 높이에 맞춰 창을 조정한다. 최대 80%를 넘으면 로딩 단계에서 오류를 돌려준다.
- 작성 지침을 시나리오 폴더의 `AGENTS.md`에 넣고, GUI 시연 프레임으로 네 화면을 확인한다.
- 길이 검사는 지원하는 최대 UI 배율 160%에서 1280×850 화면이 800×531 UI 단위가 되는 경우를 기준으로 한다. 더 작은 창에서는 작전 개요가 문구를 잘라 보여주지 않고 UI 크기를 줄이라는 안내를 표시한다.
