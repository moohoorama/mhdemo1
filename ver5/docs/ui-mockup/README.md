# 전장 UI 개편 시안

`index.html`은 브라우저용 움직이는 시안이다. 게임 코드가 아니며, 구현할 때 연출·타이밍의 기준으로 본다.
초상은 `assets/graphics/portraits/`를 그대로 읽고, `img/`에는 게임 캡처만 둔다.

```sh
cd ver5 && python3 -m http.server 8090   # http://localhost:8090/docs/ui-mockup/
```

## 확정한 것

| # | 항목 | 요점 |
|---|---|---|
| 1 | 맵 밖 타일 | 이미 그리는 맵 밖 타일을 다듬는다: 채도 낮춘 풀·돌·작은 숲, 멀수록 안개, 맵 경계 밝은 테, 구름 그림자 |
| 2 | 턴 전환 | 굵은 붓질 → "제7턴" 붓글씨가 왼쪽부터 써짐 → 진영 이름 + 진영색 밑줄. 낙관·먹방울 없음 |
| 3 | 상단 바 | 옻칠 바·금테·구름무늬, 턴 원패, 승패 두루마리(장 시작 때 한 번만 펼침), 한글 세로 이름패 |
| 3 | 카메라 | 이름패를 누르면 그 장수를 가운데로 옮기고 선택. 적 차례에는 동시에 움직이는 적들의 가운데 지점에 가장 가까운 적에 초점 |
| 4 | 타격감 | 붓글씨 피해 숫자·먹 튐, 치명은 "치명" + 금빛 고리, 체력 바는 유닛 폭 약 1.2배·4칸 눈금·흰 잔상 |
| 5 | 대화창 | 도트 부품 두루마리(축 꼭지·몸통, 비단 띠, 종이). 펼칠 때 easeOutBack, 접을 때 easeInCubic |
| 6 | 명령 메뉴 | 사각 목록 유지, 위에서 펼침, 금빛 강조 줄, 하위 목록에 병법치·설명. UI 크기 80–160% 설정(모바일 기본 130%) |
| 7 | 일기토 컷인 | 위아래를 자른 가운데 띠. 한 사선을 나눠 가진 두 초상이 맞부딪힘, 장수 이름을 붓글씨로 크게 찍음 |
| 9 | 장수 첫 등장 | 먹 번짐 마스크로 초상이 드러나고 이름·자·소개(characters.json) |

## 원칙

- 한국판 화면 글자는 한국어만 쓴다. 한자 인장·한자 메뉴는 쓰지 않는다.
- 전투 로그는 죽간으로 바꾸지 않는다. 피해(주색)·회복(초록)·장수 이름(진하게)의 글자 색 구분만 쓴다.
- 메뉴 밖 맵 클릭·우클릭·Esc는 한 단계 취소다. 대상 고르는 단계에서 대상이 아닌 칸을 누르는 것도 취소로 맞춘다.
