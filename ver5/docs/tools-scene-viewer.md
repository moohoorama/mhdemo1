# 공통 장면 맵 뷰어

`go run ./cmd/_scene`은 `assets/graphics/index.json`에 등록된 `S_` 장면 맵을 한 화면에서 선택해 그린다. 모든 맵은 같은 배율·스크롤·회전·바닥 기준 커서 표시를 사용한다. 비교용 on/off 설정은 두지 않는다.

그림은 게임의 타일셋·소품 아틀라스와 각 맵 JSON을 직접 읽는다. `ground`와 `decorations`는 기존 픽셀 좌표에, `props`는 기존 논리 좌표에 그린다. `native` 이전 형식의 바닥·장식 타일은 게임처럼 두 배 크기로 그린다. `small_props`의 자유 소품은 작은 칸 중심에 붙이고, 절벽 모서리의 픽셀 보정과 `small_faces`의 면 피벗 보정은 유지한다. 높은 절벽은 한 번만 그린다. 고지대의 천장은 모든 고지대 칸에 올리고, 이웃보다 높은 경계에만 벽면이나 얇은 뒤쪽 경계선을 그린다. 바닥 조각의 중심과 면 방향을 함께 회전한다.

현재 관문 외 맵은 기존 `props` 형식이다. 뷰어는 이 위치를 보존한다. 다른 맵을 작은 칸·면 자료로 바꾸는 작업은 해당 맵의 배치 자료를 별도로 변환해야 한다.
