# 관문 장면의 2×2 배치 격자 시도

## 범위

`S_checkpoint`와 `S_checkpoint_closed`의 소품 배치를 기존 논리 칸의 2배 해상도인 작은 격자로 저장한다. 논리 맵 크기(12×8), 바닥 `small_tiles`, 장면 배우 좌표, 전투 이동 규칙은 그대로 둔다. 배우 한 명이 차지하는 논리 칸 1×1은 이 작은 격자에서 2×2칸이다.

## 자료 형식

- 기존 장면 맵의 `props`는 계속 `[이름, u, v]`를 쓴다.
- 시도 대상 맵은 칸 중심 소품에 `small_props`, 칸의 한 면에 붙는 그림에 `small_faces`를 쓴다. 전자는 `[이름, U, V]` 또는 `[이름, U, V, dx, dy]`, 후자는 `[이름, U, V, 면]` 또는 `[이름, U, V, 면, dx, dy]`다. `U,V`는 작은 격자의 정수 칸이고 `dx,dy`는 칸 또는 면 중심에서 스프라이트 피벗을 옮기는 화면 픽셀이다.
- 작은 격자 중심은 바닥 작은 칸의 중심과 같은 `x = 16(U−V)`, `y = 8(U+V+1)`(화면 픽셀, 맵 원점 제외)다. 기존 좌표로 `u=(U−0.5)/2`, `v=(V−0.5)/2`이며, `dx,dy`를 적용한 뒤 기존 피벗을 뺀다.
- 성벽·성문 조각은 작은 격자에서 1칸씩 떨어진 `SW` 면에 붙는다. 절벽의 열린 면과 그림자도 이를 덮는 칸의 면에 붙는다. 상세한 면 기준과 관문 이음새 보정은 [scene-tile-faces.md](scene-tile-faces.md)를 본다.

## 확인 기준

1. 새 파일의 모든 `small_props`·`small_faces`에서 `U,V,dx,dy`가 정수이고, 소품 이름과 개수가 원본과 같다.
2. 면 기준 변환 전후 소품의 화면 기준점이 픽셀 단위로 같다. 높은 절벽 그림의 잘린 밑단만 복구한다.
3. 열린 관문과 닫힌 관문 모두 게임 로더로 읽히며, 다른 장면 맵은 기존 형식으로 계속 읽힌다.
4. HTML 뷰어에서 작은 격자와 2×2 배우 점유를 확인할 수 있다.
