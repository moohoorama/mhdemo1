# 장면 나무 전체 4프레임 흔들림 시안

잎·꽃이 있는 장면 나무 13개 변형(`stree_pine_*`, `stree_broad_*`, `stree_willow`, `stree_old`, `stree_bush_*`, `stree_plum_*`, `peach_bloom_*`)을 각 4프레임·250ms로 만든다. `stree_dead`는 잎이 없어 정지 그림으로 둔다. 게임 런타임 에셋은 바꾸지 않는다.

1. 기존 `scene_props3d.py`의 모델과 카메라에서 나무마다 줄기·가지 면은 그대로 두고 잎·꽃 면만 네 자세로 변형해 2×2 참조 시트로 렌더한다.
2. 각 참조 시트와 기존 원화를 입력으로 같은 화풍의 2×2 원화 시트를 만든다. 나무 몸통과 뿌리는 매 칸 같은 자리에 둔다.
3. `pixelize_tree.py`의 각 나무 설정에 적힌 크기·팔레트·외곽선 처리를 네 칸에 적용한다. 원화 생성 중 어긋난 뿌리는 맞추고, 줄기·가지 색 픽셀은 첫 프레임으로 통일한다.
4. HTML에서 나무별 원본·3D 참조·최종 도트, 네 프레임과 250ms 반복을 보여준다. 각 셀의 팔레트·알파·잘림·줄기 고정·고유 프레임을 검사한다.

시안 그림은 `tools/spritetool/assets/scene-tree-sway/`에 둔다. 최종 도트 시트의 칸은 기존 나무별 캔버스·뿌리 기준점을 따른다.
