# 자동 저장 분리

불러오기 창을 자동 시나리오, 자동 전투, 수동 탭으로 구성한다. 자동 탭은 저장 시간 최신순으로 열리며, 처음 불러오기 창을 열면 가장 최근 저장이 있는 탭을 선택한다.

- 시나리오 자동 저장은 출진 승낙 직전 상태를 저장한다. 전투 자동 저장은 전투 시작과 매 아군 턴 시작 상태를 저장한다. 두 종류는 각각 열 칸을 독립적으로 순환한다.
- 기존 `auto1`~`auto10`은 원래 슬롯 ID로 계속 불러올 수 있다. 불러오기 창에서는 저장된 단계에 맞는 자동 탭에 표시한다. 새 자동 저장은 별도 파일명으로 기록한다.
- 수동 저장 창과 단축키는 기존 수동 슬롯을 사용한다. 이어하기와 CLI는 세 종류의 저장 목록을 함께 사용한다.
- 저장소 회전, 출진 직전 복원, 이전 저장 호환과 자동 탭 선택을 시험한다. 저장 데모로 네 화면을 캡처한다.
