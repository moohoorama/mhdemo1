# 전투 학습 모델 (시험용)

`battle.json`은 debug 자동실행의 기본 정책이다. 현재는 **장비·특성·전투를 함께 학습한 모델**이며 승급·편성·부관·이야기·상점은 기존 규칙을 쓴다. 실제 재고와 포인트로 합법 명령을 선택한다. 모델 실행 실패를 탐색 AI의 전투 판단으로 자동 대체하지 않으며 데이터 해시가 다르면 실행을 거부한다.

## 현재 공동 학습 모델

- 주 평가: 정상 매우 어려움 새 게임에서 첫 패배 전 연속 승리 수. 검증에는 재도전을 쓰지 않는다.
- 최고 기록: 개발 시드 310004에서 **11탄 무패, 12탄 첫 패배**. 같은 모델을 현재 게임 데이터에서 별도로 실행해 10탄 무패를 재현했다.
- 개발 4시드: 5·5·5·11탄. 미사용 460001~460008: 평균 5.5탄, 최저 3·최고 8탄. 같은 시드의 공동 학습 출발 모델은 평균 5.0탄·최고 6탄이었다. 안정적인 11탄 도달/전체 완주 모델은 아니다.
- 준비망은 입력 128, 전투 정책망은 128(목표 구역 관측을 쓰는 B09/B10은 136), 가치망은 64다. 은닉층은 모두 tanh 32→32다. B01·B07·B09·B10 전투 전문가와 B09/B10 준비 전문가가 있으며, 나머지는 공통 정책을 쓴다.
- 전체 새 게임 학습 320회·1,838전투, 추가 구간 학습 1,928회와 교사 탐색을 실행했다. 이 수는 전체 실험량이며 선택한 가중치 하나의 PPO 갱신 횟수와 구별한다. 구간/교사 승리는 무패 기록으로 세지 않는다.
- 선택 과정: 실제 무패 진입 상태의 교사 모방으로 B07/B09를 배우고, B10의 신경망 승리 1회(전투 66·준비 43판단)를 400회 재학습한 모델이다. 장비 지급·무한 소모품·밸런스 변경은 없다. 일부 강화 병법/회복 아이템의 동일 입력 문제는 남아 있다.
- 콘텐츠 해시: `e59a78a638619b6aeb5b237fdfcbd08c28c9808d75a2ab5001a092ad03e95de3`. 모델 SHA-256: `ee6a4d25e426d3e3f65d253fbe979a25cad8f30c727041cc155287a059750b01`.

상세와 재현은 [tools-autoplay.md 9절](../../docs/tools-autoplay.md#9-첫-패배까지의-특성장비전투-공동-학습), 가중치와 전체 결과는 작업 공간 `reports/autoplay/goal10/`에 있다. `go run ./cmd/srpg-gui`를 다시 실행하면 새 모델을 사용한다. Android에는 `make android android-install ANDROID_MODE=debug`로 새로 빌드·설치해야 반영된다.

## 공동 학습 이전의 전투 전용 모델 기록

이하 기록은 현재 모델의 출발점이 된 이전 배포 모델에 관한 것이다. 당시 장비·특성도 기존 `CampaignPlayer`가 처리했다.

- 정책망: 입력 128 → tanh 32 → tanh 32 → 출력 1. 현재 모든 아군 장수의 합법 행동을 함께 점수화한다.
- 가치망: 상태 64 → tanh 32 → tanh 32 → 출력 1. PPO 학습 때 최종 보상을 예측한다.
- 특징 형식: `BattleFeatureVersion=1`. 위치·위협·실제 행동 효과·승리 대상·남은 턴·장수 성장 가중치 등. 런타임에 교사 후보 점수나 장수/스테이지 이름은 입력하지 않는다.
- 초기 모방: 실제 매우 어려움 새 게임 캠페인의 시드 12·13 기록. B01 3전투 33판단으로 10회, 이어 B01~B06의 승리 기록 620판단으로 40회 학습했다. 완결된 준비 상태 24개를 강화학습 시작점으로 썼다. 패배 명령은 모방하지 않는다.
- 공통 가중치의 PPO: B01 128전투, B01~B06 혼합 512전투(누적 640), 학습 시드 7000. 학습마다 실제 준비 상태의 RNG만 바꿨다. 첫 전투 외에는 이 혼합 학습 가중치를 쓴다.
- 공통 가중치의 학습 보상: 승리 `2 + 0.2 × 가중 획득 레벨`, 패배·중단 `−2`. 가중 획득 레벨은 실제 획득 XP / 10,000에 기존 장수 순위 가중치를 곱한 합이다. 종료를 앞당기는 보상·미래 할인·확정 승리 강제 분기는 없다.
- 외부 추론 라이브러리 없이 Go로 학습·추론한다. 앱 실행 중에는 학습하지 않는다.

학습 코드·재현 명령·평가 범위·한계는 [tools-autoplay.md](../../docs/tools-autoplay.md)의 7절에 있다. 학습에 사용한 실제 기록은 작업 공간의 `reports/autoplay/watch/`에 있다. 이 폴더는 버전 관리 대상이 아니므로 다른 작업 공간에서 재학습하려면 정상 캠페인 기록부터 생성해야 한다. 난이도·레벨·장비·물자 지급을 보정한 전투 지점 시작 기록을 섞으면 같은 실험이 아니다.

최초 공통 모델의 고정 준비 평가 RNG는 40001~40008이었다. B01은 8/8 승리, 평균 가중 획득 레벨 4.2955(기존 탐색 8/8·3.039875). 기존 탐색 캠페인 시드 12의 첫 B06 준비를 고정한 시험은 1/8(기존 탐색도 1/8)이었다. 이를 앞서 ‘약한 준비’라고 불렀지만 준비의 전반적인 열세나 패배 원인을 입증한 비교는 아니므로 정정했다. 이 공통 모델의 새 게임 31001~31003 호로관은 총 7전 3승 4패, 첫 시도 0/3이었다.

## B01 집중 학습 후 이전 배포 모델

- B01은 공통 640전투에서 출발해 첫 전투만 10,240회 추가 학습한 PPO 체크포인트(누적 `Episodes=10880`)를 쓴다. 실제 준비·재고를 유지하고 모든 합법 행동을 그대로 제공했다. 아이템/일기토를 차단하는 행동 규칙은 없다.
- 승리 보상: `10 + 0.5×가중 획득 레벨 + 4/(1+max(0,승리 대상 외 남은 적−1)) − min(8,0.75×소모품 사용 수)`. 패배/중단은 −10이다. 새 보상은 학습에만 사용한다.
- 본 추가 학습은 PPO 단독 12,416전투와 성공 기록 재학습 병행 8,192전투를 실행했다. 마지막 가중치 대신 개발 평가의 좋은 체크포인트를 보존했다. 개발 128판에서 PPO 128승·목표 100판, 성공 재학습 124승·목표 122판으로, 승리 수를 우선해 PPO를 골랐다.
- 선택 후 미사용 RNG 90001~90512: PPO 511/512 승리, ‘무소모품·남은 일반 적 1기 이하·승리’ 415/512. 변경 전은 512/512 승리·동시 달성 0/512였다. 아직 확정 승리·완전한 경험치 최적화 모델은 아니다.
- 실제 새 게임 130001~130010: 첫 전투 10/10 첫 시도 승리. 9판은 무소모품·일반 적 1기 잔존, 1판은 소모품 1개·일반 적 1기 잔존이었다.
- 전체 캠페인 120001~120003, 전투당 최대 5회 시도: 선택한 PPO는 세 시드 모두 B06까지 승리 후 B07에서 5패. 성공 기록 재학습의 최종 모델은 각각 B05·B06·B06까지 승리 후 중단했다. 두 모델 모두 완주 0/3이다.

2탄 이후의 정책/가치망은 이전 공통 모델과 같다. 바뀐 첫 전투의 경험치·재고는 정상적으로 다음 전투에 이어진다. 현재 모델 묶음 SHA-256: `11e90bd42c43a7e8d315c27ebcea50eab82f6d4723e07dcf18bbcbaf6cc03a99`.
