# 시나리오 문구 작성

- `say`, `narrate`, 탐색 대사, 출진 확인 질문, 전투목표 문구를 수정한 뒤 `cd ver5 && go test ./internal/gui -run TestUIContentFits`를 실행한다.
- 게임은 GUI 초기화 때 실제 글꼴과 줄바꿈으로 문구를 검사한다. 대사·나레이션이 표시 영역을 넘거나 중앙 창이 화면 가로·세로의 80%를 넘으면 로딩을 거부한다.
- 거부된 문장은 뜻을 유지하며 여러 노드·대사로 나누거나 짧게 고친다. 오류에 표시된 노드·스테이지·탐색 위치를 확인한다.
- 전투목표는 승리·패배·부목표·장수 이름·턴 제한을 합친 화면 기준으로 검사한다.
