# 출전 준비 통합 탭 개선안

기존 `sortie-slide-prototype.md`의 3개 영역과 슬라이딩 상세를 두 영역으로 단순화한 제안이다. [대화형 시안](../reports/sortie-unified/index.html)에서 장수 선택, 편성, 탭 전환과 특성 선택을 살펴볼 수 있다. 수치와 병종 기호는 예시다.

- 왼쪽: 기존 3×6 출전 격자를 유지한다. 모든 병종 발밑에 그림자를 두고 모든 출전 장수는 대기 애니메이션을 반복한다. 군주·필수 출전 장수는 격자의 금색 `필수` 표시로 구별한다. 선택 테두리도 유지한다. 복병은 기존처럼 격자와 출전 인원에서 제외한다.
- 가운데와 오른쪽: 하나의 넓은 작업 영역으로 합친다. `기본`, `전투력`, `열전`은 전체 부대 표이며 선택과 정렬을 제공한다. `장비`, `특성`, `부관`은 선택 장수의 기존 편집 화면을 보여 준다. 탭을 바꿔도 장수 선택과 출전 격자는 유지한다. 편성 화살표는 왼쪽 격자와 오른쪽 작업 영역 사이에 두고, 위에는 출전용 왼쪽 화살표, 아래에는 출전 취소용 오른쪽 화살표를 작게 배치한다. 표와 편집 화면 모두에서 접근할 수 있다.
- 특성: 선택 장수 이름 옆에 **남은 특성치 N**을 항상 표시한다. 특성을 고르지 않았거나 이미 습득한 경우에도 보이며, 학습 가능 특성을 선택하면 기존 상세의 `N → 학습 후 잔여`와 비용·부족 안내를 함께 보여 준다. 학습 후 값은 즉시 갱신한다. 공통 특성 화면에도 같은 위치와 방식으로 표시한다.
- 편성 규칙: 군주·필수·복병·부관 및 인원 제한은 현재 규칙을 그대로 사용하고, 실행할 수 없는 편성은 이유를 알려 준다. 부관 임명과 해임, 장비 교체 및 특성 학습도 기존 규칙을 따른다.
- 조작: 표에서 행이나 출전 격자의 부대를 선택한 뒤 탭에서 편집한다. 편집 탭에서 다른 장수를 선택하려면 기본·전투력·열전 표나 출전 격자를 사용한다. 소지품·출진·닫기는 하단에 둔다.

구현 시 실제 병종 스프라이트의 그림자와 애니메이션 프레임을 사용한다. 좁은 화면에서 탭과 표의 스크롤 및 터치 영역을 확인하고, 필수·선택 출전, 복병, 부관 제약과 특성치 0·부족·학습 후 갱신을 시험한다. 기존 UI 데모에 각 탭과 대기 동작과 필수 표시을 추가해 일반 화면과 휴대폰 화면을 캡처한다.
