# 직접 타일로 그리는 순서

이 문서는 작업 제안이다. 아래 레이어·타일 분류·작업 순서를 코에이의 실제 데이터 사양으로 읽지 않는다.

## 바탕 지도

`images/`의 전체 지도에서 해안선, 황하·장강과 지류, 산줄기, 도시의 상대 위치를 먼저 확인한다. 원본 해상도와 다운로드 상태는 `sources.json`을 본다. 고해상도 이미지가 있으면 세부 지형용으로, 작은 미리보기는 전체 구도용으로 쓴다.

원작과 비슷한 밀도를 원하면 200×200 논리 격자를 출발점으로 삼을 수 있다. 자체 게임에 맞는 다른 크기를 선택해도 된다. **이미지 가로·세로를 각각 200으로 나누어 바로 덮는 방식은 정확한 복원이 아니다.** 지도 여백과 격자의 투영을 먼저 확인해야 한다.

## 레이어 제안

| 레이어 | 기록할 내용 | 그릴 때 볼 것 |
|---|---|---|
| 지표 | 평지·풀밭·흙·습지 등 | 넓은 지역의 바탕색과 전이 |
| 수계 | 바다·강·호수 | 강의 연결, 하구, 물길 폭 |
| 고도·장애물 | 산·암벽·숲 | 통로를 막는 능선과 골짜기 |
| 길·도하 | 육로·다리·나루 | 도시 사이 이동 경로와 강을 건너는 곳 |
| 시설 | 도시·관문·항구·야전 시설 | 위치, 점유 칸, 출입 방향 |
| 지역 | 도시권·이름 붙은 지역 | 칸별 지역 소속과 경계 |
| 이동 판정 | 육상·수상 통행, 건설 가능 여부 | 그림과 실제 통로의 일치 |
| 표시 | 도시명·지역명·참고점 | 지형 그림과 분리하여 수정 가능하게 |

최초 타일 세트는 평지, 물, 해안·강둑, 산, 숲, 길, 다리부터 시작하면 된다. 모서리·끝·직선·굽이·교차 연결을 고려한다. 도시·관문·항구는 지형 위에 별도로 놓으면 바탕을 고치기 쉽다. 이 분류는 제작 편의를 위한 것이며 원작 지형 종류의 완전한 목록이 아니다.

## 작업 절차

1. 지도 전체를 보고 큰 물줄기와 육지 윤곽만 단색으로 그린다.
2. 산줄기를 넣어 지역 사이에 통과 가능한 길이 어디에 남는지 확인한다.
3. `cities.csv`의 50개 거점을 체크하며 도시 위치를 표시한다. 표의 지역 목록은 주변 지명 확인용이다.
4. 그림에서 확인한 관문·항구·다리를 표시한다. 이름만 보고 모든 지역을 시설로 바꾸지 않는다.
5. 도시 사이 이동 경로와 도하 지점을 연결하고 이동 판정을 칠한다.
6. 지형 경계 타일과 작은 장식을 넣는다. 지역명은 마지막에 겹쳐 확인한다.

먼저 낙양·장안 주변이나 한중·자동·성도처럼 한 구역만 완성해 타일 크기와 강·산의 폭을 정하면 전토 작업이 수월하다.

## 좌표 기록

`cities.csv`의 `x`, `y`에는 선택한 논리 격자의 좌표를 적는다. JSON의 같은 필드는 초기값이 `null`이다. 이미지 픽셀 좌표를 이 칸에 섞지 않는다. 측정해서 입력하면 `coordinate_status`도 `manual_reconstruction` 등으로 바꾸고 근거를 `notes`에 남긴다. CSV와 JSON은 자동 동기화되지 않으므로 편집본 하나를 기준으로 정한다.

서로 다른 이미지에 표시한 점을 비교할 때는 이미지 파일명·해상도·픽셀 위치를 함께 기록한다. 원작의 정확한 칸 좌표를 확보하기 전에는 이미지에서 읽은 위치를 확정 좌표라고 표시하지 않는다.
