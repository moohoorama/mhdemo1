# 삼국지 9 타일 지도 참고 자료 수집

사용자 요청: 인터넷에서 확인한 맵 관련 정보를 `./koei9/`에 보관하여 타일 지도를 그릴 때 참고한다.

## 작업 범위와 방식

1. 전체 지도 이미지의 실제 다운로드 가능 여부와 크기를 확인하고 원본 출처를 기록한다.
2. 도시·주·주변 지역의 사실 데이터를 CSV/JSON으로 정리한다. 확인되지 않은 게임 좌표는 비워 둔다.
3. 200×200 격자와 Square 번호, 지형·통행 속성에 관한 모딩 연구를 한국어로 요약한다.
4. 타일 작업 순서와 레이어 구성을 별도 안내로 적는다. 원작에서 확인한 사실과 제작 제안을 구분한다.
5. 이미지 열기, 데이터 형식·개수·출처를 검사하고 `ver5/docs/history.md`에 변경 파일과 이유를 남긴다.

게임 코드·런타임 에셋은 바꾸지 않는다. 지도 이미지의 픽셀 해상도를 논리 격자의 정확한 투영식으로 간주하지 않는다.

## 결과

- 공식 지도와 팬 미리보기 2개 저장. 이미지의 실제 해상도·SHA-256 기록 및 화면 확인.
- 도시 45곳·이민족 거점 5곳·표에 나열된 주변 지역명 136개를 CSV/JSON으로 정리.
- 한국어 맵 구조 설명과 타일 제작 안내, 출처·다운로드 상태를 저장.
- 12,800px 원본 압축파일은 서버 연결 실패로 미확보. 링크와 사유 기록.
