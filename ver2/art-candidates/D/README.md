# 후보 D — 수묵 UI + 고해상도 도트

정사각 탑다운 격자에 64×64 원본 셀(×1 표시)의 hi-bit 도트를 쓴다. 부대·지형은 차분한 흙빛 팔레트에 부위별 1px 어두운 테두리(sel-out)와 먹색 외곽선을 넣는다. 차별점은 UI다. 화선지 질감 패널, 붓질 먹 테두리, 진영과 턴을 표시하는 붉은·청색 낙관, 족자형 행동 메뉴, 수묵 산수 배경의 족자 표구 초상을 쓰고, 지도 위 장식은 최소화했다. 지도에는 맵 단위의 3단 먹 농담(seamless 월드 좌표 노이즈)을 깔아 붓으로 칠한 느낌을 낸다.

실행: `python3 art-candidates/D/gen.py` (ver2/에서 실행, Pillow만 사용, 결정적)

## 규격

| 항목 | 값 |
|---|---|
| 부대 셀 | 64×64, 원본 = 표시(displayScale 1) |
| 기준점 | (32,57): 발/말발굽 외곽선의 최하단 행. 모든 프레임 고정 |
| 지형 타일 | 64×64. 초원/숲 바닥은 64px 주기 노이즈라 이음매가 없다 |
| 초상 | 72×72 원본, ×3 표시(216×216) |
| 알파 | 0/255만 사용 |
| 시트 행 | 0 `infantry-ally` 대기 0–7 · 걷기 8–15 / 1 `cavalry-ally` 대기 0–7 · 걷기 8–15 / 2 `bandit-enemy` 대기 0–7 |
| 시간 | 대기 150ms, 보병 걷기 100ms, 기병 걷기 110ms (초안) |

동작
- 보병 대기: 발을 고정한 채 상체만 1px 호흡한다 `[0,0,0,1,1,1,0,0]`.
- 보병 걷기: 접지 → 하강 → 통과(발 들기) → 상승 → 반대 접지 순서이고, 방패와 칼 든 팔이 반대로 흔들린다.
- 기병 대기: 다리를 고정하고 목·꼬리·기수 호흡만 움직인다.
- 기병 걷기: 4박 보법이다. 각 다리는 5/8 접지, 3/8 들기이며 항상 두 다리 이상이 땅에 닿는다.

## 영걸전·조조전 목표 대비

강점
- UI가 시대감과 독자성이 가장 뚜렷하다. 정보가 화선지 패널 한 곳에 모이고 지도 위 UI가 최소라 전장이 넓게 보인다.
- 64px 셀이라 후반에 장비·병종 차이를 그릴 여유가 있다.
- 부위 레이어와 정수 이동으로 동작을 구성하므로 고정 부위의 픽셀이 프레임 간에 정확히 같다.

한계
- 캐릭터가 64 셀 안에서 약 30×50px로 작다. 조조전 정도의 밀도를 얻으려면 손으로 다듬어야 한다. 현재 몸체는 절차적 도형 조합이라 손맛과 관절 표현이 부족하다.
- 걷기 보폭은 정면 3/4에서 좌우 이동으로 표현해 조금 미끄러져 보인다.
- 말 다리의 관절 표현이 단순하다.
- 마을은 64px 타일 안에 집 1–2채를 넣는 구성이라 반복감이 있다. 경계 자동 연결(autotile)이 없다.
- 수묵 UI는 어두운 정보 패널·금색 테두리라는 기존 4.2 팔레트 지침과 다르다. 밝은 종이 위 먹 글씨라 대비는 충분하지만 지침 변경이 필요하다.
- 걷기 이외의 공격·피격·탈진 동작과 일기토 측면 원화는 아직 없다.
