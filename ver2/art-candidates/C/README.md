# 후보 C — 아이소메트릭

상위 저장소의 32×16 마름모 지형 체계(`screenX=(u−v)×16`, `screenY=(u+v)×8`)를 그대로 이어받은 쿼터뷰 전장이다. 맵 전체를 한 덩어리의 흙 받침(slab) 위 디오라마로 보여 주고, 나무·바위·잔디는 상위 저장소 `assets/objects.png`를 입력으로 읽어 재사용한다(상위 파일은 수정하지 않음). 부대는 화면 오른쪽 아래(SE)를 바라보는 2.5등신 도트이며 적은 좌우 반전해 SW를 본다. 격자는 옅은 마름모 선으로 그리고, 이동 범위는 청색 반투명, 공격 대상은 적색 마름모로 표시한다. UI는 금색 테두리의 반투명 남색 패널로, 마름모 맵이 비워 두는 네 모서리(좌상 제목·우상 턴/목표·좌하 장수 카드·우하 기록)에 배치하고 행동 메뉴는 좌상 빈 공간에서 선택 부대로 연결선을 긋는다.

```sh
python3 art-candidates/C/gen.py   # ver2/에서 실행, Pillow만 사용, 결정적
```

## 규격

| 항목 | 값 |
|---|---|
| 지형 타일 | 32×16 마름모, 맵 받침 두께 7px |
| 부대 셀 | 40×40, 접지 기준점 (20,36) — 발/말발굽 외곽선 최하단 행 |
| 표시 배율 | 시트·미리보기 ×3, 전장(18×14 전체) ×2 |
| 초상 | 48×48, ×3 표시(144px), 배경 투명·프레임은 UI가 그림 |
| 시트 행 | infantry-ally(대기8+걷기8), cavalry-ally(대기8+걷기8), bandit-enemy(대기8), officer-enemy(대기8), cavalry-enemy(대기8) |
| 재생 | 대기 150ms, 보병 걷기 100ms, 기병 걷기 110ms |
| 알파 | 0/255만 사용, 1px 외곽선 자동 부여(상위 오브젝트와 동일한 언어) |

팔레트(스프라이트): 외곽 #16121A, 피부 #ECBA8C/#C48662, 청색 갑옷 #5480CC/#32529A/#1E2A5C, 금장 #E2B852/#A0702C, 강철 #D6DEE6/#7A8498, 적 #C83634/#7C2028, 황건 #F0CE48/#B28828, 가죽 #926038/#563624, 말 #B27446/#804E30/#4E2E20. 지형: 초원 #6F9A48 계열, 마을 흙 #B99863 계열, 물 #2F6F86 계열, 받침 #6B4A33 계열.

프레임 순서: 대기 = 상체 호흡 `0,0,0,1,1,1,0,0`px(발 고정), 걷기 = 접지(뒤A/앞B)→하강→통과(B 들림)→상승→접지(앞A)→하강→통과(A 들림)→상승, 반대 팔 1px 흔들기. 기병 걷기는 4박 보행(다리 위상 2프레임씩 어긋남), 말 머리 끄덕임과 몸통 1px 하강, 발굽은 접지 행 고정.

## 검수 결과

- 모든 프레임: 알파 ⊆ {0,255}, 최하단 불투명 행 = 36(기준점), 셀 가장자리 접촉 없음 — `gen.py` 실행 시 자동 검사.
- 머리·투구·방패·말 몸통은 동일 격자를 정수 오프셋으로만 재사용(프레임별 다시 그리기·배율 변경 없음).

## 영걸전·조조전 목표 대비

장점
- 상위 저장소의 지형 에디터·오브젝트·결정적 배치를 그대로 잇는다. 맵 전체가 한 화면에 보이고 입체감(받침·나무 겹침)이 있다.
- 정사각 격자 대비 대각선 화면 구성이 넓어 18×14 전체와 UI 네 패널을 1280×850 안에 동시에 담는다.

한계
- 영걸전·조조전은 정면 내려다보기 정사각 격자다. 아이소메트릭은 원작의 화면 문법과 다르며, 이동·사거리 마름모가 정사각 격자보다 읽기 어렵다.
- 전장 ×2에서 부대가 화면상 약 30×56px로 작다. 인접 칸(같은 열 위아래) 부대가 겹쳐 보이고, 높은 집·나무 뒤 부대가 가려진다(마을 칸 일부에만 집을 둔 이유).
- 단일 방향(SE) 원화 + 좌우 반전이라 북쪽으로 이동할 때 뒷모습이 없다. 실제 게임에는 NE/NW 뒷모습 원화가 추가로 필요하다(작업량 약 2배).
- 공격·피격·탈진, 일기토 측면 원화, 산·성 지형은 이 후보에 포함하지 않았다. 말 머리 형태와 기수-말 비율은 추가 다듬기가 필요하다.
