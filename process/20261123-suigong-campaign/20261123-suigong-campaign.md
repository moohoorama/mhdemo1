# 수공 본편 적용과 하비 회상 장면맵·신야 전투 재구성

사용자가 `result/20261123/20261123-suigong-march-water-audio/suigong.mp4`의 수공 연출을 매우 좋아했고 **본편에 적용**해 달라고 했다. 이어서 아래의 하비 회상 장면맵과 신야 전투를 수공에 맞춰 재구성한다. 실제 데이터·코드 적용과 검증을 수행한다.

## 1. 승인된 수공 연출 본편 적용

- 승인 영상: `result/20261123/20261123-suigong-march-water-audio/suigong.mp4`
- 구현·검증 기록: `result/20261123/20261123-suigong-march-water-audio/result.md`
- 기존 관련 코드·에셋: `ver5/internal/gui/uidemo_suigong.go`, `ver5/internal/gui/field_surge.go`, `ver5/tools/floodsim.py`, `ver5/assets/graphics/effects/flood/`, `ver5/assets/sounds/flood-*.ogg`
- 먼저 현재 25장의 이야기·장면·전투 연결을 조사하고, 승인된 연출의 장면 구성, 카메라, 둑·물·파편, 조조군 걷기와 소리를 실제 본편 흐름에 자연스럽게 연결한다. 데모 전용 동작이 본편에서 빠지지 않도록 게임 캡처와 효과음을 확인한다.

## 2. 관우·미축의 하비 회상 장면맵

- 현재 관우와 미축이 하비를 회상하는 장면맵이 이상하므로 새롭게 만든다. **현재보다 약 3배 크고**, 이야기의 맥락에 맞으며 멋진 장면을 요청했다. 실제 기존 맵의 가로·세로·면적을 확인해 어떤 치수를 늘렸는지와 이유를 기록한다.
- 후보 위치: `ver5/assets/scenario/hero/story25.json`의 `c25-flash1`(하비 거리 회상)과 `c25-flash2`(하비 성 밖 회상). `ver5/assets/scenes/ch25.json`에서 실제 사용 맵과 연출을 확인하고, 사용자가 지칭한 해당 장면을 판별한다. 필요하면 두 회상 장소의 연결도 함께 살핀다.
- 기존 대사와 이야기 맥락, 등장인물 위치·시선, 카메라와 실제 보이는 화면을 확인하여 설계한다. 이야기 문구를 쓰거나 바꿀 필요가 있으면 `ver5/docs/story-writing.md`의 초안·사용자 선택 절차를 따른다.

## 3. 신야 전투 재구성

- **신야성에서 북서쪽으로 가는 조조군의 허리가 수공으로 끊긴 뒤**, 서쪽에서 유비군이 공세를 취하고 조조군이 패주하는 전투로, 승인된 수공 장면의 지형·방향·구도에 맞춰 전투맵과 배치·전투 흐름을 재구성한다.
- 물길과 둑, 진군 방향, 전투 시작 시 병력의 위치와 퇴로가 앞선 영상 및 이야기와 서로 맞아야 한다. 지형과 실제 플레이에서 이 흐름이 읽히도록 한다. 유비군이 서쪽에서 공격하고 조조군이 패주한다는 핵심을 지킨다.
- `ver5/docs/stage_lv_balance.md`, `ver5/docs/presentation-facing.md` 및 관련 장면 문서를 먼저 읽고 랭크·병력 수·시선·이벤트를 정한다. `_balance` 측정, `srpg-cli -slot 9` 실제 플레이와 GUI 캡처를 프로젝트 지침대로 수행한다. 다른 기존 미커밋 변경을 보존한다.
