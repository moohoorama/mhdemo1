# 연의 장판파와 적벽 개편

기존 작업을 먼저 Git 체크포인트로 커밋하고, Markdown 계획을 작성한 뒤 합의한 연의 루트를 구현한다.

- 장판파는 조운이 구한 아두를 데리고 빠르게 다리를 돌파한다. 흩어진 아군 보병은 HP 약 3분의 2로 시작하고, 버티는 시간은 양군의 거리로 조절한다. 조조군을 약화하거나 아군에 버프를 주지 않는다.
- 장비는 개막에 장판교로 이동한 뒤 자리 고정. 조운과 장비 필수 출전, 유비 제외, 자유 편성 둘. 두 장수의 퇴각 또는 후방 진영 침입은 패배. 조운 도달과 하후은 일기토는 부목표. 조운이 건너면 하후돈과 장비의 교전, 먼지 보고, 강릉 우회, 장비의 후방 이동을 거쳐 승리한다.
- 강하와 번구의 왕복은 유지한다. 흩어진 장수와의 재회, 공명의 전갈, 오군과의 회의, 관청 정비와 암전, 적벽 소집 및 화용도 복병 배치를 구현한다.
- 적벽은 U자 강과 강하 앞 좁은 수로에 조조·주유의 수군과 육상 본대를 배치한다. 관우·장비·조운은 모두 화용도에 가 있어 유비·제갈량과 유기의 본군만 출전한다. 황개의 화공과 동남풍, 조조군 혼란 및 북쪽 후퇴, 건재한 장윤 수군을 구현한다. 조조 퇴각도 승리이며 성과 차등은 작게 둔다.
- 화용도 독립 전투를 제거한다. 강하에서 유기의 부상과 복병 성과를 보고하고, 관우의 군령 위반, 유비와 제갈량이 함께 무릎 꿇는 연출, 공동 책임 인정, 잔치와 2장 종료를 연결한다.
