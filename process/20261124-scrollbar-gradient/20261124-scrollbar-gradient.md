# 도트 스크롤바 그라데이션 시안과 스크린샷

기존 도트 스크롤바 시안에 **픽셀 단위 그라데이션과 명암**을 주어 더 입체적으로 만들고, 실제 게임 스크린샷을 보여 달라는 요청이다. 기존 5종을 바탕으로 각 시안의 색과 모양을 살리면서 명암을 적용해 비교한다. 벡터의 부드러운 블러가 아니라 도트를 직접 배치한 색 단계와 필요시 디더링으로 표현한다.

- 기존 결과·시안: `result/20261124/20261124-scroll-sortie-pixel/result.md`, `comparison.html`. 기존 소스: `tools/spritetool/assets/ver5-ui/seed.py`, `pixels.json`, `settings.json`, 관련 게임 UI 에셋과 `scrollbar_style.go`. 기존 창의 금색 `window_rim` 아트와 톤·빛 방향도 참고한다.
- 해당 아트 가이드와 대상 에셋 설정·README를 먼저 읽고, 런타임 에셋과 원본을 프로젝트 규칙에 맞게 다룬다. 9분할 조각의 모서리·반복 구간과 상태별 썸이 늘려도 끊기지 않도록 한다.
- 같은 실제 게임 화면에서 각 시안의 PC·모바일 참고 크기 스크린샷을 캡처하고, 실제 크기와 확대본을 나란히 볼 수 있는 비교 페이지를 만든다. 게임 캡처가 아닌 이미지는 구분한다. 기존 카드 크기·공통 스크롤 동작과 다른 작업의 미커밋 변경을 보존한다.
- `result/YYYYMMDD/<task-name>/`에 PNG·비교 페이지·결과 Markdown을 저장하고 `ver5/docs/history.md`를 갱신한다. 테스트와 실제 확인 범위를 기록한다. 사용자가 선택하기 전 최종 스타일을 확정하지 않는다.
