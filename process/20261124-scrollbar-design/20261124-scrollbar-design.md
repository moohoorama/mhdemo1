# 공통 스크롤바 디자인 시안 5개와 게임 화면 캡처

기존 공통 스크롤 영역 작업에 사용할 스크롤바를 새로 디자인하고 **서로 구분되는 시안 약 5개**를 만들어 사용자가 스크린샷으로 비교할 수 있게 보여 달라는 요청이다.

- 현재 게임의 UI 스타일과 기존 스크롤바를 먼저 조사한다. 기존 HTML 동작 시안 `result/20261123/scroll-window-proposal/index.html`과 관련 요청 `process/20261123-scroll-sortie-implement/20261123-scroll-sortie-implement.md`를 참고한다. 이전 공통 스크롤·출전 3열/5열 작업은 마지막 보고서상 미구현이므로 이미 적용됐다고 가정하지 않는다.
- 같은 출전 부대 목록 등 스크롤이 보이는 실제 게임 화면에서 각 디자인을 비교할 수 있게 한다. 가로·세로가 작아도 손잡이와 터치 위치를 알아볼 수 있고 마우스로도 조작하기 쉬운 디자인을 고려한다. 화면의 분위기, 대비, 손잡이·트랙·끝점, 스크롤 가능 여부가 각각 어떻게 보이는지 살핀다.
- `ver5/cmd/_uidemo-vm` 등 프로젝트 지침에 따라 **실제 게임 화면으로 각 시안을 캡처**한다. PC와 휴대폰 참고 크기 또는 UI 배율에서도 알아볼 수 있게 하며, 동일 조건으로 비교한다. 기존 다른 작업의 미커밋 변경을 보존하고, 공유 소스 수정이 다른 작업과 겹치면 충돌을 피할 방법을 먼저 판단한다.
- `result/YYYYMMDD/<task-name>/`에 시안별 PNG와 5개를 나란히 볼 수 있는 HTML 또는 이미지 비교판을 저장한다. 각 시안의 이름, 특징과 모바일에서 손으로 잡을 영역에 관한 설명을 간단히 덧붙인다. 실제 게임 캡처가 아닌 모형은 구분해 표시한다.
- 사용자가 고르기 전에는 어느 시안도 최종 채택했다고 가정하지 않는다. 시안 생성에 사용한 변경과 검증·남은 사항을 결과 Markdown에 기록하고 `ver5/docs/history.md`를 갱신한다.
