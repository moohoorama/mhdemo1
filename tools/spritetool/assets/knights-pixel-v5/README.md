# 기사 에셋 설정 · v5 프레임별 도트 보정

[공통 제작 가이드](../SPRITE_ART_GUIDE.md)와
[캐릭터 설정](../knights-pixel-v4/README.md)을 적용한다.
48×48 셀, (24,38) 기준점, 28색, 알파 0/255, 방향·행·프레임 순서와 시간은 v4와 같다.

160프레임을 방향별 확대 시트로 확인하고 14프레임의 국소 문제를 수정했다.
`review.json`은 수정하지 않은 프레임을 포함한 전체 검수 목록이다.
각 변경에는 이유·픽셀 좌표 또는 마스크·변경 픽셀 수를 기록한다.

- NE 걷기 1: 떨어진 양쪽 팔 연결.
- SE 걷기 3: 방패 팔과 몸통 절단면 연결.
- SW 걷기 1·3: 가슴 빈틈, 검 옆의 잔여 조각, 발 아래 잔여 픽셀 보정.
- W 걷기 1·3: 가슴 빈틈, 검 조각, 방패 밑줄 보정.
- NW 걷기 3: 가슴 빈틈과 발 주변 잔여 픽셀 보정.
- SE 피격 3·4: 예전 손·방패 잔재 제거, 골반 연결 및 방패 회전 구멍 보정.
- S 피격 3·4: 방패 아래 남은 줄 제거 및 방패 구멍 보정.
- SW 피격 3: 회전한 상체와 골반 연결.
- W 피격 3·4: 떠 있는 방패 밑줄 제거.

전역 자동 조각 삭제나 추가 회전·리사이즈를 하지 않는다. 작은 분리 부위도 장비일 수 있으므로
실제 의미를 확인해 연결하거나 지운다. 머리·눈의 모양, 발 위치, 선택한 자세를 유지한다.
대기·공격·탈진의 픽셀은 그대로 보존했다.

```sh
python3 tools/retouch_knight_frames.py
python3 tools/build_knights.py
```

입력 v4는 보존한다. 미리보기의 ‘수정 직전 · 조각 비교’가 보정 전 런타임 아틀라스다.
이번 보정은 기존 staged 버전을 변경하지 않고 작업 트리에 남긴다.
