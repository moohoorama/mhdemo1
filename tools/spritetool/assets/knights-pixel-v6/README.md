# 기사 v6 · 연결부 재구성

[공통 기준](../SPRITE_ART_GUIDE.md)과 [크기·방향·시간 설정](../knights-pixel-v4/README.md)을 따른다.
v5의 조각 삭제와 빈틈 채우기는 사용자가 지적한 형태 파손을 해결하지 못했다.
분리 성분 개수나 셀 경계 검사 통과는 자연스러운 형태를 보장하지 않는다.

걷기·피격·탈진을 v2의 온전한 기준 자세에서 다시 구성한다.

- 가슴과 팔은 별도 사각형 조각으로 붙이지 않는다. 부드럽게 이어지는 이동장을
  역방향 최근접 샘플링해 어깨·팔꿈치의 연결을 유지한다. 이동장을 부드럽게 만들 뿐
  출력 이미지에 블러나 중간색을 넣지는 않는다.
- 걷기의 투구·눈은 고정한다. 신발은 원래 픽셀 모양을 유지하고 무릎 연결부를 그린다.
  방패와 겹치는 다리 경계는 별도로 지정해 방패 밑부분을 발과 함께 옮기지 않는다.
- 피격은 머리부터 허리까지 이어지는 뒤로 젖힘이며 발 쪽에서 변형을 0으로 줄인다.
- 탈진은 온전한 첫 자세의 호흡으로 바닥 근처까지 연결한다.
- 대기와 공격은 v5에서 유지한다. 색, 알파, 셀과 배치 기준점은 동일하다.

```sh
python3 tools/rebuild_knight_motion.py
python3 tools/build_knights.py
```

검수는 확대 프레임에서 실제 어깨·손목·허리·무릎의 형태와 장비 겹침을 확인한다.
숫자 검증은 머리의 픽셀 유지, 피격 발 고정, 4개 보행 자세, 원본-아틀라스 일치,
투명도와 잘림을 보조 확인하는 용도다. 브라우저 재생 확인과 별개로 기록한다.
이전 v5는 미리보기의 ‘직전 조각 보정본’에서 비교한다.
