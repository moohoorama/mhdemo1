# ver2 병종 후보 (SW, 대기 첫 프레임)

[공통 기준](../SPRITE_ART_GUIDE.md)을 따른다. ver2 후보의 경보병·황건 적병·경기병을 기사 v6 화풍으로 다시 그린 외형 후보다.
병종마다 4종이며 선택 후 애니메이션과 다른 방향을 제작한다.

| 항목 | 보병·적병 | 기병 |
|---|---|---|
| 셀 | 48×48 | 48×56 |
| 기준점 | (24,38) — 기사 v6와 동일 | (24,50) — 가까운 앞발굽 최하단 행 |
| 팔레트 | 기사 v6 28색 + 삼베 3색 `#d9c698` `#a89266` `#6c583c` | 동일 |
| 알파 | 0/255 | 0/255 |

- 보병·적병: 기사 SW 대기 프레임의 몸통·다리·발을 그대로 쓰고 머리·무기·방패만 교체했다. 머리 크기는 기사 투구와 같다.
- 얼굴: 투구·두건 테두리 아래에 그림자 한 줄을 두고 눈(세로 2px)을 그 아래에 둔다. 모든 머리가 같은 얼굴 행을 공유한다.
- 황건 적병: 장착 무기인 칼을 모두 든다. 기사 칼과 손 위치를 그대로 쓴다.
- 기병: 기사 원본과 같은 3D 렌더 계열인 `imageset/legacy/dist/units/cavalry.webp` 대기 첫 프레임을 체크무늬 제거 → 0.18배 BOX 축소(기수 투구 ≈ 10px) → 기사 팔레트 양자화 → 점 얼룩 제거 → 두께 3px 이상 영역의 가장자리 1px 외곽선 순으로 도트화했다. 말 털색은 팔레트 치환, 기수 머리는 보병 머리 격자로 교체한다.

```sh
python3 tools/unit3d/candidates_2d.py   # → 이 폴더 PNG 12장 + output/ver2-unit-candidates.png
```
