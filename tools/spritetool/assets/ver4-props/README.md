# ver4 장면 소품·실내 타일

시나리오 장면 무대에 놓는 소품과 실내 타일. 생성: `python3 tools/unit3d/props.py`
(후보 비교: `python3 tools/unit3d/props.py --candidates` → `output/ver4-prop-candidates.png`).
고른 것은 `props.py`의 `CHOSEN`, 나머지 후보 정의는 백업으로 남긴다(2026-10-05 사용자 선택).

## 크기 기준

- 전투 맵 타일·구조물(`ver4-structures/`)은 맵 픽셀(칸 32×16)로 그리고 게임에서 K=2배로 늘린다.
  **소품은 캐릭터와 같은 1배 픽셀**로 그린다. 그래서 캔버스에서 한 칸은 64×32이고, 서 있는 장수는 약 30px이다.
- 칸에 맞춰야 하는 것(바닥·다리·벽·성문)은 한 칸 = 모델 2단위(`props.TILE`)로 그린다. 높이는 캐릭터 기준 그대로다.
- 따로 서는 소품(군막·깃발·탁자·주막 등)은 캐릭터 크기에 맞춘다. 주막은 건물이라 1.6배 키웠다.
- 렌더러·카메라는 `structures.py`와 같다(방위 SW, 고도 30도, 셀 렌더 외곽선). 모델 x = 맵 u, 모델 y = −맵 v.

## 시트

`props.png`에 소품마다 픽셀 경계로 잘라 가로로 붙인다. `props.json`의 `sprites[이름]`:
`rect`(시트 안 x, y, w, h), `pivot`(rect 안 좌표, 바닥 발자국 중심 = 놓는 칸의 중심), `layer`.

| layer | 그리는 방법 |
|---|---|
| `ground` | 지면에 굽는다(바닥·다리). 유닛보다 항상 아래 |
| `object` | 유닛과 함께 발밑 y로 정렬한다 |

| 이름 | 내용 |
|---|---|
| `floor_wood`, `floor_carpet`, `floor_palace`, `floor_tent` | 나무 마루, 금테 붉은 카펫, 검은 전돌(궁), 흙바닥+돗자리(막사) |
| `bridge_u`, `bridge_v` | 난간 없는 나무 다리. u/v 방향으로 놓아 폭과 길이를 칸 수로 정한다 |
| `wall_plaster_nw/ne`, `wall_lacquer_nw/ne`, `wall_canvas_nw/ne` | 회벽+목재, 붉은 칠(궁), 천막 벽. 칸의 뒤쪽 변(nw·ne)에만 세우고 앞은 비워 무대처럼 안을 보인다. 조각마다 따로 렌더해서 ㄱ자 그림자가 없다 |
| `pillar_red`, `pillar_wood` | 붉은 칠 기둥, 나무 기둥 |
| `dais` | 상석: 2단 단상, 의자, 뒤쪽 두 변의 병풍 |
| `table_wine`, `altar`, `desk` | 술상, 제단(향로·향·복숭아), 서안(종이·붓) |
| `peach_tree` | 꽃이 만개한 복숭아나무 |
| `gate_u`, `gate_v` | 문루가 있는 성문. 통로 높이 1.6단위(서 있는 장수보다 높음) |
| `notice_board` | 방문(벽보) |
| `tent`, `tent_round` | A자 군막, 원형 장수 막사 |
| `banner`, `command_flag` | 긴 깃발, 사각 사령기 |
| `forest_0`–`forest_3` | 전투 맵 숲(`f`) 칸: 굵은 3층 침엽수 9그루를 칸 전체에 고르게 흩뿌려 이웃 칸과 이어진다. 배치를 흔든 변형 4장을 칸마다 번갈아 쓴다(5차 후보, 2026-10-05 사용자 선택) |
| `tavern` | 주막: 돌 기단, 회벽 목조, 짚 지붕(처마·용마루 짙은 짚, 짚 결), 붉은 포렴과 등롱, 평상과 술독, 술 깃발 |

- 팔레트는 병종과 같은 키(`tools/unit3d/render.py`). 복숭아꽃은 분홍 램프 `A B C D`를 추가했다. 알파 0/255.
- 장면 맵에서는 `ver4/assets/scenes.json` 맵의 `Props`로 놓는다: `[이름, x, y]`(소수 가능) 또는 바닥 채우기 `[이름, x0, y0, x1, y1]`.
- 전투 맵에서는 지형 기호로 놓는다(2026-10-05 사용자 결정): `b` 나무 다리는 모든 계열에서 초원과 같은 보정·이동 비용,
  `g` 성문은 진입 불가. GUI가 다리 방향(양 끝이 땅인 축)과 성문 방향(성벽이 이어지는 축)을 고르고, 성벽은 성문을 성벽으로 보고 이어 그린다.
