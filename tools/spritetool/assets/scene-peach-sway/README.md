# 장면 복숭아나무 흔들림 시안

대상은 `peach_bloom_0`이다. 게임 원본은 `assets_candidate/tiles/peach_bloom_0.png`이고 이 폴더의 결과는 시안이다.

- 프레임 순서: 바람의 한 주기를 0~7로 균등 분할, 0 다음에 7이 이어지는 반복 재생.
- 재생 시간: 프레임당 160ms(한 주기 1280ms).
- 최종 도트 셀: 93×96px, 뿌리 기준점 (56, 91). 여덟 칸 모두 같은 셀과 기준점.
- 팔레트와 변환값: `assets_candidate/tiles/sources/trees.json`의 `peach_bloom_0` 설정.
- 3D 참조: `ver5/tools/render_peach_sway.py`가 줄기·가지 면을 고정하고 꽃·잎 면만 조금 움직인다.
- 그림: 3D 참조 8칸을 포즈로, 기존 손도트를 그림체로 삼아 한 장에 다시 그린다. 마젠타 배경, 칸 밖 내용 없음. 고해상도 시트는 제작 중간 결과이며 HTML에는 보이지 않는다.
- 도트 변환: 각 칸에 `ver5/tools/pixelize_tree.py`의 팔레트 매핑·외곽선 처리를 적용한다. `prepare_peach_sway.py`가 생성 과정에서 달라진 줄기·가지 픽셀을 첫 프레임으로 통일한다.

| 파일 | 내용 |
|---|---|
| `reference-3d.png` | 3D 모델에서 렌더한 4×2 자세 시트 |
| `painted-sheet.png` | 이미지 생성 도구로 다시 그린 4×2 중간 원화 시트 |
| `dot-sheet.png` | 팔레트·외곽선 처리한 4×2 투명 도트 시트 |

그림 생성 도구에는 고정된 줄기의 3D 시트를 **자세 참조**, 기존 `assets_candidate/tiles/sources/peach_bloom_0.png`를 **화풍 참조**로 주었다. 요청은 “같은 복숭아나무 여덟 자세를 순서와 뿌리 위치를 지킨 4×2 시트로 다시 그릴 것. 어두운 굽은 줄기, 유기적인 분홍 꽃, 작은 녹색 잎, 기존 화풍·색·왼쪽 위 빛을 유지할 것. 줄기와 모든 갈색 가지는 프레임마다 같은 자리에, 꽃과 잎만 산들바람에 조금 흔들릴 것. 둥근 3D 덩어리와 플라스틱 같은 명암을 피할 것. 칸 밖은 순수한 #FF00FF, 글자·테두리·그림자·바닥은 없을 것”이었다.
