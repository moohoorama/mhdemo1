# 병종 스프라이트 기준

병종(보병·기병·궁병·영웅 등) 스프라이트를 만들거나 고칠 때 [공통 기준](SPRITE_ART_GUIDE.md)과 함께 읽는다.
구현 설명은 [`tools/unit3d/DESIGN.md`](../../unit3d/DESIGN.md), 현재 세트 기록은 [`ver2-units/README.md`](ver2-units/README.md).

## 1. 화풍 기준

- **기준 그림은 기사 v6**(`knights-pixel-v6/`)다. 2.5등신, 머리(투구) 약 10px, 1px 외곽선, 렌더 배율 11.5px/단위.
- **팔레트**는 기사 v6 28색이 기본이다. 추가는 재질 단위로만 한다: 삼베 `S T U`, 녹색 `G H I J`, 붉은 피부 `K L M`,
  진영 키 `W X Y Z`(`tools/unit3d/render.py`의 `EXTRA`). 새 색이 필요하면 4단 램프로 추가하고 이 목록에 적는다.
- **몸 도트는 알파 0/255**, 이펙트만 반투명이다.

## 2. 만드는 방식: 3D로 자세·방향, 2D로 얼굴

- 몸·무기·말은 3D 관절 모델(`tools/unit3d/units.py`)을 목표 해상도로 직접 렌더한다. 크게 그려 줄이지 않는다.
  4배 슈퍼샘플 후 칸마다 최빈 (재질, 명암 단계)를 골라 팔레트 키로 바로 바꾼다. 새 색·블러가 생기지 않는다.
- **카툰 명암**: 빛은 화면 기준 왼쪽 위 하나(모든 방향 동일). 그림자·기본·밝은 면·반사광 4단, 경계는 끊는다.
  다른 부위에 가려지는 곳에 그림자를 떨어뜨린다(기수 아래 말 등, 머리 아래 목, 팔 아래 몸통).
- **선**: 실루엣 바깥 1px + 앞뒤로 겹치는 경계의 뒤쪽 1px. 부위마다 다르게 두지 않는다.
- **얼굴은 손그림 머리**(`tools/unit3d/heads.py`)를 투영한 머리 중심에 찍는다. 3D로 얼굴을 그리지 않는다.
- 48px에서 사라지는 가는 부위(창대·활·시위)는 굵게 과장한다.
- 오목한 형태(초승달 날, 물결 창날)는 볼록 사각형 띠로 나눠 그린다. 렌더러는 볼록 다각형만 채운다.

## 3. 머리와 얼굴

- 13px 폭 격자. S·SW·W·NW·N 5종을 그리고 SE·E·NE는 좌우 반전한다.
- 얼굴 구성은 모든 병종이 같다: 투구·두건 테두리 → 그 아래 그림자 한 줄(`i`) → 세로 2px 눈(`0`) → 볼·턱.
  테두리를 밝은 색 줄로 그리면 머리카락·눈썹처럼 보이므로 피한다.
- 뒷모습(N·NW·NE)은 머리카락·투구 뒷면만 그린다. 검은 덩어리가 얼굴처럼 보이지 않게 머리카락은 짙은 갈색(`f g`)과 하이라이트를 쓴다.
- **표정**은 눈 픽셀을 자동으로 바꾼다(`heads.expression`): 피격 3·4프레임은 질끈 감은 눈 + 벌린 입,
  탈진은 반쯤 감은 눈 + 입 + 땀방울. 새 얼굴은 눈이 "피부 사이의 세로 2px `0`" 규칙을 지켜야 표정이 적용된다.
- 머리 위로 긴 장식(여포 꿩깃)은 격자 위에 행을 더하고 `heads(..., crest=행 수)`로 얼굴 기준점을 유지한다.
  귀(유비)처럼 작은 특징은 1–2px로만 넣는다. 크게 그리면 볼처럼 보인다.
- **영웅은 고유 조형**으로 구분한다(관우 긴 수염·붉은 얼굴, 장비 뻣뻣한 수염·거뭇한 얼굴). 기존 머리에서
  색 치환 + `heads.beard` 등으로 파생시키고, 상징색은 진영색으로 바꾸지 않는다.

## 4. 동작

| 동작 | 기준 |
|---|---|
| 대기 | 발 고정, 상체만 1px 호흡. 기병은 기수 호흡·말 고개 끄덕임·꼬리·몸통 호흡까지 |
| 걷기 | 원본 3D 보행(팔다리 교차, 통과 자세 포함) |
| 공격 | **1·2프레임 힘 모으기 → 3프레임 터뜨리기 → 4프레임 마무리**. 재생 180·280·240·200ms |
| 피격 | **자세만**. 3프레임에 상체가 뒤로 휘청·팔이 늘어짐, 4프레임 회복. 번쩍임·색 입히기·파티클은 런타임 특수효과 |
| 탈진 | 원본 주저앉기 + 탈진 표정 |

공격 설계(`tools/unit3d/attacks.py`):

- 힘 모으기 자세는 **좌하단(SW)에서 무기가 보여야 한다**. 무기 팔이 몸 반대편에 있으므로 무기를 몸 바깥·위로 뺀다.
- 휘두르기 궤적은 **경유 자세(`via`)를 따라간다**. 두 키프레임을 직선 보간하면 머리 위가 아닌 몸 앞을 질러가 궤적이 짧고 틀린다.
- 트레일 반경은 칼날보다 30%(장병기 10%) 넓게 과장한다.
- 찌르기는 무기와 같은 궤적을 그리지 않는다: 끝 앞의 쐐기 + 충격 고리 + 몸 뒤 속도선.
- 활은 활에서 화살까지 반투명 꼬리 + 속도선.

## 5. 이펙트

- 반투명 레이어(`tools/unit3d/effects.py`). 몸 뒤(under)가 기본, 찌르기 쐐기·고리만 앞(over).
- 픽셀은 또렷하게(4배 그려 칸 판정), 띠마다 고정 알파: 트레일 몸통 약 35% · 바깥 60% · 날 끝 85%.
- 색은 하늘색 계열 `p q r`만 쓴다. 별·꽃 모양 충격 이펙트는 쓰지 않는다(꽃처럼 보인다).

## 6. 진영색

- 진영 따라 바뀌는 부위(상의·두건·허리 장식·안장·투구 술·황건 띠)는 **진영 키 `W X Y Z`로만** 그린다.
  이 색은 다른 재질에 쓰지 않는다. 그래야 키색 픽셀만 치환해도 칼·테두리가 물들지 않는다.
- 고정: 피부·철·가죽·무기·말·수염, 영웅 상징색(관우 녹포, 장비 흑갑).
- 진영은 색을 고르지 않고 OKLCH **색조·채도 배율·밝기 보정**으로 정의한다(`tools/unit3d/factions.py`).
  흰색은 채도↓밝기↑, 곤색은 밝기↓, 노랑 계열은 밝기↑채도↑. 비슷한 색조의 진영은 색조를 조금씩 다르게 둔다.

## 7. 정렬과 검사

- 방향마다 **대기 첫 프레임의 최하단(발 외곽선) = 기준점 행**, 같은 보정을 그 방향 전체에 쓴다.
- 칸 크기는 병종의 **전 프레임 합집합 + 1px**로 자동으로 정한다. 칸을 추측해 고정하지 않는다.
- 작업 캔버스 가장자리 비접촉, 대기 접지 행을 생성 시 검사한다(`build.py`).
- 확인은 반드시 실제 렌더 결과를 크게 보고 한다: 좌하단 정지 프레임 → 8방향 → 재생(뷰어).

## 8. 작업 흐름

1. 외형·동작은 **좌하단(SW) 한 장으로 후보 4개**를 만들어 사용자가 고른다.
2. 고르지 않은 후보는 지우지 않고 **백업**한다(정의는 코드에 남기고 선택만 `SELECTED`로).
3. 고른 것을 **8방향 대기**로 확인 → **전체 동작** 렌더 → 뷰어(`ver2-units-preview.html`)로 확인.
4. 바뀐 기준은 이 문서에, 세트 기록은 세트 폴더 README에 적는다.

Codex 이미지 생성은 일러스트·원화용이다. 줄이면 화풍과 프레임이 흔들리므로 스프라이트 제작에 쓰지 않는다.

## 9. 겪은 실수

- 기사 v6 프레임의 머리 영역을 사각형으로 지우면 몸·칼이 잘리고(E 일자 잘림) 공격·피격 프레임에서 머리를 추적할 수 없다.
- 원화를 축소해 도트를 만들면 얼룩이 생기고, 블록 최빈만 쓰면 외곽선이 두꺼워진다.
- 직선 보간 궤적, 오목 다각형, 셀 가장자리 닿음(트레일·화살·말 일어서기)은 한 번씩 문제를 냈다.
- 미리보기 모드가 완성 시트를 덮어쓰지 않게 한다(검토 모드는 검토 시트만 쓴다).
