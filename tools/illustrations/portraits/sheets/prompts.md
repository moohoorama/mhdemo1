# 초상 시트 프롬프트 (2026-10-05)

각 시트는 `tools/illustrations/portrait_sheet.sh <시트 이름> "<아래 인물 문장>"`으로 만들었다. 스크립트가 앞뒤에 공통 문장(3×2 격자, 수묵 담채 화풍, 인물마다 다른 포즈·배경, 글자 금지)을 붙이고 `tools/illustrations/style-samples/4-ink-wash.png`를 참조 이미지로 넘긴다. 칸마다 외형, 포즈, 배경을 적는다.

`A-shu.png`는 포즈와 배경을 지정하지 않은 첫 시도다(모두 같은 흉상, 같은 산 배경). 비교용으로 남겼다.
