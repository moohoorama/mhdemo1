# ver2 병종 8방향 애니메이션 제작 설계

## 목표

ver2 병종(경보병·황건 적병·창병·궁병·경기병·관우·장비)을 기사 v6와 같은 형식으로 만든다.
8방향 × 6동작(대기·걷기·공격·피격·탈진·막기) × 4프레임, 병종별 `{D}-pixel.png`(4열 × 5행)과 `frames.json`.
확인은 저장소 루트의 `ver2-units-preview.html`(병종·방향·동작별 뷰어).

## 원본

`temp/soldier-archer-cavalry-motion-v9.zip`의 `tools/`에 기사·궁병·기병 3D 모델 생성 코드가 있다.
타원체·원기둥·상자 폴리곤으로 만든 관절 모델이며 동작별 4포즈가 정의되어 있다.
`base_model.py`는 원본 그대로 보관하고, 병종·자세 정의는 `units.py`, 공격은 `attacks.py`에 둔다.

## 파일

| 파일 | 역할 |
|---|---|
| `build.py` | 진입점. 병종 목록·재생 시간, 렌더 → 머리 → 이펙트 합성, 칸 자르기, 시트·`frames.json`·`factions.json` 출력 |
| `units.py` | 병종 장비(`KITS`)·무기·말, 동작별 자세 |
| `attacks.py` | 공격 키프레임·경유 자세·이펙트 형상, 병종별 선택 `SELECTED`(나머지는 백업) |
| `heads.py` | 손그림 머리 격자, 영웅 머리 파생(수염), 표정, 진영색 머리 픽셀 |
| `render.py` | 카툰 렌더러, 재질 → 팔레트 램프, 추가 색 `EXTRA` |
| `effects.py` | 반투명 이펙트 레이어 |
| `factions.py` | 진영 색조·채도·밝기 → 치환 램프 |
| `base_model.py` | 원본 3D 모델 (수정하지 않음) |
| `attack_candidates.py` | 공격 후보 비교 이미지 |
| `looks.py` | ver4 신규 병종·장수 외형 후보(장비·머리 조합)와 선택 `SELECTED`; `build.UNITS`에 고른 것이 추가된다 |
| `look_candidates.py` | 외형 후보 비교 이미지 (좌하단 대기·공격 순간) |
| `blocks.py` | 막기 동작: 무기 계열별 4안(막아서기·쳐내기·비켜 피하기·물러서기)과 선택 `SELECTED`; `build.py`가 6번째 행으로 그린다 |
| `block_candidates.py` | 막기 후보 비교 이미지 |
| `civilian.py` | 장면용 평복 외형 후보·선택과 장면 동작(말하기·포권·건배·놀람·끄덕임) |
| `civilian_candidates.py`, `civilian_build.py` | 평복 후보 비교, 전체 생성(`ver4-civilians/`) |
| `structures.py` | ver4 맵 구조물: 마을 초가집 묶음, 성벽(성가퀴·벽면 16변형), 성내 돌바닥 → `ver4-structures/` |
| `candidates_2d.py` | 초기 2D 후보 생성기 (보관) |

기준은 [`UNIT_ART_GUIDE.md`](../spritetool/assets/UNIT_ART_GUIDE.md), 작업 절차는 `.claude/skills/unit-sprite`.

## 방식

모든 병종을 같은 3D 카툰 렌더러로 만들고 머리만 2D 도트를 찍는다.
기사 v6 프레임에서 머리를 바꾸는 방식은 시험했으나, 머리 영역 삭제가 몸·칼을 자르고
(E 일자 잘림, 목·등 어색함) 공격·피격·탈진에서 머리 추적이 불가능하며 궁병을 만들 수 없어 폐기했다.

1. **모델** `units.py`: 머리 없는 병사 + 병종 장비. 머리 중심 좌표·표정·이펙트 형상을 함께 반환한다.

   | 병종 | 옷·장비 | 머리 | 공격 |
   |---|---|---|---|
   | 경보병 | 청색 상의, 칼, 원형 방패 | 철투구 | 횡베기 |
   | 황건 적병 | 삼베 옷, 황색 띠, 칼, 원형 방패 | 상투 + 황건 | 내려베기 |
   | 창병 | 청색 상의, 창 | 원뿔 투구 | 찌르기 |
   | 궁병 | 청색 상의, 활·화살·화살통 | 청색 두건 | 강궁 |
   | 경기병 | 원본 기병, 창, 밤색 말 | 철투구 | 돌진 찌르기 |
   | 관우 | 녹포, 청룡언월도, 적토마 (기마) | 녹건, 붉은 얼굴, 긴 수염 | 언월도 횡베기 |
   | 장비 | 진영색 옷·붉은 띠, 검은 철갑, 장팔사모, 흑마 | 검은 투구, 거뭇한 얼굴, 덥수룩한 갈색 수염 | 휘두르기 (기마) |

   창대·활은 48px에서 사라지지 않도록 굵게 과장한다. 오목한 날(언월도, 장팔사모)은 볼록 사각형 띠로 나눠 그린다.
2. **공격** `attacks.py`: 1·2프레임에 힘을 모으고(젖히기·웅크리기·당기기), 3프레임에 터뜨리고, 4프레임에 마무리한다.
   병종별 선택은 `SELECTED`, 나머지 후보(올려베기·내려찍기·도약 찌르기·낮게 쏘기·하늘로 쏘기·속사 등)는
   백업으로 정의를 남긴다. 비교는 `attack_candidates.py` → `output/ver2-attack-candidates.*`.
   휘두르기 궤적은 경유 자세(`via`)를 따라가고 칼날보다 30%(장병기 10%) 넓게 과장한다.
3. **이펙트** `effects.py`: 반투명 레이어(몸 뒤 under, 앞 over). 픽셀은 또렷하게 두고 띠마다 고정 알파를 쓴다.
   휘두르기 트레일, 찌르기의 쐐기·충격 고리·속도선, 화살 꼬리·속도선. 몸 도트는 알파 0/255.
4. **렌더** `render.py`: 목표 해상도로 직접 렌더한다.
   - 정사영, 고도각 0.48rad, 방위각 8개(원본 뷰어와 동일).
   - 4배 슈퍼샘플 z-버퍼 → 블록 최빈 (재질, 명암 단계)로 축소. 재질별 4단 팔레트 램프로 바로 대응한다.
     팔레트는 기사 v6 28색 + 삼베 3색 + 녹색 4색 + 붉은 피부 3색.
   - 카툰 명암: 화면 기준 왼쪽 위 빛 하나, 그림자·기본·밝은 면·반사광 4단의 경계 있는 명암,
     빛 공간 깊이 지도로 드리운 그림자(기수 아래 말 등, 머리 아래 등).
   - 선: 실루엣 바깥 1px, 가려지는 경계의 뒤쪽 1px. 모든 부위에 같은 규칙.
5. **머리** `heads.py`: 방향별 손그림 머리(S·SW·W·NW·N, SE·E·NE는 반전)를
   투영한 머리 중심에 찍는다. 원뿔 투구·관우·장비 머리는 기존 머리에서 색 치환과 수염 추가로 만든다.
   상황별 표정: 피격 3·4프레임은 눈을 질끈 감고 입을 벌리고, 탈진은 눈꺼풀이 반쯤 내려오고 입을 벌리며 땀방울이 맺힌다.
6. **연출**: 대기 중 기병은 기수 호흡·말 고개 끄덕임·꼬리·몸통 호흡이 있다.
   피격은 자세만 만든다: 3프레임째 상체가 뒤로 휘청이고 팔이 늘어지며, 4프레임째 회복한다.
   번쩍임·색 입히기·파티클은 런타임 특수효과로 처리한다.
   재생 시간: 대기 180, 걷기 120, 공격 180·280·240·200(힘 모은 상태와 타격을 길게), 피격 120, 탈진 220 ms.
7. **칸 크기와 검사**: 넓은 작업 캔버스에 모든 프레임을 그린 뒤, 병종마다 전 프레임의 합집합 범위 + 1px로
   잘라 칸 크기와 기준점을 정한다(`frames.json`의 `cell`, `pivot`). 방향마다 대기 첫 프레임의 최하단을
   기준점 행에 맞추고 같은 보정값을 그 방향 전체에 쓴다. 작업 캔버스 가장자리 비접촉, 대기 접지 행을 검사한다.

## 진영색

진영색 부위(상의·두건·허리 장식·안장·투구 술·황건 띠)는 전용 키 램프 `W X Y Z`(`factions.TEAM_KEYS`,
다른 재질에 쓰지 않는 청색 4단)로 그린다. 영웅의 상징색(관우 녹포, 장비 흑갑)은 고정한다.
진영은 색을 고르지 않고 OKLCH의 색조·채도 배율·밝기 보정 세 값으로 정의한다(`factions.py`).
흰색(공손찬)은 채도를 낮추고 밝기를 올리며, 곤색(동탁·여포)은 밝기를 내린다. 비슷한 색조의 진영은
색조를 조금씩 달리하고 고유 조형으로 구분한다. `build.py`가 `ver2-units/factions.json`(키색과
진영별 치환 램프)을 쓰고, 뷰어는 키색과 정확히 같은 픽셀만 바꿔 보여 준다. 게임에서는 같은 표로
Ebiten 셰이더에서 4색을 치환한다(게임 연결 단계에서 구현).

## 범위 밖
